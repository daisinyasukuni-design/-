# ランダムワード法（Random Word / Random Input）

## 概要

ランダムワード法は、**解きたい課題とは無関係にランダムで選んだ語**（多くは具体名詞）を刺激とし、その語の
**属性・機能・連想・比喩**を課題へ**強制的に結びつけ（force fit）**、使い慣れた思考の溝から外れた
アイデアの入口を作る発想技法。狙いは語を課題に直接つなぐことではなく、**無関係な入り口から脳を課題の周りで
動かす**こと。

- **核となる考え方（なぜ効くか）**: 脳は経験でできたパターン（溝）に沿って考えるため、行き詰まると同じ発想に
  戻る。ランダム語は連想ネットワークの**別の場所**から強制的にテーマへ再アプローチさせ、既存パターンを組み替える。
  de Bono はこれを、真偽（judgment）でなくアイデアを前へ動かす **movement（動き）** の価値と呼ぶ。
- **鉄則**: (1) 語は**本当にランダム**に選ぶ（課題に関係する語を選ぶと既存パターンの強化にしかならない）。
  (2)「関係ない」と却下しない——無関係さを埋める作業そのものが技法。(3) 評価は後回し（発散と収束を分ける）。
- **出自（諸説あり・年号は要確認）**: 提唱者は **Edward de Bono**（マルタ出身の心理学者、"lateral thinking" の
  提唱者）。本人が「最も単純な創造技法」と称したとされる。考案年は情報源で食い違い（1960年代／1967／1968 等）、
  体系的整理は *Lateral Thinking*(1970) や *Serious Creativity*(1992) に見られる。**年号・初出書籍は断定しない**
  （→出典・要確認）。近縁に provocation / po などの「パターンを壊す」ツール群がある。

## いつ使う / 使わない

**使う（適する状況）**
- 発想が**煮詰まった/マンネリ**で、毎回同じ案しか出てこないとき。刺激で強制的に横へ飛ばしたい。
- 新規事業・商品・企画・ネーミング・コピー等の**ネタ出しの起点**が欲しいとき（オープンな問い）。
- ブレストが手詰まりのときの**ウォームアップ/打開策**、グループシンク（同調）を崩したいとき。
- 個人〜小グループで、**手早く大量の種**を出したいとき（辞書やスマホですぐ始められる）。

**使わない / よくある誤用（アンチパターン）**
- **語を恣意的に選ぶ**——課題に関係しそうな語を選んでしまう最頻の失敗。既存パターンの強化にしかならず、
  ランダム性という効能の源泉を殺す。乱数生成器や辞書パラ開きで**選ぶ余地を無くす**。
- **「関係ないから」と却下して引き直す**——無関係な語を無理やりつなぐ作業こそが本体。引き直しは逃げ。
- **早すぎる判断でアイデアを潰す**——「実現不可能」と発散中に切ると movement が止まる。評価は必ず別工程へ。
- **抽象名詞を選ぶ**（faith, 幸福 等）——具体属性が出にくく連結が難しい。**具体名詞**（鼻・橋・魚・信号）が機能する。
- **最初の1連結で満足する**——量が肝で、大半は捨てる前提。1語あたり複数、語も複数試す。
- **これ一本で完結させる**——種を出すだけの発散ツール。収束・評価（PMI／ペイオフ）を後段に必ず置く。
- 分析・収束・最適化・真因究明・データ精査・実行フェーズには不向き。正解が定まった well-defined 問題にも向かない。

## 前提と限界

- **前提**: (1) 解く課題（focus）が1つに絞れていること——曖昧だと連想が発散して戻ってこない。
  (2) 参加者が**判断を保留**して無関係な連結に付き合えること——ここが崩れると「関係ないね」で終わる。
  (3) 出た種を後で選別する**収束工程**を用意できること。
- **限界（批判を踏まえて）**:
  - **実証が弱い**——lateral thinking 全般は「疑似科学的で、de Bono の中核主張は厳密に検証・実証されていない」と
    批判される。ランダム語の効果も、研究上は統計的に有意でも**ユニーク回答の差は小さい**との報告がある。
    「必ず良案が出る魔法」ではなく、パターンを外す**確率を上げる触媒**と捉える。
  - **低ヒット率が設計仕様**——大半の連結は使えない前提。数を出して初めて数個が実る。効率を求める場面には合わない。
  - **収束が別途必要**——種のままでは意思決定できない。放置すると「作って終わり」になる。
  - **集団運用の注意**——集団ブレストは名義集団（個人を後で合算）に生産性で劣り得る（発言の待ち・評価懸念）。
    人数が多いなら個人記入→共有（ブレインライティング的運用）と併せると取りこぼしが減る。
- これらは、**収束にPMI/ペイオフマトリクス、種の変形にSCAMPER、比喩の橋渡しにアナロジー/シネクティクスを併用**
  することで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **課題（focus）を1文で固定する。** 「何のアイデアが欲しいか」を具体化する（例: 「店舗の再来店を増やす施策」）。
   なぜ: 焦点が無いと連想が拡散し、課題へ戻せない。強制連結には帰る先が要る。
2. **ランダム語を1つ、本当に無作為に選ぶ。** 辞書をパラ開いて指さし、乱数生成器、「◯ページ◯番目の名詞」等の
   事前ルールで**選ぶ余地を消す**。**具体名詞**を優先（抽象語は避ける）。
   なぜ: 恣意選択は既存パターンを強化して効果を消す。ランダム性こそが別の入口を開く。
3. **語の属性・特徴・機能・比喩・反対を5〜6個書き出す。** 「何をする物か」「どんな構造・質感・連想か」を列挙する
   （簡単な絵を描くと連想が広がる）。
   なぜ: 語そのものでなく**属性**が連結の材料になる。属性を割ると接点が一気に増える。
4. **各属性を課題へ強制連結する（force fit）。** 「もし課題が“この属性”だとしたら？」と問い、無理やり橋を架けて
   アイデアの種を書き出す。far-fetched でも捨てない。
   なぜ: 無関係を強引につなぐ瞬間に、既存パターン外の発想が生まれる。ここが技法の核。
5. **時間を区切って量を出す。** 1語あたり5分など制限を設け、連結を数多く出す。判断はしない。
   なぜ: 適度な制約が脳を刺激し、量が質の母数になる。判断を混ぜると発散が止まる。
6. **語を替えて反復する。** 種が枯れたら別のランダム語で2〜4周回す。
   なぜ: 1語の連想は早晩尽きる。入口を変えると別方向の種が出る。
7. **収束工程で選別・洗練する（別フェーズ）。** 出た種を基準（インパクト×実現性など）で絞り、有望案を具体化する。
   なぜ: ランダムワード法は種出しまで。ここで止めると使えない。PMI／ペイオフ等へ渡す。

## 壁打ち質問リスト

各要素を埋めるために利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. 今回**アイデアが欲しい課題（focus）**を1文で言うと何ですか？（誰の・何を・どうしたい）
2. これまで**すでに出ている案**は何で、なぜ「同じ案ばかり／煮詰まった」と感じますか？（壊したいパターンの特定）
3. アイデアの**成否を分ける制約や評価基準**は何ですか？（後段の収束で使う——コスト/実現性/新規性など）
4. ランダム語は**どの手段でランダムに選び**ますか？（辞書パラ開き／乱数生成器／その場の物）——恣意選択を避ける段取り。
5. 選んだ語の**属性・機能・比喩**を、まず5〜6個挙げると何になりますか？（連結の材料を先に割る）
6. その属性を課題に無理やりつなぐと、**どんな突飛な連結**が浮かびますか？（「関係ない」で止めず1つ出してみる）
7. 今回は**発散だけ**でよいですか、それとも**収束（絞り込み）まで**必要ですか？（後段フレームの要否を確認）
8. 個人でやりますか、**複数人**ですか？（人数によりブレインライティング的な個人記入→共有を混ぜる）

## 出力フォーマット

ALWAYS この型（刺激→強制連結→種→収束の入口）で出力する。未評価の種を確定的な正解のように提示しない。

```
【設定】課題(focus): <1文> ／ 評価基準: <後段で使う軸> ／ 形式: <個人/複数・時間制限>

【ラウンド1】ランダム語: <具体名詞>（選定法: <辞書/乱数/その場>）
  属性:  - <属性1> / <属性2> / <属性3> / <属性4> / <属性5>
  強制連結 → 種:
    - <属性> × 課題 → <アイデアの種>
    - <属性> × 課題 → <アイデアの種>
    …（判断せず量を出す。far-fetchedも残す）

【ラウンド2】ランダム語: <別の具体名詞>
  属性 / 強制連結 → 種:（同上）

【種の一覧（未評価）】<全ラウンドの種を箇条書きで集約>
【収束の入口】<有望そうな種を数個・理由の芽。※本評価はPMI/ペイオフへ委ねる>
【次の一手】<深掘り or 別レンズへの接続の提案>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。「地域の書店の再来店を増やす施策」を発想する場面。

- **手順①focus**: 「一度来た客がまた来たくなる仕掛けを増やす」。評価基準=低コストで試せること。
- **手順②ランダム語**: 乱数生成器で **「灯台(lighthouse)」** を得る（課題と無関係＝狙いどおり）。
- **手順③属性**: 遠くから見える／光を回して知らせる／夜も働く／目印になる／孤立して立つ／船を導く。
- **手順④強制連結 → 種**:
  - 「遠くから見える」× 再来店 → 店内の一角を、外の通りから見える**灯り**にして「今夜の一冊」を掲示。
  - 「光を回して知らせる」× 再来店 → 新着・入荷を**定期の合図**（毎週決まった曜日の告知）で来店の理由を作る。
  - 「夜も働く」× 再来店 → 閉店後も楽しめる**夜間の持ち帰り仕掛け**（翌日取り置き予約など）。
  - 「船を導く」× 再来店 → 好みに合わせて次の一冊へ**導く**手書きの道しるべ（読書の順路）。
- **手順⑤量**: 5分で上記＋α。「関係ない」と切らず、突飛な連結も残す。
- **手順⑥反復**: 語を **「傘」** に替え、「畳む/広げる」「雨を防ぐ」から別方向の種を追加。
- **手順⑦収束（別工程）**: 出た種を「低コストで試せるか×効きそうか」で数個に絞り、PMI／ペイオフへ渡す。
- **未確認の前提**: どの種が実際に再来店に効くかは**未検証の仮説**。ここで正解扱いせず、後段で選別・検証する。

## 相性（組み合わせると効く）

- `scamper`: ランダム語で出た種に7動詞（代用/結合/応用…）を当て、種を具体的な打ち手へ**変形**する後工程。
- `pmi`: 出た種を Plus/Minus/Interesting で多面評価し、発散から**収束**へ橋渡し（同じ de Bono 系）。
- `payoff-matrix`: 種を「インパクト×実現性」で選別し、**どれを試すか**を決める収束ツール。
- `synectics`: 「異質を親しく／親しいを異質に」する比喩・アナロジーで、強制連結の**橋の架け方**を強化する近縁技法。
- `analogical-thinking`: ランダム語の構造を遠い分野から借りる視点転換。比喩の飛距離を伸ばす。
- `brainwriting-635`: 複数人時、個人記入→回覧に載せて集団ブレストの取りこぼし（発言待ち・同調）を減らす。
- `osborn-checklist`: 別系統の強制発想（9つの問い）。ランダム語と交互に回すと入口が増える。
- 揺さぶり枠として `reverse-assumption`（前提を反転させる別種の刺激）を挟むと、パターン破壊の角度が変わる。
