# クロスSWOT（TOWS Matrix）

## 概要

クロスSWOTは、SWOTで棚卸しした **強み(S)/弱み(W)/機会(O)/脅威(T)** を **内部×外部** で掛け合わせ、
**4類型の具体戦略**に変換するフレームワーク。原典名は **TOWS Matrix**。SWOTが「4つの独立したリスト」を
作るのに対し、クロスSWOTは**その次の一手**として、要素間の関係（マッチング）から戦略を導く。

|  | 機会(O)〔外部・追い風〕 | 脅威(T)〔外部・向かい風〕 |
|---|---|---|
| **強み(S)**〔内部〕 | **SO＝積極化**（強みで機会を最大化） | **ST＝差別化**（強みで脅威を最小化） |
| **弱み(W)**〔内部〕 | **WO＝改善**（弱み克服で機会を掴む） | **WT＝防衛/撤退**（最悪シナリオ回避） |

- **核となる考え方**: 4象限の棚卸しだけでは動けない。**外部要因と内部要因を最低1つずつ組み合わせて**
  初めて具体的な戦略オプションが立ち上がる。Weihrich の原典は「要素自体は新しくない。新しいのは**要素間の
  関係を体系的に特定し、それに基づいて戦略を立てること**」と述べる。
- **4戦略の意味**（原典の maxi/mini ラベル ／ 日本の実務慣用）:
  - **SO＝Maxi-Maxi＝積極化戦略**: 強みで機会を最大限掴む。方向性は「進出・拡大」。最大の狙い所。
  - **ST＝Maxi-Mini＝差別化戦略**: 強みで脅威を最小化。脅威を逆手に取り差別化に転換する。方向性は「防衛・差別化」。
  - **WO＝Mini-Maxi＝改善戦略（段階的施策）**: 弱みを克服し機会を逃さない。方向性は「強化」。
  - **WT＝Mini-Mini＝防衛/撤退戦略**: 弱み×脅威の最悪領域。守り・縮小・撤退で存続を守る。方向性は「回避」。
- **出自（要確認扱い）**: **Heinz Weihrich** が **1982年** に "The TOWS Matrix — A Tool for Situational
  Analysis"（*Long Range Planning* 15(2):54-66）で提示。「TOWS」= SWOT の逆並びは意図的で、**外部（T/O）を
  先に検討する順序**を強調するため（→出典・要確認項目参照）。

## いつ使う / 使わない

**使う（適する状況）**
- **SWOTは棚卸したが戦略に落ちていない**とき——クロスSWOTの本命用途（SWOT最頻の失敗を潰す工程）。
- 事業戦略・マーケ戦略・新規事業の**打ち手の方向性を決めたい**とき（進出/差別化/強化/撤退のどれを狙うか）。
- **強みをどの機会にぶつけるか**、**脅威にどう守るか**を具体的な選択肢に変えたいとき。
- 複数の戦略候補を並べ、**優先順位をつけて絞り込みたい**とき。

**使わない / よくある誤用（アンチパターン）**
- **「意図の表明」で止める**——最頻の失敗。「強みXで機会Yを活かす」は戦略ではない。各セルは**具体的な
  初動アクション・担当・期限**まで落として初めて戦略になる。
- **セルを孤立させて扱う**——4つのマスを個別に埋めて満足し、要素間のつながりを活かさない。
- **SOに偏りWTを軽視**——SOは魅力的なので集中しがちだが、WT（存続に関わるリスク）を無視すると足元を掬われる。
  逆にWTばかりで守りに入ると成長機会を逃す。
- **全戦略を同時追求**——資源が分散し何も達成できない。実現性×インパクトで絞る（→payoff-matrix）。
- **内部/外部の混同**——強み↔機会、弱み↔脅威の取り違え。各戦略に外部・内部を1つずつ含むかで検算する。
- **前工程のSWOTが雑**——入力が薄いと戦略も薄い（garbage in, garbage out）。先にSWOTを詰める。
- 精緻な定量最適化・因果分析や、優先順位が既に確定した実行フェーズには不向き。他フレームで補完する。

## 前提と限界

- **前提**: 目的・スコープが1つに定まっていること。そして**SWOTの4象限（少なくとも主要な数個ずつ）が
  埋まっている**こと。無ければ先に `swot` を回す（このスキルは薄いSWOTなら壁打ちで補強してから掛け合わせる）。
- **限界（批判を踏まえて）**:
  - **重みづけが組み込まれていない**——4セルは同じ視覚スペースだが重要度は等価でない。TOWS自身は「どの戦略が
    最重要か」を教えない。別途、優先順位づけ（インパクト×実現性）が要る。
  - **静的（単一時点のスナップショット）**——市場・競合・自社能力の変化に追随しない。四半期ごと、または外部環境が
    大きく変わったら見直す前提で使う。
  - **主観・バイアスに引きずられる**——1人や声の大きい人で作ると偏る。事実・データで裏を取り複数視点を入れる。
  - **入力依存**——SWOTの質を超えられない。強みが本当に優位か（→vrio）、外部が網羅的か（→pest/five-forces）を疑う。
- これらは、**優先順位づけを別途足す（payoff-matrix/decision-matrix）／防衛・撤退戦略を先回りで潰す（premortem）
  ／SOの過信を疑う（devils-advocate）／定期的に見直す**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **目的とスコープを1つに固定する。** 「このクロスSWOTで何を決めるか」（例: この事業を伸ばすか守るか、
   新製品を出すか）を明文化する。なぜ: 目的が無いと戦略候補が発散し、抽象論で終わる。
2. **SWOTの4象限を確定し、外部(O/T)を先に据える。** 各象限を重要順に主要な数個へ絞る。外部→内部の順で並べる。
   なぜ: 「TOWS」の順序思想。外部の土俵（機会・脅威）を先に固定すると、強み/弱みの意味と使いどころが定まる。
   材料が薄ければ pest（マクロ）／five-forces（業界構造）で補ってから持ち込む。
3. **各セルを掛け合わせて戦略オプションを出す。** 4セルを順に埋める。**必ず外部要因×内部要因を1つずつ**紐づける。
   - **SO（強み×機会）＝積極化**: 「どの強みで、どの機会を、どう最大化するか」。
   - **ST（強み×脅威）＝差別化**: 「どの強みで、どの脅威を、どうかわす/差別化に転換するか」。
   - **WO（弱み×機会）＝改善**: 「どの弱みを、どう克服して、どの機会を逃さないか」。
   - **WT（弱み×脅威）＝防衛/撤退**: 「どの弱みと脅威が重なる最悪シナリオを、どう回避/縮小/撤退するか」。
   なぜ: 掛け合わせて初めて具体的な選択肢が出る。1セルに複数案を出してよい。
4. **各戦略を「意図の表明」から「動ける施策」に落とす。** 各オプションに**初動アクション・担当・期限**を添える。
   なぜ: 「強みXで機会Yを活かす」は戦略ではない。最初の一歩・責任者・時間軸が無いと実行に繋がらない（最頻の失敗）。
5. **内部/外部の検算をする。** 各戦略に外部要因（O or T）と内部要因（S or W）が1つ以上含まれるか、混同が無いかを確認。
   なぜ: 片側だけの記述は「クロス」になっていない。混同（強み↔機会）はTOWS最大の技術的ミス。
6. **優先順位をつけて絞り込む。** 全戦略を並べ、インパクト×実現性（＋目的・資源との整合）で上位を選ぶ。
   なぜ: 全部を同時に追うと資源分散で何も進まない。TOWSは重みづけを内蔵しないので、ここで人が判断する。
7. **次の一手と見直し条件を決める。** 選んだ戦略から着手する1〜3個を確定し、いつ再検討するか（例: 四半期／外部環境の
   大変化時）も決める。なぜ: クロスSWOTは静的。放置すると陳腐化する。起点であってゴールではない。

## 壁打ち質問リスト

各セルを事実で埋め、戦略化するために利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. このクロスSWOTで**最終的に決めたいこと**は何ですか？（伸ばす/守る/強化する/撤退する、どの意思決定か）
2. SWOTの4象限のうち、**戦略に最も効く強み・弱み・機会・脅威**は各どれですか？（重要度で上位を数個ずつ）
3. **SO（積極化）**: どの強みを、どの機会にぶつければ最大の成果になりますか？その組み合わせが有効な根拠は？
4. **ST（差別化）**: 迫っている脅威に対し、どの強みで守れますか？その脅威を逆手に取って差別化できませんか？
5. **WO（改善）**: 機会を逃す原因になっている弱みはどれで、どこまで克服すれば機会を掴めますか？
6. **WT（防衛/撤退）**: 弱みと脅威が重なる最悪シナリオは何で、撤退・縮小・回避のどれで備えますか？
7. 出した戦略それぞれについて、**最初の一歩・担当・期限**は何ですか？（意図の表明で止めないため）
8. 実行できる数は限られます。**インパクトと実現性で見て、まず着手すべき戦略**はどれですか？
9. この戦略はいつ見直しますか？（外部環境のどんな変化があれば前提が崩れますか＝時間軸の確認）

## 出力フォーマット

ALWAYS この2段構えで出力する（マトリクス→絞り込み）。型を固定し、逸脱しない。

```
【前提】目的（決めたいこと）: <…> ／ 対象・スコープ: <…>
【SWOT要点（入力）】S: <上位> / W: <上位> / O: <上位> / T: <上位>

【クロスSWOT（4戦略）】各セルは「掛け合わせ → 施策（初動・担当・期限）」で書く
  SO 積極化(強み×機会):   <どの強み×どの機会> → <施策／初動・担当・期限>
  ST 差別化(強み×脅威):   <どの強み×どの脅威> → <施策／初動・担当・期限>
  WO 改善  (弱み×機会):   <どの弱み×どの機会> → <施策／初動・担当・期限>
  WT 防衛/撤退(弱み×脅威): <どの弱み×どの脅威> → <施策／初動・担当・期限>

【優先順位づけ】インパクト×実現性で上位を選ぶ
  1位: <戦略> — 理由（インパクト/実現性）
  2位: <戦略> — 理由
  （以下必要に応じて）

【次の一手】着手する1〜3個（具体アクション）
【見直し条件】いつ/どんな外部変化で再検討するか
【未確認の前提】事実確認が要る点（壁打ちで埋める）
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。地域の中小コーヒー焙煎店が、SWOTを棚卸し済みで
「拡大の打ち手を具体化したい」場面。SWOT要点は次のとおり（入力）。

- S: 自家焙煎の品質、常連客との関係、生活動線上の立地
- W: 資金力の限界、オンライン販路の弱さ、スタッフ数の制約
- O: 家庭用高品質豆への関心増、EC/サブスクの普及、作り手の物語への評価
- T: 大手チェーン/EC専業の低価格攻勢、生豆価格の変動、地域の人手不足

- **手順①目的**: 「拡大するなら、どの方向でどう動くか」を決める。スコープ=同店。
- **手順②外部先行**: O（家庭需要・EC普及・物語評価）とT（価格攻勢・原料変動・人手不足）を主要論点に固定。
- **手順③掛け合わせ（4戦略）**:
  - SO 積極化: 品質(S)×EC/サブスク普及(O) → 焙煎したての豆の定期便を立ち上げる。
  - ST 差別化: 品質・物語性(S)×低価格攻勢(T) → 安売り競争を避け、産地/焙煎の物語で高付加価値化。
  - WO 改善: EC販路の弱さ(W)×EC普及(O) → 自前構築せず外部ECモールで低コスト参入し、段階的に整える。
  - WT 防衛/撤退: 資金・人手の制約(W)×価格競争/人手不足(T) → 多店舗化を避け、主力商品と常連基盤に集中。
- **手順④動ける施策に落とす**: SO=「定期便を小ロットで試験提供／店主／来四半期まで」のように初動・担当・期限を付す。
- **手順⑤検算**: 各戦略が外部要因×内部要因を含むか確認（例: SOは品質=内部×EC普及=外部。混同なし）。
- **手順⑥優先順位**: インパクト×実現性で「SO 定期便（高インパクト・中実現性）」を1位、「ST 物語化」を2位に。
- **手順⑦次の一手と見直し**: 定期便を小さく試し継続率を検証。家庭需要が鈍化 or 原料が急騰したら前提を再検討。
- **未確認の前提**: 家庭需要の実規模、常連のEC移行意向——実データで裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `swot`: 前工程。4象限の棚卸し（S/W/O/T）がクロスSWOTの入力。薄ければ先にこちらを回す。
- `pest`: 機会・脅威（外部）をマクロ視点で網羅し、掛け合わせる素材の抜け漏れを防ぐ。
- `five-forces`: 脅威(T)を業界構造で掘り下げ、ST/WT戦略の精度を上げる。
- `vrio`: SO/STで使う「強み」が本当に持続的優位か（価値/希少/模倣困難/組織）を検証し、思い込みを弾く。
- `payoff-matrix`: 出した戦略群をインパクト×実現性で絞り込む（手順⑥の道具）。lensが決定系で相補。
- `decision-matrix`: 戦略候補を複数の評価軸で採点し、選択を透明化する。
- `ansoff`: SO（積極化）の成長方向を製品×市場の4象限でさらに具体化する。
- 揺さぶり枠として `premortem`（WT/防衛戦略の失敗要因を先回り）、`devils-advocate`（SOの過信・楽観を疑う）を
  添えると、守りの穴と攻めの前提が炙り出せる。
