## フェーズ別ツール逆引き表

| フェーズ | 目的 | 主なツール |
|---|---|---|
| Define | 問題と顧客要求を確定 | プロジェクト憲章 / VOC / CTQツリー / Kano / SIPOC / ステークホルダー分析 |
| Measure | 現状を数値化・測定系検証 | データ収集計画 / MSA・Gage R&R / 工程能力Cp,Cpk / チェックシート / ヒストグラム / パレート / ランチャート |
| Analyze | 真因Xを統計で実証 | 特性要因図 / なぜなぜ / パレート / 仮説検定(t,ANOVA,χ²) / 相関・回帰 / DOE / FMEA |
| Improve | 打ち手を設計・検証 | DOE / FMEA / ポカヨケ / パイロット・シミュレーション / Kaizen / 5S |
| Control | 改善を定着 | 管理図(SPC) / 管理計画 / SOP・作業標準 / ポカヨケ / 監査・レビュー |

> QC7つ道具（パレート/特性要因図/ヒストグラム/チェックシート/散布図/グラフ/管理図）は全フェーズの基礎。
> まずここで解けるかを見極め、統計的検定やDOEは真因が絞れないときの追加手段とする。

## 統計の中核: シグマ水準・DPMO・3.4という数字
- **シグマ水準(σ level)**: 工程平均から最も近い規格限界までに、標準偏差σが何個入るか。大きいほどばらつきに対し規格に余裕があり不良が出にくい。
- **DPMO(Defects Per Million Opportunities)**: 100万機会あたりの欠陥数。品質水準を機会ベースで揃えて比較する指標。
- **6σの目標=3.4 DPMO**: 「100万回に3.4回以下しか欠陥を出さない」水準。**長期の平均ドリフト(1.5σ)を織り込んだ実務値**。
- 参考の対応（1.5σシフト込み・概算）: 3σ ≈ 66,807 DPMO / 4σ ≈ 6,210 / 5σ ≈ 233 / 6σ ≈ 3.4。
  （※これらの換算値は標準的な早見表の概数。厳密値・前提は出典で確認。数値を断定引用しない。）

## 1.5シグマシフト（と、その論争）
- **考え方**: 短期的にばらつきが小さくても、長期には工程平均が平均±1.5σ 程度ドリフトする、という経験則的補正。
- これを入れると、純統計上ほぼゼロ（6σ短期で約0.002 ppm）の欠陥率が、実務目標の **3.4 DPMO** になる。
- **論争**: 1.5という値の根拠は恣意的との批判がある（統計家 Donald J. Wheeler は "goofy" と評したとされる）。
  → **3.4という数字を絶対視せず**、自組織のデータで工程能力を見るのが実務的。数値目標の目的化を避ける。

## 工程能力指数 Cp / Cpk
- **Cp**: 規格幅がばらつき(6σ幅)に対してどれだけ広いか＝**ばらつきの締まり具合**（中心のズレは見ない）。
- **Cpk**: Cpに**中心のズレ**（平均が規格中心からどれだけ外れているか）も加味した実力値。Cpk ≤ Cp。
- 使い方: Measureでベースラインを、Controlで改善後を算出し、**Before/Afterで能力向上を確認**する。
- 直感: Cpが高くてもCpkが低い＝ばらつきは小さいが狙いがズレている（平均を動かす対策が要る）。両方低い＝まずばらつきを締める。

## 測定システム分析(MSA / Gage R&R)
- **目的**: 観測されたばらつきのうち「本当の工程のばらつき」と「測定のばらつき」を切り分ける。
- **Gage R&R**: 繰返し性(Repeatability, 同一測定者・同一機器の再現)と再現性(Reproducibility, 測定者間の差)を評価。
- **なぜ最優先か**: 測定系が信用できないと、Analyzeで「ばらつきの真因」を追ったつもりが**測定誤差を追っていた**という誤診に陥る。Measureで必ず先に通す。

## 使う統計手法の当て方（早見）
- **2群の平均差を見たい**（例: 設定A vs B で膜厚が違うか） → t検定。
- **3群以上の平均差** → ANOVA（分散分析）。
- **カテゴリ変数の関連**（例: ラインと不良の有無） → カイ二乗検定。
- **連続変数どうしの関係**（例: 温度と膜厚） → 相関・回帰分析。
- **複数の要因(X)と交互作用を効率よく** → DOE(実験計画法)。少ない試行で効くXと最適条件を特定。
- **時間的な異常・特殊原因の検知** → 管理図(SPC)。
> 検定はあくまで「その差は偶然か、意味があるか」を判定する道具。**サンプルサイズと測定系の妥当性**が前提。ここが崩れると結論も崩れる。
