# RFM分析

## 概要

RFM分析は、既存顧客を **Recency（直近性＝最終購入からの経過）/ Frequency（購入頻度）/ Monetary（累計購入金額）**
の3指標でスコア化し、価値と反応可能性で**セグメント分け**する顧客分析フレームワーク。
「次に反応（購買）しやすいのは誰か」を過去の購買行動で近似し、限られた販促資源を誰に振り向けるかを決める。

| 指標 | 見るもの | スコアの向き |
|---|---|---|
| **R**ecency（直近性） | 最終購入からの経過日数 | 最近買った人ほど高得点（5） |
| **F**requency（頻度） | 期間内の購入回数 | 回数が多いほど高得点（5） |
| **M**onetary（金額） | 期間内の累計購入額 | 金額が大きいほど高得点（5） |

- **核となる考え方**: 各指標を通常5段階（五分位＝クインタイル）でスコア化し、`555`〜`111` の3桁コードにする（5×5×5=最大125セル）。
  実務では125を「優良／ロイヤル／新規優良／離反懸念／休眠…」等の**名前付きセグメント10前後**に束ね、施策に落とす。
  Recency（直近性）がダイレクトメールの反応率と強く相関するという経験則が土台で、売上の大半が一部顧客に偏る（パレート）前提とも整合する。
- **出自（諸説あり・要確認）**: 単一の考案者・年号は確定しがたい。
  (a) カタログ通販のダイレクトマーケターが顧客ごとの索引カードに最終購入・回数・累計額を記録し反応の良い層を選別した実務慣行に遡る。
  (b) **George Cullinan** が早くからRFMの活用を広めた人物としてしばしば挙げられるが、**その提唱年は「1961年」「1977年」等と資料間で食い違い、現状は一次資料で特定できない**（本スキルは年を断定しない）。
  (c) 学術的定式化として **Bult & Wansbeek (1995)「Optimal Selection for Direct Mail」**（Marketing Science 14(4):378-394）がよく引用される。
  (d) 五分位で各指標を5等分し `555`〜`111` の125セルにコード化する実務手法は、**Arthur M. Hughes『Strategic Database Marketing』（McGraw-Hill, 初版1994／以降改訂）の該当章**が具体的に提示している。本スキルの125セル方式はこの確認済み一次書誌に依拠する（＝誰が「最初に」考案したかとは切り離して扱う）。
  **起源は断定せず、多層的な経緯と不確実性を前提に扱う**（→出典・要確認）。

## いつ使う / 使わない

**使う（適する状況）**
- 購買履歴が溜まった**リピート型・多数顧客**の事業（小売・EC・通販・カタログ・DM・サブスクの一部）で、顧客を整理したいとき。
- 販促予算・メール配信・クーポンを**誰に集中させるか**、データで優先順位を決めたいとき。
- **優良顧客/VIPの発見**、**離反しそうな顧客の引き止め（ウィンバック）**、**休眠顧客の掘り起こし**の対象を絞りたいとき。
- CRM/顧客理解の**初手**として、まず既存顧客を価値と状態で俯瞰したいとき。

**使わない / よくある誤用（アンチパターン）**
- **スコアを出して終わり、打ち手に繋げない**——最頻の失敗。125コードや名前付きセグメントは手段であり、必ず**セグメント別の施策と優先順位**へ変換する。
- **一度作って放置**——Recencyは時間で必ず劣化する。静的スナップショットのまま使うと陳腐化する。定期再計算が前提。
- **「なぜ」を求めて使う**——RFMは「誰が優良/離反か」は示すが、その**理由（満足/不満・ニーズ）は示さない**。原因究明が主目的なら不向き（→JTBD・アンケートで補う）。
- **低頻度・高単価/少数大口に適用**——住宅・車などの一度きり購入や、少数大口のBtoBではFが機能せず五分位が割れない（Fが1に集中）。顧客数が少ない場合も五分位が無意味になる。
- **セグメント内を均質と誤認**——属性・商品カテゴリ・粗利・獲得コストを見ないため、同じセグメントに多様な顧客が混在する。画一施策に陥りやすい。
- **新規顧客の切り捨て**——履歴の浅い有望新規が低スコアに沈む。セグメント設計で救済しないと育成機会を逃す。

## 前提と限界

- **前提**: 顧客IDに紐づく**購買履歴データ**（誰が・いつ・いくら）が一定量あること。分析目的・集計期間・各指標の定義（Recencyの基準日など）を先に固定すること。
  リピートが起きる業態であること（Fが動く）。
- **限界（批判を踏まえて）**:
  - **過去志向で未来を保証しない**——過去実績の要約であり、将来価値の予測モデルではない。将来のLTV予測が要るならCLVモデル（BG/NBD等）を足す。
  - **3指標は独立でなく、Recencyに引っ張られやすい**——重み付けは恣意的になりがち。業態でF・Mの寄与は変わる。
  - **相対スコアの罠**——五分位は「相対順位」。全体が底上げ/悪化しても各人は必ずどこかの五分位に入り、絶対的な良し悪しは見えにくい。
  - **説明力の欠如**——分類はできるが、行動の背景・動機は説明しない。
- これらは、**セグメントを人物像に肉付け（persona）・STPのターゲティングに接続・JTBDで「なぜ」を補完・CLVで将来価値を推定**
  することで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **目的・期間・指標定義を先に固定する。** 何を決めるためのRFMか（例: 販促予算配分／休眠掘り起こし対象の抽出）を明文化し、集計期間・Recencyの基準日・F/Mの数え方を決める。
   なぜ: 定義が揺れると全顧客のスコアがぶれる。目的が無いとスコアを出して終わる最頻の失敗に直結する。
2. **顧客ごとにR/F/Mの生値を算出する。** R=最終購入からの日数、F=期間内購入回数、M=期間内累計金額（または平均単価）を集計する。
   なぜ: スコアの前に生値の分布を見ると、後の五分位が割れるか（特にFの偏り）を早期に判断できる。
3. **各指標を5段階にスコア化する。** 方式を選ぶ。
   - **独立ソート**: R・F・Mを各々独立に五分位化。実装が容易で一般的。セル人数は不均等になりうる。
   - **入れ子ソート**: Rで5分位→各R群内をFで5分位→各RF群内をMで5分位。各セルの人数が均等になり、施策のテスト・反応率比較に向く。
   Rは「最近ほど5」、F・Mは「多いほど5」。なぜ: 向きを揃えないと3桁コードの解釈が壊れる。
4. **3桁コードを作り、名前付きセグメントに束ねる。** 125セルは多すぎるので、事業に合わせて10前後のセグメント（優良/ロイヤル/新規優良/離反懸念/休眠 等）に集約する。
   なぜ: 125個に個別施策は打てない。束ね方（どのコード範囲をどのセグメントにするか）の設計がRFM実務の肝。
   束ね方の具体例（コード範囲→名称。境界の数値は事業・分布で調整する）:

   | 条件（R/F/M の各1〜5スコア） | セグメント名 | 状態の含意・向き |
   |---|---|---|
   | R∈{4,5} ∧ F∈{4,5} ∧ M∈{4,5} | 優良（Champions） | 最近・高頻度・高額。維持と拡大が最優先 |
   | R∈{4,5} ∧ F・M が中〜低（≤3） | 新規優良（見込ロイヤル） | 最近来たが実績は浅い。頻度を上げ育成 |
   | F∈{4,5} ∧ M∈{4,5} だが R∈{1,2} | 離反懸念（At Risk） | かつて高価値・最近来ない。引き止め |
   | R∈{1,2} ∧ F∈{1,2} ∧ M∈{1,2} | 休眠/離脱（Hibernating） | 全指標低下。抑制 or 限定的な掘り起こし |

   （名称は実務慣用で原典標準ではない。残るセルは事業に応じ「ロイヤル」「要注意」等へ追加配分する。）
5. **セグメントの規模と価値を確認する。** 各セグメントの人数・売上構成比を出し、どこに売上が偏っているか（パレート）を把握する。
   なぜ: 小さすぎるセグメントに個別施策は非効率。人数×期待効果で投資先を絞る。
6. **セグメント別の打ち手と優先順位を決める。** これがRFMを施策にする核。
   - **優良（R高F高M高）**: VIP優遇・早期アクセス・紹介依頼で維持・拡大。
   - **新規優良（R高・F/M中低）**: オンボーディングで2回目購入を促し、頻度を上げて定着させる。
   - **離反懸念（かつてF/M高・R低下）**: 個別の再訪促進・ウィンバックで引き止める。
   - **休眠/離脱（R・F・M低）**: 標準配信は抑制し、費用対効果の高い層に資源を回す（掘り起こしは限定的に）。
   なぜ: セグメントごとに最適な打ち手は逆向き（優遇 vs 抑制）。一律配信は資源の浪費になる。
7. **効果測定と再計算のサイクルを設計する。** 施策後にセグメント間の移行（例: 離反懸念→優良）を追い、一定周期でRFMを再計算する。
   なぜ: Recencyは時間で必ず変わる。RFMはゴールでなく回し続ける運用。ここで止めると「作って終わり」に陥る。

## 壁打ち質問リスト

各指標・セグメント設計を埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. このRFMで**最終的に決めたいこと**は何ですか？（販促予算の配分／ウィンバック対象の抽出／VIP選定 など、目的を1つに）
2. **顧客IDに紐づく購買履歴データ**はどれくらい溜まっていますか？（対象顧客数・期間・記録項目＝誰が・いつ・いくら）
3. あなたの事業は**リピートが起きる業態**ですか？ 典型的な**購入間隔・購入頻度**はどれくらいですか？（低頻度・高単価だとFが機能しにくい）
4. Recencyの**基準日**と、F・Mを数える**集計期間**はどう置きますか？（例: 直近1年、全期間）——ここで結果が変わります。
5. 各指標のスコアは何段階にしますか？（通常5段階）また**独立ソートと入れ子ソート**のどちらが目的に合いますか？
6. 125セルを**どんな名前付きセグメント**に束ねたいですか？ 事業上、特に見つけたいのは誰ですか（優良／離反しそう／休眠／育てたい新規）？
7. セグメントごとに打てる**施策の選択肢**（クーポン・メール・DM・電話・VIP優遇・配信停止 等）と、1件あたりのコストはどれくらいですか？
8. すでに分かっている顧客の傾向・仮説は何で、まだ**確認できていない前提**は何ですか？（推測と事実を分ける）

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。リピート購入のあるEC/通販事業が、限られた販促予算の配分先を決める場面。

- **手順①目的・定義**: 「次の四半期、販促予算をどのセグメントに集中するか」を決める。対象=購買履歴のある既存顧客、期間=直近1年、Rの基準日=分析日。
- **手順②生値**: 顧客ごとにR（最終購入からの日数）・F（1年の購入回数）・M（1年の累計額）を集計。Fの分布を見て、購入1回に偏っていないかを確認する（偏るとFの五分位が割れない）。
- **手順③スコア化**: 各指標を5段階に。ここでは独立ソートを採用し、Rは最近ほど5、F・Mは多いほど5とする。
- **手順④セグメント化**: 3桁コードを、優良（R高F高M高）／新規優良（R高・F低）／離反懸念（F高だがR低下）／休眠（R低F低M低）等に束ねる。
- **手順⑤規模と価値**: 各セグメントの人数と売上構成比を確認。売上が優良層に偏る（パレート）なら、その維持が最優先候補になる。
  以下は**架空・例示（実データではなく、手順→出力の埋め方を示す雛形）**の構成比:

  | セグメント | 人数比（例） | 売上構成比（例） |
  |---|---|---|
  | 優良 | 8% | 42% |
  | 新規優良 | 20% | 12% |
  | 離反懸念 | 12% | 22% |
  | 休眠/離脱 | 45% | 8% |
  | その他 | 15% | 16% |

  読み方（この架空例）: 優良8%が売上42%を握る＝パレートが立つ一方、離反懸念12%が売上22%を占め流出インパクトが大きい。人数×売上×施策コストで見て「離反懸念のウィンバック」が次の一手の有力候補、という判断が数値から追える。この表がそのまま【RFMセグメント（棚卸し）】の「規模/売上比」欄を埋める。
- **手順⑥施策化**:
  - 優良 → 紹介依頼・限定先行販売で維持と単価向上（安売りは不要）。
  - 新規優良 → 2回目購入クーポンとフォローで定着させ、頻度を上げる。
  - 離反懸念 → 「最近ご無沙汰です」の個別再訴求でウィンバック。ここは反応が戻れば費用対効果が高い。
  - 休眠 → 標準配信を絞り、掘り起こしは低コスト手段に限定。
- **手順⑦優先順位・測定**: 人数×期待効果×コストで、まず「離反懸念のウィンバック」を試す。施策後に離反懸念→優良への移行率を測る。
- **未確認の前提**: 適切な集計期間、購入間隔の実態、休眠の定義日数——ここは実データで裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `stp`: RFMは行動ベースのセグメンテーション。STPのターゲティング/ポジショニングにそのまま接続し、狙う層の打ち手を戦略化する。
- `persona`: RFMの各セグメント（優良/離反懸念 等）を具体的な人物像に肉付けし、施策のメッセージを設計しやすくする。
- `customer-journey`: 離反懸念や休眠が「どの体験段階で離れたか」を可視化し、RFMの状態変化に原因の当たりをつける。
- `decision-matrix`: どのセグメントに投資するかを、人数・期待効果・コストなどの評価軸で採点し優先順位を客観化する。
- `ppm-bcg`: 事業ポートフォリオの選別発想を顧客ポートフォリオに借り、維持/育成/抑制/撤退の資源配分を考える。
- `jtbd`: RFMは「誰が・いくら」を示すが「なぜ買う/離れる」を示さない。ジョブ理論でその空白を埋めると施策の精度が上がる（相補的な緊張関係）。
- 揺さぶり枠として `premortem`（ウィンバック施策が失敗する要因を先回り）や `devils-advocate`（「優良顧客」判定や休眠切り捨てへの過信を疑う）を添えると洞察が増す。
