# マーケティングミックス（4P）

## 概要

4P（マーケティングミックス）は、売り手が市場に価値を届けるために操作できる**戦術的な打ち手**を、
**Product（製品）/ Price（価格）/ Place（流通・チャネル）/ Promotion（販促・コミュニケーション）** の
4カテゴリに束ねて設計するフレームワーク。すべて P で始まる4語で覚える。

| P | 決めること | 主な変数（例） |
|---|---|---|
| **Product（製品）** | 何を提供するか | 機能・品質・デザイン・ブランド・パッケージ・保証・サービス・品揃え |
| **Price（価格）** | いくらで | 価格帯・値引き・支払条件・価格戦略（浸透/上澄み）・価格弾力性 |
| **Place（流通）** | どこで・どう届けるか | 販売チャネル・立地・在庫・物流・カバレッジ・オンライン/オフライン |
| **Promotion（販促）** | どう伝えるか | 広告・PR・人的販売・販売促進・SNS・コンテンツ・購買動線 |

- **核となる考え方**: 4つのPは**単独で最適化するものではなく、ターゲットとポジショニングに向けて一貫（整合）させる**ことで
  初めて顧客に価値が伝わる。整合性には2層ある——**内的整合性**（4P同士が矛盾せず相互補強するか）と
  **外的整合性**（市場・競合・顧客・自社資源に適合するか）。4Pは「戦略（STP）を戦術に翻訳する橋渡し」である。
- **出自（諸説あり・年号は要確認）**:
  - 上位概念「マーケティングミックス」は **Neil H. Borden**（ハーバード）が1940年代後半から用い、論文
    **"The Concept of the Marketing Mix"（1964頃）** で普及させた。着想は **James Culliton** の
    「マーケティング担当者は**材料の調合者（mixer of ingredients）**」という比喩（1948頃）とされる。
    Borden のミックスは製品計画・価格・ブランド・チャネル・人的販売・広告など約12要素だった。
  - これを4カテゴリ **Product/Price/Place/Promotion** に整理し「4P」として定式化したのは
    **E. Jerome McCarthy**、著書 **『Basic Marketing: A Managerial Approach』（初版1960とされる）**。
    以後、入門教科書の標準構造になった。**Philip Kotler** が実務・教育へ広く普及させた。
  - **起源・年号・書誌は断定せず**、複数説と不確実性を前提に扱う（→出典・要確認項目）。

## いつ使う / 使わない

**使う（適する状況）**
- STP（誰に・どんな価値で）を決めた後、**具体的な施策に落とし込む**実行設計フェーズ。
- 新商品・新サービスの**売り方を一枚に具体化**したいとき（何を・いくらで・どこで・どう伝えるか）。
- 既存のマーケ施策が**ちぐはぐ**に感じるとき、4P間の整合性を診断したいとき。
- **競合の打ち手を4Pに分解**して自社と比較し、差別化の余地を探るとき。
- 部署横断（開発・営業・販促）の施策を**共通の器に並べて全体像**を掴みたいとき。

**使わない / よくある誤用（アンチパターン）**
- **STP不在のまま4箱を埋める**——最頻の失敗。ターゲット/ポジショニングが無いと「誰にでも当てはまる=誰にも刺さらない」
  一般論になる。4Pの前にSTPを固定する（後述の手順①）。
- **売り手視点（inside-out）に偏る**——「自社が売りたいもの」起点で顧客の都合が抜ける。4Pへの不満から
  買い手視点の4Cが生まれた経緯がある。**4Cで各Pを検算**して視点を反転させる。
- **4P間の不整合**——担当者ごとに各Pを別々に決めると矛盾する。例）高級ポジションなのに「安売り訴求のマス広告」。
  高価格なら流通は選別（安売り店を外す）・販促は品質訴求、が整合する。整合性の点検が4Pの本体。
- **Promotion=広告 と矮小化**——販促は広告だけでない。PR・人的販売・販売促進・購買動線全体の設計を含む。
- **一度作って放置**——静的なため環境・競合変化に追随しない。定期的に見直す前提で使う。
- **無形サービス/デジタルに4Pだけで挑む**——サービスは People/Process/Physical evidence を足した**7Pで補完**する。

## 前提と限界

- **前提**: STP（セグメント・ターゲット・ポジショニング）が定まっていること。目的・対象顧客が曖昧な4Pは
  各Pの判断がぶれ、羅列に堕ちる。市場・競合・自社資源の基礎情報も要る。無ければ壁打ちで補うか、
  STP・3C・PEST を先に回す。
- **限界（批判を踏まえて）**:
  - **売り手視点（supply-side / inside-out）**——4Pは「自社が動かせる変数」の一覧であり、構造上、顧客の
    未充足ニーズや文脈を取りこぼしやすい。Lauterborn の4C はこの是正として提案された。
  - **サービス・体験・関係性に手薄**——無形性・同時性・変動性を扱いきれず、Booms & Bitner の7P
    （People/Process/Physical evidence）等での拡張が要る。
  - **静的・記述的**——時間軸や競合の反応、顧客の購買プロセスの動態を表現しない。
  - **要素の相互依存を一覧が隠す**——4箱に並べると独立に見えるが、実際は Price と Place と Promotion は
    強く連動する（安売り店で高級品は売れない）。一覧の見た目に騙されず整合を問い直す。
- これらの限界は、**4Cで買い手視点に反転する / サービスは7Pで補う / STP・ペルソナで顧客解像度を上げる /
  カスタマージャーニーで購買プロセスの動態を補う**ことで軽減できる（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。4Pは Product→Price→Place→Promotion の順で設計するのが一般的だが、
相互依存が強いので反復して調整する。

1. **STP（対象と価値）を先に固定する。** 「誰に（ターゲット）」「競合に対しどんな価値で（ポジショニング）」を明文化する。
   なぜ: これが無いと各Pの判断基準が無く、一般論の穴埋めに終わる（4P最頻の失敗）。未確定なら壁打ちで先に詰める。
2. **Product（製品）を設計/棚卸しする。** ターゲットのニーズに対し、機能・品質・デザイン・ブランド・付随サービスを定義する。
   製品はコア（顧客が本当に買う便益）／実体（機能・品質・デザイン・ブランドの形）／付随（保証・アフター・配送等の周辺）の3層で捉え、競合と横並びになりにくい層——多くはコア便益か付随サービス——を差別化点に定める（実体の機能競争は模倣されやすい）。
   なぜ: 価値の核はProduct。ここがポジショニングとずれると後続3Pが何をしても刺さらない。
3. **Price（価格）を設計/棚卸しする。** 価格帯・値引き・支払条件・価格戦略を、ポジションと顧客の支払意思に合わせて決める。
   浸透（低価格で一気にシェアを取る）か上澄み（高価格で利幅を先取り）かは、市場規模が大きく・価格弾力性が高く・競合の模倣が速いなら浸透、市場が小さく・弾力性が低く・特許やブランドで模倣を遅らせられるなら上澄み、で選び分ける。
   なぜ: 価格は「品質のシグナル」でもある。ポジション（高級/普及）と価格の方向を一致させる。
4. **Place（流通）を設計/棚卸しする。** どのチャネル・立地・オンライン/オフラインで、どう在庫・物流するかを決める。
   チャネルの広さは、最寄品で想起即購入なら開放的（できるだけ多くの店に置く）、専門品・高関与なら選択的（絞った優良店）、高級・独自性の保護が要るなら排他的（限定店・直営）、と製品特性とブランド保護度で選定する。
   なぜ: 「どこで買えるか」はブランド価値と一致させる（高級品を安売り店に置かない）。ターゲットの購買動線に合わせる。
5. **Promotion（販促）を設計/棚卸しする。** 広告・PR・人的販売・販促・SNS・コンテンツを、伝えるべき価値に沿って選ぶ。
   プッシュ（人的販売・流通業者向け販促でチャネルに押し込む）とプル（広告・ブランドで最終顧客の指名買いを喚起し流通を引き寄せる）の比重は、単価が高く説明が要る・流通の説得が鍵ならプッシュ寄り、購入頻度が高くブランド想起で選ばれるならプル寄り、で決める。
   なぜ: 販促=広告と矮小化しない。訴求メッセージはポジショニング（品質か価格か等）と一致させる。
6. **内的整合性を検算する。** 4つのPが同じ方向（ターゲット/ポジション）を指し、互いに矛盾せず補強し合うかを点検する。
   なぜ: これが4Pの本体。1つでも逆を向くと（高級なのに安売り広告など）顧客に違和感が伝わり価値が崩れる。
7. **外的整合性を検算する。** 市場・競合・自社資源に照らし、実行可能で差別化になっているかを確認する。
   なぜ: 内的に整っても、競合と同じ・自社の能力を超える打ち手は機能しない。競合の4Pと並べて差を見る。
8. **買い手視点で反転チェックし、次の一手に落とす。** 各Pを4C（Customer value（顧客価値）/Cost/Convenience/Communication）に置き換え、
   顧客都合で穴が無いかを見る。検証すべき仮説・意思決定・アクションを1〜3個決める。
   なぜ: 売り手視点の盲点を潰し、4Pを「作って終わり」でなく実行と検証に繋ぐ。

## 壁打ち質問リスト

各Pを事実で埋め、整合性を検算するために利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この4Pで**最終的に決めたいこと**は何ですか？（新商品の売り方／既存施策の立て直し／競合比較 など、目的を1つに）
2. **ターゲットは誰**で、競合に対して**どんな価値で選ばれる位置づけ（ポジショニング）**ですか？（STPが未確定ならここを先に）
3. **Product**: 顧客のどのニーズを、どんな機能・品質・ブランドで満たしますか？競合と何が違いますか？
4. **Price**: 価格帯と値引き・支払条件はどうしますか？その価格は、狙うポジション（高級/普及）と顧客の支払意思に合っていますか？
5. **Place**: 顧客はどこで・どう買いますか？そのチャネルは、製品の価値やブランドと矛盾しませんか？（例: 高級品を安売り店に置いていないか）
6. **Promotion**: 何を・誰に・どの手段（広告/PR/人的販売/SNS 等）で伝えますか？そのメッセージはポジショニングと一致していますか？
7. **整合性**: 4つのP同士で、互いに逆を向いている・ちぐはぐな組み合わせはありませんか？（内的整合性の点検）
8. すでにある事実・数字は何で、まだ**確認できていない前提**は何ですか？（推測と事実を分ける）

## 出力フォーマット

ALWAYS この2段構えで出力する（4P設計 → 整合性診断）。型を固定し、常にこの形で返す。

```
【前提】目的: <この4Pで決めたいこと> ／ ターゲット: <誰> ／ ポジショニング: <どんな価値で選ばれるか>

【4P（設計・棚卸し）】
  Product（製品）:   <機能/品質/ブランド/付随サービス — ポジションとの対応>
  Price（価格）:     <価格帯/値引き/支払条件/価格戦略 — なぜその水準か>
  Place（流通）:     <チャネル/立地/オンライン・オフライン/物流>
  Promotion（販促）: <広告/PR/人的販売/販促/メッセージ — 何を訴求するか>

【整合性診断】
  内的整合（4P同士）: <矛盾している組み合わせ／相互補強している組み合わせ>
  外的整合（市場・競合・自社）: <市場適合・競合との差別化・実行可能性>
  買い手視点(4C)での穴: <Customer value（顧客価値）/Cost/Convenience/Communication に置換した時の見落とし>

【次の一手】<検証すべき仮説・意思決定・アクションを1〜3個>
【未確認の前提】<事実確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。地域の中小コーヒー焙煎店が、
高品質豆を家庭向けにオンライン販売する新事業の売り方を設計する場面。

- **手順①STP**: ターゲット=自宅で本格コーヒーを淹れたい愛好層。ポジショニング=「作り手と産地の物語つき・焙煎したての高品質」。
- **手順②Product**: 少量・鮮度重視のスペシャルティ豆、焙煎日を明記、産地ストーリーの同梱、初心者向けの淹れ方ガイド。
- **手順③Price**: 量販品より高い価格帯（品質と鮮度のシグナル）。初回お試しと定期便割引で継続を促す。
- **手順④Place**: 自社ECと少数の相性の良い専門店。安売りモールでの大量流通は**あえて避ける**（ブランド毀損回避）。
- **手順⑤Promotion**: 価格訴求のマス広告でなく、SNSでの焙煎・産地コンテンツ、既存常連の口コミ、試飲イベント。
- **手順⑥内的整合**: 「高品質・物語（Product）」×「高価格（Price）」×「選別チャネル（Place）」×「品質訴求（Promotion）」が
  同じ方向を指す。もし「Place=安売りモール」や「Promotion=最安値訴求」を混ぜると即座に矛盾する——ここを弾く。
- **手順⑦外的整合**: 大手の低価格攻勢とは土俵を分け、鮮度・物語で差別化。自社の焙煎能力・小ロットの範囲で実行可能。
- **手順⑧買い手視点(4C)＋次の一手**: Customer value（顧客価値）=淹れる体験まで欲しい／Cost=送料込みの総額が割高に感じないか／
  Convenience=定期便の変更が簡単か／Communication=一方通行でなく質問に答える双方向か、を点検。
  次の一手=「定期便を小さく試し、継続率という仮説を検証」。
- **未確認の前提**: 家庭向け高品質豆の需要規模、送料込み総額への価格感度——実データで裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `stp`: 4Pの前提となるターゲット/ポジショニングを決める前工程。STP無しの4Pは羅列に堕ちるため事実上セット。
- `4c-marketing`: 4Pを買い手視点（Consumer/Cost/Convenience/Communication）に反転して検算し、売り手視点の盲点を潰す。
- `3c`: 市場・競合・自社の3視点で、4P設計の入力（特に競合の打ち手と自社資源）を精緻化する。
- `persona`: ターゲットを具体的な顧客像に落とし、各Pの判断基準を鮮明にする。
- `customer-journey`: Place と Promotion を「点」でなく購買プロセス全体の体験として設計し直す。
- `swot`: 4Pに入る前の現状整理（強み・弱み・機会・脅威）で、差別化の起点と制約を押さえる。
- 揺さぶり枠として `premortem`（この4Pが失敗するとしたら何が原因か先回り）や
  `devils-advocate`（「4Pは整合している」という思い込みを疑う）を添えると洞察が増す。
