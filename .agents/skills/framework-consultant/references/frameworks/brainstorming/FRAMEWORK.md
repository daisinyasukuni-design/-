# ブレインストーミング

## 概要

ブレインストーミングは、**判断を保留したまま自由連想でアイデアを大量に出す発散法**。核となる原理は
2つ——**「判断を保留する（defer judgment）」** と **「量が質を生む（quantity breeds quality）」**。
評価・批判・実現性の議論を後工程に切り離し、まず選択肢の幅を最大化することに徹する。

**オズボーンの4原則**（発散フェーズを支配するルール）:

| 原則 | 原典に近い表現 | 意味 |
|---|---|---|
| **批判をしない** | Criticism is ruled out | 否定・評価・「でも」はセッション中は禁止。判断は後回し。 |
| **自由奔放** | Freewheeling is welcomed | 突飛・非現実的な案ほど歓迎。荒削りな種が良案の元になる。 |
| **質より量** | Quantity is wanted | 数を稼ぐ。多く出すほど良案に当たる確率が上がる。 |
| **結合改善** | Combination and improvement | 他者の案に便乗し、組み合わせて発展させる（「1+1=3」）。 |

- **考案者・出自（要確認扱い）**: 広告会社BBDOの **Alex F. Osborn（アレックス・F・オズボーン）** が提唱。
  1939年頃から創造会議を実践し、著書『Your Creative Power』(1948) で手法を提示、
  『Applied Imagination』(1953) で用語を広めルールを定義したとされる（年号・書誌は出典・要確認参照）。
- **位置づけ**: 発散専用の道具。単独の万能手法ではなく、**発散→収束の前半**を担う。出した案は必ず
  評価・収束フレーム（投票、ペイオフマトリクス、PMI、KJ法）に渡して初めて意思決定に繋がる。

## いつ使う / 使わない

**使う（適する状況）**
- アイデアが**出ない・一つに固まって**視野が狭いとき、選択肢の**幅を一気に広げたい**とき。
- 企画・新規事業・課題解決の**初期（発散フェーズ）**で、まず候補を数多く並べたいとき。
- 会議で意見が広がらない、特定の人の案に流れる——**多様な切り口**を引き出したいとき。
- 心理的安全性を作り、**荒削りな案でも口に出せる場**をチームに作りたいとき。

**使わない / よくある誤用（アンチパターン）**
- **発散と収束を混ぜる**——最頻の失敗。出しながら批判・評価すると口が止まる。批判は必ず別フェーズへ。
- **集団の生産損失を無視して大人数で口頭のみ**——実証研究では対面集団は個人産出（名義集団）に量・質で
  劣ることが一貫して示される（→前提と限界）。人数が増えるほど生産妨害・評価懸念が効く。声の大きい人に
  引きずられる場では**書面式（ブレインライティング）や匿名（電子式）、一人ブレスト**に切り替える。
- **出して終わり（収束しない）**——大量の付箋を貼っただけで意思決定に繋げない。必ず収束フレームへ渡す。
- **テーマが漠然**——「何かいい案を」では発散しない。1つの具体的な問いに絞る。
- **精緻な分析・単一正解の探索・優先順位づけ**そのものには不向き。それは分析系/意思決定系フレームの仕事。

## 前提と限界

- **前提**: 発散すべき**具体的な問い（1つ）**が定まっていること。評価は後、という規律を全員が守れること。
  出た案を受け止める**収束の受け皿**（誰がどう選ぶか）が用意されていること。
- **限界（実証研究を踏まえて）**:
  - **集団ブレストは名義集団に劣りやすい**——Taylor, Berry & Block (1958) 以降、対面ブレスト集団は
    同人数の個人が別々に出して後で集約した「名義集団」より、量・質ともに劣るとの報告が一貫する。
    Diehl & Stroebe (1987) は22の実験を比較し、うち18で対面集団が名義集団に劣ったと報告した（数値は要確認）。
  - **生産損失の主因**:
    - **生産妨害（production blocking）**——一度に1人しか話せず、順番待ちの間に発想が抑制・忘却される。
      最大の要因とされる。**ブレインライティング/電子式で順番待ちを無くす**と緩和できる。
    - **評価懸念（evaluation apprehension）**——他者の目を気にして自由な発想を抑える。**匿名化**で緩和。
    - **フリーライド／社会的手抜き**——責任分散で手を抜く。**産出を個人に紐づける**と緩和。
    - **集団生産性の錯覚**——「集団の方がたくさん出せた」と過大評価し、劣る手法を好み続ける。
  - **協調的固着**——他者の案に引きずられ新規性が下がる。**先に個人で発散**してから共有すると効く。
- これらの限界は、**書面式（`brainwriting-635`）や一人発想への切り替え、刺激ツール（`scamper`/
  `osborn-checklist`）の併用、出力を必ず収束フレーム（`kj-method`/`payoff-matrix`）に渡す**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **問いを1つに絞って可視化する。** 「〇〇を増やす／減らす／実現する案を」の形で、具体的な発散テーマを1文にする。
   なぜ: 漠然としたテーマ（「何かいい案を」）は発散しない。焦点があるほど連想が走る。
2. **4原則とゴール（何個出すか・制限時間）を宣言する。** 「批判禁止・自由奔放・質より量・便乗歓迎」を明示し、
   例えば「20分で50案」といった量の目標を置く。なぜ: 原則の共有が心理的安全性を作り、数の目標が発散を駆動する。
3. **人数と形式を選ぶ（生産損失対策）。** 大人数・声の偏りが懸念されるなら、**まず各自が黙って書き出す**
   （ブレインライティング/一人ブレスト）→後で共有、の書面式にする。なぜ: 口頭のみの集団は生産妨害・評価懸念で
   個人産出に劣る。書面・匿名・個人先行がこれを打ち消す。
4. **発散する（評価を一切しない）。** 思いつくまま出し、否定語（「でも」「無理」）が出たら司会が止める。
   量が鈍ったら刺激を注入する（後述の質問リスト、`scamper`/`osborn-checklist`/`random-word`）。
   なぜ: 評価を混ぜた瞬間に口が止まる。刺激は停滞を破り、遠い連想を呼ぶ。
5. **便乗・結合を促す。** 他者の案に「乗っかると？」「2つ足すと？」「逆にすると？」と問い、派生を増やす。
   なぜ: 単発の案より、組み合わせ・改変の方が良案に化けやすい（結合改善＝1+1=3）。
6. **全て見えるように記録する。** 付箋・ホワイトボード・共同ドキュメントで全案を可視化し、重複も残す。
   なぜ: 可視化された既存案が次の連想の呼び水になる。消すと連鎖が切れる。
7. **発散を締めて収束フェーズへ渡す。** ここで初めて評価する。似た案をグルーピング（`kj-method`）し、
   効果×実現性で絞る（`payoff-matrix`）、または多面評価（`pmi`）。なぜ: ブレストはゴールでなく起点。
   収束に渡さなければ「出して終わり」の典型的失敗になる。

## 壁打ち質問リスト

各要素を埋め、発散を回すために利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この発散で**答えを出したい問いは1文で何**ですか？（「何を増やす/減らす/実現する案が欲しい」の形に）
2. これは**発散フェーズ**ですか、それとも**もう評価・絞り込み**の段階ですか？（評価段階なら収束系フレームへ切り替え）
3. **何人で・口頭か書面か**でやりますか？声の大きい人への偏りや、評価を気にして言い出しにくい空気はありますか？
   （懸念があれば一人ブレスト/ブレインライティング/匿名式に切り替える判断材料）
4. **今どんな案が既に出ていて**、どの方向に偏っていますか？（既出を踏まえ、まだ触れていない切り口を狙う）
5. **量の目標と制限時間**をどう置きますか？（例: 「◯分で◯個」。数の目標が発散を駆動する）
6. 発想が**行き詰まったときに使える刺激**——制約を外す・逆にする・別業界ならどうする、といった揺さぶりを入れてよいですか？
7. 出した案は**この後どう選び、誰が決めます**か？（収束の受け皿。ここが無いと「出して終わり」になる）
8. **絶対に外せない条件や制約**（予算・期限・技術・法規）はありますか？（発散は自由だが、後の収束で効く前提を把握）

## 出力フォーマット

ALWAYS この2段構えで出力する（発散→収束への橋渡し）。評価は収束の器に入るまで保留する。

```
【発散テーマ】<1文の問い> ／ 形式: <口頭/書面/一人・人数> ／ 目標: <個数・時間>

【発散（アイデア出し）】※批判せず量を出す。便乗・結合には「＋」で由来を示す
  - <案1>
  - <案2>
  - <案3（案1＋案2の結合）>
  … （重複可・荒削り可。数を稼ぐ）

【刺激で広げた案】※停滞時に制約外し/逆転/異業種アナロジー等で追加した案
  - <刺激: 逆にすると → 案>
  - <刺激: 別業界なら → 案>

【収束への橋渡し】※ここから評価フェーズ。ブレスト自体では結論を出さない
  グルーピング（KJ法）: <似た案の束の見出しを数個>
  次工程の提案: <payoff-matrix で効果×実現性に配置 / pmi で多面評価 / 投票 など>

【未確認の前提】<収束時に効く制約・条件で、事実確認が要る点>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。社内カフェテリアの**食品廃棄を減らす案**を出す場面。

- **手順①問い**: 「社員食堂の食品廃棄を減らす案を出す」に1文で固定。
- **手順②宣言**: 4原則を共有し、「15分でできるだけ多く」と量目標を置く。
- **手順③形式**: 参加者が多く遠慮が出そうなので、**最初の数分は各自が黙って書き出す**（ブレインライティング）→共有、の書面先行にする。
- **手順④発散（評価しない）**: 例として——「盛り付け量を選べるようにする」「売れ残りを夕方に割引」「事前予約で食数を読む」
  「余りを翌日のまかないに転用」など、実現性を問わず数を出す。
- **手順⑤便乗・結合**: 「予約」＋「割引」を結合→「予約が少ない日は自動で少なめ発注し、余れば割引」。
  「逆にすると？」→「作り置きをやめ、注文後に仕上げる」。
- **手順⑥可視化**: 全案を共同ボードに残し、重複も消さない。
- **手順⑦収束へ**: 似た案をKJ法で「需要予測」「メニュー設計」「余剰の再利用」に束ね、
  `payoff-matrix`（効果×実現性）に配置して次に検証する案を選ぶ——評価はここで初めて行う。
- **未確認の前提**: 廃棄の主因（作り過ぎか、食べ残しか）、予約制の受容度——収束時に事実で裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `brainwriting-635`: 発話の順番待ち（生産妨害）と評価懸念を、黙って紙で回す書面式で回避する直接の代替・補完。集団で口が止まるときの第一選択。
- `osborn-checklist` / `scamper`: 発散が停滞したときに「転用・応用・変更・拡大・縮小・逆転…」と強制的に切り口を注入する刺激ツール。
- `random-word`: 無関係な語を触媒に、遠い連想へジャンプさせて固着を破る。
- `mind-map`: 一人ブレストや個人の発散を放射状に広げ・記録する相棒（協調的固着を避ける個人先行に有効）。
- `kj-method`: 大量に出た案を親和性でグルーピングし、収束の入口を作る後工程（出力フォーマットの「収束への橋渡し」に対応）。
- `payoff-matrix` / `pmi`: 発散で得た候補を効果×実現性、またはPlus/Minus/Interestingで評価・選別する収束フレーム。
- 揺さぶり枠として `six-hats`（緑帽子で発散・黒帽子で批判、と役割を時間分離）、`reverse-assumption`（前提を反転して発想を飛ばす）、`premortem`（有力案の失敗要因を先回りして磨く）を添えると、発散の質と収束の妥当性が上がる。
