# シックスハット（6つの帽子思考法）

## 概要

シックスハットは、検討対象を **6色の帽子＝6つの思考モード**に切り替えながら、
**一度に一種類だけ**考えるフレームワーク。全員が同時に同じ色の帽子をかぶって同じ方向へ思考を向ける
**並行思考（parallel thinking）** が核で、「賛成派 対 反対派」で殴り合う従来の議論（adversarial argument）を、
「全員で順に全側面を見る」協調型に置き換える。

| 帽子 | 思考モード | 中身（何を出すか） |
|---|---|---|
| 白 White | 事実・情報 | 客観的な数字・データ・既知の情報／不足情報／入手先。**解釈・意見は出さない** |
| 赤 Red | 感情・直感 | 直感・勘・好き嫌い・不安。**理由や正当化は不要**。手短に吐き出す |
| 黒 Black | 慎重・批判 | リスク・弱点・実現困難・懸念。ただし**論理的な根拠を添える**（感情的否定ではない） |
| 黄 Yellow | 楽観・価値 | 利点・価値・実現可能性・良い面。**根拠のある前向き**（黒の対） |
| 緑 Green | 創造・発想 | 新しいアイデア・代替案・可能性。判断せず**発散**（水平思考） |
| 青 Blue | 進行・統制 | 思考プロセスの管理。目的・順序・時間を決め、要約・結論・次の一手を出す。**最初と最後にかぶる** |

- **核となる考え方**: 人は事実・感情・批判・希望・発想を同時にやろうとして混線し、対立する。
  帽子で思考を**分離**し、全員で1モードずつ揃えると、混線・エゴ・堂々巡りが減り、全側面を網羅できる。
- **出自（要確認扱い）**: 提唱者は **Edward de Bono（エドワード・デボノ、マルタ出身）**。
  書籍『Six Thinking Hats』は **1985年**刊とされる。帽子のメタファはより早く **1971年『Lateral Thinking for Management』**
  で言及されたと紹介されるが、初出年・書名は一次資料で未確証（→出典・要確認）。
  日本語では『6つの帽子思考法』（川本英明訳）として知られる。

## いつ使う / 使わない

**使う（適する状況）**
- 会議が**声の大きい人・特定の立場に偏る**、または**賛否が対立して膠着**しているとき（並行思考で全員を同じ土俵に）。
- 一つの案（企画・戦略・製品・意思決定）を**多角的に・抜け漏れなく**検討したいとき。
- **感情論と事実が混線**して議論が発散するとき（赤と白を分離する）。
- **ブレストが早すぎる批判で萎む**とき（緑で発散に集中し、批判は黒に後送りする）。
- **反対意見・懸念を角を立てずに全員から**引き出したいとき（黒帽子なら批判が「攻撃」でなく「役割」になる）。
- 短時間で**論点を一巡**させ、会議・レビューの型を作りたいとき。個人の思考整理にも使える。

**使わない / よくある誤用（アンチパターン）**
- **役割ごっこで終わる**——最頻の失敗。帽子をかぶるパフォーマンスだけで、出力が結論・意思決定に使われない。青で必ず統合し次の一手に落とす。
- **黒帽子の使いすぎ**——批判モードが支配し、緑（発想）・黄（利点）が育たない。de Bono自身が黒の過用を警告する。時間配分で黒を膨らませない。
- **青（進行）が権威的統制に堕す**——ファシリテーターが議論を誘導・支配すると並行思考が崩れる。青は「交通整理」であって「裁定者」ではない。
- **オンハット崩れ**——緑の最中に黒（批判）が割り込む等、モードが混ざる。混ざるなら「それは黒で扱います」と後送りする。
- **白帽子に意見を混ぜる**——「事実」と称して解釈・願望を持ち込む。数字と一次情報だけに絞り、意見は黄/黒/赤へ。
- **データが無いのに回す**——白帽子を埋める材料が皆無なら空回りする。先に情報収集するか、緑・赤中心に運用する。
- 単一の正解を計算する定量最適化・厳密な因果分析・一刻を争う即断には不向き。他フレームで補完する。

## 前提と限界

- **前提**: 検討テーマが1つに定まっていること（青帽子で焦点を絞る）。複数人で使うなら**心理的安全性**と、
  各人が「今は全員この帽子」という約束を守れること。文化・上下関係が強い場では赤帽子（感情表明）が抑圧され参加が偏るので、青が意識的に均等発言を促す。
- **限界（批判を踏まえて）**:
  - **認知の過度な単純化**——思考を6モードに機械的に割ると、統合的・微妙な判断を取りこぼす。gimmicky（お手軽な小道具）との批判がある。
  - **実証エビデンスの乏しさ**——効果を示す厳密な対照研究は限られ、支持は逸話的なものが中心。教育・創造性で効果を報告する研究もあるが限定的。**「必ず質が上がる」とは断定しない**。
  - **順序・時間配分が成果を左右する**——設計を誤ると（黒を最初に置く、緑に時間を割かない等）発想が死ぬ。テーマに応じてシーケンスを設計する必要がある。
  - **帽子の切替コスト**——短時間の即断には向かない。1色ごとに切り替える時間が要る。
- これらは、**青で必ず結論・次の一手に統合する / 黒の時間を抑え緑・黄を確保する / 発散は brainstorming・lateral-thinking、決め切りは pmi・decision-matrix に接続する**
  ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。標準は**青で始まり青で終わる**。

1. **【青】目的と焦点、順序・時間配分を決める。** 「この会で何を決める/生み出すか」を1つに固定し、使う帽子の順番と各色の持ち時間（目安1色3〜5分）を宣言する。
   なぜ: 焦点が無いと帽子ごっこに堕ちる。順序設計そのものが成果を左右するため、最初に設計する。
2. **【白】事実・情報を出し切る。** 既知の数字・データ・一次情報、そして「まだ分からないこと（不足情報と入手先）」を並べる。解釈・意見は禁止。
   なぜ: 土台となる事実と、感情・意見を最初に分離する。ここで推測を混ぜると以降が崩れる。
3. **【緑】アイデア・代替案を発散する。** 判断を保留し、新しい案・可能性・別の切り口を量で出す。
   なぜ: 早すぎる批判は発想を殺す。批判は後の黒に隔離し、ここでは広げることだけに集中する。
4. **【黄】各案の利点・価値・実現可能性を挙げる。** 「なぜうまくいくか」を**根拠付き**で。先に前向きな面を尽くす。
   なぜ: 黒（批判）を先に置くと有望案が芽のうちに潰れる。良い面を十分に見てから欠点を見る順が定石。
5. **【黒】リスク・弱点・懸念を挙げる。** 実現困難・落とし穴を**論理的な理由付き**で。感情的否定は赤に回す。
   なぜ: 批判を「役割」として全員で行うと、提案者を攻撃せずにリスクを洗える。ただし時間を割きすぎない（黒の過用を防ぐ）。
6. **【赤】直感・感情を短く表明する。** 好き/嫌い、乗り気/不安を**理由なしで**手短に共有する。
   なぜ: 隠れた感情は議論を裏で歪める。表に出して可視化することで、後の判断材料にできる。
7. **【緑（再）】黒で出た懸念を、緑で解消・改良する。** 弱点を潰す代替案・修正案を出す（必要な場合）。
   なぜ: 批判で終わらせず、懸念を改善に転換する。黒→緑の往復がアイデアを鍛える。
8. **【青】統合し、結論と次の一手を出す。** 各帽子の出力を要約し、決定・保留・追加調査を仕分け、アクションを1〜3個決める。
   なぜ: シックスハットはゴールでなく起点。ここで止めると「作って終わり」の典型に陥る。

> テーマで順序は変える。初期アイデア出しは「青→白→緑→青」、評価が主眼なら「青→白→黄→黒→…→青」。**始点と終点の青は固定**する。

## 壁打ち質問リスト

各帽子を中身で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この検討で**最終的に決めたい/生み出したいこと**は何ですか？（意思決定か、発想か、案の評価か——目的を1つに）
2. これは**1人での思考整理**ですか、**複数人の会議**ですか？（会議なら人数・立場と、対立や偏りが起きているかも）
3. 【白】いま手元にある**確かな事実・数字・データ**は何ですか？逆に、**まだ分かっていないこと**は何ですか？
4. 【緑】この件について、すでに出ている**案・選択肢**は何ですか？まだ試していない**別の切り口**はありそうですか？
5. 【黄】その案が**うまくいくとしたら、その理由・価値**は何ですか？誰がどう得をしますか？
6. 【黒】現実的に、**失敗するとしたらどこ**で、なぜですか？（論理的な懸念・リスク・制約を根拠付きで）
7. 【赤】理屈抜きで、この案に**乗り気ですか、不安ですか**？関係者の**本音の温度感**はどうですか？
8. 【青】今回、**どの帽子を重点的に**使いたいですか？（例: 発想を広げたい＝緑中心／決め切りたい＝黄・黒中心）そして最後は何を**アウトプット**にしますか？

## 出力フォーマット

ALWAYS この型で出力する（6帽子の一巡 → 青で統合）。使わない帽子は省いてよいが、**必ず青で始め青で締める**。

```
【青（設定）】目的: <この検討で決めたい/生み出したいこと> ／ 対象: <テーマ> ／ 進め方: <帽子の順序・重点>

【白 事実】     - <数字・データ・既知情報> …／未確認: <不足情報と入手先>
【緑 発想】     - <アイデア・代替案・別の切り口>（判断保留・量を出す）
【黄 利点】     - <各案の価値・実現性・良い面＋根拠>
【黒 リスク】   - <弱点・懸念・実現困難＋論理的な理由>
【赤 感情】     - <直感・好き嫌い・温度感（理由不要）>
【緑 改良】     - <黒の懸念を潰す修正案>（必要時）

【青（統合）】
  結論/方向性: <各帽子を踏まえた判断>
  次の一手:    <アクションを1〜3個（決定・保留・追加調査）>
  未確認の前提: <白で埋まらなかった、裏取りが要る点>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**社内向けチームが「週次定例会議を見直すか」を検討する**場面。1人の企画担当が壁打ちで整理する想定。

- **【青】設定**: 目的=「定例会議を今の形で続けるか、変えるか、やめるか」を決める。進め方=白→緑→黄→黒→赤→青。
- **【白】事実**: 参加人数・所要時間・開催頻度は既知。一方「会議後に実際に意思決定が何件生まれたか」は記録が無く**未確認**（＝入手先: 議事録の棚卸し）。
- **【緑】発想**: (a)現状維持、(b)時間短縮＋アジェンダ事前共有、(c)非同期（テキスト）報告に置換、(d)隔週化、(e)目的別に分割。
- **【黄】利点**: 非同期化は各自の時間を守り、記録が残る。時間短縮は負担減。分割は議題ごとに濃く議論できる。
- **【黒】リスク**: 非同期は雑談的な相談や暗黙の情報共有が失われうる。隔週化は緊急案件の遅延リスク。根拠として「今の会議で価値が出ている部分」を白で測れていない点が弱い。
- **【赤】感情**: 参加者の一部は「会議が多すぎる」と感じている一方、対面の安心感を好む声もある——温度感は割れている。
- **【緑（改良）】**: 黒の懸念に対し「非同期を基本にしつつ、月1で対面の相談枠を残す」ハイブリッド案を追加。
- **【青】統合**: 結論=「即断せず、まず1か月試す」。次の一手=(1)議事録を棚卸しし会議で生まれた意思決定件数を実測（白の穴埋め）、(2)ハイブリッド案を1か月トライアル、(3)参加者の赤（温度感）を匿名で再取得。未確認の前提=「会議の実際の意思決定価値」——ここは実データで裏取りしてから本決定する。

（ポイント: 帽子で分けたことで「感情の割れ」と「事実の欠落」が可視化され、いきなり廃止/存続を殴り合わず、検証プロセスに落ちた。）

## 相性（組み合わせると効く）

- `brainstorming`: 緑帽子の発散を本格的なブレストとして深掘りする。シックスハットは「批判を黒に隔離してブレストを守る」器になる。
- `lateral-thinking`: 緑帽子の中核をなす de Bono の別体系。前提を疑い横に飛ぶ発想で緑の質を上げる。
- `pmi`: 黄（Plus）・黒（Minus）を de Bono の PMI で構造化し、Interesting（面白い点）を足して評価を締める。相互に地続き。
- `premortem`: 黒帽子の懸念を「すでに失敗した前提」で深掘りし、リスクの洗い出しを徹底する。
- `devils-advocate`: 黒帽子をさらに強い反対役として運用する対照アプローチ。並行思考（協調）と対峙型のどちらが適するか選べる。
- `decision-matrix`: 6帽子で洗った論点を評価軸に落とし込み、複数案を採点して決め切る後工程。
- 揺さぶり枠として `reverse-assumption`（青で焦点を決める前に前提そのものを反転して問い直す）を添えると、検討の土俵自体を疑える。
