# 等価変換理論（Equivalent Transformation Theory）

## 概要

等価変換理論（ET理論）は、**「等価性の発見」を思考の中心に置き、既知の事例・自然現象から本質を抜き出して未知の課題へ移し替える**ことで、意図的にブレークスルーを起こそうとする発想技法。

- **核となる考え方**: 等価性とは「2つの事象が互いに異なっていても、**ある一定の観点をおいて見れば同じ事象として認定できる**」こと。
  創造の核心は「似ているものを同じと見なす」ことではなく、**一見まったく別の二つの物事の間に、ある観点のもとで共通の本質を見出す**ことにある。
  例: 葉脈と気管支は「枝分かれ構造」という観点で等価。落ちるリンゴと月の運動は「万有引力」という観点で等価。
- **右脳と左脳の掛け合わせ**: 偶然の閃き頼みにせず、「観点の設定→本質の抽出→再具体化」という**手順**で類推を制御する。ここが自由連想やブレストとの違い。
- **等価変換の骨格（記号は市川1966『Energy』3(4)〈中川TRIZページに全文再録〉に基づく。各記号と観点/本質/発想概念の対応の細部は要確認）**:

  | 記号 | 意味 |
  |---|---|
  | Aₒ（原系） | 既知の参照事例・モデル（自然現象・他分野の解・過去事例） |
  | ε（本質） | 観点のもとで Aₒ から抜き出した抽象的な核＝「欲求の中心」 |
  | c | 対象へ移すときに与える**限定条件** |
  | cε | 限定条件 c を本質 ε に与えた**発想概念（アイデアの核）** |
  | Σa / Σb | 原系で捨てる不要要素(Σa) / 対象領域で足す必要要素(Σb) |

  ※**観点そのものには記号を割り当てない**（本質 ε は観点のもとで抽出される思考の方向）。
  流れ: **既知 Aₒ →〔観点のもとで本質 ε を抽出・Σaを捨てる〕→ 発想概念 cε →〔対象へ再具体化・Σbを足す〕→ 新解 Bτ**。
- **出自**: 考案者は **市川亀久彌（1915年生・1938年京都大学工学部卒・元同志社大学教授）**。電気工学の「等価回路」を着想源に**1955年頃**確立し、**1966年10月『Energy』第3巻4号「創造的思考の方法論―主に等価変換理論について」（特集「人間と創造性」5–9頁）**で等価変換方程式を体系化した。
  ※しばしば混同されるが、**中山正和が考案したのはNM法**（類比発想の別技法）であり、ET理論の考案者ではない（→相性・要ファクトチェック）。
- **3つの表現アプローチ**: 原理図・構造図で考える**作画処理法**／言葉で考える**言語処理法**／数式・数理モデルで考える**数理処理法**。対象と思考者の得意で使い分ける。

## いつ使う / 使わない

**使う（適する状況）**
- 技術開発・新規事業・新機構で、**既存の延長では出ない飛躍（ブレークスルー）**が欲しいとき。
- **異分野・自然界の知見を自社のテーマに転用**したいとき（バイオミメティクス的な発想を含む）。
- 課題を**本質のレベルまで抽象化して捉え直し**、思い込みの解決像から抜けたいとき。
- 「思いつき」でなく、**再現性のある手順**でアイデアを出したい／出させたいとき。
- 良い**アナロジー（借用元）を見つけたが、それを具体案にどう落とすか**で詰まっているとき。

**使わない / よくある誤用（アンチパターン）**
- **表層アナロジーのこじつけ**——最頻の失敗。形や言葉が似ているだけで結び、観点＝本質の抽出が甘いと、既存解の焼き直しやムリな比喩に終わる。「何の観点で等価なのか」を必ず言語化する。
- **観点を1つに絞らず総花的に借りる**——借用元の性質を丸ごと持ち込むと、対象領域の制約(Σb)で破綻する。**Σa（捨てる要素）を明示**しないと変換にならない。
- **検証（手順8）を飛ばす**——借りた構造が対象で成立するとは限らない。机上の等価で止めると空論になる。
- **記号・数式の形だけ真似る**——ε/cε/Σ の形式をなぞっても、観点と本質の中身が伴わなければ意味がない。形式は思考の補助であって目的ではない。
- **答えが分析・計算で一意に決まる問題**や、**打ち手が既に定まった実行フェーズ**、純粋な優先順位づけ・意思決定には不向き。発散・着想の技法である。

## 前提と限界

- **前提**: 「何を実現したいか（解決目標）」が1つに定まっていること。目標が曖昧だと観点が選べず、借用が発散する。
  借用元(Aₒ)の引き出し——他分野の事例・自然現象・過去の発明——の**手持ちの広さ**が発想の質を左右する（乏しければ壁打ちや調査で補う）。
- **限界（属人性・熟練依存）**:
  - **観点の善し悪しに成否が強く依存する**。凡庸な観点からは凡庸な等価物しか出ない。良い観点の発見自体が熟練を要し、属人的になりやすい。
  - **研究会・指導を前提に発達した経緯**があり、独学では形式（記号体系）だけ真似て中身が伴わない罠がある。
  - **公開ツールの整備がTRIZほど進んでいない**（TRIZの40原理・矛盾マトリクスのような逆引きDBが乏しく、日本語圏中心）。汎用の「観点辞書」に当たるものは限定的。
  - **実装可否は別問題**——等価が成立して見えても、対象領域の物理・コスト・規制（Σb）で成り立たないことがある。工学的・事業的な検証は別途要る。
- これらは、**借用元を体系的に探すならTRIZやアナロジー思考を併用／こじつけ検出に悪魔の代弁者を添える／本質抽出をSo What?・なぜなぜで補強**することで緩和できる（→相性）。

## 進め方（手順）

命令形で示す。市川の8段階（課題抽出→…→検証）を、本スキルでは7手順＋観点を変えた再周回（任意）に再構成した。各ステップの「なぜ」を添える。

1. **課題を抽出し、解決目標を1つに定義する。** 「本当は何を実現したいのか」を、現状の解決像を外して書く（例: 「配管を太くしたい」ではなく「熱をむらなく運び去りたい」）。
   なぜ: 目標が既存の解に縛られていると、そもそも飛躍が起きない。目的語のレベルを上げる。
2. **観点を設定する——切り口を複数出し、2軸で仮採点して1つに絞る。** 目標を「どの切り口で見るか」の候補を、まず定番リストから3個以上に広げる。
   - **切り口リスト（観点のたたき台）**: 構造（かたち・つながり）／機能（何をする働きか）／流れ（何がどこへ移動するか）／エネルギー（力・熱・変換）／情報（信号の伝達・制御）／時間（順序・タイミング・周期）。解決目標の動詞に最も効く切り口から当てる。
   - **各候補を2軸で仮採点（○/△/×）**: ①**目標への効き**＝その観点で見ると解決目標の勘どころを突けるか。②**借用元の見つけやすさ**＝その観点で「すでにうまくやっている」既知系(Aₒ)を思い浮かべやすいか。①②とも○の候補を最優先。①○×②△なら壁打ち・調査で借用元を補う前提で採用可。①が△以下は捨てる。
   - 最終的に観点を1つに絞り、なぜその切り口かを一言添える（有力候補が複数なら、観点ごとに手順3以降を別々に回す）。
   なぜ: 等価性は観点があって初めて成立し、観点が本質(ε)の抽出軸になる。ここがET理論の心臓部かつ最も属人的な工程——切り口の型と2軸採点で「凡庸な観点への固着」を外すのが要。
3. **その観点で成り立つ既知の事例(Aₒ)を探す。** 自然現象・他分野の技術・過去の発明から、同じ観点で「うまくやっている」ものを挙げる（活用ヒントの特定）。
   なぜ: 借用元が発想の原資。遠い分野ほど飛躍が大きい。1つに決め打ちせず複数出す。
4. **本質(ε)を抽出する（Σaを捨てる）。** Aₒから「観点のもとで効いている核」だけを取り出し、その事例固有の枝葉(Σa)を捨てて言語化する。
   なぜ: 借用元を丸ごと持ち込むと破綻する。抽象化して核だけ残すのが「等価変換」の変換たるゆえん。
5. **限定条件を与えて発想概念(cε)を確立する。** 抽出した本質に、解決目標側の条件を重ねて「この課題での核はこうなる」という概念に固める。
   なぜ: 抽象のままでは手が動かない。本質と対象を接続して初めてアイデアの核になる。
6. **対象領域へ再具体化する（Σbを足す）。** 発想概念を、対象領域で必要な新要素(Σb)を加えて具体的な機構・仕組み・施策(Bτ)に落とす。1案でなく複数変換する。
   なぜ: 同じ本質から複数の具体案が生まれる。ここで発散させると選択肢が広がる。
7. **具体案を検証する。** 借りた構造が対象領域の物理・コスト・制約で本当に成立するかを問い、成立しないものを外す／条件を足す。
   なぜ: 机上の等価は空論になりうる。検証を省くとこじつけが残る。ET理論が明示的に置く最終段階。
8. **観点を変えて再周回する（任意）。** 案が弱ければ手順2に戻り、別の観点や別の借用元(Aₒ)で回す。
   なぜ: 最初の観点が最良とは限らない。観点を変えると等価物が総入れ替わりし、新しい系統の案が出る。

## 壁打ち質問リスト

各要素（目標・観点・借用元・本質・具体化・検証）を埋めるための問い。空欄は勝手に埋めず、まずこれで引き出す。

1. いま解決したい課題は何ですか？ そして**既存の解決像を一旦外すと、本当に実現したいことは何**ですか？（「◯◯を大きく/速くしたい」ではなく、その先の目的語で）
2. その目標を**どの切り口（観点）で見ますか**？（構造・機能・流れ・力/エネルギー・情報・時間など）候補を2〜3個挙げるとどれですか？
3. その観点で「**すでにうまくやっている**」ものを、**自然界・他業界・過去の発明**から思い浮かびますか？（遠い分野ほど歓迎）
4. その借用元で**効いている核（本質）は何**ですか？ 逆に、その事例に**固有で今回は要らない部分（捨てる要素）**は何ですか？
5. 抽出した本質を、今回の課題に重ねると「**この課題での勘どころ**」はどう言い換えられますか？
6. それを具体的な機構・仕組み・施策にすると、**対象領域で新たに足すべき要素**は何ですか？ 案は複数出せますか？
7. その具体案は、対象領域の**物理・コスト・規制・運用**の制約で本当に成り立ちそうですか？ 破綻しそうな点はどこですか？
8. いまの案が弱いなら、**別の観点／別の借用元**で見直すとしたら、どの切り口を試したいですか？
9. これは「観点による等価」ですか、それとも「**見た目が似ているだけのこじつけ**」ですか？——何の観点で等価だと言えますか？

## 出力フォーマット

ALWAYS この2段構えで出力する（等価変換シート→具体案と検証）。命令形テンプレを固定して使う。

```
【等価変換シート】
  解決目標:     <既存の解決像を外した、実現したいこと>
  観点:         <どの切り口で見るか（1つに絞る／複数試すなら列挙）>
  借用元(Aₒ):   <同じ観点でうまくやっている既知の事例・自然現象・他分野の解>
  本質(ε):      <観点のもとで効いている核＝抽出した本質>
    捨てる(Σa): <借用元に固有で今回は不要な部分>
    足す(Σb):   <対象領域で新たに要る要素>
  発想概念(cε): <本質 ε に解決目標側の限定条件 c を与えた「この課題での核」>

【具体案（Bτ）】※同じ本質から複数変換する
  案1: <本質を対象へ再具体化した機構・仕組み・施策>
  案2: <別解>
  案3: <別解>

【検証】各案が対象領域の物理/コスト/規制/運用で成立するか（○/条件付き/×＋理由）
【次の一手】<試作・実験・追加調査など、検証すべき仮説を1〜3個>
【別観点での再挑戦】<弱ければ試す別の観点や別の借用元(Aₒ)>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**発熱する電子機器の内部を、むらなく効率よく冷やしたい**という技術課題の場面。

- **手順①目標**: 既存像「ファンを大きくする／配管を太くする」を外し、真の目標を「**発熱部の隅々まで、むらなく熱を運び去る**」と定義する。
- **手順②観点**: 候補として「熱の流れ」「流体の分配構造」「表面積」を出し、**「末端まで均等に流体を届ける分配構造」**という観点を選ぶ。
- **手順③借用元(Aₒ)**: 同じ観点でうまくやっている既知の系を探す。**樹木の葉脈**や**生物の血管網**が、太い幹から細い末端まで枝分かれで隅々へ流体を届けている。
- **手順④本質(ε)抽出／Σa**: 効いている核は「**太→細へ段階的に枝分かれし、全域へ均等分配する分岐構造**」。葉緑体で光合成する・血液が酸素を運ぶといった生物固有の機能(Σa)は捨てる。
- **手順⑤発想概念**: 課題側に重ねると「**冷却流体を、枝分かれ流路で発熱面の全域へ均等に行き渡らせる**」が勘どころだと固める。
- **手順⑥再具体化(Bτ)／Σb**: 本質から複数変換する。案1=フラクタル状に分岐する冷却流路を刻んだ放熱板。案2=中心から放射状に分岐するヒートパイプ配置。案3=分岐ダクトで風を全域へ配る送風構造。足す要素(Σb)は流路の加工性・圧力損失対策など。
- **手順⑦検証**: 各案を対象の制約で吟味。分岐が細かすぎると圧力損失・目詰まりで破綻しうる→「条件付き○」。加工コストが合うか要確認。
- **次の一手**: 分岐段数と圧力損失のトレードオフを試作・実測で確かめる（机上の等価を実データで裏取り）。
- **別観点での再挑戦**: 弱ければ観点を「表面積」に替え、別の借用元（例: 腸絨毛の微細突起）で再周回する。

## 相性（組み合わせると効く）

- `analogical-thinking`: 遠い分野の構造を借りる思考一般。ET理論の観点・借用元(Aₒ)探しの上位レンズとして併走する。
- `nm-method`: 中山正和のNM法。キーワード→類比→アイデアの手順で借用元を量産する実務的な類比技法。ETの手順③を回す補助になる（別系統だが親和的）。
- `synectics`: ゴードンのシネクティクス。異分野をメタファーで借用する海外発の技法。ETの海外対応物として発想の幅を広げる。
- `triz`: 体系的発明技法。40原理・矛盾マトリクスで借用元・打ち手を体系的に探せる。ETの観点探しの弱点（属人性）を補完する同じ発明レンズ。
- `scamper`: 本質から得た発想概念(cε)を具体案(Bτ)へ落とす手順⑥で、代用・結合・逆転などの操作を当てて別解を増やす。
- 揺さぶり枠として `devils-advocate`（「それは観点による等価か、見た目のこじつけか」を疑わせる）や `reverse-assumption`（観点そのものを反転させ別系統の借用元を出す）を添えると、表層アナロジーの罠を弾ける。
