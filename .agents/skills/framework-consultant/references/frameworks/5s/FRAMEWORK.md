# 5S

## 概要

5Sは、職場を **整理(Seiri) / 整頓(Seiton) / 清掃(Seiso) / 清潔(Seiketsu) / 躾(Shitsuke)** の
5段階で継続的に整える、日本発の現場改善・職場管理の基本フレームワーク。頭文字がすべて「S」なので5S。
単なる掃除ではなく、**「探す・迷う・間違える・危ない」ムダを見える化して潰し、異常が一目で分かる職場をつくり、
それを守る習慣（人づくり）まで到達する**のが狙い。リーン生産方式・TPS・標準作業の土台に位置づけられる。

| S | 漢字 | 英語（定訳） | 核心 |
|---|---|---|---|
| Seiri | 整理 | Sort | 要る／要らないを分け、**要らないものを捨てる** |
| Seiton | 整頓 | Set in order | 必要物の置き場を決め**表示**し、誰でも即取り出せる状態に |
| Seiso | 清掃 | Shine | きれいにしつつ**点検**する（清掃点検で異常を発見） |
| Seiketsu | 清潔 | Standardize | 3S（整理・整頓・清掃）の状態を**維持する仕組み・標準**をつくる |
| Shitsuke | 躾 | Sustain | 決めたことを守る**習慣づけ**（言われなくてもやる） |

- **核となる考え方**: 順序に意味がある。整理（捨てる）→整頓（置き場と表示）→清掃（点検）で現場を整え、
  清潔（標準化）で「元に戻らない」状態を固定し、躾（習慣化）で自律的に回るようにする。前段が甘いと後段が崩れる。
- **整頓の要は「表示」と「3定」**: 定位（決めた場所）・定品（決めた物）・定量（決めた量）。置き場を決めるだけでなく、
  誰が見ても分かるラベル・区画・姿置き（shadow board）まで行って初めて整頓。
- **出自（諸説あり・断定回避）**: 戦後日本の製造現場で「整理・整頓」等が発展し、**トヨタ生産方式(TPS)の基盤の一つ**とされる。
  「5つのS」への体系化と世界普及は **Takashi Osada『The 5S's』(英語版1991)** と **Hiroyuki Hirano『5 Pillars of the
  Visual Workplace』(英語版1995)** に負う面が大きい。「大野耐一が考案／トヨタが1960年代に体系化」は二次資料の通説だが
  一次資料での確証が弱く、**人名・年の帰属は断定しない**（→出典・要確認項目参照）。

## いつ使う / 使わない

**使う（適する状況）**
- 工場・倉庫・店舗・病院・オフィスなど**物理的な現場が散らかり**、探すムダ・置き場の混乱・過剰在庫が起きているとき。
- **安全でミスの少ない職場**にしたい、ヒヤリハットや異常の見逃しを減らしたいとき。
- リーン／標準作業／VSM／カンバンなど**他の改善手法を入れる前の土台**を整えたいとき。
- **改善文化の第一歩**として、全員参加で「自分たちで職場を良くする」経験と習慣を作りたいとき。

**使わない / よくある誤用（アンチパターン）**
- **一度きりの「大掃除イベント」で終える**——最頻の失敗。clean-up day化し、日常業務に埋め込まないと数週間で元に戻る。
- **躾(Sustain)を軽視する**——5Sの中で最も難しく最も無視される段。監査・標準・リーダーの継続関与が無いと launch 後に劣化する。
- **「きれいにすること」が目的化（本末転倒）**——本来の狙いは探すムダ・在庫・**異常の見える化**・安全・効率、そして
  **人づくり（自律したマインド）**。見た目重視の"やらせ整頓"や、監査を通すためだけの飾りは効果を生まない。
- **トップダウンで押し付ける**——現場の入力なしに強制するとオーナーシップが育たず抵抗・形骸化する。置き場・3定・基準は**現場が主体で決める**。
- **整理を飛ばして整頓に走る**——不要物を残したまま並べ替えると、無駄な物の無駄な指定席を作るだけ。まず捨てる。
- **標準化・効果測定の欠如**——文書化した基準が無いとチーム間でばらつき逆戻り。効果を数値で示せないと予算削減で打ち切られる。
- 5S単独で**工程の再設計・ボトルネック解消・戦略課題**を解こうとする場面には不向き。土台づくりであって万能ではない（他フレームで補完）。

## 前提と限界

- **前提**: 対象の現場・エリアが特定されていること（「工場全体」より「この組立ライン」「この棚」等、範囲を切る）。
  全員参加とリーダー（管理職）の継続的コミットが要る。整頓の置き場や基準は現場作業者自身が決められる裁量があること。
- **限界（批判を踏まえて）**:
  - **持続が最大の壁**——多くの5Sは立ち上げは成功しても「維持（清潔・躾）」で崩れる。ある業界記事は失敗の大半が持続段階と
    するが、割合の数値は原典未確認のため断定しない（→要確認）。仕組み（監査・標準・見える化）で支えないと属人・根性論になる。
  - **手段の目的化**——整理整頓それ自体を評価対象にすると、改善でなく"きれいさ競争"に堕ち、現場が疲弊する。
    常に「これで何のムダ・危険・異常が減るか」に紐づけて運用する。
  - **知識労働・デジタル領域への過度な形式適用**——物理現場の比喩は有効だが、そのまま持ち込むと過剰なルール化で創造性を削ぐことがある。
    デジタル5S（フォルダ・データ整理）は目的を絞って軽く適用する。
- これらの限界は、**PDCAで回し続ける／VSMで工程全体のムダに接続する／ECRSで作業のムダを具体的に削る／清掃点検で見つけた
  異常を five-whys・fishbone で真因追究する**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。**前段が未達なら次に進まない**のが原則。

1. **対象エリアと目的を1つに絞り、着手前を記録する。** 範囲（例: この棚／この工程）と狙い（探す時間削減／安全／不良低減）を明文化し、
   ビフォー写真・現状の困りごとを残す。なぜ: 範囲を切らないと発散し、効果の前後比較もできない。
2. **整理: 要／不要を分け、不要を捨てる（赤札作戦）。** 判断に迷う物には理由と処分期限を書いた**赤札**を貼り、赤札置き場へ隔離。
   期限超過は原則処分。なぜ: 不要物を残すと後工程（整頓）で無駄な指定席を作る。捨てる決断がスペースと視界を生む。
3. **整頓: 置き場を決め、表示し、3定で固定する。** 定位（場所）・定品（物）・定量（量）を決め、ラベル・区画線・姿置きで
   誰でも一目で分かる状態に。使用頻度の高い物を手元へ。なぜ: 「表示」が無ければ整頓ではない。探す・迷う・間違えるムダを消す。
4. **清掃: 掃除と同時に点検する（清掃点検）。** 担当・頻度・手順を決め、掃除しながら設備・工具の異常（油漏れ・緩み・傷）を発見・記録する。
   なぜ: 5Sの清掃は「点検」。汚れの発生源を断ち、異常を早期に捕まえる。目標は「不慣れな人でも数秒で異常に気づける」状態。
5. **清潔: 3Sを維持する標準と見える化を作る。** チェックリスト・写真付き基準・責任分担・スケジュールを整備し、
   「あるべき状態」を掲示する。なぜ: ここで仕組み化しないと個人の頑張り任せになり逆戻りする。standardize=元に戻らない設計。
6. **躾: 習慣化し、定期監査で回す。** 毎日の「5Sタイム」や定期パトロール・点数化で定着させ、良い実践を横展開する。
   なぜ: 躾は最難関。監査とリーダーの関与を止めた瞬間に劣化する。ルールを守る文化＝人づくりがゴール。
7. **効果を測り、次の改善に接続する。** 探す時間・在庫・不良・ヒヤリハット等の指標で前後比較し、
   残ったムダをVSM/ECRS/PDCAへ橋渡しする。なぜ: 効果を示せない5Sは打ち切られる。5Sは終点でなく改善の起点。

## 壁打ち質問リスト

各Sを事実で埋めるために利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. 対象の現場・エリアはどこで、**この5Sで最終的に減らしたいムダ・リスク**は何ですか？（探す時間／在庫／不良／事故のどれ）
2. 現状、**モノを探す・見つからない・置き場が分からない**ことでの手間や遅れは、どこで、どのくらい起きていますか？
3. いま職場にある物のうち、**この1年ほぼ使っていない・要否の判断がつかない**ものは何ですか？（＝整理・赤札の候補）
4. よく使う物の**置き場と量は決まっていますか？** 決まっているなら、誰が見ても分かる**表示（ラベル・区画）**はありますか？
5. 清掃は**誰が・どの頻度で**やっていますか？ 掃除のときに**設備や工具の異常（漏れ・緩み・傷）に気づく**仕組みはありますか？
6. 一度整えても**元に戻ってしまう**としたら、原因は何だと思いますか？（基準が無い／時間が無い／人によるばらつき／関心が薄い）
7. 5Sのルールや置き場は**現場の人が主体で決めています**か、それとも上や本部が決めて渡していますか？
8. 改善の**効果を測る指標**（探す時間、在庫金額、不良率、ヒヤリハット件数など）で、いま取れるものはありますか？

## 出力フォーマット

ALWAYS この型で出力する（現状棚卸し → 5S計画 → 定着と効果）。各Sは「現状／打ち手／担当・頻度」を必ず埋める。

```
【対象と狙い】エリア: <どこ> ／ 減らすムダ・リスク: <探す時間/在庫/不良/安全 等> ／ 着手前の状態: <写真・困りごと>

【5S 棚卸しと打ち手】
  整理(Sort):        現状<要否が曖昧な物> → 打ち手<赤札作戦・処分基準/期限>
  整頓(Set in order):現状<置き場/表示の有無> → 打ち手<3定=定位/定品/定量・ラベル・姿置き>
  清掃(Shine):       現状<掃除の頻度/点検の有無> → 打ち手<担当・頻度・清掃点検の着眼>
  清潔(Standardize): 現状<標準の有無> → 打ち手<チェックリスト・写真基準・責任分担>
  躾(Sustain):       現状<定着の仕組み> → 打ち手<5Sタイム・定期監査・点数化・横展開>

【効果測定】指標: <探す時間/在庫/不良/ヒヤリハット等> ／ 測り方: <前後比較の方法>
【次の一手】<残ったムダを接続する先: VSM/ECRS/PDCA/真因追究 など>
【未確認の前提】<現場で確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。小売店のバックヤード（在庫と作業スペース）を整える場面。

範囲・狙い（品出しで探すムダと賞味期限切れ・過剰在庫の削減）を設定して着手前を記録し、赤札作戦で整理→3定で整頓→清掃点検→写真付き基準で標準化→5Sタイム・週次監査で習慣化→効果測定して残ったムダを ECRS/VSM/five-whys へ接続、の流れで進める。上の「出力フォーマット」をこの手順で埋めると次のようになる。

```
【対象と狙い】エリア: 小売店バックヤードの棚と作業台 ／ 減らすムダ・リスク: 品出し時に探すムダ・賞味期限切れ/過剰在庫 ／ 着手前の状態: 通路に段ボール山積みのビフォー写真、「梱包資材が見つからない」の現場の声

【5S 棚卸しと打ち手】
  整理(Sort):        現状<用途不明の販促什器・重複備品が棚に混在> → 打ち手<赤札作戦: 理由と処分期限を書いた赤札を貼り赤札置き場へ隔離、期限超過分は処分し空き棚を確保>
  整頓(Set in order):現状<梱包資材の定位置・表示が無く量も不定> → 打ち手<3定=よく使う資材を作業台の手元(定位)/種類別に区画とラベル(定品)/補充点を示す線で持ちすぎ防止(定量)、工具は姿置き>
  清掃(Shine):       現状<閉店後に気づいた人が掃除、点検の仕組み無し> → 打ち手<担当・頻度を決め、台車の車輪の緩みや冷蔵什器の異音をチェックリストで清掃点検・記録>
  清潔(Standardize): 現状<あるべき状態の基準が無く人によりばらつく> → 打ち手<写真付き基準を掲示し、棚ごとの担当と点検スケジュールを明確化>
  躾(Sustain):       現状<維持の仕組みが無く数週間で元通り> → 打ち手<開店前の短い5Sタイム＋週次の簡易パトロール(点数化)、良い工夫を他の棚へ横展開>

【効果測定】指標: 品出し1回あたり所要時間 / 廃棄ロス / 棚卸差異 ／ 測り方: 着手前後で同条件のサンプルを計測し前後比較
【次の一手】残る動線のムダは ECRS/VSM へ、逆戻りの原因は five-whys へ接続
【未確認の前提】「探すムダ」の実頻度・時間、赤札対象の要否判断は現場当事者に確認（推測のまま処分・固定しない）
```

## 相性（組み合わせると効く）

- `ecrs`: 整頓・清掃で見えた作業や動線のムダを、排除・結合・交換・簡素化で具体的に削る直接の続き。
- `value-stream-mapping`: 5Sで現場基盤を整えた上で、工程全体（バリューストリーム）のムダとリードタイムを可視化する上位視点。
- `pdca`: 5S活動を「一度きり」で終わらせず回し続けるための改善サイクルの器（清潔・躾の実装エンジン）。
- `five-whys`: 清掃点検で見つかった異常・不具合や「元に戻る」現象の真因を掘り下げる（別レンズ＝分析）。
- `fishbone`: 5Sだけでは消えない根深い問題（不良・遅延）の要因を人・設備・方法・材料などで体系的に洗う。
- 揺さぶり枠として `premortem`（5S活動が形骸化・逆戻りする失敗を先回りで潰す）や `devils-advocate`（「整理整頓が目的化していないか」を疑う）を添えると、定着設計の抜けに気づける。
