# GROWモデル

## 概要

GROWモデルは、コーチングの対話を **Goal（目標） / Reality（現実・現状） / Options（選択肢） / Will（意志・行動）**
の4段の問いで構造化する会話プロセスモデル。指示や助言で答えを与えるのではなく、**問いによって相手自身に
答えと次の一手を見つけさせる**ための"問いの順序"である。

| 段階 | 問いの狙い | 中心の問い |
|---|---|---|
| **G** Goal | 目指す先を定める | 何を達成したいか／成功とは何か |
| **R** Reality | 現在地を正確に把握する | 今どうなっているか／何が障害か |
| **O** Options | 進み方の選択肢を広げる | どんなやり方があるか（フィルタせず数多く） |
| **W** Will | 具体的な行動に約束させる | 何を・いつ・誰が／やり抜く意志は |

- **核となる考え方**: コーチングの目的は相手の **Awareness（気づき・自己認識）と Responsibility（当事者意識・責任）**
  を高めること。「教える(tell)」のではなく「問う(ask)」ことで、本人が状況を再認識し、自分で選び、自分の言葉で
  コミットする。GROWはそれを引き出す足場であり、**順序そのものはコーチングではない**（後述の限界を参照）。
- **なぜGoalが先か**: 先に「目指す先」を置くと、どの現実が関連するかが定まり、Realityの掘り下げが焦点を持つ。
  現状分析から入ると問題探しに終始しやすい。ただし一度Realityを見て目標を調整する行き来は正常（直線的でない）。
- **出自（諸説あり・議論がある）**: 英国発。共同開発者として **Sir John Whitmore / Graham Alexander / Alan Fine**
  の3名が挙げられる。名称「GROW」は **Max Landsberg** が Graham Alexander との会話で名付けたとされ（Whitmoreの
  後年の記述）、Landsberg は *The Tao of Coaching*（1996）で公表。Whitmore は ***Coaching for Performance*（1992初版）**
  で最初に活字化した。知的源流は Timothy Gallwey **『The Inner Game of Tennis』(1974)** で、Whitmore らが1979年に
  欧州へ持ち込んだ Inner Game の思想（内的な妨げを取り除く）を継ぐ。**発表年・命名年・共同開発者の役割分担は当事者間で
  主張が食い違い、一次資料で確定しないため断定を避ける**（→出典・要確認項目参照）。

## いつ使う / 使わない

**使う（適する状況）**
- **1on1・面談・育成の対話**で、上司/メンターが部下の目標設定と行動計画を引き出したいとき。
- 相手に**答える能力・材料はあるが、自分で考え抜く支援**が要るとき（答えは本人の中にある系のテーマ）。
- **当事者意識・やる気**を持たせたいとき。押し付けの計画より、本人が選んだ行動の方が実行される。
- 会話が発散・堂々巡りしていて、**構造（目標→現状→選択肢→行動）で整理**したいとき。
- 継続的な支援関係（定期1on1）で、毎回の対話に**共通の型**を持たせたいとき（→T-GROW/RE-GROW）。

**使わない / よくある誤用（アンチパターン）**
- **問いのふりをした指示（ティーチング化・詰め）**——最悪の誤用。Whitmore は「**Any dictator can use GROW
  （どんな独裁者でもGROWは使える）**」と警告した。信頼・気づき・責任を伴わず順序だけをなぞると、誘導・操作になる。
- **チェックリスト化して直線的に回す**——GROWを穴埋め手順として機械的に進めると対話の流動性が死ぬ。
  相手に応じて段を行き来する前提（GからRへ戻る等）。
- **Realityを急いで飛ばしてOptionsへ**——セッションが浅く事務的になる最頻の原因。Realityは対話の"本体"。
- **強制的な目標設定**——相手が準備できていないのに目標を迫ると、抵抗・不関与を生む。
- **相手の現実認識が誤っている/選択肢が本当に見えないとき**に問いだけで押し切る——直接的な情報提供・助言が
  要る場面もある（純粋コーチングに固執しない）。
- 深い心理的・感情的問題（セラピー領域）、実存・価値観・人生の方向づけの探求、知識ゼロで**教える**必要がある場面、
  即座の指示が要る**緊急時**には不向き。別のアプローチ（ティーチング/メンタリング/専門家紹介）へ切り替える。

## 前提と限界

- **前提**: (1) コーチと相手の間に**信頼関係**があること（日本語二次資料も「上手くいかない一番の要因は信頼関係」と指摘）。
  (2) 相手が答えに到達できる**知識・経験**を持っていること（無ければ先にティーチングが要る）。
  (3) コーチが**傾聴・質問・沈黙を待つ**スキルを持つこと。順序を知っているだけでは機能しない。
- **限界（批判を踏まえて）**:
  - **目標志向ゆえの射程の狭さ**——Passmore & Cantore は「GROWは目標志向のため人生の哲学的側面を探れない。
    スポーツ/ビジネスの目標領域には向くが、キャリア・役割適合・ライフコーチングには向きにくい」と指摘。
  - **根底の問題を扱えない**——目標設定と行動計画に焦点が寄り、進捗を妨げる**深層の要因**（心理的抵抗・価値観の葛藤）
    には届きにくい。必要なら真因探索や別のレンズを併用する（→相性）。
  - **単一モデル依存**——GROWは足場。経験を積んだコーチはこれに縛られず、より柔軟で人間中心の対話へ移るべき、との批判。
  - **形式が硬く感じられる**——構造を好まない相手には窮屈。段を明示せず、問いの流れとして自然に用いる。
- これらの限界は、**Realityを丁寧に掘る／段を行き来する／深層要因は five-whys 等で補う／行動計画は premortem で
  ストレステストする**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。GROWは直線でなく、必要に応じ前段へ戻る。

0. **（任意）Topic＝テーマを緩く定める（T-GROW）。** 相手が何を話したいか曖昧なら、まず「今日は何について話すか」を置く。
   なぜ: テーマが無いと目標が定まらず対話が発散する。緩くてよいので焦点を作る。
1. **Goal＝この対話のゴールを引き出す。** 「何を得たいか／成功とはどんな状態か」を本人の言葉で。
   なぜ: 先に目指す先を置くと、どの現実が関連するかが定まる。**End Goal（最終的にありたい姿。自分だけでは統制しにくい）**
   と **Performance Goal（達成の可能性を左右する、自分で統制できる到達水準）** を分けると行動に落ちやすい。
2. **Reality＝現状を正確に描かせる。** 事実と解釈を分け、評価を交えず「今どうなっているか」「何が障害か」を語らせる。
   ここで**時間を惜しまない**。なぜ: Realityは対話の本体であり、自己認識が深まるほど選択肢と行動の質が上がる。
   飛ばすと浅く事務的な結論になる（最頻の失敗）。
3. **目標と現状のギャップを本人に確認させる。** 「目標に対して今どの位置か」を言語化させる。
   なぜ: ギャップが見えて初めて、埋めるための選択肢が必要だと本人が実感する。
4. **Options＝選択肢をフィルタせず数多く出させる。** コーチは答えを言わず、発散を促す。「他には？」を繰り返す。
   なぜ: 最初に出る案は既知の1〜2個に偏る。「制約が無ければ？」「失敗しないと分かっていたら？」で枠を外す。
   選択肢が本当に見えないときのみ、許可を得て情報提供する。
5. **Options を本人に評価・選択させる。** 出した案を効果・実現性で見比べ、やる案を本人が選ぶ。
   なぜ: 選んだのが本人であるほど実行される（当事者意識）。コーチが選ぶと押し付けになる。
6. **Will＝具体的な行動に約束させる。** 「何を・いつまでに・誰が」を確定し、**やり抜く意志を1〜10で自己評価**させる。
   なぜ: 曖昧な決意は実行されない。数値が低ければ障害が残っている合図——Reality/Optionsへ戻る。
7. **障害と支援を先回りする。** 「何が邪魔しそうか」「どんな支援が要るか」を確認し、次回フォローを約束する。
   なぜ: GROWは1回で完結しない。継続の1on1（RE-GROW=前回の振り返りから入る）で行動を定着させる。

## 壁打ち質問リスト

相手（コーチイ）から各段を引き出すための問い。空欄を勝手に埋めず、**本人に語らせる**のが原則。
※本スキルを相談者（＝コーチする側/自分をコーチする人）に使うときは、以下をそのまま投げ返して状況を確定する。

1. この対話（1on1）の相手は誰で、**あなたとの関係・信頼の度合い**はどれくらいですか？（部下/後輩/自分自身、信頼の前提を確認）
2. 相手が**今日／この期間で達成したいこと**は何ですか？それが叶ったら、どんな状態になっていますか？（Goal）
3. その目標について、**現状はどうなっていますか**。事実として何が起きていて、何が障害になっていますか？（Reality）
4. 相手は**目標と現状のギャップ**をどう認識していますか。本人はどこが一番の課題だと感じていますか？
5. 目標に近づく方法として、**どんな選択肢**が挙がりますか？（まずフィルタせず数を。制約が無ければ何を試すか、も）
6. その中で相手が**やると選んだこと**は何で、**いつまでに・どうやって**実行しますか？（Will）
7. 「やり抜く意志」を**1〜10で言うと何点**ですか？低いとしたら、何が引っかかっていますか？
8. あなたはこの対話で、つい**答えを教えたり指示したり**していませんか？（ティーチング化の自己点検）まだ本人から引き出せていない点はどこですか？

## 出力フォーマット

ALWAYS この型で出力する（対話の設計図＋引き出すべき問い＋行動）。段は行き来する前提で、埋まっていない箇所は
「本人への問い」を提示する（勝手に代入しない）。

```
【GROWセッション設計】相手: <誰／関係> ／ テーマ(Topic): <あれば>
  G 目標(Goal):
    - End Goal（ありたい姿）: <…>
    - Performance Goal（統制可能な到達水準）: <…>
    - 引き出す問い: 「<成功の定義を問う>」
  R 現実(Reality):
    - 事実 / 現在地: <…>
    - 障害: <…>   ／  目標とのギャップ: <…>
    - 引き出す問い: 「<現状・障害を語らせる問い>」
  O 選択肢(Options):
    - 案: - <案1> - <案2> - <案3>…（フィルタせず）
    - 枠を外す問い: 「もし制約が無ければ？」「他には？」
  W 意志・行動(Will):
    - やること / 期限 / 担当: <What / When / Whom>
    - 実行意志(1-10): <n> ／ 低い場合の障害: <…>
    - フォロー: <次回いつ・何を確認>

【コーチの自己点検】ティーチング化していないか／Realityを飛ばしていないか／本人が選んだか
【次の一手】<本人が合意した最初の一歩>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名・個人名は用いない）。上司が、あるメンバーと定期1on1を行い、
「もっと責任ある仕事を任されたい」という漠然とした希望を扱う場面。

- **手順0 Topic**: 「今日は何について話したい？」→「もっと責任ある仕事を任されたい」をテーマに設定。
- **手順1 Goal**: 「任されたら、どんな状態になっている？成功をどう定義する？」と問う。
  - End Goal（ありたい姿）: 一つの案件を自分の判断で最後まで回せる。
  - Performance Goal（統制可能）: 次の四半期に、小さめの案件で自分が主担当として進行を回し切る。
- **手順2 Reality**: 「今はどこまでできていて、何が障害？」を本人に語らせる（急がない）。
  - 事実・現在地: 補助として関わった経験はあるが、主担当の経験はまだ無い。
  - 障害: 判断に迷ったとき誰に相談してよいか不明／全体像を掴む機会が少ない。
- **手順3 ギャップ確認**: 「主担当に必要な力のうち、今一番足りないのは？」→本人「進行の段取りと巻き込み方」。
- **手順4 Options（発散）**: 「近づく方法は？制約が無ければ何を試す？他には？」
  - 案: 先輩の案件にシャドー同行する／小さい案件を主担当で任せてもらう／段取りのテンプレを自作する／週次で相談枠を持つ。
- **手順5 選択**: 本人が「小さい案件を主担当で持つ＋週次の相談枠」を選ぶ（コーチは選ばせるだけ）。
- **手順6 Will**: 「何を・いつ・どう？」→「来週、任せてもらえそうな案件を上司と特定し、再来週から主担当で着手」。
  実行意志を1〜10で自己評価→本人「7」。低い分の理由は「途中で判断に詰まる不安」。
- **手順7 障害・支援・フォロー**: 詰まったときの相談先を上司＝自分に決め、隔週1on1で進捗を確認（RE-GROWで次回は振り返りから）。
- **コーチの自己点検**: 案は全て本人が出した／Realityを飛ばさず障害まで掘れた／答えを与えていない。OK。

## 相性（組み合わせると効く）

- `five-whys`: Reality で出た障害の**根本原因**を掘る。表面の「時間が無い」から真因へ（分析レンズで補完）。
- `kgi-kpi-okr`: Goal を**測れる指標**に落とし、進捗を追える形にする（曖昧な目標のSMART化）。
- `decision-matrix` / `payoff-matrix`: Options が多いとき、効果×実現性で**選択肢を評価・優先**する（手順5の道具）。
- `premortem`: Will で決めた行動計画を「もう失敗したとして原因は？」と**事前に叩き**、抜けを塞ぐ（揺さぶり枠）。
- `six-hats`: Options の発散が細るとき、6つの視点で**選択肢を強制的に増やす**（視点転換で補完）。
- `herzberg` / `maslow`: Will の「意志が上がらない」背景にある**動機づけ要因**を読み解く（people レンズ）。
- `pdca`: セッション後の実行を、計画→実行→評価→改善の**継続サイクル**で回す（RE-GROWの受け皿）。
- 揺さぶり枠として `devils-advocate`（本人の目標・現状認識をあえて疑う）を軽く添えると、思い込みを弾ける。
