## 2. モデル別の詳細

### 2.1 AIDA（原型）
- 段階: **A**ttention（注意）→ **I**nterest（興味）→ **D**esire（欲求）→ **A**ction（行動）。
- 効果階層モデル（hierarchy of effects）の祖。「広告接触が認知→感情→行動と段階的に効く」という発想の起点。
- 後続すべての購買行動モデルの母型。段階が最小限のため、まず全体像を掴む時の共通言語になる。

### 2.2 AIDMA（マスメディア時代）
- 段階: 注意 → 興味 → 欲求 → **M**emory（記憶）→ 行動（購買）。
- AIDAに「記憶」を追加。TV・新聞・雑誌など**広告接触と購買のあいだに時間差**がある状況を説明する（広告を見た日と買う日が違う）。
- 企業からの一方向コミュニケーションが前提。記憶段階の施策＝**想起されるブランド化**（反復露出、記憶に残るコピー/ロゴ、店頭での再接触）。
- 向く: マス広告中心、比較的高関与でも認知〜購買が主にオフラインで完結する商材。

### 2.3 AIDCA / AIDCAS（対面・ダイレクト販売）
- 段階: 注意 → 興味 → 欲求 → **C**onviction（確信）→ 行動（→ **S**atisfaction 満足）。
- 欲求と行動のあいだに「確信」を挟む。**買って大丈夫という納得**を作る段階を重視。
- 向く: ダイレクトレスポンス広告、営業・対面販売、高額・不安の大きい商材。実証（データ・保証・お客様の声）で確信を作るのが要。

### 2.4 AISAS（インターネット時代）
- 段階: 注意 → 興味 → **S**earch（検索）→ 行動（購買）→ **S**hare（共有）。
- 電通が2004年に提唱（登録商標★）。ネット普及で消費者が**自ら検索し、購買後に感想を共有**する双方向・非線形の行動を組み込んだ。
- 「検索」＝比較・裏取りの主戦場（指名検索、口コミ検索、比較サイト）。「共有」＝購買後のUGC/レビューが次の人の「検索」で見つかる循環を生む。
- 向く: Web経由の流入が主な商材、口コミ・レビューが購買に効くカテゴリ。

### 2.5 AISCEAS（比較検討が重い商材）
- 段階: 注意 → 興味 → 検索 → **C**omparison（比較）→ **E**xamination（検討）→ 行動 → 共有。
- AISASの「検索〜行動」を**比較・検討**に細分化。検討期間が長く、複数候補を並べて選ぶ購買を精緻に扱う。
- 向く: 高額商材、BtoB、住宅・保険・SaaSなど**比較検討が購買を左右**するカテゴリ。比較表・導入事例・レビュー・無料トライアルが効く。

### 2.6 SIPS（ソーシャルメディア時代）
- 段階: **S**ympathize（共感）→ **I**dentify（確認）→ **P**articipate（参加）→ **S**hare & Spread（共有・拡散）。
- 電通「サトナオ・オープン・ラボ」が2011年に発表。SNSで**共感を起点**に人が動く行動を説明。
- 特徴: ゴールを必ずしも「購買」に置かない。「参加」（いいね/シェア/イベント参加など購買未満の関与も価値）を段階に含む。ファン/アンバサダーづくりと相性。
- 向く: SNSでの認知・関係構築が主戦場のブランド、コミュニティ型・共感訴求の商材。

### 2.7 DECAX（コンテンツマーケ時代）
- 段階: **D**iscovery（発見）→ **E**ngage（関係構築）→ **C**heck（確認）→ **A**ction（購買）→ e**X**perience（体験・共有）。
- 電通が2015年に提唱。**消費者側が有益なコンテンツを「発見」する**ところが起点（広告主体でない）。オウンドメディア/コンテンツSEOと相性。
- 「関係構築」＝継続接触で信頼を積む（メルマガ購読、SNSフォロー、連載閲覧）。「確認」＝コンテンツの信頼性・自分への適合を吟味。
- 向く: コンテンツマーケ、オウンドメディア、検討が長くまず情報提供で信頼を作る商材。

### 2.8 Dual AISAS（買う／広めるの二層）
- AISASを「**買う**ための行動（Attention〜Action）」と「**広める**ための行動（Activate/Share〜Spread）」の二層で捉える発展形。
- 購買者と拡散者（インフルエンサー/ファン）の動機は違う、という前提。拡散設計を購買設計と分けて考えたい時に使う。
- アタラ合同会社が2015年に提唱★。

## 3. モデル選定の早見表

| 状況・条件 | 第一候補 | 補助 |
|---|---|---|
| マス広告中心・オフライン購買が主 | AIDMA | AIDA |
| 対面/営業/高額で「確信」づくりが要 | AIDCA | AIDMA |
| Web検索起点・口コミが効く | AISAS | AISCEAS |
| 比較検討が長い高額/BtoB/SaaS | AISCEAS | AISAS |
| SNS起点・共感/コミュニティ | SIPS | Dual AISAS |
| オウンドメディア/コンテンツSEO起点 | DECAX | AISAS |
| 拡散設計を購買設計と分けたい | Dual AISAS | SIPS |

> 実務では**流入経路別に複数モデルを併用**することが多い（例: マス広告流入はAIDMA、検索流入はAISAS、SNS流入はSIPS）。

## 4. 段階別KPI・施策の逆引き

| 段階（横断） | 代表KPI | 代表施策 |
|---|---|---|
| 注意/認知 (Attention) | インプレッション、リーチ、UU、指名検索前の流入 | マス/運用型広告、SEO、PR、SNS露出 |
| 興味/関心 (Interest) | CTR、滞在時間、ページ回遊、エンゲージ率 | 訴求コピー、ファーストビュー、動画/コンテンツ |
| 検索 (Search) | 指名検索数、検索ボリューム、比較サイト流入 | SEO/指名検索対策、口コミ醸成、比較記事 |
| 比較/検討 (Comparison/Examination) | 比較ページ閲覧、事例/レビュー閲覧、トライアル申込 | 比較表、導入事例、レビュー、無料トライアル、FAQ |
| 欲求/確信 (Desire/Conviction) | 資料請求、サンプル、カート追加、見積依頼 | 実証データ、保証、お客様の声、限定オファー |
| 記憶 (Memory) | 再訪率、リターゲ反応率、ブランド想起 | 反復露出、リタゲ広告、メルマガ、記憶に残る表現 |
| 行動/購買 (Action) | CV、CVR、CPA、客単価 | カート最適化、決済/申込導線、クロージング |
| 参加 (Participate) | いいね/シェア、コメント、イベント参加 | 参加型企画、コミュニティ、UGC喚起 |
| 共有/拡散 (Share/Spread/eXperience) | UGC数、レビュー投稿、SNS言及、NPS | レビュー依頼、ハッシュタグ、アンバサダー、体験設計 |
