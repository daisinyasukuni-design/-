# 3C分析

## 概要

3C分析は、事業環境を **市場・顧客(Customer) / 競合(Competitor) / 自社(Company)** の3視点から
調査・整理し、**KSF（Key Success Factor＝重要成功要因）** を特定して競争優位のある戦略の起点を作る
フレームワーク（原典『The Mind of the Strategist』の英語表記はKFS: Key Factors for Success。日本の実務ではKSFが通用しており本Skillでも KSF を用いる）。考案者はこの3者の関係を **戦略的三角関係（strategic triangle）** と呼んだ。

```
            顧客・市場 (Customer)
                 △
                / \
  自社の提供価値 /   \ 競合の提供価値
              /     \
    自社 ────┴───────┴──── 競合
 (Company)   競争・差別化   (Competitor)
```

- **核となる考え方**: 「**顧客が求める価値**を、**競合よりも上手く**、**自社の資源**で提供できる領域」＝勝ち筋を探す。
  3者のどれか1つを最適化するのではなく、**3者を統合してバランスさせる**ことで持続的な競争優位が生まれる、という主張。
  分析の到達点は「情報の整理」ではなく **KSFの特定**（この市場で勝つには何が決定的に効くか）。
- **出自**: 考案者は **大前研一（Kenichi Ohmae）**、日本の経営コンサルタントで元マッキンゼー・アンド・カンパニーのコンサルタント。
  大前は著書 **『The Mind of the Strategist: The Art of Japanese Business』（McGraw-Hill, 1982）** でこの戦略的三角関係を提示した。
  日本語の源流は **『企業参謀――戦略的思考とはなにか』（1975）**。**この「大前が同書で strategic triangle を提示した」点は一次資料で確定できる断定事実**。
  一方、**「3C」という頭字語ラベルが本人の命名か後年の実務での定着か**、後年の再版（1991年版など）の版表記、マッキンゼーでの正確な役職は
  資料で表現が揺れるため、**そこは断定せず扱う**（→出典・要確認参照）。

## いつ使う / 使わない

**使う（適する状況）**
- 事業・マーケ戦略や事業計画の**初期**に、外部（顧客・競合）と自社を一望して勝ち筋を探したいとき。
- **新規事業・新市場への参入**検討で、市場の魅力度・競合の強さ・自社の適合を突き合わせたいとき。
- 「なぜ競合に勝てない／選ばれないのか」を、顧客ニーズと競合優位と自社能力の**ズレ**として整理したいとき。
- SWOT・STP・4Pの**入力**（特に顧客ニーズと競合比較の事実）を、事実ベースで用意したいとき。

**使わない / よくある誤用（アンチパターン）**
- **主観・願望で埋める**——最頻の失敗。「当社の技術は業界トップ」「顧客はこれを求めているはず」を客観データ無しに断定する。
  売上・シェア・満足度・リピート率・性能比較など**事実**で裏を取る。想像で作った3Cは戦略を丸ごと誤らせる。
- **自社から始めて内向きになる**——自社の強みを起点にすると、顧客・競合が「自社正当化の後付け」に堕ちる。**顧客起点**で始める。
- **3視点を並べて終わり（KSF・戦略に繋げない）**——3Cは整理が目的ではない。3者の重なり＝勝ち筋を抜き出し、SWOT等へ橋渡しする。
- **競合分析が薄い**——競合の内情は入手しにくく手薄になりがち。「競合が**なぜ**成果を出せているか（仕組み）」まで踏み込まないと差別化余地が見えない。
- **情報過多で分析麻痺**——市場が大きいほど収集対象が膨大になる。「何をKSFとして決めるか」で調べる範囲を絞る。
- **データの陳腐化**——半年〜1年前の数字をそのまま使うと現状と乖離する。鮮度を確認し、定期的に見直す。
- **3Cだけで網羅できると思う**——外部環境は3CではMECEにならない。マクロ要因はPEST、業界構造は5フォースで補う。
- 精緻な定量最適化・実行フェーズの細部設計（価格・チャネル等）には不向き。他フレームで補完する。

## 前提と限界

- **前提**: 分析の目的・対象事業・市場スコープが1つに定まっていること。目的が曖昧だと収集対象が発散し、情報過多に陥る。
  外部（顧客・競合）を語るには市場・競合の基礎情報が要る。無ければ壁打ちで補うか、PESTを先に回してマクロを固める。
- **限界（批判を踏まえて）**:
  - **MECEにならない**——3Cは外部環境を尽くさない。マクロ変化（政治・経済・社会・技術）や業界構造（新規参入・代替品）は
    こぼれる。PEST・5フォースとの併用が前提。
  - **競合情報の非対称性**——自社・顧客情報は事業活動で蓄積されるが、競合の内情は外から見えにくく、推測が混ざりやすい。
    「事実」と「推測」を分けて記録し、推測は検証対象として明示する。
  - **主観バイアスに弱い**——分析者の願望・思い込みが入りやすい。特に自社評価は甘くなりがち。客観データと複数視点で補正する。
  - **静的**——環境変化に追随しない。作った瞬間から陳腐化が始まる前提で、定点でなく定期的に更新する。
- これらの限界は、**PEST/5フォースで外部を補い、SWOTで統合し、VRIOで自社の強みを検証する**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。**顧客→競合→自社→統合**の順を基本とする（どのCからでも始められるが、
顧客起点が内向きを防ぐ）。

1. **目的とスコープを1つに固定する。** 「この3Cで何を決めるか」（例: この市場に参入するか／どこで差別化するか）と、
   対象事業・市場の範囲を明文化する。なぜ: 目的が無いと収集が発散し、情報過多で分析麻痺に陥る。
2. **市場・顧客(Customer)を洗い出す。** 市場規模・成長性・トレンド、顧客セグメント、ニーズ・価値観、購買行動・購買プロセス、
   購買の意思決定者と決め手を、事実で押さえる。なぜ: 顧客が求める価値が、後段の「勝ち筋」の物差しになる。ここが推測だと全体が崩れる。
3. **競合(Competitor)を洗い出す。** 主要競合の数・シェア、製品/価格/特徴、強み弱み、そして**なぜ成果を出せているか（ビジネスの仕組み・結果とその要因）**を分析する。
   なぜ: 競合の「結果」だけでなく「要因」まで見ないと、真似すべき点・差別化できる点が判別できない。情報が薄い所は推測と明記する。
   競合の内情は直接聞けないので外から三角測量する——公開IR・決算資料（コスト構造・利益率）、求人票（増員職種＝注力領域）、価格表・製品カタログ、口コミ/レビュー（強み弱みの実態）、特許・商標（技術の重心）を突き合わせ、複数ソースが一致した点は事実に近い確度、割れた点は［推測］として残す。
4. **自社(Company)を洗い出す。** 自社の強み弱み、売上・シェア、保有リソース（人・モノ・カネ・技術＝人-金-物のバランス）を、
   **競合との相対**と**顧客ニーズへの適合**で評価する。なぜ: 強みは絶対値でなく「顧客が評価し、競合が持たない」ときに初めて武器になる。
5. **3者を突き合わせてKSFを抽出する。** 「顧客が求める価値 × 競合がまだ十分満たせていない × 自社が競合より上手くできる」の
   重なりを探す。これがこの市場のKSF＝勝ち筋。なぜ: 3Cの核心は整理でなくKSFの特定。ここを飛ばすと「並べただけ」で終わる。
6. **KSFを戦略の型に落とす。** 抽出したKSFの**主レバーがどこにあるか**で、大前の3類型から型を一意に選ぶ。
   - **顧客起点戦略**（主レバーが＝顧客の未充足ニーズのとき）: セグメントを絞り、その顧客の未充足ニーズに集中する。
   - **自社起点戦略**（主レバーが＝自社の模倣困難な資源のとき）: 自社の強みを最大化し、コストや内製/外注（make or buy）を最適化する。
   - **競合起点戦略**（主レバーが＝機能面の差別化余地のとき）: 購買・設計・営業・ブランド等の機能で差別化する。
   なぜ: KSFは方向。「いずれか」で迷わせず、レバーの所在で型を決めると打ち手がぶれない（複数該当なら主レバー＝最も効くもの1つを選ぶ）。
7. **次の一手と検証すべき前提を決める。** 戦略から、検証する仮説・意思決定・アクションを1〜3個に絞り、
   推測で埋めた箇所を「要検証」として残す。なぜ: 3Cは起点であってゴールではない。ここで止めると「作って終わり」になる。

## 壁打ち質問リスト

各Cを事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この3C分析で**最終的に決めたいこと**は何ですか？（参入可否／差別化の軸／伸ばす領域など、目的を1つに）対象の市場・事業の範囲は？
2. **顧客・市場**について：狙う市場の規模と成長性は？ 主な顧客セグメントと、その人たちが本当に**求めている価値・満たされていない不満**は何ですか？（数字・顧客の声など根拠は？）
3. 顧客はどんな**購買プロセス・意思決定**で選んでいますか？（誰が決めるか、決め手は価格か品質か体験か）
4. **競合**は誰で、シェアや強みはどうですか？ その競合が**なぜ選ばれている／成果を出せているのか**（仕組み・要因）まで説明できますか？
5. 競合について、**確かな事実**と**まだ推測でしかない部分**はそれぞれどこですか？（競合情報は薄くなりがち。分けて把握する）
6. **自社**の強み・弱みは、**競合と比べて**どうですか？ その強みは**顧客が実際に評価している**ものですか？（自己申告でなく顧客・データ基準で）
7. 保有するリソース（人・モノ・カネ・技術）で、**競合が容易に真似できない**ものは何ですか？
8. 使っている情報の**鮮度**はどのくらいですか？（半年〜1年以上前の数字は現状と乖離しうる。いつ時点のデータか）

## 出力フォーマット

ALWAYS この2段構えで出力する（3視点の整理 → KSF・戦略化）。埋められない箇所は「要確認」と明記し、捏造しない。

```
【3C（整理）】目的: <この3Cで決めたいこと> ／ 対象市場・事業: <スコープ>
  市場・顧客(Customer): - 市場規模/成長: <…>  - 主要セグメント: <…>
                        - 求める価値/未充足ニーズ: <…>  - 購買行動/決め手: <…>
  競合(Competitor):     - 主要競合/シェア: <…>  - 強み・弱み: <…>
                        - 成果を出せている要因(仕組み): <…>  ※推測は［推測］と表記
  自社(Company):        - 強み(競合比・顧客評価つき): <…>  - 弱み: <…>
                        - リソース(人/モノ/カネ/技術): <…>

【KSF（勝ち筋）】<顧客が求める × 競合が満たせていない × 自社が競合より上手い、の重なり>

【戦略化】<KSFを型に落とす: 顧客起点 / 自社起点 / 競合起点 のいずれか＋具体策>

【次の一手】<検証すべき仮説・意思決定・アクションを1〜3個>
【要確認の前提】<推測で埋めた点・データ鮮度など、事実確認が要る箇所>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。地域の中小工務店が、リフォーム事業への注力を検討する場面。

- **手順①目的**: 「リフォームに注力するなら、どこで差別化して勝つか」を決める。対象市場＝地域の住宅リフォーム。
- **手順②市場・顧客(C)**: 築年数の経過した住宅ストックの増加で需要は底堅い。主要セグメントは中高年の持ち家層。
  求める価値は「価格の安さ」よりも「相談のしやすさ・施工後の安心・地元での実績」。決め手は知人紹介と対面の信頼。
- **手順③競合(C)**: 大手リフォームチェーン（ブランド力・広告量が強い）、ネット系見積もり仲介（価格訴求）、他の地元業者。
  大手が選ばれる要因は「安心感のブランド＋広告到達」。ネット系は「価格比較のしやすさ」。※各社の実コスト構造は［推測］。
- **手順④自社(C)**: 強み＝地元での長年の施工実績と口コミ、顔の見える対応。弱み＝広告・Web集客が弱い、営業人員が少ない。
  リソースは職人の技術と地域ネットワーク（＝競合の大手が簡単に真似できない）。
- **手順⑤KSF抽出**: 顧客が求める「安心・信頼・地元実績」× 大手が構造的に出しにくい「顔の見える密着対応」× 自社の「実績と口コミ」
  の重なり＝**「地元密着の信頼」がこの市場のKSF**。価格競争はKSFではない。
- **手順⑥戦略化（顧客起点）**: セグメントを「地元の持ち家リフォーム層」に絞り、施工事例と顧客の声を可視化して信頼を積み増す。
  価格の安さで大手・ネット系と正面から戦わない。
- **手順⑦次の一手**: 「既存客からの紹介が実際の受注の何割か」を検証し、紹介を促す仕組みを小さく試す。
- **要確認の前提**: 各競合のコスト構造・実シェア、地域需要の規模——ここは推測のまま進めず、実データで裏取りする。

## 相性（組み合わせると効く）

- `pest`: 3Cのマクロ側（市場のトレンド）を政治/経済/社会/技術で網羅する**前工程**。3CのCustomerはミクロに絞れる。
- `swot`: 3Cで集めた事実（顧客ニーズ・競合比較・自社の強み弱み）を強み/弱み/機会/脅威に**統合**し戦略へ橋渡しする直接の続き。
- `five-forces`: Competitorを「競合他社」から**業界構造**（新規参入・代替品・売り手/買い手の交渉力）へ広げて脅威を掘る。
- `stp`: 3CのCustomer理解を受け、セグメント→ターゲット→ポジショニングで**狙う市場を絞る**下流工程。
- `value-chain`: Company分析を機能（購買・製造・販売・保守）に分解し、KSFを生む活動と差別化余地を特定する。
- `vrio`: 挙げた「自社の強み」が本当に持続的優位か（価値/希少/模倣困難/組織）を検証し、思い込みを弾く。
- 揺さぶり枠として `devils-advocate`（「その強みは本当に顧客が評価しているか」を疑う）や
  `premortem`（選んだ戦略が失敗する要因を先回り）を添えると、主観バイアスを補正できる。
