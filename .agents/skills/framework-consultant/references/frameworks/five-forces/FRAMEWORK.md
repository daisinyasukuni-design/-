# 5フォース分析（ファイブフォース）

## 概要

5フォース分析は、ある**業界（事業ライン）の競争環境**を、収益性を左右する**5つの構造的な力（force）**に分解して分析し、
その業界が**どれだけ儲かるか（魅力度・収益性）**と、利益を圧迫している要因を突き止めるフレームワーク。
中核の考え方は「業界の収益性は、業界の構造（5つの力）と、その中での自社の相対ポジションで決まる。
**力が強いほど、その業界で得られる利益は薄い**」というもの。5つの力が生む圧力が、業界が生む経済価値を
新規参入者・代替品・売り手・買い手・競合へと**奪い合う/流出させる**構図を可視化する。

| 力 | 中身 | 強いと（収益性への影響） |
|---|---|---|
| **新規参入の脅威** | 新しい企業が参入してくる圧力 | 参入障壁が低い＝脅威大→価格・シェアが崩れ収益↓ |
| **代替品の脅威** | 別技術で同じニーズを満たす製品/サービス | 魅力的な代替が多い＝脅威大→価格上限が抑えられ収益↓ |
| **売り手の交渉力** | 供給業者が価格・条件を有利にする力 | 売り手が強い＝コスト↑で収益↓ |
| **買い手の交渉力** | 顧客が値下げ・高品質を要求する力 | 買い手が強い＝値下げ圧力で収益↓ |
| **既存競合との敵対** | 業界内の企業どうしの競争の激しさ | 競争が激しい＝価格競争・販促費で収益↓ |

- **核となる考え方**: 個社の優劣ではなく**業界の「土俵の傾き」**を見る。5つの力の合計が業界の平均収益性を決める。
  戦略とは、この力の弱いポジションへ自社を置く／自社の手で力を弱める（参入障壁を上げる、代替を封じる等）こと。
- **出自（要確認）**: 考案者は **Michael E. Porter**（ハーバード・ビジネス・スクール教授）。初出は
  **1979年 Harvard Business Review "How Competitive Forces Shape Strategy"**、体系化は著書
  **『Competitive Strategy』(1980、邦題『競争の戦略』)**、**2008年 HBR "The Five Competitive Forces That Shape Strategy"**
  で参入障壁の要因などを整理・更新した。年号・書誌は→出典/要確認を参照。

## いつ使う / 使わない

**使う（適する状況）**
- **業界への参入・撤退**を判断したいとき（この業界は構造的に儲かるのか＝魅力度の診断）。
- 既存事業で**なぜ利益が出にくいのか**、収益を圧迫している構造要因（誰に価値を奪われているか）を特定したいとき。
- **競合環境・業界構造を整理**したい、値下げ圧力・価格決定力の源泉を知りたいとき。
- 新規事業・事業計画・中期計画の**外部環境（業界）分析パート**として。
- M&Aや投資判断で、対象事業の**業界の魅力度**を構造から評価したいとき。

**使わない / よくある誤用（アンチパターン）**
- **業界分析と自社の競争優位を混同する**——最頻の誤用。5フォースは「業界がどれだけ儲かるか」を見るもので、
  「自社が他社より強いか」は扱わない。自社固有の資源・能力は **VRIO / バリューチェーン / SWOT** で別途評価する。
- **業界（スコープ）の定義が曖昧**——Porterは「事業ライン（line-of-business）レベル」で使えとし、
  粗い業界セクターでは使わないとした。製品/顧客/地理/チャネルを絞らないと、特に「代替品」「新規参入」の評価が歪む。
- **5枠を埋めて終わる**——各力を「強い/弱い」と判定するだけで、収益への影響や打ち手に繋げない。棚卸しは手段。
- **静的な一枚で固定する**——構造は動く（規制・技術・新規プレイヤー）。スナップショットを恒久的な結論にしない。
- **主観・印象で判定**——「なんとなく競争が激しい」で埋める。集中度・スイッチングコスト・成長率などを**データで裏取り**する。
- **補完財・提携を見落とす**——ゼロサム（奪い合い）前提のため、共創・提携（co-opetition）が支配的な市場では割り引いて使う。

## 前提と限界

- **前提**: 分析する**業界の境界が1つに定まる**こと（製品/顧客セグメント/地理/チャネル）。多角化事業は事業ごとに複数分析する。
  各力を判定する市場・競合の基礎情報（集中度、成長率、価格、スイッチングコスト等）が要る。無ければ壁打ちで補う。
- **限界（批判を踏まえて）**:
  - **外部・業界レベルに限定**——自社固有の資源/能力（RBV: Resource-Based View）を扱わない。「強い業界にいるが自社は弱い」
    「弱い業界だが自社は独自の優位を持つ」は5フォースでは見えない。VRIO/コアコンピタンスで補う。
  - **静的（スナップショット）**——変化の速いデジタル市場・境界が動く市場に追随しにくい。継続的に見直す前提で使う。
  - **ゼロサム前提**——価値の奪い合いを前提にし、補完財による市場拡大や、供給業者・競合との共創/提携を捉えにくい。
    **第六の力＝補完財（complementors）**を加える拡張（Value Net）がある（→出典・要確認）。
  - **Coyne & Subramaniam の批判**——「買い手/競合/供給業者は互いに無関係で結託しない」「価値は参入障壁から生まれる」
    「不確実性が低く予測計画できる」という3前提が現実と合わない場合がある（→要確認）。
  - **打ち手を直接は示さない**——力の強弱は分かっても、具体的な戦略は別途導く必要がある。
- これらは、**内部・自社はSWOT/VRIO/バリューチェーンで、マクロ環境はPESTで、打ち手化はSWOTやアンゾフで補完**して埋める（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。**印象でなくデータで各力を判定する**のが肝。

1. **目的と業界スコープを1つに固定する。** 「何のための分析か」（参入可否／収益改善／競合把握）と、**業界の境界**
   （どの製品・どの顧客セグメント・どの地理・どのチャネルか）を明文化する。
   なぜ: スコープが曖昧だと「代替品」「新規参入」の範囲が定まらず、5つの力の判定が総崩れになる。
2. **新規参入の脅威を評価する。** 参入障壁をチェック——規模の経済、必要資本、スイッチングコスト、ブランド/顧客ロイヤルティ、
   流通チャネルへのアクセス、政府規制/特許、既存企業の報復。障壁が高いほど脅威は弱い。
   なぜ: 今の競合が少なくても、参入が容易なら将来利益は削られる。「潜在」の圧力を見る力。
3. **代替品の脅威を評価する。** 「別の技術・手段で同じニーズを満たすもの」を洗い出し、その**相対的な価格対性能**、
   買い手の乗り換え傾向、スイッチングコストを見る。業界の外側にある点に注意。
   なぜ: 代替品は業界全体の**価格の上限**を抑える。業界内競合だけ見ると見落とす。
4. **売り手（供給業者）の交渉力を評価する。** 供給業者の集中度/数、投入財の希少性・差別化、スイッチングコスト、
   前方統合の可能性を見る。売り手が強いほどコストを押し上げられる。
   なぜ: 利益は業界の外（上流）にも流出する。誰にコストを握られているかを特定する。
5. **買い手（顧客）の交渉力を評価する。** 買い手の集中度/数、1回の購入規模、価格感応度、スイッチングコスト、
   情報の入手可能性、後方統合の可能性を見る。買い手が強いほど値下げを迫られる。
   なぜ: 利益は下流（顧客）にも流出する。価格決定力が自社と顧客のどちらにあるかを見る。
6. **既存競合との敵対の激しさを評価する。** 競合の数と規模の均衡、業界成長率（低成長ほど激化）、固定費/退出障壁、
   製品差別化の弱さを見る。価格競争・販促費の消耗を測る。
   なぜ: 5つのうち最も直接的に収益を削る力。差別化が効かない業界ほど消耗戦になる。
7. **各力を「強い/中/弱い」で判定し、根拠を添える。** 印象でなく、集中度・成長率・スイッチングコスト等の
   **事実**で裏づける。5つを俯瞰し**業界全体の魅力度（儲かるか）**を総合判断する。
   なぜ: 5枠の穴埋めで止めず、「この業界の収益性は構造的にどうか」という問いに答えるため。
8. **収益を圧迫する主因を特定し、打ち手に変換する。** 最も強い力（例: 買い手が強すぎる）に対し、
   自社が**力を弱める/避けるポジション**を設計する。防御＝参入障壁を上げる/スイッチングコストを作る、
   攻勢＝競合の弱い力を突く、差別化で価格競争を回避、上流/下流の統合、など。
   なぜ: 5フォースはゴールでなく起点。構造を「所与」でなく「変えられる対象」として次の一手に落とす。

## 壁打ち質問リスト

各力を事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この分析で**最終的に決めたいこと**は何ですか？（参入/撤退/収益改善/価格戦略など、目的を1つに）
2. 分析対象の**業界の境界**をどう定義しますか？（どの製品・どの顧客層・どの地域・どのチャネルか。広すぎないか）
3. **新規参入**を難しくしている障壁は何がありますか？（必要な投資・規制・特許・ブランド・スイッチングコスト等）。逆に参入が容易な点は？
4. 自社の製品/サービスと**同じニーズを、別の手段で満たすもの（代替品）**は何ですか？その価格・性能は自社と比べてどうですか？
5. **仕入れ・供給側**で、価格や条件を握っている相手はいますか？（供給業者が少数か、代わりが効かない部材か、乗り換えコストは）
6. **顧客側**の交渉力はどうですか？（特定の大口顧客に依存していないか、顧客は簡単に他社へ乗り換えられるか、価格にどれだけ敏感か）
7. **業界内の競争**はどれくらい激しいですか？（競合の数・規模、業界は成長しているか停滞か、価格競争になっていないか、差別化は効いているか）
8. 各力について、**印象でなく裏づけられるデータ・事実**はどこまでありますか？（集中度・シェア・成長率・スイッチングコスト等。未確認はどれか）
9. この業界で、**補完的な製品/サービスや、提携できる相手**は存在しますか？（ゼロサムでなく市場を広げる余地の確認）

## 出力フォーマット

ALWAYS この2段構えで出力する（構造診断→戦略化）。各力は必ず**強/中/弱＋根拠**で示す。

```
【5フォース分析】目的: <決めたいこと> ／ 業界スコープ: <製品・顧客・地理・チャネル>

  1. 新規参入の脅威   [強/中/弱]  根拠: <参入障壁の状況（資本・規制・ブランド・スイッチングコスト等）>
  2. 代替品の脅威     [強/中/弱]  根拠: <同ニーズを満たす別手段・価格対性能・乗り換え傾向>
  3. 売り手の交渉力   [強/中/弱]  根拠: <供給業者の集中度・希少性・スイッチングコスト>
  4. 買い手の交渉力   [強/中/弱]  根拠: <顧客の集中度・価格感応度・スイッチングコスト>
  5. 既存競合の敵対   [強/中/弱]  根拠: <競合数・成長率・差別化・退出障壁>

【総合判断（業界の魅力度）】<5つを俯瞰した収益性の見立て：構造的に儲かるか／薄いか>
【収益を圧迫する主因】<最も強い力＝どこに価値が流出しているか>
【打ち手（ポジショニング）】<主因に対し力を弱める/避ける戦略。防御=障壁/スイッチングコスト、攻勢=競合の弱み、差別化、統合 等>
【次の一手】<検証すべき仮説・意思決定・アクションを1〜3個>
【未確認の前提】<データで裏取りが要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。ある**都市部の宅配専業クラウドキッチン（配達のみの飲食）**が
新規参入を検討する場面。

- **手順①目的・スコープ**: 目的=「この業態に参入すべきか」。業界スコープ=「特定都市の、配達専用・単一ブランドの調理宅配」。
- **手順②新規参入の脅威 [強]**: 初期投資が比較的小さく、厨房は間借り可能、ブランドや特許の障壁が薄い→**参入は容易＝脅威は強い**。
- **手順③代替品の脅威 [強]**: 内食（自炊）、中食（総菜・冷凍）、店舗のテイクアウトなど、同じ「食事を済ませる」ニーズを
  満たす手段が豊富で価格対性能も競合的→**脅威は強い**。
- **手順④売り手の交渉力 [中〜強]**: 食材供給は代替が効くが、**配達プラットフォームが集客・配達を握る**なら、その手数料が
  実質的な「売り手の力」として利益を圧迫し得る→**中〜強**。
- **手順⑤買い手の交渉力 [強]**: 顧客はアプリ上で他店へ**ワンタップで乗り換え可能**、価格・レビューに敏感、スイッチングコストが低い→**強い**。
- **手順⑥既存競合の敵対 [強]**: 参入が容易ゆえ多数がひしめき、差別化しにくくクーポン等の価格競争に陥りやすい→**強い**。
- **手順⑦総合判断**: 5つの力の多くが強く、**構造的に収益性が薄い（魅力度が低い）土俵**。素の参入では利益が出にくい。
- **手順⑧打ち手**: 力を弱める設計が必要——(a)代替・競合と差別化できる**独自メニュー/ブランド**、(b)自社アプリや定期購入で
  **買い手のスイッチングコストを作る**、(c)プラットフォーム依存（売り手の力）を薄める直販チャネル、(d)価格競争を避ける高付加価値化。
- **次の一手**: 「独自ブランド＋直販での再購入率」を小さく試し、買い手の力を弱められるかを検証する。
- **未確認の前提**: 都市の実需要規模、プラットフォーム手数料の実水準、再購入率——実データで裏取りが要る（印象で進めない）。

## 相性（組み合わせると効く）

- `swot`: 5フォースで洗い出した業界の脅威（外部）を、SWOTの機会・脅威(O/T)に統合し、自社の強み/弱みと掛け合わせて戦略化する。
- `pest`: 5つの力を動かす**マクロ要因**（政治・経済・社会・技術）を先に押さえ、参入障壁や代替の変化の背景を捉える前工程。
- `3c`: 市場・競合・自社の3視点。5フォースの「競合」「買い手」を、より自社目線の打ち手に翻訳する。
- `vrio`: 業界が儲かるか（5フォース）とは別に、自社の資源が**持続的な競争優位**かを検証。業界分析と自社分析の混同を防ぐ相棒。
- `value-chain`: 収益を圧迫する力（例: 売り手が強い）に対し、自社の価値連鎖のどこで対抗・差別化できるかを具体化する。
- `ansoff`: 業界の魅力度が低い場合の、新市場/新製品への展開など成長の方向を選ぶ続き。
- 揺さぶり枠として `reverse-assumption`（「参入障壁は高い」等の前提を反転させ機会を探す）や
  `premortem`（参入後の失敗要因を先回り）を添えると、静的・ゼロサムな見立ての盲点を突ける。

- 「業界＝事業ライン(line-of-business)レベルで使う」というスコープ限定はPorterの指摘に基づくが、具体的な線引きは対象ごとに要判断。
