# ハーズバーグの二要因理論

## 概要

二要因理論（動機づけ・衛生理論 / Motivation-Hygiene Theory）は、職場の**満足を生む要因**と
**不満足を生む要因**は**別種**である、と主張するフレームワーク。核心は次の一文に集約される——
**「満足の反対は"不満足"ではなく"満足がない状態"。不満足の反対は"満足"ではなく"不満足がない状態"」**。
満足と不満足は同一直線上の両端ではなく、**独立した2つの連続体**として扱う。

| 種類 | 何に効くか | 性質 | 代表要因 |
|---|---|---|---|
| **動機づけ要因**（motivators／満足要因） | 満足↑・やる気↑ | 仕事の**内容**に内在（intrinsic） | 達成・承認・仕事そのもの・責任・昇進・成長 |
| **衛生要因**（hygiene／不満足要因） | 不満足↓（満たしても満足は生まない） | 仕事の**環境**（extrinsic） | 給与・会社の方針/管理・監督・上司/同僚との関係・労働条件・地位・雇用の安定・個人生活 |

- **核となる考え方**: 衛生要因を改善しても、不満足を「マイナスからゼロ（中立）」に戻すだけで、
  積極的な満足・動機づけ（プラス）は生まれない。真のやる気は、**仕事そのものに動機づけ要因を
  組み込む**ことでしか生まれない。ここから **職務充実（job enrichment）** の思想が導かれる。
- **「動き」と「動機づけ」の区別**: 賃上げ・罰・報酬で人を動かすのは、外から尻を蹴る **KITA
  （Kick In The Ass）** による **動き（movement）** に過ぎず、繰り返し刺激が要る（=電池）。
  内発的な **動機づけ（motivation）** は自家発電（=発電機）で、仕事の中身から生まれる。
- **出自（諸説あり・要確認扱い）**: 心理学者 **Frederick Herzberg**（生没 1923–2000 とされる）が
  Bernard Mausner・Barbara B. Snyderman と行った研究。原典は **『The Motivation to Work』(1959)**。
  ピッツバーグ地域の**技術者・会計士 約203名**に、Flanagan の**臨界事象法（Critical Incident
  Technique）**で「仕事で非常に良い/悪いと感じた出来事」を語らせ分析した。実務普及の中核は
  HBR論文 **"One More Time: How Do You Motivate Employees?"（1968、2003再掲）**。
  （※サンプル数・年号・要因リストの厳密表現は資料間で揺れる → 出典・要確認項目参照。）

## いつ使う / 使わない

**使う（適する状況）**
- 「**給与や待遇を改善したのに、やる気が出ない/離職が止まらない**」——最も効くケース。満足と不満足の
  混同を解き、打ち手を「衛生の是正」と「動機づけの付与」に振り分ける。
- **エンゲージメント・定着率・モチベーションの診断**。何が不満（衛生）で、何がやる気の源泉（動機づけ）
  かを棚卸ししたいとき。
- **職務設計・職務充実（job enrichment）**の検討。責任・裁量・成長機会を仕事に組み込む再設計。
- **サーベイ設問・1on1・評価/報奨制度の観点出し**。二要因を設問や対話の骨格に使う。

**使わない / よくある誤用（アンチパターン）**
- **「不満を消せば満足が生まれる」と取り違える**——最頻の誤用。衛生改善は不満足をゼロにするだけ。
  給与・制度・オフィスを良くしても、動機づけ要因（達成・成長等）が無ければやる気は出ない。
- **衛生要因を軽視して"やりがい"だけ説く**——逆の誤用。給与や人間関係の不満（衛生）を放置したまま
  「成長できる仕事だ」と説いても、不満が噴出して動機づけが効かない。**衛生は土台、動機づけは上物**。
- **満足＝生産性と短絡する**——本理論は元来「職務満足」の研究。満足が高くても生産性が上がるとは
  限らない（相関は弱いとの指摘）。満足・動機づけ・業績を同一視しない。
- **給与を単純に衛生へ固定する**——給与は主に衛生だが、業績連動・昇給が承認/達成の signal として
  動機づけ的に働く場面がある。文脈で二重性を見る。
- **個人差・文脈を無視した機械適用**——何が動機づけになるかは個人・職種・文化・キャリア段階で変わる。
  白書的リストの丸写しは危険。
- 精密な因果分析・定量最適化・金銭的インセンティブ設計の唯一の根拠には不向き。他理論で補完する。

## 前提と限界

- **前提**: 「満足が低いのか、不満足が高いのか」を**分けて観測できる**こと。両者を1本の満足度スコアで
  測ると二要因の切り分けができない。対象（個人/チーム/職種）と、扱う問題（離職・やる気・職務設計）を
  1つに定めること。
- **限界（批判を踏まえて）**:
  - **手法依存の批判（最重要）**——臨界事象法は**自己奉仕バイアス**を誘発しうる。人は良い出来事を
    自分の達成（内的＝動機づけ）に、悪い出来事を環境（外的＝衛生）に帰属しがちで、**二要因の分離が
    手法の産物**である可能性が指摘される。別手法だと二分が再現しにくいとの追試批判がある。
  - **サンプルの偏り**——対象がホワイトカラー専門職（技術者・会計士）。ブルーカラー・他文化・他世代
    への一般化には慎重を要する。
  - **満足・動機づけ・生産性の混同**——三者は別概念。満足の向上が業績を保証しない。
  - **要因の重なり**——給与のように衛生と動機づけの両面を持つ要因があり、二分は理念型（割り切り）。
- これらの限界は、**個人差はGROW等の対話で補う / 職務充実は職務特性モデル(JCM)で精緻化する /
  欲求段階の対比にはマズローを併用する / 施策の失敗要因はプレモータムで先回りする**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **対象と問題を1つに固定する。** 誰の（個人/チーム/職種）、何を（離職・やる気低下・職務再設計）
   扱うかを明文化する。なぜ: 対象が曖昧だと衛生/動機づけの棚卸しが総花的になり打ち手に繋がらない。
2. **不満足の源泉（衛生要因）を洗い出す。** 給与・方針/管理・監督・上司/同僚/部下との関係・労働条件・
   地位・雇用の安定・個人生活について、**現状で不満を生んでいるもの**を挙げる。
   なぜ: 衛生の欠如は動機づけ施策を無効化する「地雷」。先に地雷を特定する。
3. **満足の源泉（動機づけ要因）を洗い出す。** 達成・承認・仕事そのもの・責任・昇進・成長について、
   **今その仕事にどれだけ組み込まれているか**を点検する。
   なぜ: ここが薄いと、衛生を完璧にしても「不満はないが、やる気もない」中立状態で頭打ちになる。
4. **各要因を「満足軸」か「不満足軸」かで検算する。** 「これは満たすと"やる気が出る"のか、欠けると
   "不満が出る"だけなのか」を問う。なぜ: 給与・人間関係など**衛生を動機づけと誤認する**のが最大のミス。
   ここで弾く。給与の二重性（承認signalになる場面）も明記する。
5. **打ち手を2系統に振り分ける。**
   - **衛生の是正（不満足→中立）**: 不満の原因を除去・改善する（是正であって、やる気の源ではないと明記）。
   - **動機づけの付与（中立→満足）**: 仕事そのものに達成・責任・成長を組み込む。
   なぜ: 両者は目的が違う。混ぜると「給与を上げればやる気も出る」式の失敗に直結する。
6. **動機づけは職務充実（垂直的職務負荷）で具体化する。** 単に仕事量を増やす**職務拡大（水平）**では
   なく、**責任・裁量・達成機会を加える職務充実（垂直）**にする。HBRの7原則を指針にする——
   ①統制を一部外すが説明責任は残す ②本人の説明責任を増やす ③完結した作業単位を与える
   ④追加の権限・裁量を与える ⑤定期報告を上司経由でなく本人に直接届ける ⑥より難しい新課題を導入する
   ⑦専門的な課題を任せ専門家に育てる。なぜ: 「やりがいを持て」の精神論を、設計変更に落とすため。
7. **次の一手に落とす。** 衛生の是正1〜2件と、動機づけ（職務充実）の試行1件を、小さく試す形で決める。
   なぜ: 二要因理論は診断の枠。ここで止めると「分類して終わり」になる。個人差があるので小さく検証する。

## 壁打ち質問リスト

各要因を事実で埋めるために、利用者へ投げ返す問い。空欄を勝手に埋めず、まずこれで引き出す。

1. この相談で**最終的に解きたい問題**は何ですか？（離職を止めたい／やる気を上げたい／職務を再設計したい など、1つに）そして対象は誰ですか（個人・チーム・職種）？
2. 対象の人（たち）が**辞めたい/不満だと言う具体的な理由**は何ですか？（給与・上司・制度・労働条件・人間関係など＝衛生の候補）その根拠は本人の声ですか、推測ですか？
3. 直近で**改善した施策**（昇給・福利厚生・オフィス改善など）は何ですか？それで**やる気は実際に上がりましたか、不満が減っただけですか**？（衛生と動機づけの切り分けの要）
4. その仕事には、**達成感・承認・裁量（責任）・成長/学習の機会**が今どれだけありますか？直近で「良い仕事をした」と本人が感じた瞬間はいつ、なぜですか？
5. 本人が**任されている裁量の範囲**はどこまでですか？成果や失敗の**説明責任は本人**にありますか、それとも上司が握っていますか？（職務充実の余地を測る）
6. 承認・フィードバックは**誰から・どんな頻度**で届いていますか？成果の報告は本人に直接返っていますか、上司止まりですか？
7. その職場で「不満はないが、やる気もない（中立）」状態の人はいますか？いるなら、何が**動機づけ要因の欠如**を示していますか？
8. 動機づけになるものは人によって違います。この対象に固有の事情（キャリア段階・価値観・生活状況）で、**一般論が当てはまらない点**はありますか？

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。ある企業が、待遇を改善したのに若手の離職が続き
「やる気も上がらない」と悩む場面。

- **手順①対象と問題**: 対象＝若手の実務担当層、問題＝「離職を止め、やる気を上げたい」に固定。
- **手順②衛生要因（不満足の源泉）**: 面談で挙がった不満——給与水準への不安、承認の乏しい人間関係、
  細かく管理される業務（裁量が薄い）、繁忙期の労働条件。
- **手順③動機づけ要因（満足の源泉）**: 現状、達成感の実感が薄い／仕事が細切れで「自分の成果」が
  見えにくい／裁量（責任）が上司に集中／成長機会が定型業務に埋もれている。
- **手順④検算**: 「昇給」は満たしても不満が減るだけ＝衛生。ただし昇給が「評価された」という承認の
  signal になれば一部動機づけ的にも働く（給与の二重性を明記）。「裁量の欠如」は満たすとやる気が
  出る＝動機づけ側の問題、と切り分け。
- **手順⑤2系統に振り分け**:
  - ① 衛生の是正: 給与不安への説明（等級・昇給基準の透明化）、過度なマイクロマネジメントの緩和。
    ——これは不満をゼロに戻す是正で、やる気の源ではないと明記。
  - ② 動機づけの付与: 仕事を「自分の成果」と感じられる形に再設計する。
- **手順⑥職務充実（垂直的負荷）**: 細切れ業務を**完結した作業単位**にまとめて任せる（原則③）／
  成果の**報告を上司経由でなく本人に直接**返す（原則⑤＝承認）／裁量と説明責任を本人に寄せる
  （原則②④＝責任）／定型業務の中に**新しい難しい課題**を1つ足す（原則⑥＝成長）。
- **手順⑦次の一手**: 衛生（昇給基準の説明＋管理の緩和）を先に是正しつつ、1チームで「完結単位＋本人
  直接報告」の職務充実を小さく試し、やる気と定着の変化を観察する。
- **未確認の前提**: 離職の主因が本当に「やる気」なのか「他社条件」なのか、本人の声で裏取りが要る。
  何が動機づけになるかは個人差があるため、一律施策にせず試行で確かめる（推測のまま広げない）。

## 相性（組み合わせると効く）

- `maslow`: 欲求段階説と対で使う定番。衛生要因≒低次欲求、動機づけ要因≒高次欲求として対比し、
  「今どの層の欠乏を扱っているか」を立体化する（別系統の理論だが補完的）。
- `grow-model`: 何が動機づけになるかは個人差が大きい。1on1のGROW対話で、その人固有の達成・成長の
  源泉を引き出し、二要因の空欄を本人の言葉で埋める。
- `mckinsey-7s`: 衛生要因（制度・方針・組織構造＝Systems/Structure）と動機づけの担い手（人・スキル・
  共有価値）を組織全体の7要素に位置づけ、施策の打ち所を広く点検する。
- `five-whys`: 「なぜ辞めるのか／なぜ不満なのか」を掘り、表層の不満（衛生）の奥にある真因を特定する
  前工程。二要因の分類前に因果を確かめる。
- `kgi-kpi-okr`: 動機づけ（達成・成長）を、本人が意味を感じられる目標・指標に落とす。職務充実の
  「達成が見える」設計を目標設定に接続する。
- 揺さぶり枠として `premortem`（職務充実施策が失敗する要因を先回り）や `devils-advocate`
  （「衛生を良くすれば満足が出る」という思い込みを疑う）を添えると、誤用を防ぎ洞察が増す。
