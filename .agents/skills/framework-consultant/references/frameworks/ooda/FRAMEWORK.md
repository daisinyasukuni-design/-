# OODAループ

## 概要

OODAループは、**観察(Observe) → 情勢判断/方向づけ(Orient) → 意思決定(Decide) → 行動(Act)** の
4局面を連続的に回し、不確実・変化が速い・相手（競合や環境）のいる状況で「相手より速く、かつ的確に」
適応するための意思決定ループ。米空軍大佐 John Boyd が体系化した。

```
観察(O) ──▶ 情勢判断(Orient)★ ──▶ 意思決定(D) ──▶ 行動(A) ──┐
  ▲             │  ▲                                        │
  │             │  └── 熟達時は Decide を飛ばす直結（暗黙の誘導・統制）
  └─────────────┴──────── フィードバック（行動の結果を観察に戻す）◀──┘
```

- **核となる考え方**: OODAは「きれいな4段の線形サイクル」ではない。**Orient（情勢判断・方向づけ）が全体を
  支配する重心（Boyd は Schwerpunkt と呼んだ）**であり、観察を解釈・意味づけして後続の決定と行動を規定する。
  同じ観察でも Orient が違えば別の決定になる。**速さそのものより、方向づけの質が本質**——雑なOrientで速く
  回せば「速い誤り」を量産する。
- **暗黙の誘導・統制(Implicit Guidance & Control)**: 現実が熟達した心的モデルに合致するとき、Orient から
  Act へ **Decide を飛ばして即応する高速経路**がある。習熟・共通理解があるほどこの経路が使える。
- **相手のループの内側に入る(tempo)**: 自分のOODAを相手より速く・意外な形で回すと、相手の判断が現実に
  追いつかず混乱する。優位はここで生まれる（対立・競争がある場面での中核概念）。
- **出自（年号・人名は要確認）**: 考案者は **John Boyd**（USAF戦闘機パイロット／ペンタゴンの改革者、
  1927–1997 とされる）。1970年代前半に着想。Boyd は書籍を残さず**ブリーフィングで思想を伝えた**ため、
  一次資料は論考 "Destruction and Creation"(1976)、講義群 "Patterns of Conflict"、唯一図示された
  "The Essence of Winning and Losing"(1995) など。年号・帰属は資料で揺れるため断定を避ける（→出典・要確認）。

## いつ使う / 使わない

**使う（適する状況）**
- 競合の新製品・値下げ・新規参入など、**外部の動きに素早く即応**する一手を決めたいとき。
- トラブル・障害・炎上・災害など、**先が読めない危機下でとにかく動きながら立て直す**必要があるとき。
- 計画を精緻に立てる時間がなく、**不完全な情報のまま意思決定して動き、走りながら修正**したいとき。
- スタートアップ・新規事業・現場のリアルタイム判断など、**変化が速く一発で当てられない**領域。
- 「分析ばかりで動けない（分析麻痺）」状態を、観察→行動→観察の小さな回転で崩したいとき。

**使わない / よくある誤用（アンチパターン）**
- **速さの過信（最頻の誤用）**——「相手より速く回す」だけに矮小化する。Boyd は Orient が最重要と明言した。
  方向づけが雑なまま速く回すと、速く間違え続ける。**速さは目的でなく、良い方向づけの上でのみ効く**。
- **線形手順化**——「O→O→D→Aを1回きちんと通す」チェックリストとして扱う誤り。実際は並行・多方向の
  フィードバックがあり、熟達時は Decide を飛ばす。**ループであり手順書ではない**。
- **Orient の飛ばし**——観察した事実をそのまま決定に直結し、解釈・前提・バイアスの点検を省く。ここを省くと
  過去の心的モデルの惰性で動いてしまい、環境変化に負ける。
- **観察と解釈の混同**——「事実」と「自分の解釈」を分けずに観察に書く。生データが解釈で汚れ、判断が歪む。
- **長期の羅針盤の代替にしてしまう**——OODAは局面適応であり、「そもそもどこを目指すか」は与えない。
  短期最適の連打が方向性を失わせることがある（→ backcasting 等で目的地を別途持つ）。
- 定型・標準化された反復業務の最適化、時間的余裕があり精緻な定量最適が要る意思決定、Orient を養う経験・
  データが乏しい領域には不向き。**そこは PDCA・意思決定マトリクス等に譲る**。

## 前提と限界

- **前提**: (1) 変化・不確実性・対立があり、一発で正解を出すより「速い学習」が効く局面であること。
  (2) 観察を意味づける **Orient の土台**（経験・データ・複数視点）がある程度あること。乏しければ、速く回す前に
  観察と前提点検に時間を割く。(3) 行動の結果を**観察に戻すフィードバック**が回せること（結果が見えないと
  ループが閉じない）。
- **限界（批判を踏まえて）**:
  - **処方箋が薄い**——Boyd は原理を語り、具体手順をほぼ残さなかった。実務適用は解釈に依存し、
    「速く回せ」という精神論に堕ちやすい（Commoncog はこれを "RUN HARDER" 型の空虚な助言と批判）。
  - **証拠は限定的**——検証された適用というより「もっともらしい議論(plausible argument)」に留まるとの評価が
    ある。特定の戦果（例: 湾岸戦争）への寄与も係争的で、断定できない。
  - **曖昧さ**——航空史家 Michael Hankins は「OODAは曖昧で、支持者も批判者も見たいものを見られる」「直感的
    過程の一記述に過ぎず、誤りではないが唯一無二でも深遠でもない」と評す。**万能の魔法ではない**前提で使う。
  - **短期適応バイアス**——高速適応ゆえ、長期の方向性・不可逆な大決定には向かない。可逆な一手には強いが、
    不可逆な賭けはOODAの回転だけで決めない。
- これらの限界は、**Orient を複数視点で強化する(six-hats) / 前提を疑う(devils-advocate) / 目的地を別途持つ
  (backcasting) / 安定期は PDCA に切り替える**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップに「なぜ」を添える。OODAは反復前提——1周で終わらせず、行動の結果で必ず回し直す。

1. **局面と制約を1行で固定する。** 何に適応するのか（競合の一手／障害／市場変化）と、使える時間・可逆性
   （やり直せる決定か）を明示する。なぜ: 制約が決まらないと「速く回す」意味が定まらず、過剰分析か拙速に振れる。
2. **観察(Observe)——事実だけを集める。** 相手の動き・数字・現場の兆候・環境変化を、**解釈を混ぜず**に列挙する。
   なぜ: 生データが解釈で汚れると、後続すべてが歪む。「事実」と「自分の推測」を物理的に分けて書く。
3. **情勢判断(Orient)——観察を意味づける（最重要・時間をかける）。** 次を明示的に行う:
   - 観察が**何を意味するか**を、複数の解釈で書き出す（1つに飛びつかない）。
   - その解釈を支えている**自分の前提・心的モデル**を言語化し、「それは今も正しいか」を疑う。
   - **分析と統合**: 状況を要素に分解し（分析）、別領域の知見や過去の型と組み替えて新しい見立てを作る（統合）。
   なぜ: ここが Boyd の言う重心。同じ観察でも Orient 次第で決定が正反対になる。ここを厚くするのが最大の投資。
4. **意思決定(Decide)——採る一手と捨てる案を決める。** 可逆な決定は速く、不可逆な決定は一段慎重に。
   「今の見立てが外れていた場合の兆候」も同時に決める。なぜ: 決定を仮説として扱い、反証条件を先に置くことで
   次の観察が鋭くなる。
5. **行動(Act)——小さく、速く、観察に戻せる形で動く。** 大きく賭けず、結果が観察できる最小の一手を打つ。
   なぜ: 行動は情報収集でもある。小さく動けばループが速く閉じ、誤りの傷が浅い。
6. **フィードバックで回し直す。** 行動の結果を観察(2)に戻し、特に Orient を更新する。前提が外れていたら
   見立てを捨てて作り直す。なぜ: OODAの価値は1周でなく回転にある。更新を止めた瞬間、ただの直感になる。
7. **（対立局面のみ）相手のループに働きかける。** 自分が速く回るだけでなく、先手・意外性・撹乱で相手の判断を
   現実から遅らせられないか考える。なぜ: 競争優位は「相手のループの内側に入る」ことで生まれる。

## 壁打ち質問リスト

各局面を事実で埋めるために利用者へ投げ返す問い。空欄を勝手に埋めず、まずこれで引き出す。

1. いま**何に適応しようとしていますか**？（競合の一手／トラブル／市場変化など）そして**決断までに使える時間**と、
   その決定は**やり直せますか（可逆）／後戻りできませんか（不可逆）**？
2. 【観察】いま起きている**事実**を、解釈を混ぜずに挙げるとどれですか？（相手の動き・数字・現場の兆候）
   そのうち**確認済みの事実**と、まだ**あなたの推測**なのはどれですか？
3. 【情勢判断】その観察は**どう解釈できますか——できれば2つ以上**の見方を挙げてください。あなたが自然に
   採った解釈は、どんな**前提・思い込み**の上に立っていますか？
4. 【情勢判断】その前提は**今も正しい**と言えますか？最近の変化で**崩れている可能性**はどこですか？
   （過去の成功体験や社内の常識が、今の判断を縛っていないか）
5. 【意思決定】採ろうとしている一手は何で、**捨てる選択肢**は何ですか？その判断が**外れていたと分かる兆候**
   （反証サイン）は具体的に何ですか？
6. 【行動】結果を早く観察できる**最小の一手**は何ですか？いきなり大きく賭けず、小さく試せる形にできますか？
7. 【回し直し】**いつ・何を見て**この判断を見直しますか？（次に観察し直すトリガーや期限）
8. 【対立局面のみ】相手（競合・環境）に対して、**先手・意外性・撹乱**で優位を取れる余地はありますか？

## 出力フォーマット

ALWAYS この型で出力する（スナップショット → テンポと次サイクル）。Orient を最も厚く書く。

```
【OODAスナップショット】目的/局面: <何に適応するか> ／ 制約: <使える時間・可逆/不可逆>
  観察(O)      : - <事実のみ。解釈を混ぜない> …
  情勢判断(Orient)★: - 見立て（複数解釈）: <解釈A / 解釈B>
                    - 前提・心的モデル: <その見立てを支える前提／疑う点・バイアス>
                    - 分析と統合: <分解して見えた要素／別領域・過去の型からの再構成>
  意思決定(D)  : 採る一手: <…> ／ 捨てる案: <…> ／ 反証サイン: <外れの兆候>
  行動(A)      : <結果を観察に戻せる最小の一手>

【テンポと次サイクル】
  再観察のトリガー/期限 : <いつ・何を見て回し直すか>
  相手/環境への働きかけ : <先手・意外性・撹乱があれば（対立局面のみ）>
  誤りの兆候と撤退線    : <どうなったら見立てを捨ててOrientをやり直すか>

【未確認の前提】<推測と事実の切り分け。壁打ちで埋める点>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。地域の学習塾が、近隣に大手チェーンの新校が開校し、
月謝の割安さを打ち出してきた局面に即応する場面。

- **手順①局面と制約**: 適応対象=大手チェーンの新規参入と低価格訴求。制約=次の入塾シーズン前（数週間）に
  一手を打つ必要／広告や値下げは可逆、校舎移転や大量採用は不可逆。
- **手順②観察(O・事実のみ)**: 新校がチラシで低月謝を訴求。自塾の体験申込が前年同時期より鈍い。既存の
  保護者から料金を尋ねる問い合わせが数件。※「生徒が大量流出する」はまだ推測で、事実ではない。
- **手順③情勢判断(Orient・厚く)**:
  - 見立て（複数解釈）: (A)価格競争が始まった、(B)保護者の本当の関心は価格でなく「合格実績と面倒見」で、
    価格は比較の入口に過ぎない——どちらとも取れる。
  - 前提の点検: 「安さで負けたら終わり」という前提は、過去の別業態の記憶に引きずられていないか。自塾の
    強み（少人数・個別対応・地元校への実績）を価格に還元して見ていないか。
  - 分析と統合: 保護者の意思決定を「価格／実績／通いやすさ／安心感」に分解し、大手が取りにくい「安心感・
    個別対応」に自塾の資源を組み替えられないか。
- **手順④意思決定(D)**: 採る一手=値下げ競争に乗らず、面倒見と実績を可視化する（可逆な販促）。捨てる案=
  対抗値下げ（不可逆に近い収益毀損）。反証サイン=販促後も体験申込の鈍化が続き、離塾理由の最上位が「価格」なら
  見立て(B)は誤り。
- **手順⑤行動(A・最小の一手)**: 全面刷新でなく、既存保護者向けに個別面談と実績の説明会を小さく告知して
  反応を見る。
- **手順⑥回し直し**: 面談での質問内容と申込の動きを観察に戻す。「価格」への言及が想定より多ければ Orient を
  作り直す。
- **手順⑦相手への働きかけ**: 大手が動きにくい「地元密着・個別対応」を早く前面に出し、価格軸の土俵から外す。
- **未確認の前提**: 保護者が本当に重視する軸、鈍化の真因——面談で実データを取るまで推測のまま突き進まない。

## 相性（組み合わせると効く）

- `pdca`: OODAは不確実・高テンポの適応、PDCAは標準化された反復改善。**局面で切り替える**（初期/危機はOODA、
  安定後はPDCA）と、速さと精度を両取りできる。両者の「late commitment vs early commitment」の対比が指針。
- `decision-matrix`: OODAの意思決定(D)で、時間に余裕があり選択肢が並ぶときに評価軸で採点し、勘だけの決定を補強する。
- `premortem`: 行動(Act)に踏み切る前、その一手が失敗した未来を先回りして反証サイン・撤退線を具体化する（揺さぶり枠）。
- `six-hats`: 情勢判断(Orient)の質を上げる中核の相棒。複数視点を強制的に入れ、単一解釈への飛びつきを防ぐ。
- `devils-advocate`: Orient の前提・心的モデルをわざと疑い、過去の成功体験による惰性を弾く（揺さぶり枠）。
- `backcasting`: OODAが欠く「長期の目的地」を与える。短期適応の連打が方向性を失わないよう、あるべき未来を別に固定する。
- `lean-startup-mvp`: Build-Measure-Learn は OODA と同型。行動(Act)を「最小の実験」に具体化する実装レシピとして使える。
