# PEST / PESTLE分析

## 概要

PEST分析は、自社ではコントロールできない**マクロ外部環境**を4つの視点で走査(scanning)し、
機会と脅威の源泉を体系的に洗い出すフレームワーク。4視点は頭字語のとおり：

| 視点 | 見るもの（例） |
|---|---|
| **P**olitical（政治） | 政策・規制・税制・通商/関税・政治情勢の安定性（国政/地方/国際/業界規制） |
| **E**conomic（経済） | 景気・金利・為替・インフレ・賃金・雇用・与信・消費動向 |
| **S**ocial（社会） | 人口動態・価値観・ライフスタイル・健康志向・働き方・文化 |
| **T**echnological（技術） | 破壊的技術・自動化/AI・DX・代替技術・技術変化の速度 |

- **PESTLE / PESTEL** は上記に **L**egal（法規制：雇用法・消費者保護・製品安全・輸出入等）と
  **E**nvironmental（環境：脱炭素・資源制約・持続可能性・倫理的調達）を加えた6視点の拡張。
  他に STEEP / STEEPLE(+倫理) / STEEPLED(+人口統計) / SLEPT / STEER など多数の派生があるが、
  **追加された文字は網羅性を上げるための拡張**であって別物ではない。事業の性質に応じて選ぶ。
- **核となる考え方**: 業界・競合・自社（ミクロ）の手前にある「マクロ環境」を構造化して見ることで、
  思い込みや盲点を減らし、戦略の前提を問い直す。分類そのものが目的ではなく、外部変化を抜け漏れなく
  捕捉し、それが**自社にどう効くか（cause-and-effect）**を読むためのチェックリスト。
- **出自（諸説あり・要確認）**: 1967年、ハーバードの **Francis J. Aguilar** が著書
  『Scanning the Business Environment』で、経営者が注目すべき外部情報として Economic / Technical /
  Political / Social の4カテゴリを提示した——ただし当時の頭字語は **「ETPS」** であり、**Aguilar自身は
  「PEST」という語を使っていない**。その後 Arnold Brown（Institute of Life Insurance）が
  **STEP**（Strategic Trend Evaluation Process）に並べ替え、さらに現在の「PEST」順へ定着したとされる。
  「PESTの考案者=Aguilar」は後年の通説で、誰がPESTの並びを定着させたかは資料により曖昧。近年の学術研究
  （Puyt ら）はこの起源譚の史実性自体を再検証している。**起源は断定せず不確実性を前提に扱う**（→出典・要確認）。

## いつ使う / 使わない

**使う（適する状況）**
- 新規事業・新市場参入・海外進出の前に、外部環境の**追い風/向かい風を体系的に把握**したいとき。
- 中期経営計画・事業計画の初期に、**戦略の前提となるマクロトレンド**を棚卸ししたいとき。
- SWOTの機会(O)・脅威(T)を埋める材料が薄く、**外部要因を漏れなく洗いたい**とき（PESTはSWOTの外部側の入力工程）。
- 規制・技術・社会の変化が激しい業界で、**見落としている構造変化がないか点検**したいとき。
- シナリオプランニングの前段として、**不確実性の高いドライバー**を特定したいとき。

**使わない / よくある誤用（アンチパターン）**
- **チェックリスト化して大量列挙で終わる**——最頻の失敗。40〜60項目を優先順位なしで並べても戦略ではなく
  "busywork"（si-labs）。因果（その要因が自社にどう効くか）と優先順位づけの無い羅列は使えない。
- **業界内の競争構造をこれで見ようとする**——競合・買い手・売り手・代替品・新規参入は5フォースの領域。
  PEST（マクロ）は業界内のミクロ競争や3Cの代わりにはならない。
- **内部資源（強み・弱み）を無視して片手落ちにする**——PESTは外部のみ。単独では戦略に不十分で、SWOT/VRIOと併用する。
- **現状の静的スナップショットで止める**——マクロは流動的。過去の説明はできても将来予測には向かない。定期更新が前提。
- **政治=国政に限定する**——地方自治体・国際機関・業界規制など多層で捉えないと漏れる。
- **環境(E)をCSRのお題目扱いにする**——Environmentalを「社会貢献の話」に矮小化し、戦略要因として扱わない。
- 短期の戦術判断や、優先順位が既に定まった実行フェーズには過大。他フレームで補完する。

## 前提と限界

- **前提**: 分析のスコープ（対象事業・地域・時間軸）を**1つに固定**していること。曖昧だと因子が発散して
  羅列に堕ちる（手順①が要）。各因子を裏づける一次情報（政府統計・中央銀行・規制当局・業界レポート等）に
  アクセスできること。無ければ壁打ちで前提を明示し、推測と事実を分ける。
- **限界（批判を踏まえて）**:
  - **予測ではなく走査(scanning)**——因子の将来の動きや相互作用を自動では教えない。分析者の解釈に強く依存する。
  - **優先順位の欠如が最大の弱点**——情報過多で「どれが致命的か」が埋もれる。impact×probabilityでの重みづけが必須。
  - **認知バイアスに弱い**——確証バイアス・直近バイアス・集団思考・楽観バイアスが結果を系統的に歪める。
  - **相互作用を見落とす**——各カテゴリを独立に見ると、要因のカスケード（例: エネルギー高×労働力不足→自動化投資）を
    捉え損なう。単独では正当化されない優先度が、因子の重なりから初めて見える。
  - **時間軸の混同**——短期の事実（今の金利）と構造的トレンド（人口動態）を同列に混ぜると分析法が破綻する。
  - **高不確実性環境**では、PESTLE単独よりシナリオプランニングが有効な場合がある。
- これらは、**SWOTのO/Tへ流し込んで戦略化する / 業界構造は5フォースで補う / 内部はVRIO・3Cで補完する /
  未来視点はバックキャスティングで補う**ことで緩和できる（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **スコープと時間軸を1つに固定する。** 対象事業・地域・「今後3年」等と、支えたい意思決定（参入可否/投資判断/中計の前提）を明文化する。
   なぜ: スコープが曖昧だと因子が発散し、羅列で終わる最頻の失敗に直結する。
2. **カテゴリごとに因子を発散させる（P/E/S/T〔/L/E〕）。** 各カテゴリでまず最大8〜10個を出す。
   なぜ: 網羅性を担保するため。ただし列挙は途中工程であり、ここで止めない。
3. **各因子を「自社への含意」に翻訳する。** 単なる事実（例: 金利上昇）でなく、含意（→設備投資の資金調達コスト増）まで書く。
   なぜ: 因果（cause-and-effect）の無い列挙は戦略に使えない。PEST最大の失敗はここの欠落。
4. **機会/脅威に振り分け、各カテゴリ3〜5個に絞る。** 重要度の低いものを落とす。
   なぜ: 情報過多を防ぎ、示唆を濃くする。等価な長大リストは示唆を生まない。
5. **impact×probabilityで優先順位づけする。** 影響度1-5 × 発生確率1-5 = 優先スコア（1-25）。スコア帯で四象限に機械的に割り当てる：**≥15＝対処**、**8-14＝監視/シナリオ化**（影響大×確率低＝シナリオ化、影響小×確率高＝監視）、**<8＝無視**。ただし影響度≥4かつ確率≤2の因子は、積スコアに関わらず『シナリオ化』に割り当てる（高影響・低確率のテールリスクを無視に落とさないため）。上位5個に集中する。
   なぜ: 「どれが致命的か／機会か」を明示する肝。閾値を固定すると、採点者が変わっても四象限への振り分けがぶれず、出力の再現性が上がる。純粋な積スコアだけだと影響大×確率低の因子（例: 5×1=5）が『無視』に落ち、同じ手順の四象限規則と矛盾するため、軸ベースの例外で救う。
6. **因子間の相互作用（増幅・相殺・カスケード）を検討する。** 同じ打ち手を後押しする因子の重なりを探す。
   なぜ: 単独では正当化されない優先度が、相互作用から見えてくる。
7. **戦略的含意と次の一手に落とす。** 取りにいく機会・備える脅威・再検証すべき前提を1〜3個決め、SWOTのO/Tへ橋渡しする。
   なぜ: 走査はゴールでなく起点。ここで止めると「作って終わり」の典型に陥る。

## 壁打ち質問リスト

各カテゴリを事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この分析で**最終的に決めたいこと**（支えたい意思決定）は何ですか？ 対象事業・地域・時間軸（何年先まで）はどこに固定しますか？
2. **政治(P)**: 事業に効く政策・規制・税制・通商/関税・政治情勢の変化は何ですか？（国政だけでなく地方・国際・業界規制も含めて）
3. **経済(E)**: 景気・金利・為替・インフレ・賃金・消費動向で、この1〜3年に効きそうな変化はどれですか？
4. **社会(S)**: 人口動態・価値観・ライフスタイル・働き方の変化で、需要や採用に効くものは何ですか？
5. **技術(T)**: 破壊的技術・自動化/AI・DX・代替技術で、追い風/向かい風になりそうなものはどれですか？
6. **法規制(L)/環境(E)**（PESTLEで見る場合）: 新法・コンプラ・訴訟リスク／脱炭素・資源制約・サステナ要請で、対応が要るものはありますか？
7. 挙げた各因子は、自社に**どのくらいの影響度（1-5）**で、**どのくらいの確率（1-5）**で効きますか？（優先順位づけの材料）
8. **事実として確認できている因子**と、まだ**推測に留まる前提**はどれですか？（一次情報の裏取り状況）

## 出力フォーマット

ALWAYS この2段構えで出力する（走査 → 優先順位づけ・含意）。PESTかPESTLEかはスコープに応じて選ぶ。

```
【PEST/PESTLE 走査】スコープ: <対象事業/地域/時間軸> ／ 支える意思決定: <…>
  Political(政治):      - <因子> → <自社への含意（機会 or 脅威）>
  Economic(経済):       - <…>
  Social(社会):         - <…>
  Technological(技術):  - <…>
  (Legal 法規制):       - <…>          ※PESTLEのとき
  (Environmental 環境): - <…>          ※PESTLEのとき

【優先順位づけ（impact×probability）】上位5個に絞る
  因子           | 影響度(1-5) | 確率(1-5) | スコア | 機会/脅威 | 含意・打ち手
  <因子1>        |     5       |    5      |  25   |  脅威    | <…>
  <因子2>        |     …       |    …      |  …    |  …       | <…>
  ※例外: 影響度≥4かつ確率≤2の因子は積スコアが<8でも『シナリオ化』に置く（高影響・低確率のテールリスクを無視に落とさない）
  相互作用（カスケード）: <因子A×因子Bが同じ方向に効く 等>

【戦略的含意 / 次の一手】<取りにいく機会・備える脅威・再検証すべき前提を1〜3個>
【SWOTのO/Tへ】機会(O): <…> ／ 脅威(T): <…>（SWOTの外部側に橋渡し）
【未確認の前提】<一次情報で裏取りが要る点（推測のまま進めない）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の実数値・企業名は用いない）。国内の自動車部品サプライヤーが中期の投資方針を検討する場面。
※ 下の影響度・確率は「優先順位づけの型」を示すための例示であり、実データではない。

- **手順①スコープ**: 対象=同社の主力部品事業／地域=欧州・国内／時間軸=今後3〜5年。決めたいこと=どの領域に投資を寄せるか。
- **手順②③走査（因子→自社への含意）**:
  - Political: EV・通商をめぐる関税/産業政策の変化 → 国内・域内へのサプライチェーン回帰が相対的に有利化（機会）。
  - Economic: エネルギーコスト・金利の上昇 → 労働集約より自動化投資の合理性が上がる（脅威兼機会）。
  - Social: 労働人口の減少・採用難 → 省人化・自動化が中長期の前提に（脅威）。
  - Technological: EV/ソフトウェア領域の技術シフト → 自前開発か提携かの判断が必要（機会兼脅威）。
  - Legal: サステナ情報開示など規制強化 → 開示データ基盤の整備が必要（脅威）。
  - Environmental: CO2規制の強化 → 製品ポートフォリオをEV部品側へ再配分（機会）。
- **手順④絞り込み**: 影響が大きい「エネルギーコスト」「労働人口減」「環境規制」を主要論点に据える。
- **手順⑤優先順位づけ**: 3因子に差をつけて採点する（全部を最高点にしない）。エネルギーコスト高=影響度5×確率5=**25→対処**／労働人口減=4×5=**20→対処**／環境規制強化=5×3=**15→対処**（閾値ちょうど・確率がやや低くシナリオ化寄り）／技術シフト（EV/SW）=4×3=**12→監視/シナリオ化**で次点。差がつくことで「まず何に張るか＝自動化投資×国内回帰」が一意に定まる（全部25では優先順位が立たない）。
- **手順⑥相互作用**: 「エネルギーコスト高」と「労働力不足」が**"自動化投資"という同じ打ち手を共に後押しする**
  （単独では踏み切りにくい投資が、複数因子の重なりで優先度が上がる＝カスケード効果）。
- **手順⑦含意/次の一手**: (1)自動化投資を優先検討、(2)EV部品へのポートフォリオ再配分を仮説として検証、
  (3)「関税がどこまで国内回帰を後押しするか」を一次情報で裏取り。
- **SWOTへ**: 機会(O)=国内回帰・自動化の追い風／脅威(T)=技術シフト遅れ・規制対応コスト、としてSWOTに接続。
- **未確認の前提**: 各因子の実際の発生確率・影響度は市場データで裏取りが必要（推測のまま進めない）。

## 相性（組み合わせると効く）

- `swot`: PESTで洗った外部因子を機会(O)/脅威(T)としてSWOTに流し込む。**PESTはSWOTの外部側の入力工程**（直接の続き）。
- `five-forces`: PEST（マクロ）で捉えきれない**業界内の競争構造**（新規参入・代替品・売り手/買い手の交渉力・競合）を補完し、マクロ→業界の解像度を上げる。
- `3c`: 市場・競合・自社のミクロ視点で、PESTの含意を具体的な事業判断に落とす。
- `backcasting`: 望ましい未来から逆算し、PESTの弱点である「現状延長・未来視点の欠如」を補正する（揺さぶり枠）。
- `premortem`: 優先した打ち手が失敗する前提で、外部要因の読み違い・見落としを先回りする（揺さぶり枠）。
- `devils-advocate`: 「その機会/脅威判定は本当か」「確証バイアスで都合よく読んでいないか」を突く（揺さぶり枠）。
