# ディシジョンツリー（決定木・期待値分析）

## 概要

ディシジョンツリーは、不確実性を伴う意思決定を**分岐図**に描き、各経路の**期待値（EMV: Expected Monetary Value）**を
計算して、**期待値が最大になる選択と経路**を導くフレームワーク。「何を選べるか（自分の裁量）」と
「何が起こりうるか（確率的な運）」を明示的に分け、**選択→不確実な結果→次の選択…**の連鎖を1枚で扱う。

| ノード | 記号 | 意味 | 畳み込みのルール |
|---|---|---|---|
| **決定ノード** | □（四角） | 自分が選べる分岐（裁量・agency） | 後続枝の**最大EMVを取る（max）** |
| **チャンスノード** | ○（丸） | 不確実な事象。各枝に確率、合計=1.0 | **期待値を取る（Σ 確率×ペイオフ）** |
| **終端ノード** | △（三角）／ペイオフ | 経路の最終的な金額 | そのまま値になる |

- **核となる考え方**: 意思決定を「裁量（□）」と「運（○）」に分解し、右端のペイオフから**左へ畳み込む
  （ロールバック／フォールドバック＝後方帰納 backward induction）**。○では期待値を、□では最大値を取り、
  最初の決定ノードに達したとき、たどってきた枝が**期待値最大の最適経路**になる。
- **EMVの式**: あるチャンスノードの EMV ＝ Σ(枝の確率 × その枝のペイオフ)。
  「良い結果の確率×良い金額」＋「悪い結果の確率×悪い金額」を足したもの。
- **EMVの正体（誤解しやすい）**: EMVは**長期に繰り返したときの平均**であって、**その1回の予測値ではない**。
  1回勝負では期待値プラスでも大損しうる。だから分散（ばらつき）とリスク態度は別途見る（→前提と限界）。
- **情報と段階化まで扱える**: 「調査にいくら払ってよいか（EVPI）」「今決めるか、小さく試して様子を見て
  から決めるか（段階投資・情報の価値）」を、同じ木の中で数値化できるのが他の優先順位ツールとの決定的な差。
- **出自（要確認あり）**: **John F. Magee** が **1964年**の HBR 論文で経営層に広めた
  （"Decision Trees for Decision Making" と設備投資版 "How to Use Decision Trees in Capital Investment"）。
  理論的土台の**決定分析(decision analysis)**は **Ronald A. Howard**（1966、用語の創始）と
  **Howard Raiffa**（1968）が体系化。リスク態度は **von Neumann–Morgenstern**(1944) の期待効用に接続する。

## いつ使う / 使わない

**使う（適する状況）**
- **結果が確率的**な投資・撤退・GO/NO-GO を、勘でなく**期待値**で判断したいとき。
- **一括か、段階か**（小さく試す→伸びたら拡大、のステージゲート）を、様子見の価値込みで比較したいとき。
- **テスト・パイロット・追加調査にお金をかける価値**があるか（払ってよい上限）を知りたいとき。
- 「選択→結果→次の選択」という**逐次的な分かれ道**を、後の手も見越して今の一手を決めたいとき。
- 複数のリスキーな案（賭け）を、**期待値と下振れ**の両面で並べて説明可能に選びたいとき。

**使わない / よくある誤用（アンチパターン）**
- **確率もペイオフも数値で置けない**——深い不確実性で確率が当てずっぽうなら、EMVは幻。scenario-planning で
  複数未来を物語る方が誠実（確率を置けないのに置く、が最大の誤用）。
- **選択肢がまだ無い発想段階に使う**——決定木は与えられた選択肢を評価する道具。案出しはブレストや発想系で先に。
- **EMVだけで一発勝負の大博打を決める**——期待値が最大でも下振れが会社を潰すなら選べない。EMVは長期平均。
  リスク態度・破産確率を無視して機械的に最大EMVを選ぶのは危険（→効用・確実性等価で補正）。
- **確率を都合よく置く**——結論に合わせて確率を動かせば答えは操作できる。確率の出所を明示し、感度分析で殴る。
- **木を作り込みすぎる**——段階と枝が増えると読めなくなり、確率推定も雑になる。通説では4段超は Monte Carlo が適する。
- **決定ノードとチャンスノードを混同する**——「自分が選べる（□）」と「運任せ（○）」を混ぜると畳み込みが壊れる。
- **感度分析を省く**——確率・ペイオフが少し動くだけで推奨が反転することは多い。閾値を見ずに数値を信じ切らない。
- 多基準の確定的比較（decision-matrix）や、効果×実現性の定性配置（payoff-matrix）で足りる話に持ち出さない。

## 前提と限界

- **前提**: (1) **選択肢が既に列挙**されている（決定ノードの枝がある）こと。(2) 各不確実事象の**結果を離散化**し、
  各枝に**確率（合計1.0）**を置けること。(3) 各終端に**ペイオフ（金額など共通尺度）**を割り当てられること。
  確率もペイオフも数値化できないなら、まず市場調査・実験でデータを取るか、scenario-planning へ切り替える。
- **限界（批判を踏まえて）**:
  - **主観確率への依存**——確率が勘・希望的観測になりがち（アンカリング等のバイアス）。GIGO（質の悪い入力→無意味な出力）。
  - **EMVはリスク中立を仮定**——同じ期待値でも分散が違えば選好は変わるのに、EMVは平均しか見ない。個人・組織の
    リスク態度を無視する。これを埋めるのが**効用関数**（vNM）と**確実性等価**（そのくじと無差別な確実額）。
  - **EMVは予測ではなく長期平均**——1回限りの意思決定では期待値通りにならない。下振れの絶対額を必ず併記する。
  - **木の爆発**——段階×枝の掛け算で急速に複雑化し、可読性と確率推定の信頼性が落ちる。段階が深いなら Monte Carlo。
  - **離散・静的**——連続的で曖昧な未来は自然に収まらない。新選択肢を足すと木を作り直す（不安定）。
  - **感度への脆さ**——境界近傍では確率・ペイオフの小さな差で最適が反転する。
- これらは、**確率・ペイオフを lean-startup-mvp の小さな実験で更新し、下振れ側の失敗筋を premortem で洗い、
  確率が置けない深い不確実性は scenario-planning に委ね、多基準の確定的比較は decision-matrix に渡す**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップに「なぜ」を添える。**□（選べる）と○（運任せ）を混ぜないこと、右端から左へ畳むこと**が肝。

1. **決めたいこと（根の決定）と選択肢を確定する。** 木のいちばん左に置く決定ノード（□）と、そこから伸びる
   選択肢の枝を明文化する。なぜ: 何を選ぶ問題かが曖昧だと、木全体の目的地が定まらない。まず根を1つに固定する。
2. **各選択肢の後に起こる不確実な事象をチャンスノード（○）で展開する。** 結果を**互いに排他で網羅的**な少数の
   離散状態に分ける（例: 成功／中位／失敗）。なぜ: 確率を置くには結果をMECEに刻む必要がある。刻みすぎると木が爆発する。
3. **逐次性があれば「選択→結果→次の選択」を段階でつなぐ。** テスト→結果を見て本投資、のような段階構造を枝で表す。
   なぜ: 決定木の真価は、後の手（様子見・撤退・拡大）を見越して今の一手を決められること。一括と段階を同じ木で比べる。
4. **各チャンスノードの枝に確率を置く（合計1.0）。** 出所（実データ／過去実績／専門家推定）を各確率に注記する。
   なぜ: 確率の質が結論の質を決める。推測と実測を分け、後で感度分析にかける前提として出所を残す。
5. **各終端にペイオフを置く。** 共通尺度（通常は正味の金額。投資額・費用を差し引いた純額）で、下振れも含めて記入する。
   なぜ: 期待値は同一尺度でしか足せない。コスト控除後の純ペイオフに統一し、損失はマイナスで明示する。
6. **右端から畳み込む（ロールバック）。** ①各チャンスノード(○)で EMV＝Σ(確率×ペイオフ) を計算 →
   ②一つ左の決定ノード(□)で**最大EMVの枝を選び**、他を剪定（×印）→ ③そのノードをEMV値で置換 → ④根まで反復。
   なぜ: 後方帰納で「将来も最適に選ぶ」前提を織り込むと、今の最適な一手が一意に決まる。左から足すと将来の裁量を捨ててしまう。
7. **最適経路と下振れを併記する。** 選ばれた経路のEMVだけでなく、その経路の**最悪ペイオフと確率**を必ず添える。
   なぜ: EMVは長期平均。一発勝負なら下振れが致命的か（リスク態度）を人が判断できるよう、平均と分散の両方を見せる。
8. **感度分析で頑健性を確かめる。** 主要な確率・ペイオフを1つずつ動かし、**推奨が反転する閾値（breakpoint）**を求める。
   なぜ: 境界近傍では小さな差で最適が跳ねる。「確率が何%を超えたら判断が変わるか」が分かれば、どの前提を詰めるべきか決まる。
9. **情報の価値を評価し、次の一手に落とす。** 完全情報の価値 EVPI＝EV(完全情報あり)−EV(現状の最善) を出し、
   調査・テストに払ってよい**理論上限**を示す。EVPI はあくまで上限（必要条件）——超える調査費は即却下できるが、
   **上限内でも自動でGoにはしない**。実際の調査・パイロットは不完全情報しか得られないため、実施判断は**その調査で
   得られる情報の価値（EVSI）**が費用を上回るか（ENBS＝EVSI−調査・遅延コスト＞0）で行い、実施後は結果で確率を
   更新（事前→事後）してから本投資に進む。
   なぜ: 「今決める／様子見する／いくらまで調べる」を数値で裁定できる。EVPIを超える調査費は正確でも価値破壊。

## 壁打ち質問リスト

各ノードを事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この決定木で**最終的に決めたいこと**（根の決定）は何ですか？選べる**選択肢**は何と何ですか？
2. 各選択肢の後に起こる**不確実な結果**は何ですか？互いに排他で網羅的な少数の状態（成功／中位／失敗など）に刻めますか？
3. 各結果の**確率**はどれくらいですか？その数字の**出所**は実データ・過去実績・専門家の勘のどれですか？（合計は1.0ですか）
4. 各結末の**ペイオフ（金額）**はいくらですか？投資額・費用を**差し引いた純額**で、損失はマイナスで置けますか？
5. これは**逐次的な意思決定**ですか？（先に小さく試す→結果を見て拡大／撤退、のような段階構造はありますか）
6. これは**一回限りの勝負**ですか、何度も繰り返せる意思決定ですか？（EMVが平均として意味を持つかが変わります）
7. 最悪ケースの**下振れ額**が出た場合、それは受け入れられますか？（リスク態度・破産回避の制約はありますか）
8. どの確率／ペイオフが**いちばん怪しい（自信がない）**ですか？（感度分析でそこを動かして反転する閾値を見ます）
9. 決める前に**追加調査・テスト・パイロット**は可能ですか？いくらまでなら払う価値がありそうですか？（EVPI／情報の価値の検討）

## 出力フォーマット

ALWAYS この型で出力する（木の構造 → 期待値の畳み込み → 感度・情報の価値 → 意思決定）。型を固定し、常にこの構造で返すこと。

```
【決定木（構造）】決めたいこと(根の□): <選択肢A / 選択肢B / …>
  選択肢A → ○チャンス: [結果1 p=__ , ペイオフ=__] [結果2 p=__ , =__] …（p合計=1.0）
  選択肢B → ○チャンス: [ … ]
  （段階がある場合）選択肢A→[結果]→次の□: <拡大 / 撤退> → ○ …

【期待値（ロールバック）】右端から畳み込み
  ○各チャンスノードのEMV = Σ(確率×ペイオフ): A=__ / B=__ / …
  □決定ノードで最大EMVを選択（剪定した枝は×）: 最適な初手 = <選択肢__>（EMV=__）
  最適経路: <根から終端までの枝> ／ 経路の下振れ: 最悪ペイオフ=__（確率=__）

【感度・情報の価値】
  感度: <怪しい確率/ペイオフ>を動かすと、__が__%（or 金額__）を超えたとき推奨が<A→B>へ反転
  EVPI: EV(完全情報)−EV(現状最善) = __（調査に払ってよい理論上限。実施可否は EVSI−費用 で判断）
  段階投資/様子見: <パイロットで確率更新してから本投資する価値／今一括で決める価値>

【次の一手】<採る初手・段階化の設計・追加調査の要否を1〜3個。確率とペイオフの検証計画>
【未確認の前提】<確率の出所・ペイオフ推定・下振れ許容・リスク態度・木の刻み方——裏取りが要る点>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の企業名・でっち上げ数値は用いず、構造と計算手順を示す）。ある事業が、
**不確実な需要の新製品**に対し「大型設備を一括投資する／小型で試してから拡大する／見送る」を選ぶ場面
（Magee のStygian Chemical 型の設備投資問題を一般化）。

- **手順①根と選択肢**: 根の□＝「新製品への投資方式」。枝＝〈一括・大型〉〈段階・小型→様子見〉〈見送り〉。
- **手順②③展開**: 各投資の後に○チャンス＝需要が〈高・中・低〉の3状態（MECEに離散化）。段階案は
  「小型→需要シグナルを見て□〈拡大／撤退〉」という二段構造でつなぐ。
- **手順④⑤確率とペイオフ**: 各需要状態に確率（合計1.0）を置き、出所（過去の類似品実績／専門家推定）を注記。
  終端は投資額控除後の純額で、低需要は損失（マイナス）として記入。段階案は「まず小型投資額のみ先出し」で下振れを抑える構造。
- **手順⑥ロールバック**: 各○で EMV＝Σ(確率×ペイオフ) を計算。段階案の右端の□〈拡大／撤退〉では大きい方を選び、
  その値を左のチャンスノードへ戻す。根の□で3案のEMVを比較し、最大の初手を選ぶ（剪定枝に×）。
- **手順⑦下振れ併記**: 仮に一括・大型のEMVが最大でも、低需要時の損失額が大きければ、段階案（EMVはやや低いが
  下振れが浅い）の方が一回勝負では妥当なことがある——平均と最悪を並べて人が判断できるようにする。
- **手順⑧感度分析**: 「高需要の確率」を動かし、大型案と段階案のEMVが逆転する**閾値**を求める。実際の確信が
  その閾値のどちら側かで、詰めるべき前提（需要確率の裏取り）が決まる。
- **手順⑨情報の価値**: EVPI＝完全情報があれば得られるEV−現状最善のEV、を計算し「情報収集に払ってよい理論上限」を出す。
  調査費が EVPI 超なら即却下。EVPI 以内なら、パイロットで得られる情報の価値（EVSI）が調査・遅延コストを上回るかを
  見積もった上で、小型パイロットで需要シグナルを取り、事前確率を事後確率に更新してから拡大/撤退を決める段階戦略を敷く。
- **次の一手**: まず段階・小型で張り、需要データで確率を更新→閾値を超えたら拡大、を採る。調査費は EVPI 超なら即却下し、EVPI 以内は EVSI との見合いで実施を判断する。
- **未確認の前提**: 各需要状態の確率の出所、純ペイオフの推定精度、低需要時の損失を組織が飲めるか（リスク態度）、
  需要状態を3つに刻んだ妥当性——いずれも実データでの裏取りが要る。

## 相性（組み合わせると効く）

- `decision-matrix`: 確率で測れない**多基準の確定的比較**（重み付き採点）が要るとき、決定木の前後で選択肢を絞る/採点する。役割が相補的。
- `payoff-matrix`: 名称は似るが**別物**。効果×実現性の定性2軸でざっくり打ち手を絞ってから、残った勝負どころを決定木で確率的に精査する前工程。
- `scenario-planning`: 確率を置けない**深い不確実性**はシナリオで複数未来を物語り、確率が置ける分岐だけを決定木でEMV評価する——2ツールの分担。
- `lean-startup-mvp`: 決定木が示す「段階投資・情報の価値」を、実際の**MVP/小さな実験**で回し、事前確率を事後確率へ更新する実行手段。
- `premortem`: 決定木の**下振れ経路**（低需要・失敗枝）を「もう失敗した」前提で掘り、確率とペイオフの楽観バイアスを叩く揺さぶり枠。
- `fta` / `fmea`: 失敗事象の確率・影響を構造的に見積もり、チャンスノードの確率とペイオフの入力を精緻化する。
- `unit-economics`: 各終端ペイオフ（純額）を単位経済で裏取りし、でっち上げでない金額を木に載せる。
