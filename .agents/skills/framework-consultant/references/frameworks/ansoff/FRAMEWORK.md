# アンゾフの成長マトリクス

## 概要

アンゾフの成長マトリクスは、企業の成長戦略を **製品(Products)** と **市場(Markets)** の2軸で整理し、
各軸を **既存(existing) / 新規(new)** に分けた 2×2 マトリクス。4象限それぞれが、性質もリスクも異なる
「成長の方向」を表す。核心は「どの製品を、どの市場に当てて伸ばすか」という**成長の方向選択**にある。

| | 既存製品 | 新規製品 |
|---|---|---|
| **既存市場** | 市場浸透（最も低リスク） | 新製品開発 |
| **新規市場** | 新市場開拓 | 多角化（最も高リスク） |

- **核となる考え方**: 新規側（右・下）へ進むほど「未知」が増え、リスク・必要投資・R&Dが増大する。
  同じ「成長したい」でも、既存の延長で稼ぐか、新しい製品/市場に賭けるかで打ち手も難易度も別物になる。
  この**リスク階段**を可視化し、成長策を横並びで比較・選択できるようにするのが本フレームの価値。
- **4つの戦略**:
  - **市場浸透**（既存製品×既存市場）: 今の市場でシェア・購買頻度・利用量を増やす。最も低リスク。
  - **新製品開発**（新規製品×既存市場）: 既存の顧客基盤・ブランドを活かし新しい製品を投入する。
  - **新市場開拓**（既存製品×新規市場）: 実績ある製品を新地域・新セグメント・新用途へ展開する。
  - **多角化**（新規製品×新規市場）: 製品も市場も新規。ハイリスク・ハイリターン。
- **出自（要確認を含む）**: 応用数学者・経営学者の **H. Igor Ansoff（イゴール・アンゾフ）** が、
  **Harvard Business Review, 1957, "Strategies for Diversification"** で示した product-market 戦略の枠組みが原型。
  ただし原論文の主眼は「多角化」の論考で、現在広く流通する**整った2×2グリッド図・"Ansoff Matrix" の呼称・
  4戦略の和名は後年に普及・整形された形**である点に注意（→出典・要確認項目）。

## いつ使う / 使わない

**使う（適する状況）**
- 「成長したい／売上を伸ばしたい」が**次の一手の方向が定まらない**とき。選択肢を4象限で構造化する。
- **新規事業・多角化・海外進出・新セグメント参入**の是非や優先順位を検討したいとき。
- 既存事業の**伸びしろ（浸透余地）**と、新規開拓のどちらに資源を振るかを**リスク込みで比較**したいとき。
- 経営戦略・事業計画の初期に、成長オプションを**漏れなく並べて**議論の土台を作りたいとき。

**使わない / よくある誤用（アンチパターン）**
- **象限に埋めて満足し、方向を決めない**——最頻の失敗。マトリクスは分類器であって結論ではない。
  必ず「どの象限に、どれだけ資源を賭けるか」の**意思決定と優先順位**まで進める。
- **「市場浸透＝安全」と短絡する**——市場が破壊的技術・需要縮小で崩れつつあれば、既存に固執する市場浸透が
  **最も危険**になり得る。ラベルのリスクは絶対でなく、外部環境と併せて判断する。
- **リスク評価をラベルで代替する**——「新規製品だから中リスク」で止めず、需要・競合・必要投資・撤退可能性を
  各象限で具体的に見積もる。象限名は粗い当たりであって精査ではない。
- **外部環境・競合反応を無視した内向き分析**——本フレームは製品と市場だけを見て、マクロ環境や競合の出方を
  直接扱わない。PEST・5フォースで外部を補わないと、机上の成長絵図になる。
- **ハイブリッドを見落とす**——現実は「新製品を新地域に同時投入」など象限をまたぐ。4つを排他の道と誤解しない。
- **面白そうという理由の非関連多角化**——コア強みと無関係な多角化に飛びつくのは典型的な失敗。シナジーを問う。
- 単一施策の精緻な実行計画、定量的な投資評価そのものには不向き。他フレームで補完する。

## 前提と限界

- **前提**: 「何の事業／製品ラインを、どの成長のために検討するのか」という**対象と目的が1つに定まっている**こと。
  対象が曖昧だと象限が発散する。また「既存／新規」の線引き基準（どこからを新規市場・新規製品と呼ぶか）を
  先に合意しておく必要がある。ここが緩いと同じ施策が人により別象限に入り、比較が崩れる。
- **限界（批判を踏まえて）**:
  - **単純化のしすぎ**——成長判断に関わる無数の変数（企業文化・供給網・資金・組織能力）を4象限に還元する。
    分類はできても、その象限で「勝てるか」は別途検証が要る（→VRIO・5フォース）。
  - **リスクを粗く扱う**——象限ラベルは相対リスクの当たりに過ぎない。**新市場開拓と新製品開発の相対リスクは
    論者・文脈で入れ替わる**（R&D不要な分、新市場開拓を低リスクとする論もある）。順序を絶対視しない。
  - **外部・競合・動学の欠落**——競合反応、代替品、規制、時間軸を織り込まない静的モデル。
  - **規範的すぎ・分析麻痺**——枠に沿った計画偏重は、行動より熟考過多（paralysis by analysis）を招くと批判された。
- これらは、**成長判断の入力をSWOT/3Cで整理し、外部をPEST・5フォースで補い、賭ける強みの持続性をVRIOで検証し、
  高リスク象限（多角化・新市場）の失敗要因をpremortemで先回りする**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **検討対象と成長目的を1つに固定する。** 「どの事業/製品ラインを、何のために成長させるのか」
   （例: 主力事業の売上を3年で拡大／頭打ちの既存市場から次の柱を作る）を明文化する。
   なぜ: 目的が無いと象限が発散し、埋めて終わる最頻の失敗に直結する。
2. **「既存／新規」の定義を先に合意する。** どこからを新規市場（新地域・新セグメント・新チャネル）、
   新規製品（新機能でなく新カテゴリか）と呼ぶかの線引きを決める。
   なぜ: 線引きが曖昧だと同じ施策が別象限に入り、リスク比較が成り立たなくなる。
3. **4象限それぞれに成長機会を書き出す。** 市場浸透・新市場開拓・新製品開発・多角化の各枠に、
   自社が採り得る具体施策を並べる。空欄の象限があってもよい（無理に埋めない）。
   なぜ: 一象限（例: 目先の新製品）に固執せず、選択肢を漏れなく机に載せるため。
4. **各象限のリスク・必要資源・リターンを見積もる。** 需要の確からしさ、競合の出方、必要投資・時間、
   自社能力とのギャップ、失敗時の撤退可能性を、施策ごとに粗くでも評価する。
   なぜ: 象限ラベルのリスクは当たりに過ぎない。「市場浸透でも市場が縮むなら危険」をここで拾う。
5. **既存側の伸びしろ（浸透余地）を必ず先に検算する。** 新規に飛ぶ前に、市場浸透・製品開発でどこまで
   伸ばせるかを見る。安価で低リスクな手を取りこぼしていないかを確認する。
   なぜ: 新規開拓は魅力的に見えるが、既存の未回収の伸びしろの方が費用対効果が高いことが多い。
6. **多角化は「関連／非関連」を切り分け、シナジーを問う。** 多角化を検討するなら、既存の技術・顧客・
   ブランド・チャネルと**どこがつながるか（関連多角化）**を具体化し、無関係なら賭ける理由を厳しく問う。
   なぜ: 「面白そう」での非関連多角化は典型的失敗。シナジーの有無がリスクと成否を分ける。
7. **方向を決め、資源配分と優先順位に落とす。** 全象限を等価に扱わず、「どの方向に、どれだけ賭けるか」
   （例: 浸透7・製品開発2・多角化を小さく実験1）を決め、検証すべき仮説と次の一手を1〜3個定める。
   なぜ: マトリクスは分類器。ここで止めると「埋めて終わり」の典型に陥る。

## 壁打ち質問リスト

各象限を事実で埋め、方向を決めるために利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この検討で**最終的に決めたいこと**は何ですか？（既存を深掘るか／新市場か／新製品か／多角化か、目的を1つに）
2. 対象の事業・製品は何で、**どこからを「新規市場」「新規製品」と呼ぶ**ことにしますか？（線引きの合意）
3. **既存市場・既存製品での伸びしろ**はまだありますか？（シェア・購買頻度・未開拓チャネル・解約率など、市場浸透の余地）
4. 狙う**新規市場は具体的にどこ**ですか？（地域／セグメント／用途）そこで既存製品はそのまま通用しますか、要改変ですか？
5. **新製品**を出すなら、既存顧客の未充足ニーズは何で、既存の強み（技術・ブランド・チャネル）のどれを活かせますか？
6. 多角化を考えるなら、既存事業と**どこがつながり（シナジー）**、無関係ならそれでも賭ける理由は何ですか？
7. 各方向で、**失敗したらどうなり、どこまでなら撤退できる**（投資額・時間・不可逆性）ですか？
8. 外部環境（競合・技術・規制・需要）の変化で、**「今の市場に留まること」自体のリスク**は上がっていませんか？

## 出力フォーマット

ALWAYS この2段構えで出力する（4象限の棚卸し → 方向の意思決定）。型は固定する。

```
【前提】検討対象: <事業/製品> ／ 成長目的: <決めたいこと> ／ 「新規」の線引き: <市場・製品の定義>

【成長マトリクス（4象限の棚卸し）】
                既存製品                        新規製品
  既存市場   [市場浸透] <施策／伸びしろ・低リスク>   [新製品開発] <施策／必要R&D・中リスク>
  新規市場   [新市場開拓] <施策／対象市場・中リスク>  [多角化] <施策／関連 or 非関連・高リスク>

  各象限メモ: リスク／必要資源・時間／需要の確からしさ／自社能力ギャップ／撤退可能性

【方向の意思決定】
  推奨する重心: <どの象限にどれだけ賭けるか（例: 浸透7・製品開発2・多角化を小実験1）＋理由>
  先に取り切る低リスク余地: <既存側の伸びしろ>
  賭ける新規策と条件: <その象限で勝つ前提／シナジー／検証すべき仮説>

【次の一手】<検証すべき仮説・意思決定・アクションを1〜3個>
【未確認の前提】<需要・競合・能力ギャップなど、事実確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。既存市場で頭打ち感のある地域密着型の食品メーカーが、次の成長の方向を検討する場面。

- **手順①目的**: 「頭打ちの主力事業から、次の3年の成長の柱をどこに作るか」を決める。対象＝同社の主力食品ライン。
- **手順②線引き**: 新規市場＝これまで売っていない地域・顧客層・販売チャネル。新規製品＝既存の味変えでなく別カテゴリ。
- **手順③4象限に機会を列挙**:
  - 市場浸透（既存製品×既存市場）: 販促強化、購入頻度を上げる用途提案、離反顧客の再獲得。
  - 新製品開発（新規製品×既存市場）: 既存顧客向けに関連する新カテゴリ商品を追加。
  - 新市場開拓（既存製品×新規市場）: 実績ある主力商品を他地域・EC・業務用チャネルへ展開。
  - 多角化（新規製品×新規市場）: 全く別カテゴリの新製品で新しい顧客層へ（関連が薄いほど高リスク）。
- **手順④リスク見積り**: 多角化は投資・不確実性が最大。新市場開拓は製品が実績ありな分、需要の読みが主論点。
- **手順⑤伸びしろ検算**: 既存市場に販促・用途提案の未回収余地が残っており、低コストで取れると判断。
- **手順⑥多角化のシナジー**: 検討中の別カテゴリは既存の製造設備・販路と接点が薄い→非関連寄りで見送り候補。
- **手順⑦方向の決定**: 重心を「市場浸透（既存の伸びしろを先に回収）＋新市場開拓（実績製品を新チャネルへ小さく試す）」に置き、
  多角化は当面見送り。検証すべき仮説＝「新チャネルで既存製品はそのまま通用するか」。
- **未確認の前提**: 新チャネルでの実需要、他地域での嗜好差、浸透施策の実際の反応——実データで裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `swot`: 成長の方向を決める前に、内外環境（強み・弱み・機会・脅威）を棚卸しして入力を整える前工程。
- `3c`: 市場・競合・自社の3視点で、各象限の「勝てるか」の入力（特に新市場・新製品の実現性）を精緻化する。
- `pest` / `five-forces`: 本フレームが手薄な**外部環境・競合構造**を補い、「今の市場に留まるリスク」を評価する。
- `vrio`: 新規策で賭ける「強み」が本当に持続的な競争優位か（価値/希少/模倣困難/組織）を検証し、思い込みを弾く。
- `ppm-bcg`: 複数事業を持つ場合、成長の方向選択の次に**どの事業に投資・撤退資源を配分するか**へ接続する。
- `jtbd`: 新製品開発・新市場開拓の中身を、顧客の片付けたい用事から発想して具体化する（発想レンズの補完）。
- 揺さぶり枠として `premortem`（高リスク象限=多角化/新市場の失敗要因を先回り）や `devils-advocate`
  （「新規に賭ける」前提や需要の楽観を疑う）を添えると、リスク評価の甘さをあぶり出せる。
