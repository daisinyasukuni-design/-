# オズボーンのチェックリスト

## 概要

オズボーンのチェックリストは、検討対象（既存の製品・サービス・企画・業務など）に対して、
**あらかじめ用意した9つの切り口の問いを強制的に当てる**ことでアイデアを引き出す発散型の発想法。
「自由に考えよう」では出てこない発想を、**視点（動詞）を機械的に切り替える**ことで漏れなく量産する
——いわゆる強制発想（forced association）の代表格。

| # | 項目（和名） | 英語(Osborn) | 問いの核 |
|---|---|---|---|
| 1 | **転用** | Put to other uses? | そのまま／改変して別の使い道は？ 新しい市場・場面は？ |
| 2 | **応用（適合）** | Adapt? | 似たものは？ 真似できる先例・他分野・他業界は？ |
| 3 | **変更** | Modify? | 色・形・音・意味・動き・様式など属性を変えたら？ 新しいアングルは？ |
| 4 | **拡大** | Magnify? | 大きく・強く・多く・長く・頻繁に・付加・誇張したら？ |
| 5 | **縮小** | Minify? | 小さく・軽く・短く・省略・分割・控えめにしたら？ |
| 6 | **代用** | Substitute? | 別の素材・人・工程・場所・アプローチで代えたら？ |
| 7 | **置換（再配置）** | Rearrange? | 順序・レイアウト・因果・スケジュール・要素を入れ替えたら？ |
| 8 | **逆転** | Reverse? | 上下・前後・役割・正負・順序を反対にしたら？ |
| 9 | **結合** | Combine? | 他のもの・機能・アイデア・目的と組み合わせたら？ |

- **核となる考え方**: 人は既存物を「今の姿」で固定して見てしまう（機能的固着）。9つの動詞で対象を意図的に
  揺さぶり、**判断を保留したまま量を出す**ことで、そのバイアスを外す。チェックリストはブレインストーミングの
  発散フェーズを駆動する「刺激（stimulus）」であり、それ単体の穴埋めが目的ではない。
- **出自（年号・項目数は要確認扱い）**: 広告代理店 **BBDO** の共同創業者 **Alex F. Osborn**（1888–1966）が、
  著書 *Applied Imagination*（初版**1953**、Charles Scribner's Sons。改訂1957/1963）で示した「idea-spurring
  questions（発想を促す問い）」に由来する。Osborn は**ブレインストーミング**の提唱者でもある。
  原典は多数の細かな問いを大きな見出しにグルーピングしたもので、**「9項目」は後年の整理・通説**（Eliminate=削除を
  足して10項目とする版、Magnify/Minify を Modify に束ねる版もある。→出典・要確認参照）。
- **派生との関係**: 後に **Bob Eberle** がこのチェックリストを7つの語呂合わせ **SCAMPER** に再編した（1971頃）。
  SCAMPER は覚えやすくした実務版で、**源流はこのオズボーンのチェックリスト**。

## いつ使う / 使わない

**使う（適する状況）**
- アイデアが**枯渇・停滞**し、切り口そのものが思いつかないとき（会議の沈黙、企画の手詰まり）。
- **既存の製品・サービス・企画・業務**を起点に、改善・派生・新用途の選択肢を**網羅的**に洗い出したいとき。
- **一人ブレスト**をしたいとき。9つの問いが「もう一人の発想パートナー」の役割を果たす。
- 発想が**いつも同じパターン**に偏る自覚があり、意図的に視点を散らしたいとき。
- SCAMPER より**網羅性・原典寄り**の切り口（逆転・置換を明示的に分ける）が欲しいとき。

**使わない / よくある誤用（アンチパターン）**
- **穴埋めで満足して止まる**——最頻の失敗。各項目に1個ずつ埋めて終わり、量産・判断保留・掛け合わせをしない。
  結果は凡庸案の羅列。チェックリストは「床（最低限の刺激）」であって「天井」ではない。
- **アンカリング／天井化**——9つの方向に思考が固定され、その枠の**外（直交する発想）**を却って見落とす。
  一巡後に「この9つに載らない案は？」と枠外を1回問い直す。
- **改変対象が無い抽象テーマに当てる**——「幸福とは」等、いじる既存物が無いテーマには噛みにくい。
  対象を具体物（製品・機能・工程・体験の一部）に落としてから使う。
- **易しい項目への偏り**——やりやすい「拡大・縮小・変更」に偏り、「逆転・代用・置換」を飛ばす。カバレッジが歪む。
- **発散のまま放置**——評価・選別・具体化の収束工程に繋がず、意思決定に使われない。必ず後工程へ渡す。
- 生まれる案は**改良・派生（漸進的）に傾く**。非連続・破壊的なイノベーション単独の創出には不向き
  （視点転換系・アナロジー系で補う）。

## 前提と限界

- **前提**: いじる対象＝具体的な既存の製品・サービス・企画・工程が1つに定まっていること。目的（何のための
  アイデア出しか＝新用途探索／コスト削減／差別化 等）が曖昧だと、9項目が空回りする。判断保留（出す段階で
  批評しない）という**ブレインストーミングの作法**を守れることも前提。
- **限界（批判を踏まえて）**:
  - **既存物への変形が発想の起点**なので、そもそもの前提や市場そのものを疑う発想（ジョブ理論・逆設定法の領域）は
    出にくい。改良に強く、再定義に弱い。
  - **チェックリストが視野を狭める逆機能**——9つの型に沿わせるほど、型外の飛躍を捨てやすい。網羅の安心感が
    創造性の天井になり得る。
  - **量は出るが質は別**——強制的に数は稼げても、そのままでは実現性・価値がバラバラ。**必ず収束（評価・選別）**が要る。
  - **項目の粒度・数に揺れ**——資料により9/10、和名訳もまちまち。厳密な「正解の項目セット」を追うより、
    **多様な動詞で対象を揺さぶる**という本質を優先する。
- これらは、**評価はペイオフマトリクス／PMIへ渡す・前提破壊は逆設定法や悪魔の代弁者で補う・遠い飛躍は
  アナロジー思考で足す**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップに「なぜ」を添える。

1. **対象とゴールを1つに固定する。** 何をいじるか（例: この製品／この申込フォーム／この社内会議）と、
   何のための発想か（新用途／差別化／時短／コスト減）を明文化する。
   なぜ: 対象と目的が曖昧だと、9項目が的外れなアイデアを量産して発散が制御不能になる。
2. **対象を要素に分解する。** 機能・部品・素材・工程・利用者・使用場面・タイミングなどに割る。
   なぜ: 「製品まるごと」に問いを当てるより、要素ごとに当てる方が具体的な変形案が出る（拡大＝何を拡大？が定まる）。
3. **判断保留のルールを宣言する。** 出す段階では批評・実現性判断をしない、量を優先する、と全員で合意する。
   なぜ: 発散と収束を混ぜると、批評が発言を止め、量が激減する（オズボーンのブレスト原則の核）。
4. **9項目を順に当て、各項目で複数案を出す。** 1項目1個で止めず、各項目3個以上を目安に絞り出す。
   飛ばしたくなる「逆転・代用・置換」ほど意図的に粘る。
   なぜ: 易しい項目への偏りがカバレッジを歪める。数の下限を決めると強制力が働く。
5. **項目をまたいで掛け合わせる。** 「縮小×結合」「逆転×転用」など、出た案どうしを組み合わせて二次案を作る。
   なぜ: 単一動詞の案は平凡になりがち。掛け合わせが飛躍を生む（結合はそのための専用項目でもある）。
6. **枠外を1回問い直す。** 「この9項目のどれにも載らない、まったく別の切り口は？」と最後に一度だけ広げる。
   なぜ: チェックリストの天井化（アンカリング）を外すための解毒ステップ。
7. **収束させる。** 出た案を目的の評価軸（効果×実現性など）で選別し、上位数個を具体化・次アクションに落とす。
   なぜ: オズボーンのチェックリストは発散の道具。ここで止めると「たくさん出して終わり」の典型に陥る。

## 壁打ち質問リスト

各項目を具体で埋めるために、利用者へ投げ返す問い。空欄を勝手に埋めず、まずこれで引き出す。

1. **何のアイデアを出したい**ですか？ 対象は具体的に何で（製品／サービス／企画／業務のどれ・どの部分）、
   出したアイデアで**最終的に何を実現**したいですか（新用途／差別化／コスト減／時短など）。
2. その対象を**要素に分けると**、機能・部品・素材・工程・使う人・使う場面・タイミングは何と何ですか？
   （どこをいじれるかの棚卸し）
3. 今の対象で**一番の不満・制約・コスト**は何ですか？（縮小・代用・逆転の当てどころになる）
4. これまで**すでに試した／却下した切り口**は何ですか？（重複を避け、飛躍を狙う起点にする）
5. 「**逆転**」を当てるとして、この対象で当たり前になっている前提・順序・役割は何ですか？（それを反転させる）
6. 「**結合・応用**」を当てるとして、他業界・他分野で似た課題を鮮やかに解いている例に心当たりはありますか？
7. 出たアイデアを後で選ぶとき、**優先したい評価軸**は何ですか？（効果／実現性／コスト／スピード／独自性など）
8. 実現性を今は**気にせず量を出してよい**という前提で進めて良いですか？（判断保留の合意確認）

## 出力フォーマット

ALWAYS この型で出力する（発散→掛け合わせ→収束の3段）。各項目は「飛ばさず」全て埋める。

```
【設定】対象: <いじる既存物と要素> ／ ゴール: <何のための発想か> ／ 評価軸: <後で選ぶ基準>

【9項目の発散】各項目 複数案（判断保留・量優先）
  1 転用(他用途):   - <案> …
  2 応用(適合):     - <案> …
  3 変更:           - <案> …
  4 拡大:           - <案> …
  5 縮小:           - <案> …
  6 代用:           - <案> …
  7 置換(再配置):   - <案> …
  8 逆転:           - <案> …
  9 結合:           - <案> …

【掛け合わせ／枠外】
  - <項目×項目 の二次案> …
  - <9項目に載らない別切り口> …

【収束（評価軸で選別）】上位案 → 効果×実現性などで採点し2〜3個に絞る
  - <採用候補> : <なぜ選ぶか>

【次の一手】<検証すべき案・試作・意思決定を1〜3個>
【未確認の前提】<事実確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。地域の書店が「来店客を増やす企画」を発想する場面。

- **手順①設定**: 対象＝実店舗の書店体験、ゴール＝来店動機を増やす、評価軸＝低コストで早く試せること。
- **手順②要素分解**: 品揃え／棚の並び／営業時間／店内の滞在体験／購入以外の目的／立地。
- **手順③判断保留を宣言**し量を優先。
- **手順④9項目の発散（各項目 抜粋）**:
  - 転用: 店内スペースを夜間はイベント会場に転用／閉店後に読書会場所として貸す。
  - 応用: 図書館の「テーマ展示」やカフェの「今月の一杯」を書店の棚づくりに応用。
  - 変更: 著者・ジャンルでなく「悩み別」に棚を並べ替える／照明や香りで体験を変える。
  - 拡大: 特定ジャンルを極端に深掘りした「専門特化コーナー」を大きく張る。
  - 縮小: 在庫を絞り「店員の推薦100冊だけ」に減らす／営業時間を朝だけに絞る。
  - 代用: 店員の推薦を、常連客の推薦カードで代用する。
  - 置換: レジと入口の配置を入れ替え、まず体験→最後に会計の動線にする。
  - 逆転: 「客が本を探す」を反転し「本の方から客に届く」定期便・選書サービス。
  - 結合: 書店＋コワーキング／書店＋文具ワークショップを結合。
- **手順⑤掛け合わせ**: 「悩み別の棚(変更)×常連の推薦(代用)」→ 常連が選ぶ悩み解決本コーナー。
- **手順⑥枠外**: 9項目に載らない切り口として「オンラインの読書仲間を実店舗に集める」発想を1つ追加。
- **手順⑦収束**: 評価軸（低コスト・早い）で「悩み別×常連推薦コーナー」を小さく試作すると決定。
- **未確認の前提**: 来店動機の実態、常連が推薦に協力するか——ここは実データ／ヒアリングで裏取りが要る
  （推測のまま量産案を採用しない）。

## 相性（組み合わせると効く）

- `scamper`: 同源流の7動詞版。暗記しやすく実務で回しやすい。網羅性重視ならオズボーン、手早さならSCAMPERと使い分け。
- `attribute-listing`: 手順②「要素分解」を体系化。属性を洗い出してから各属性に9項目を当てると精度が上がる。
- `brainstorming`: このチェックリストが前提とする発散の作法（判断保留・量重視）。集団で回す土台。
- `payoff-matrix`: 手順⑦の収束を担う。量産した案を効果×実現性で2〜3個に絞る直接の後工程。
- `pmi`: 個々の案を Plus/Minus/Interesting で多面評価し、捨てる前に「面白い点」を拾う。
- `reverse-assumption`: 「逆転」項目をさらに徹底し、対象の前提そのものを壊す（改良の枠を越えたいとき）。
- 揺さぶり枠として `analogical-thinking`（応用/結合を遠い分野へ飛ばす）や `devils-advocate`
  （量産案の過信を疑い、収束前に潰す）を添えると、漸進案への偏りを補正できる。

**要ファクトチェック（Web調査で誤りが混入しやすい断定）**
- *Applied Imagination* の年：**初版1953**が通説だが、IfM等は**1957（改訂版）**を挙げる。改訂1957/1963の存在。断定回避。
- **項目数**：本文の「9項目」は日本の定番整理。原典は多数の spur questions を見出しにまとめたもので、
  Eliminate（削除）を足して10、Magnify/Minify を Modify に束ねて7〜8とする版もある。「原典が9箇条と明示」とは断定しない。
- ブレインストーミングの初出：*How To Think Up*(1942) か *Applied Imagination*(1953) か（体系的普及は後者）。
- 派生 SCAMPER の考案者 **Bob Eberle** と刊行年（*SCAMPER: Games for Imagination Development*、**1971**頃。
  再版1996/2008等と混同注意。Frank E. Williams の影響も指摘される）。
- 和名ラベル（転用/応用/変更/拡大/縮小/代用/置換/逆転/結合）は日本の実務慣用訳で、Osborn の英語見出しと
  1対1で厳密対応するわけではない（Rearrange↔置換/再配置、Reverse↔逆転、Adapt↔応用/適合 の訳し分けに揺れ）。
