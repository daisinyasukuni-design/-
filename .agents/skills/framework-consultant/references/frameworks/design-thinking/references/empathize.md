# 共感（Empathize）— 詳細ガイド

> FRAMEWORK.md 手順①の詳細。ユーザーを深く理解し、自分の思い込みを脇に置くモード。
> ここで得た「観察された事実」が後段すべての土台になる。ここを飛ばすと全工程が思い込みの上に建つ。

## 目的
- ユーザーの**行動・文脈・感情・本音（言葉にならないニーズ）**を、作り手の仮説抜きで観察・傾聴して掴む。
- 「何を欲しがっているか（言うこと）」と「実際どう動くか（すること）」のギャップを見つける。

## 主な手法（どれをいつ）
- **デプスインタビュー（1対1）**: なぜを掘る。「最近◯◯した時のことを、最初から順に話してください」と**具体的な過去の実体験**を語らせる（一般論・意見を聞かない）。「なぜ？」を繰り返す。
- **行動観察 / シャドーイング**: 現場に同行し、実際の作業・つまずき・回避策（workaround）を見る。言葉より行動に本音が出る。
- **エクストリームユーザー**: 平均的な人でなく、極端なヘビーユーザー/非利用者に会うと、隠れたニーズや代替行動が際立つ。
- **共感マップ（Empathy Map）**: Says / Thinks / Does / Feels の4象限で観察を整理し、言動の矛盾を可視化。
- **自分で体験する（immersion）**: 可能なら作り手自身がユーザーの状況を体験する。
- **専門家・現場の詳しい人への聴取**: 背景知識の獲得。ただし「ユーザー本人」の代替にはしない。

## 成果物
- 観察ログ（発言の引用・行動・文脈をそのまま）。**解釈と事実を分けて記録**する。
- 共感マップ、印象的な生の声（quote）、驚き・矛盾のメモ。

## つまずき所・誤用
- **省略/拙速**: 「もう顧客は分かっている」で飛ばす → 最頻の失敗。基礎工事なしに家を建てるのと同じ。
- **偽の共感（false empathy）**: アンケートや数字を眺めただけ、自分の枠組みを押し付けたまま「共感したつもり」。権力・前提を手放す姿勢が要る。
- **誘導質問**: 「これ便利だと思いますか？」は Yes を誘発する。過去の実体験を聞く形に変える。
- **共感で止まる**: リサーチに沈み次へ進めない。目的（何を決めるためのリサーチか）を握って打ち切る。
- **少数の声の一般化**: n=1〜2の印象を全体像と誤認。複数・多様な相手で裏を取る。

## 壁打ちで確認すること
- 誰の、どの場面の体験を見に行くのか。実際に会える/観察できるのか。
- すでに「事実」と「思い込み」はどこで線引きできているか。
