# シネクティクス（Synectics）

## 概要

シネクティクスは、**アナロジー（類比）とメタファーを使って、問題を意図的に別分野へ飛ばし、そこで得た飛躍的な発想を元の問題に強制的に結びつける**創造的問題解決の技法。語源はギリシャ語 *synectikos*（異なった一見無関係なものを結びつける／統合する）。

核となるのは相補的な2つの態度の往復である。

| 態度 | 意味 | 役割 |
|---|---|---|
| **異質馴化**（make the strange familiar） | 見慣れないもの（問題）を分解して理解する | 問題を正しく捉え直す（分析側） |
| **馴質異化**（make the familiar strange） | 見慣れたもの（問題）を見慣れないものに変える | 固定観念を外し飛躍する（発想側） |

- **核となる考え方**: 通常の連想は「近い」ものに留まり既視感のある案しか出ない。そこで問題からわざと遠く離れた領域（生物・自然・別業界・空想）へ「遠足(excursion)」し、そこの構造を借りて戻り、問題に**force fit（強制結合）**することで、論理では届かない発想を得る。Gordonの標語は「Trust things that are alien, and alienate things that are trusted（見知らぬものを信頼し、信頼するものを疎遠にせよ）」。
- **4つの類比（発想のエンジン）**: ①直接的類比（別分野の似た仕組みを借りる）②擬人的類比（対象になりきる）③象徴的類比（詩的・矛盾を孕む比喩で本質を突く）④空想的類比（法則も常識も無視して理想を空想）。
- **出自（諸説あり・要確認）**: 1950年代、コンサル会社 Arthur D. Little のInvention Design Unitで、William J.J. Gordon と George M. Prince らが「新しいアイデアが生まれ実装される時に実際に何が起きているか」をテープ分析し、人が無意識に類比を使うことを発見したのが母体。**1961年**、Gordon が書籍 *Synectics: The Development of Creative Capacity* を刊行しこの頃命名。後に Gordon（教育応用の Synectics Education Systems）と Prince（ビジネス応用の Synectics Inc.／現 Synecticsworld、*The Practice of Creativity* 1970）に分かれ、**構造的手順の系統**と**実務ファシリテーションの系統**の2つが並存する（→出典・要確認）。
- 元来は5〜7人程度・訓練されたファシリテーターによる**集団技法**。個人でも使えるが、その場合は対象領域を徹底的に調べてから飛ばす。

## いつ使う / 使わない

**使う（適する状況）**
- ブレストや通常の発想が**既存の延長・既視感のある案しか出さず煮詰まった**とき（打破用の飛び道具）。
- **他業界・自然・別分野の仕組みを借りて**発想したいとき（例: 物流の課題に蟻の採餌や血管網の構造を借りる）。
- 製品・サービス・仕組みを**根本から作り替える**、非連続なコンセプトが欲しいとき。
- 問題の**捉え方そのものを組み替えたい**とき（表面的な解でなく再定義したい）。
- SCAMPER・オズボーンのチェックリストで出た案が平凡に感じ、**もう一段飛ばしたい**とき。

**使わない / よくある誤用（アンチパターン）**
- **類比の思いつきで満足し、force fit（強制結合）と検証を省く**——最頻の失敗。遠足で拾った面白い比喩は「素材」に過ぎず、元の問題に無理やり接続し、実現性を評価して初めて解になる。
- **象徴的類比を「上手い比喩」で終える**——本質の矛盾（compressed conflict）を突かず装飾で止めると発想が広がらない。「◯◯だが同時に△△」という緊張を抱えた対にする。
- **遠足(excursion)を飛ばして分析だけで終える**——馴質異化（飛躍）を省くと、ただの整理で終わり平凡な案しか出ない。
- **量を質と取り違える**——たくさん出た＝良い、ではない。奇抜だが不適切な案は創造的とは言えない（→後述の限界）。
- **心理的安全のない場で回す**——判断保留・非難禁止が崩れると、突飛な発言（＝種）が出なくなり機能しない。
- 緻密な**定量最適化・論理分解・原因究明**そのものには不向き。そこはロジックツリーやなぜなぜ分析等に譲り、本手法は「飛ばす」局面に使う。

## 前提と限界

- **前提**:
  - 解くべき問題（PAG）が一応定まっていること。ただし途中で**問題の再定義（PAU）を許す時間的・心理的余裕**が要る（早く答えに飛びつくと機能しない）。
  - 判断保留・非難禁止の**心理的安全**と、多様な背景のメンバー。集団なら訓練されたファシリテーターが望ましい。
  - 対象領域の基礎知識（専門家の解説 or 個人なら事前調査）。土台が薄いと類比が的外れになる。
- **限界（批判を踏まえて）**:
  - **量≠質**: 発想の数を増やすことと、実用に足る優れた1案を出すことは別問題。シネクティクス（教育モデル）の実証研究は**流暢性・柔軟性の向上を報告する点では概ね一致する一方、独創性(originality)への効果は結論が分かれ、向上を認める報告と、有効でなかったとする報告が併存する**（実装・測定条件で結果が振れる）。創造性尺度の予測妥当性も一般に脆弱との指摘がある。いずれにせよ「奇抜さ＝価値」ではなく、後段の検証が要る。
  - **検証が必須**: 類比は仮説発見の手段に過ぎない。force fit で出た案は必ず現実性・実現可能性を別途評価する（そのまま採用しない）。
  - **ファシリテーター/専門家依存・コスト**: 質がリーダーの技量と参加者の知見に左右される。7人以下という運用上の制約も実践性を下げる。
  - **メタファーの文化・個人差依存**: 象徴・比喩の効き方は文化や個人の感性に依存し、再現性が担保しにくい。
- これらは、**force fit と検証工程を必ず回す／出た案を pmi・ペイオフマトリクスで選別する／飛ばす前に問題を PAU で締め直す**ことで緩和できる（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。Gordon系の構造手順を骨格に、Prince系の実務作法（springboard／itemized response）を織り込んだ実践版。

1. **問題を提示する（PAG: Problem As Given）。** 解きたい問題を一旦そのまま置く。
   なぜ: 出発点を共有しないと飛んだ先から戻れない。ここではまだ精緻化しすぎない。
2. **異質馴化する — 問題を分解して理解し直す（PAU: Problem As Understood）。** 専門家の解説や事実で背景を共有し、「本当に解きたいのは何か」を "How to〜/ こうしたい(I wish〜)" の形で言い換え、狙い（誰の何を、どこまで）を定める。
   なぜ: 表面的なPAGのまま飛ばすと的外れな類比になる。問題の**核の緊張**を掴むほど、後の類比が効く。
3. **既存案を吐き出す（パージ）。** 今すぐ思いつく普通の解を先に全部出し切って脇に置く。
   なぜ: 既存案が頭に居座ると飛べない。吐き出して「もう出ない」状態を作ってから遠足へ向かう。
4. **馴質異化する — 喚起的質問(EQ)で遠足(excursion)に出る。** 問題から意図的に離れ、4類比で遠くの領域へ飛ぶ。1つに頼らず切り替える。
   - **直接的類比**: 「この問題と似た仕組みは、自然・生物・別業界のどこにあるか？」（例: 群れ・血管・鉄道ダイヤ）。
   - **擬人的類比**: 「自分がこの対象そのものだったら、何を感じ、どうされたいか？」（対象になりきる）。
   - **象徴的類比**: 「この問題の本質を、矛盾を孕む2語（例: 静かな爆発／優しい拷問）で言うと？」（compressed conflict を作る）。
   - **空想的類比**: 「法則も常識も無視できるなら、理想はどんな状態か？」（例: 勝手に直る／時間が戻る）。
   - ※**Gordon原著（1961, Ch.2 "The Operational Mechanisms"）の操作順序は擬人的類比を起点**とし、擬人→直接→象徴→空想の順で提示される。本稿は入りやすさを優先して直接的類比を先頭に置いており、提示順は原典と異なる（順序に優劣はなく、扱いやすい類比から入ってよい）。
   なぜ: 近い連想からは既視感のある案しか出ない。遠くへ飛ぶほど非連続な素材が手に入る。
5. **持ち帰る類比を選ぶ。** 論理的な正しさでなく、**面白さ・引っかかり**で1〜数個選ぶ（springboard＝発想の跳躍台として）。
   なぜ: この段階で論理を求めると飛躍が死ぬ。妥当性の判断は後段に回す。
6. **強制結合する（Force Fit）。** 選んだ類比の要素を、元の問題に**無理やり**当てはめ、「これを問題に適用すると何が言えるか」を具体案に翻訳する。
   なぜ: ここがシネクティクスの心臓部。遠足の土産を強制的に接続して初めて、論理では出ない解が生まれる。飛ばして分析だけでは平凡に戻る。
7. **収束・評価する（View Point）。** 出た案を itemized response で扱う——**まず良い点を挙げ切ってから懸念を1つ**述べ、案を潰さず育てる。現実妥当性で絞り、検証すべき仮説・次の一手を1〜3個決める。
   なぜ: 量≠質。奇抜さは実現性の評価とセットで初めて価値になる。ここで検証に渡さないと「面白い思いつき」で終わる。
8. **満足いく解が出るまで反復する（recycle）。** 足りなければ別の類比・別の遠足先で4〜7を回す。
   なぜ: 一度の遠足で当たるとは限らない。飛ぶ先を変えて多様な素材を集める。

## 壁打ち質問リスト

各ステップを埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. いま解きたい問題を一言で言うと何ですか？ そして「本当に叶えたいこと」を "こうしたい／どうすれば〜できるか" の形で言うと何ですか？（PAG→PAUの締め直し）
2. すでに出ている・思いつく「普通の解」は何ですか？（先に吐き出して脇に置くため。ここに満足していないから飛ばすのですよね？）
3. この問題の**本質にある緊張や矛盾**を、あえて相反する2語で表すと何になりますか？（例:「速いのに壊れない」「開いているのに秘密」＝象徴的類比の種）
4. **自然・生物・まったく別の業界**で、これと似た働き・似た困りごとを解決している例はありませんか？（直接的類比の探索）
5. もし**あなた自身がこの製品／仕組み／対象そのもの**になったら、何を感じ、どう扱われたいですか？（擬人的類比）
6. **物理法則も予算も常識も無視してよい**なら、理想の状態はどんな姿ですか？（空想的類比。ここを制約で潰さない）
7. その飛んだ発想を、元の問題に**無理やり当てはめる**と、どんな具体策になりますか？ 現実にするには何を変える必要がありますか？（force fit）
8. 出た案のうち、**良い点を先に挙げる**とどれが魅力的ですか？ そのうえで検証すべき前提・懸念は何ですか？（収束と次の一手）

## 出力フォーマット

ALWAYS この型で出力する（問題の締め直し→遠足→強制結合→収束の4段）。命令形で固定する。

```
【問題の締め直し】
  PAG（与えられた問題）: <そのままの問題>
  PAU（理解し直した問題）: <「どうすれば〜できるか / こうしたい」形＋核にある緊張>
  既存の普通の解（脇に置く）: - <…>

【遠足（4類比で飛ばす）】※使ったものだけでよいが、直接＋象徴は最低含める
  直接的類比: <別分野・自然の似た仕組み> → 借りられる要素: <…>
  擬人的類比: <対象になりきって得た視点>
  象徴的類比: <矛盾を孕む2語> → 示唆: <…>
  空想的類比: <常識無視の理想像> → 種: <…>

【強制結合（Force Fit）】
  跳躍台に選んだ類比: <面白さで選んだもの>
  無理やり接続した具体案:
    - 案1: <類比の要素 × 元の問題 = 具体策>
    - 案2: <…>

【収束と次の一手】
  良い点（先に）→ 懸念（1つ）: <itemized responseで残した有望案>
  次の一手: <検証すべき仮説・試作・意思決定を1〜3個>
  未確認の前提: <事実確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**混雑する店舗のレジ待ち行列を減らしたい**という課題。

- **PAG**: レジの待ち行列が長く、客が離脱する。
- **PAU（異質馴化）**: 本当に解きたいのは「待ち時間の長さ」そのものより「**待たされていると感じさせずに会計を終える**」こと。核の緊張＝「捌く速さ」と「一人ひとり丁寧に」の両立。
- **既存案を吐き出す**: レジ台を増やす、店員を増やす、セルフレジ導入——いずれも既知で頭打ち。脇に置く。
- **遠足（馴質異化）**:
  - 直接的類比: 高速道路の料金所ETC（止まらず課金）、テーマパークの待ち列（待ち時間の可視化と演出）、蜂の巣の分業。
  - 擬人的類比: 「自分が列に並ぶ商品だったら」→ 早くカゴから出て袋に収まりたい、勝手に数えられていたい。
  - 象徴的類比: 「立ち止まる前進」——動いていないのに進んでいる感覚。
  - 空想的類比: 「店を出た瞬間に会計が済んでいる」「商品が自分から名乗る」。
- **跳躍台の選択**: 面白さで「立ち止まる前進（象徴）」と「止まらず課金（ETC＝直接）」を選ぶ。
- **強制結合（Force Fit）**:
  - 案1: ETC×レジ → 会計を「並んでいる間」に進める（列に並ぶ動線上でスキャン・事前決済を済ませ、最後は受け取りだけ）。
  - 案2: 「立ち止まる前進」×待ち列演出 → 待ち時間を進捗として見せる（残り人数・見込み時間の提示、動く列にして体感待ち時間を下げる）。
- **収束と次の一手**: 良い点（設備投資を抑えつつ体感待ちを下げられる）→ 懸念（オペレーション変更の負荷）。次の一手＝「並んでいる間の事前スキャン」を一部時間帯で小さく試し、離脱率と体感待ち時間の変化を測る。
- **未確認の前提**: 現状の離脱が「実待ち時間」由来か「体感」由来か——ここは実データで裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `analogical-thinking`: 類比の「構造を借りる」中核ロジックを精緻化する。シネクティクスの遠足を、より意識的な構造マッピングに引き上げる同族（perspective-shift）。
- `nm-method`: シネクティクス/アナロジー発想を日本流に体系化した派生。キーワード→類比→着想の手順が明快で、個人ワークに落としやすい。
- `random-word`: 遠足先が思い浮かばないとき、無関係な語を強制刺激として投入し、force fit の素材を機械的に供給する。
- `equivalent-transformation`: 対象の**本質を抽出して別領域へ移す**発想。象徴的類比（本質の抽出）を厳密化したい局面で補完。
- `brainstorming`: シネクティクスの母体。判断保留・自由連想で種を広げてから、本手法で遠くへ飛ばすと相乗する。
- `pmi` / `payoff-matrix`: force fit で量産した飛んだ案を、多面評価（PMI）や効果×実現性（ペイオフ）で**選別・収束**する。量≠質の限界を補う後工程。
- 揺さぶり枠として `reverse-assumption`（前提を反転して新たな遠足先を作る）や `premortem`（採用案が失敗する筋を先回りして検証課題を洗う）を添えると、独創性と実装確度の両方が上がる。
