# 40の発明原理（40 Inventive Principles）

矛盾を解く普遍的な発想の型。**原理は"種"であり、そのままでは答えにならない。** 各原理を対象の部品・工程・材料へ
「翻訳（具体化）」して初めてアイデアになる。使い方は2通り。(a) 矛盾マトリクスが示した番号を深掘りする、
(b) 矛盾が曖昧なとき、上から順に「この原理を当てるとどうなる？」と刺激として通す。

## 物理的矛盾を解く「分離原理」（4種）

同一の要素が相反する性質（A と 非A）を同時に要求されるとき、**両立させず"分離"して解く**。
矛盾マトリクスより先にこちらを試すと有効なことが多い。

- **空間で分離**: 場所によって性質を変える（例: ある部位は硬く、別部位は柔らかく）。
- **時間で分離**: 時間帯・工程で性質を切り替える（例: 使用時は展開して大きく、収納時は畳んで小さく）。
- **条件で分離**: 条件・状態に応じて性質を変える（例: 荷重がかかると硬化、外れると柔軟）。
- **部分と全体で分離（システム移行）**: 全体と部分・上位系と下位系で性質を分担させる（例: 鎖は全体は柔だが各リンクは剛）。

## 使うときの注意
- 原理は**思考の刺激**。1つの矛盾に複数原理を当て、具体案を複数出してから絞る。
- 「当てはめて終わり」にしない。必ず対象の部品・工程・材料へ翻訳し、二次矛盾（新たな副作用）を点検する。
- 訳語のゆれに惑わされないよう、迷ったら英名と「発想の核」で判断する。
