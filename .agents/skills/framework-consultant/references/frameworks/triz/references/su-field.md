# 物質-場分析（Su-Field / Substance-Field Analysis）

機能を**最小単位のモデル**で表し、「何が足りない/有害/過剰か」を診断して標準的な改善方向（標準解）へつなぐツール。
矛盾が「特性の対立」でなく「**機能が働いていない/悪さをしている**」形のときに強い。

## 基本モデル

一つの機能は、最小で **3要素** で表せる。

- **S1**: 作用を受ける対象（object / 被作用物）
- **S2**: 作用を及ぼす物（tool / 作用体）
- **F**: 両者を結ぶ**場（field）＝エネルギーの種類**（機械/熱/化学/電気/磁気/音・重力 など）

```
      F（場）
   S2 ───────▶ S1     （S2 が F を介して S1 に作用する）
```

- 望ましい作用は **実線の矢印**、有害・過剰・不足な作用は **点線や波線** で描き分ける。
- 複雑な系は、この最小モデルを**連結**して表す。

## 診断 → 標準解の方向（典型パターン）

モデルを描くと、欠陥が4類型のどれかに見える。それぞれに定石の直し方がある。

- **機能が不完全（要素が足りない）**: S1しか無い、場が無い、作用体が無い → **不足要素を加えて完全な三角形にする**
  （S2 や F を導入して機能を成立させる）。
- **機能はあるが不十分**: 作用が弱い → **場を強める／別の場を追加する／作用体を効果的な物質に替える**。
- **有害な作用がある**: S2 が S1 に悪さをする → **第3の物質S3を挟んで有害作用を遮断**、または**別の場で打ち消す**。
- **過剰な作用がある**: 効き過ぎ → **緩衝物を入れる／作用を局所化する**。

これらの定石を体系化したのが **76の標準解（標準解集）**（後に111へ再整理する研究もある。数は体系により異なる＝要確認）。
標準解は大きく「物質-場の構築・強化」「有害作用の除去」「進化（マクロ→ミクロ化、場の高度化）」「測定・検出」の系に分かれる。

## 使い方（手順）

1. **問題の機能を1つ選び、S1・S2・F を書き出す。** 「何が何に、どの場で作用しているか」。
2. **欠陥を型に当てる。** 不足/不十分/有害/過剰のどれか。要素が欠けていないか点検する。
3. **対応する標準解の方向を適用する。** 要素を足す/場を替える/S3を挟む 等。
4. **具体化する。** 抽象モデル上の解を、実際の部品・材料・エネルギー源に翻訳する（→`principles-40.md`の原理も併用）。

## いつ使う / 注意
- **使う**: 「くっつかない・切れない・検出できない・壊れる・干渉する」など**機能の成否**が論点のとき。
- **注意**: モデル化に慣れが要る。まず場（F）を機械/熱/電気/化学/磁気のどれかで言えるかを確かめる。
  場が特定できない問題は、9画面や40原理から入る方が速いこともある。
