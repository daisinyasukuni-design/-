# 9画面法（Nine Windows / System Operator / 多画面法）

問題を「今・ここ・この対象」だけで見る近視眼から抜け出すためのツール。
**空間軸（システムの階層）× 時間軸（過去・現在・未来）** の3×3で対象を俯瞰し、解の探索範囲を広げる。

## 3×3の構造

| | 過去 | 現在 | 未来 |
|---|---|---|---|
| **上位システム**（対象が属する上位の系・環境） | 上位・過去 | 上位・現在 | 上位・未来 |
| **システム**（対象そのもの＝問題の主役） | 系・過去 | **系・現在（起点）** | 系・未来 |
| **下位システム**（対象を構成する部品・要素） | 下位・過去 | 下位・現在 | 下位・未来 |

- 中央の「**システム・現在**」に、いま解こうとしている対象を置くのが起点。
- そこから **上下（部品↔環境）** と **左右（それがどう生まれ、どう変わるか）** に視野を展開する。

## 使い方（手順）

1. **中央を定義する。** 問題の主役（対象システム）を「システム・現在」に置く。
2. **上下に展開する（空間）。** 下位＝それを構成する部品・要素、上位＝それが置かれる環境・上位の系。
   なぜ: 解は対象そのものより、部品側や環境側にあることが多い。
3. **左右に展開する（時間）。** 各セルについて、過去（どう生まれた/前段の状態）と未来（どう変わる/次の状態）を書く。
   なぜ: 「使う前/使った後」「原因の連鎖」「進化の方向」に解の糸口が現れる。
4. **9枠を眺めて着眼を拾う。** 「上位・未来に理想像がある」「下位・過去に原因がある」など、
   埋めた枠の間の関係から、問題の再定義や解のアイデアを取り出す。

## 効きどころ
- **問題の定義が狭すぎる**とき。対象だけをいじって行き詰まったら、上位（環境で解く）や下位（部品で解く）に逃がす。
- **原因・時間の連鎖**を捉えたいとき。有害作用が「いつ・どの階層で」生じるかを可視化する。
- **理想像（IFR）の探索**。「上位システム・未来」に、対象が消えても機能だけ残る理想を描ける。
- 技術問題に限らず、非技術の状況整理にも転用しやすい（システムオペレータの汎用性）。

## 注意
- 9枠すべてを無理に埋めることが目的ではない。**視野を広げて着眼を得る**ための足場。
- 発想が出たら、40原理・物質-場・矛盾定義に戻して具体化する（9画面は"広げる"、他ツールで"詰める"）。
