# 矛盾マトリクス（Contradiction Matrix）

技術的矛盾（「Aを良くするとBが悪くなる」）を、**39の標準パラメータ**に翻訳し、
改善したい特性×悪化する特性の交点セルから、その矛盾に**最も使われた発明原理（最大4つ）**を逆引きする表。

## 使い方（4ステップ）

1. **矛盾を "改善したい特性 vs 悪化する特性" の対で言う。** 例: 「保冷性能を上げると容積・重量が増える」。
2. **両方を39パラメータの語彙に写像する。** 例: 改善≒「エネルギー損失/温度」、悪化≒「動く物体の重量・体積」。
   ここが写像ギャップの肝。ぴったり無ければ近いパラメータを複数試す。
3. **交点セルの原理番号を引く。** そのセルに入っている原理（例: #1 分割、#15 動的性、#35 パラメータ変更 等）を候補にする。
4. **原理を具体化する。** `principles-40.md` を参照し、各原理を対象の部品・工程・材料へ翻訳して複数案を出す。

> 完全な39×39表（各セルの原理番号）は公開の実装（例: triz40.com などの Contradiction Matrix）で参照する。
> このスキルでは「どのパラメータに写像し、どの原理を引くか」の思考プロセスを主に担う。

## 39の技術パラメータ（改善/悪化の軸に使う語彙）

1. 動く物体の重量 / 2. 静止物体の重量 / 3. 動く物体の長さ / 4. 静止物体の長さ /
5. 動く物体の面積 / 6. 静止物体の面積 / 7. 動く物体の体積 / 8. 静止物体の体積 /
9. 速度 / 10. 力 / 11. 応力・圧力 / 12. 形状 / 13. 構造の安定性 / 14. 強度 /
15. 動く物体の作用時間（耐久） / 16. 静止物体の作用時間（耐久） / 17. 温度 /
18. 照度・明るさ / 19. 動く物体の使用エネルギー / 20. 静止物体の使用エネルギー /
21. 出力・パワー / 22. エネルギーの損失 / 23. 物質の損失 / 24. 情報の損失 /
25. 時間の損失 / 26. 物質の量 / 27. 信頼性 / 28. 測定精度 / 29. 製造精度 /
30. 物体に働く有害要因 / 31. 物体が生む有害要因 / 32. 製造しやすさ / 33. 使いやすさ /
34. 修理しやすさ / 35. 適応性・融通性 / 36. 装置の複雑さ / 37. 制御の複雑さ /
38. 自動化の程度 / 39. 生産性

> 訳語は体系により表記ゆれあり（例: 30/31 の「有害」方向、35「適応性/汎用性」）。番号と意味で扱う。

## 限界（頼り切らない — 重要）

- **空欄セルがある。** 交点に原理が無いことがある。→ 物理的矛盾に言い換え、`principles-40.md` の分離原理へ。
- **各セル最大4原理しか出ない。** 有効な原理を網羅しない。他の原理も刺激として試す。
- **写像ギャップ。** 現実の多様な特性を39に押し込む所に主観が入る。近いパラメータを複数当てて比較する。
- **古い特許ベース。** 最新技術分野を十分反映しない可能性（→出典の批判論文）。
- **アルトシューラー自身が後年、マトリクスを主力から外し ARIZ・物質-場/標準解へ移行**したとされる（要確認）。
  マトリクスは"入口"として有用だが、行き詰まったら物質-場（`su-field.md`）・9画面（`nine-windows.md`）へ切り替える。
