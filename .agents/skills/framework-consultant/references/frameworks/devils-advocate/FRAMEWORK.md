# 悪魔の代弁者（Devil's Advocate）

## 概要

悪魔の代弁者は、集団が支持に傾いている**決定・計画・仮説に対して「反対役」を意図的に割り当て、
それに対する最強の反論を構築する**技法。目的は、賛成一色の空気（集団浅慮 / groupthink）と
確証バイアスを崩し、**意思決定を確定する前にわざとストレステストする**こと。

- **核となる考え方**: 反対意見が「自然発生しない」なら、**役割として制度的に生成する**。
  批判を個人の資質や勇気に依存させず、正式な役・マンデートに変えることで、
  誰も傷つけずに「この決定のどこが脆いか」を机上に載せる。
- **位置づけ**: 新しい案を広げる発散技法ではなく、**既にある案を批判で磨く/検証する**技法（lens=risk）。
- **出自（諸説あり・要確認）**: 語源はカトリック教会の列聖手続きの正式な職 **advocatus diaboli**、
  正式名 **Promoter of the Faith（promotor fidei / 信仰の推進者）**。列聖候補に対し「聖人にすべきでない」
  根拠（人物・証拠の穴、奇跡の真偽）を書面で提出する役で、対になる推進側が **God's advocate（advocatus Dei）**。
  制度化は **1587年・教皇シクストゥス5世（Sixtus V）**、**1983年・ヨハネ・パウロ2世（John Paul II）** が
  改革して権限を大幅縮小、とされる（→出典・要確認）。**「悪魔の代弁者」は俗称**で、教会の正式名は promotor fidei。
- **現代への展開**: Irving Janis が集団浅慮の予防策の一つに「各会合で1人にこの役を与える」を挙げた。
  経営意思決定の実証（Schweiger, Sandberg & Ragan, 1986）では、**合意アプローチより高品質な決定**を生む一方、
  **メンバーの納得感（受容）が下がる**ことも示された（→再決定ステップが要る理由）。

## いつ使う / 使わない

**使う（適する状況）**
- **賛成一色で反対意見が出ない**とき。「全員が同意している」こと自体が危険信号のとき。
- **大きく・後戻りしにくい意思決定**（多額投資・撤退・買収・重要ローンチ）を確定する直前の点検。
- **強いリーダーや上下関係**があり、本音の異論が抑圧されていそうなとき。
- 「これで行こう」とまとまった計画を、**コミット前に一度わざと叩いておきたい**とき。
- 仮説・企画・提案書の**前提の脆さ**を、当事者以外の視点で洗い出したいとき。

**使わない / よくある誤用（アンチパターン）**
- **「ただの悪魔の代弁だけど（just playing devil's advocate）」の悪用**——当事者性なく、責任を回避しつつ
  逆張りを気取るトークン反対。「本気で言ってるわけじゃない」と**責任の盾**にする、議論を脱線・支配する、
  相手の現実を否定する（ガスライティング）——これらは技法ではなく害。役には**真剣な分析のマンデート**を課す。
- **演技が本物の異論に劣る（Nemeth 2001）**——役だと分かる反論は割り引かれやすく、さらに提案側が反論を予期して
  自説の防御論拠を固め、**かえって当初案への確信を強める（認知的補強・逆効果）**ことがある。
  **本心から反対する人がいるなら、演技より その人の真正の異論(authentic dissent)を引き出す**方が有効。
- **儀式化・形骸化**——毎回同じ人／形だけの「一応反対役」。機能させるにはローテーションと本気度が要る。
- **粗探しで終わり再決定しない**——質は上がるが納得感が下がる（Schweiger 1986）。挑戦の後に必ず**再収束**を置く。
- **攻撃対象が曖昧**なまま始める——「支持されている案」が明文化されていないと反論が空回りする。
- 新アイデアを**創出**したい（発散）局面、または純粋に決定への**合意形成・団結**を優先すべき局面には不向き。

## 前提と限界

- **前提**: (1)叩く対象＝「今まとまりつつある決定/計画」が1つに明文化されていること。
  (2)**心理的安全性と正式なマンデート**——反対役が「面倒な人」扱いされず保護されること。
  (3)提案側に、役の反論へ**本気で応答する**意思があること（「役でしょ」で流さない）。
- **限界（研究を踏まえて）**:
  - **演技型は真正の異論に劣る（Nemeth）**——割り当て型は認知的補強を招き、当初案を強化し得る。
    可能なら本物の懐疑者を招く。役でやるなら**steelman（相手の最強版）**を本気で作る。
  - **納得感の低下（Schweiger, Sandberg & Ragan 1986）**——決定の質は上がるが、メンバーの満足度・受容が下がる。
    **再決定の合意**で回収しないと、実行段階のコミットが弱る。
  - **1人・1回に依存すると偏る/燃え尽きる**——ローテーションし、役に固執させない。
- これらは、**真正の異論を併用する / 挑戦後に再収束ステップを必ず置く / 役を回す** ことで補える。
  さらに揺さぶりたければ premortem・red-team・reverse-assumption を重ねる（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **叩く対象を1文で明文化する。** 「私たちは〈X〉に決めようとしている」と決定・計画を言語化する。
   なぜ: 反対役には具体的な標的が要る。曖昧なままだと反論が空回りする。
2. **その決定が乗っている前提を3〜5個、書き出す。** 「これが崩れたら決定も崩れる」土台を特定する。
   なぜ: 悪魔の代弁者は結論そのものより**前提**を突くほうが効く。以降の攻撃対象を明確にする。
3. **反対役を明示的に割り当て、マンデートと保護を与える。** できれば**ローテーション**し、1人固定を避ける。
   なぜ: 批判を個人の勇気でなく「役割」にすることで、人を傷つけず、報復も恐れず反論できる。
4. **反対役は「最強の反論」を steelman で構築する。** 藁人形でなく、賢く情報を持つ批判者の最良版を作る。
   各前提に「これは本当か／証拠は合意や権威の追認に過ぎないか／別の解釈は／基準率(base rate)はどうか」を当てる。
   なぜ: 弱い反論は「やっぱり当初案で正しい」を補強するだけ。倒しにくい反論ほど価値がある。
5. **提案側が本気で応答する。** 「役でしょ」と流さず、各反論に証拠・論理で答える。
   なぜ: 反論を割り引くと Nemeth のいう逆効果（当初案の過信）に陥る。真剣な応酬が思考を広げる。
6. **人と立場を分離し、浮かんだ論点を回収する。** 勝ち負けでなく、**生き残った反論・未検証の前提・見落としリスク**を記録する。
   なぜ: 目的は論破でなく、確定前に**脆さの棚卸し**を得ること。
7. **再収束（再決定）する。** 出た論点を受けて、決定を「修正する／安全策を足す／目を開けたまま進める／中止する」の
   いずれかへ合意で着地させる。
   なぜ: 挑戦だけだと納得感が下がる（Schweiger）。明示的な再決定で実行のコミットを取り戻す。
8. **必要なら真正の異論へ切り替える。** 本心から反対する人がいるなら、演技より**その人の異論を引き出す**。
   なぜ: 割り当て型より authentic dissent の方が、独創的思考と実際の態度変容を生む（Nemeth）。

## 壁打ち質問リスト

反対役の反論を的確にするために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. いま**チームが決めようとしている案**は何ですか？ 1文で言い切ってください（叩く標的の明確化）。
2. その決定が**乗っている前提**は何ですか？ そのうち「これが偽なら決定が崩れる」**土台の前提**はどれですか？
3. 賛成の**根拠**は何ですか？ その根拠は実データですか、それとも「みんなが言っている／上がそう言った」という
   合意・権威の追認になっていませんか？
4. この案が**正しいと最も得をするのは誰**ですか？ その力学で**反対意見が言いにくく**なっていませんか？
   この場で異論を出すのは実際に安全ですか？
5. 賢く十分に情報を持つ**競合や批判者が「これは失敗だ」と論じる**としたら、**最強の論拠**は何になりますか？
6. 6〜12か月後にこの決定が**失敗していた**として、原因は何で、**いま既に見えている予兆**を私たちは
   どれだけ無視していますか？
7. チーム内に**本心から反対している人**はいませんか？（真正の異論の有無の確認。演技より優先すべき情報）
8. 挑戦の後——**どの反論が決定を変え、どれはノイズで、どんな安全策を足す**ことにしますか？（再決定への橋渡し）

## 出力フォーマット

ALWAYS この型で出力する（挑戦だけで終わらせず、必ず【再決定】まで書く）。命令形で反対役を演じる。

```
【対象の決定】<チームが賛成に傾いている決定/計画を1文で>
【前提（土台）】
  P1: <この決定が乗っている前提>  … P2, P3（崩れたら決定が崩れる順に3〜5個）

【悪魔の代弁者の反論】（steelman・最強の反論。前提ごとに）
  対P1: 主張<これは誤り/危うい> / 証拠・基準率<根拠> / だから<決定への含意>
  対P2: …
  （＋前提の外側からの反論：見落とされた選択肢・最悪シナリオ・利害の偏り）

【提案側の応答】<各反論への本気の再反論。証拠・論理で>

【生き残った論点】<応答しきれず残った反論・未検証の前提・見落としリスク>

【再決定】<修正して進む / 安全策を足して進む / 目を開けたまま進む / 中止> ＋ その理由
【次の一手】<再決定を実行に移す最初のアクション・追加すべき安全策・検証を1〜3個>
【未確認の前提】<事実確認が要る点（壁打ちで埋める）>
【異論メモ】<本心からの反対者がいたか。いれば演技より優先して深掘り>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。あるチームが、社内で好評な新サブスク機能を
「全員賛成」で今四半期にローンチしようとしている場面。**賛成一色＝危険信号**として悪魔の代弁者を回す。

- **手順①対象**: 「新サブスク機能を今四半期にローンチする」と1文で確定。
- **手順②前提**: P1 既存顧客が追加課金を受け入れる／P2 開発は期日に間に合う／P3 競合はすぐには追随しない／
  P4 サポート体制は増員なしで回る。
- **手順③割り当て**: 進行役とは別のメンバーを反対役に指名（次回は別の人に回す）。「本気で潰しにいく」マンデートを付与。
- **手順④最強の反論（steelman）**:
  - 対P1: 「好評」は熱心な一部の声かもしれない。無関心層・離反リスクの基準率で見ると、
    追加課金への受容は過大評価では？ 実際の支払意思のデータはあるか。
  - 対P2: 期日前提は過去の楽観見積りの再来では。バッファなしの計画が崩れた前例は？
  - 対P3: 競合が容易に模倣できるなら、先行の優位は数か月で消えるのでは。
  - 前提の外側: 「賛成一色」自体が、旗振り役への忖度で反対を言い出せない状態を示しているのでは。
- **手順⑤提案側の応答**: P1にはβ利用者の継続率という反証を出す／P2は工数根拠を示す、等。役だからと流さず応答する。
- **手順⑥生き残った論点**: 「支払意思の一次データが薄い（P1）」「バッファ不在（P2）」が反論として残った。
- **手順⑦再決定**: 中止ではなく「**安全策を足して進む**」——小規模の価格受容テストを先行し、期日にバッファを確保、
  という条件付きローンチへ修正。全員賛成の空気は、条件付き合意へと質を上げて着地。
- **未確認の前提**: 追加課金への実際の支払意思、離反率——一次データで裏取りが要る（推測のまま進めない）。
- **異論メモ**: もし内心「時期尚早」と思っていたメンバーがいたなら、演技より**その人の異論**を先に深掘りする。

## 相性（組み合わせると効く）

- `premortem`: 「この決定は**既に失敗した**」と仮定して原因を語らせる。悪魔の代弁者が「今」反論するのに対し、
  時制を未来に飛ばして揺さぶる姉妹技法。前提P2/P4の失敗シナリオを厚くできる。
- `red-team`: 敵・攻撃者を本格的に演じて脆弱性を洗う、より重い運用。反対役1人では足りない高リスク案の深掘りに。
- `reverse-assumption`: 手順②で挙げた前提を機械的に**反転**させ、反論の切り口を発想する前工程。
- `six-hats`: 黒帽子（慎重・リスク）を全員で被る役割分担。悪魔の代弁者はそれを1人の反対弁論に制度化した形。
  緑帽子と往復させると、批判の後に建設的な代替案づくりへ繋げられる。
- `pmi`: 挑戦で偏りがちな評価を Plus/Minus/Interesting で一度フラットに棚卸しし、再決定の材料を整える。
- `decision-matrix`: 生き残った論点を評価軸に落とし、修正後の選択肢を採点して再決定を客観化する。
