# ブルーオーシャン戦略（ERRC・戦略キャンバス）

## 概要

ブルーオーシャン戦略は、競合ひしめく既存市場（**レッドオーシャン**＝血の海）で需要を奪い合うのではなく、
**競争が存在しない未開拓の市場空間（ブルーオーシャン）を自ら創り出す**ための戦略フレームワーク。
中核は **バリュー・イノベーション（value innovation）** ——従来の戦略が前提とする「差別化（高付加価値）か、
低コストか」の**トレードオフを破り、両方を同時に実現する**という考え方にある。
既存業界の競争要因を並べ直し、ある要因は**大胆に減らす/捨てる**（＝コストを下げる）一方、
別の要因を**大きく高める/新しく創る**（＝買い手価値を上げる）ことで、両立を成立させる。

| | レッドオーシャン | ブルーオーシャン |
|---|---|---|
| 市場 | 既存の市場空間（境界は所与） | 未開拓の市場空間（境界を引き直す） |
| 競争 | 既存の競合と奪い合う | 競争を無意味にする |
| 需要 | 既存需要を取り合う | 新規需要を創造する |
| 価値とコスト | トレードオフ（どちらかを選ぶ） | 両立（value innovation） |

- **核となる考え方**: 競合をベンチマークして「より良く」戦うのをやめ、**買い手にとっての価値要素とコスト構造を同時に組み替える**。
  勝つべきは「競争」ではなく、まだ需要になっていない**非顧客**を含めた新しい買い手層。
- **2つの主要ツール**:
  - **戦略キャンバス（Strategy Canvas）**: 横軸＝業界が競争し投資している**競争要因**、縦軸＝各要因について**買い手が受け取る提供レベル**。
    自社・競合の提供レベルを結んだ折れ線が**価値曲線（value curve＝戦略プロファイル）**。業界が「どこで似たり寄ったりか」を暴く診断図。
  - **ERRC グリッド（四つのアクション・フレームワーク）**: 各競争要因に対し **Eliminate（取り除く）/ Reduce（減らす）/ Raise（増やす）/ Create（付け加える）**
    を問い、埋める。**Eliminate + Reduce がコストを押し下げ、Raise + Create が価値を押し上げる**。この4枠を同時に埋めることで value innovation を強制する。
- **良い戦略の3条件**: 優れた価値曲線は (1) **メリハリ（focus）**＝少数の要因に資源を集中、(2) **高い独自性（divergence）**＝競合と明確に異なる形、
  (3) **訴求力あるキャッチフレーズ（compelling tagline）**＝一言で刺さる、を満たす。3つが揃わない曲線は「戦略として弱い」サイン。
- **出自（要確認）**: 考案者は INSEAD 教授 **W・チャン・キム（W. Chan Kim）** と **レネ・モボルニュ（Renée Mauborgne）**。
  先行して HBR 論文 **"Value Innovation"（1997）**、**"Blue Ocean Strategy"（2004）** で提示し、著書
  **『Blue Ocean Strategy』（Harvard Business School Press, 2005／拡張版 2015）** で体系化した（→出典・要確認）。

## いつ使う / 使わない

**使う（適する状況）**
- **価格競争・同質化競争（レッドオーシャン）から抜け出したい**とき。値下げ以外の勝ち筋を、競争構造そのものを変えて設計したい。
- **新しい市場・カテゴリー・事業を創りたい**とき（既存の需要ではなく、まだ需要になっていない層を取りに行く）。
- 業界の**「当たり前」を疑い**、非常識な打ち手・独自ポジションを発想したいとき（発散に構造を与える器として）。
- **非顧客（今は買っていない人）**の潜在需要を掘り起こし、市場を広げたいとき。
- 新規事業・事業再定義で、**差別化と低コストの両立**という難題に挑むとき。

**使わない / よくある誤用（アンチパターン）**
- **既存市場の中で「誰に・どう売るか」だけを詰めたい**——それは STP（セグメント/ターゲット/ポジショニング）の仕事。市場境界を引き直さないなら本フレームは過剰。
- **ERRC を「思いつきの奇抜アイデア出し」で終える**——最頻の誤用。Create/Eliminate を埋めて満足し、**価値とコストの両立・採算・実現性**を検証しない。ERRCは起点であって結論ではない。
- **戦略キャンバスを競合模倣の道具にする**——競合の曲線に「勝つ」ため各要因を一律に上げると、コストが膨らみ差別化もぼやける（value innovation の逆）。**捨てる勇気**が本質。
- **「業界」の定義を曖昧なまま進める**——何を業界・市場と置くかで競争要因も非顧客も変わる。境界の恣意的な操作は結論を歪める最大の危険。
- **需要創造の裏取りをしない**——「非顧客はきっと欲しがる」という願望を検証せずに投資する。潜在需要は仮説として**小さく試す**。
- **持続性・模倣を無視する**——ブルーオーシャンも成功すれば模倣されレッド化する。参入障壁・先行優位の設計を伴わないと一過性で終わる。
- 既存事業の**オペレーション改善・原価低減そのもの**が目的なら別フレーム（バリューチェーン、リーン等）が適する。

## 前提と限界

- **前提**: (1) 分析対象の**業界・市場境界を一貫した基準で定義**できること（製品カテゴリ／買い手／地理／代替産業の範囲）。
  (2) 業界の**主要な競争要因**を列挙でき、自社・競合の提供レベルを（粗くとも）評価できること。
  (3) **非顧客層**にアクセスして潜在ニーズを観察・仮説化できること。データが無ければ壁打ちで補い、jtbd/persona で顧客理解を先に固める。
- **限界（批判を踏まえて）**:
  - **後知恵・サバイバーシップバイアス**——理論の主な根拠が「成功事例の後付け解釈」で、失敗した試行の対照群がなく**予測力・反証可能性が弱い**という批判が強い（→出典）。
  - **境界の曖昧さ**——「業界」「新市場」の線引きが理論上も曖昧で、どこからがブルーオーシャンかが恣意的になりやすい。
  - **持続可能性を語らない**——創った市場をどう守るか（参入障壁・模倣防止）の理論的手当が薄い。成功すれば模倣されレッド化する。
  - **新規性への疑問**——差別化戦略・ニッチ戦略・破壊的イノベーションの**再包装**にすぎないとの指摘（Porterの差別化との重複）。
  - **需要創造の不確実性**——新市場の需要は事前に読みにくく、外れた場合のコストが大きい。
- これらは、**業界構造の魅力度・参入障壁を five-forces で／既存市場のポジショニングを stp で／潜在ニーズの実在を jtbd・value-proposition-canvas で／
  失敗要因を premortem で先回り検証**することで補える（→相性）。ERRCは発想の起点、検証は別フレームで固める。

## 進め方（手順）

命令形で示す。各ステップに「なぜ」を添える。**「捨てる・減らす」を必ず埋める**のが肝（足し算だけでは value innovation にならない）。

1. **目的と業界・市場境界を1つに固定する。** 何のための分析か（脱・価格競争／新市場創造／事業再定義）と、どの範囲を「業界」と呼ぶかを明文化する。
   なぜ: 境界の取り方で競争要因も非顧客も変わる。ここが曖昧だと以降の全ステップが揺らぐ。
2. **現状の戦略キャンバスを描く。** 業界が競争・投資している**主要な競争要因**を横軸に列挙し、自社と代表的競合の提供レベル（縦軸）を評価して**価値曲線**を引く。
   なぜ: まず「業界全体がどこで似ているか（＝レッドオーシャン化している所）」を可視化しないと、差別化の余地が見えない。
3. **6つのパスで市場境界を見渡す。** (1)代替産業 (2)業界内の戦略グループ (3)買い手チェーン（購入者/利用者/影響者）(4)補完財・補完サービス (5)機能志向⇄感性志向 (6)時間・トレンド、の視点で境界の外を探索する。
   なぜ: 競争要因の「並べ替え」だけでは既存の枠内に留まる。枠の外に需要の源泉があるかを体系的に探すため。
4. **非顧客の3層を洗い出す。** 第1層（縁にいて必要最小限だけ買う／乗り換え予備軍）、第2層（意識的に使わないと決めた人）、第3層（選択肢として考えたこともない遠い層）を特定する。
   なぜ: 既存顧客の満足度を上げるより、**共通する未充足**を持つ非顧客を取り込む方が新規需要は大きい。誰の何を解けば海が開くかを定める。
5. **ERRC グリッドを埋める。** 各競争要因を4枠に振る——**Eliminate**（当たり前だが要らない要因）/ **Reduce**（過剰な要因）/ **Raise**（不足している要因）/ **Create**（業界に無い新要因）。
   なぜ: Eliminate+Reduce が**コストを下げ**、Raise+Create が**価値を上げる**。4枠を同時に埋めて初めて「差別化かつ低コスト」が構造として成立する。捨てる列を空にしない。
6. **新しい価値曲線（To-Be）を描き、3条件で検算する。** ERRCの結果を戦略キャンバスに反映し、(1)メリハリ (2)独自性 (3)訴求力あるキャッチフレーズ を満たすか点検する。
   なぜ: 良い曲線は少数要因に山があり競合と形が違い一言で語れる。全要因が平均的で競合と似ていれば value innovation になっていない。
7. **実現シーケンスで検証する。** ①買い手効用（並外れた効用があるか）→②価格（大衆に届く戦略的価格か）→③コスト（その価格で目標利益を出せるか＝コスト側のERRCが効くか）→④採用（従業員・取引先・社会の抵抗をどう越えるか）を順に問う。
   なぜ: 魅力的な価値曲線でも、価格・採算・普及の壁で頓挫する。アイデアを「儲かる事業」に変えるための関門。Noが出たら5に戻す。
8. **持続性と次の一手を設計する。** 模倣への障壁（規模・ブランド・ネットワーク効果等）と、小さく試して需要を検証する実験を決める。
   なぜ: ブルーオーシャンは放置すればレッド化する。need の実在確認と防衛の両方を、機械的な発想の後に必ず添える。

## 壁打ち質問リスト

各要素を事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この検討で**最終的に決めたいこと**は何ですか？（価格競争からの脱却／新市場の創造／事業の再定義——目的を1つに）
2. 対象とする**業界・市場の境界**をどう定義しますか？（どの製品・買い手・地域・どこまでを代替と見るか。広すぎ/狭すぎないか）
3. その業界で、**各社が当たり前に競争・投資している要因**は何ですか？（機能・品質・サービス・価格・チャネルなどを5〜10個挙げると）
4. 自社と主要競合の**価値曲線は似ていますか、違いますか**？（多くの要因で横並びなら、それがレッドオーシャンの証拠です）
5. 業界が**「当然」としているのに、実は買い手が重視していない要因**はどれですか？（Eliminate/Reduce の候補——ここを削るとコストが浮きます）
6. 逆に、**業界がまだ十分に提供できていない／全く提供していない価値**は何ですか？（Raise/Create の候補）
7. **今は買っていない人（非顧客）**は誰ですか？なぜ買わない・使わないのですか？（3層のどこに大きな塊がありますか）
8. その新しい価値は、**大衆に手が届く価格**で出せますか？その価格で**利益が出るコスト構造**に届きそうですか？（効用→価格→コストの順で）
9. 実現・普及の**抵抗**は誰から来ますか？（社内・取引先・規制・顧客の習慣）。また成功したら**どう模倣を防ぎ**ますか？

## 出力フォーマット

ALWAYS この型で出力する（現状診断 → ERRC → 新価値曲線 → 実現検証）。型を固定し、常にこの構造で返すこと。

```
【ブルーオーシャン設計】目的: <決めたいこと> ／ 業界・市場境界: <一貫基準>

【現状の戦略キャンバス（As-Is）】
  競争要因: <要因1, 要因2, …（業界が投資している軸）>
  価値曲線の所見: <自社と競合はどこで横並び＝レッドオーシャン化しているか>

【非顧客の3層】
  第1層（縁の非顧客）: <誰／なぜ最小限しか買わないか>
  第2層（拒否する非顧客）: <誰／なぜ使わないと決めたか>
  第3層（未開拓の非顧客）: <誰／なぜ選択肢に入らないか>  ← 共通する未充足: <…>

【ERRC グリッド】
  Eliminate（取り除く）: <業界の当たり前で不要な要因>        ┐ コストを下げる
  Reduce（減らす）:     <過剰な要因>                        ┘
  Raise（増やす）:      <不足している要因>                   ┐ 買い手価値を上げる
  Create（付け加える）: <業界に無い新要因>                   ┘

【新しい価値曲線（To-Be）】<To-Beの形> ／ 3条件: メリハリ[◯/△] 独自性[◯/△] キャッチフレーズ「<一言>」

【実現シーケンス検証】効用[可否] → 価格(大衆に届くか)[可否] → コスト(採算)[可否] → 採用(抵抗)[可否]

【次の一手】<需要を検証する小さな実験・模倣を防ぐ障壁の設計を1〜3個>
【未確認の前提】<市場境界・非顧客の需要・価格/コスト・採用の抵抗——事実確認が要る点>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**旧来型の対面式で高価格な「習い事教室」業界**の一社が、
価格競争と生徒の奪い合い（レッドオーシャン）から抜け出す新業態を検討する場面。

- **手順①目的・境界**: 目的＝「値下げ以外で独自ポジションを作り、新規需要を取る」。境界＝「特定地域の、成人向け趣味系の対面習い事」。
- **手順②現状キャンバス**: 競争要因を列挙——講師の実績、教室の立地・内装、カリキュラムの網羅性、受講料、対面の手厚さ、資格取得。
  各社の価値曲線は**ほぼ横並び**（実績と立地で競い、料金を下げ合う）＝レッドオーシャン化を確認。
- **手順③6つのパス**: 代替産業（独学アプリ・動画）、機能⇄感性（「上達」でなく「没頭できる居場所」という感性価値）に境界拡張の余地を発見。
- **手順④非顧客の3層**: 第1層＝入会したが多忙で幽霊化した層、第2層＝「高い・敷居が高い」と避ける層、第3層＝そもそも習い事を選択肢に入れない多忙な社会人。共通の未充足＝**「時間と場所の制約」と「本格的すぎる重さ」**。
- **手順⑤ERRC**:
  - Eliminate: 高コストな一等地の大型教室、網羅的な長期カリキュラム。
  - Reduce: 講師の受賞歴などの過剰スペック、受講料。
  - Raise: 予約・中断の柔軟さ、少人数の心理的な入りやすさ。
  - Create: 短時間で完結する体験単位、オンラインと対面の併用、「上達より没頭」というコミュニティ価値。
- **手順⑥新価値曲線**: Eliminate/Reduce で浮いた原資を Raise/Create に振り、**低価格かつ独自**の曲線に。キャッチ例「本格派じゃなくていい、続けられる趣味の時間」。3条件を点検。
- **手順⑦実現シーケンス**: 効用（多忙層に刺さるか）→価格（会員制で大衆価格に届くか）→コスト（大型教室を捨てた分で採算が合うか）→採用（既存講師の反発をどう越えるか）を順に検証。
- **手順⑧持続性・次の一手**: コミュニティと会員基盤を模倣障壁に。まず**1店舗＋オンラインで小さく試し**、幽霊会員の継続率で需要仮説を検証してから拡大。
- **未確認の前提**: 非顧客の規模と支払意思、大衆価格での採算、講師の受容——実データで裏取りが要る（願望で進めない）。

## 相性（組み合わせると効く）

- `stp`: ブルーオーシャンで**新市場を創った後**、その中で誰を狙いどう位置づけるかを STP で詰める（本フレームは境界を引き直す上流、STPは市場内の下流）。
- `reverse-assumption`: 「業界の当たり前」を反転させる発想の種を出す前工程。ERRCの Eliminate/Create の候補出しに効く（reverse-assumptionは種、blue-oceanは戦略化）。
- `five-forces`: 創ろうとする新市場が**構造的に儲かるか・参入障壁を築けるか**を評価。ブルーオーシャンの弱点（持続性）を補う相棒。
- `jtbd`: 非顧客の**未解決ジョブ**を起点に Create/Raise すべき価値を特定。「なぜ買わないか」を需要創造の芯に変換する。
- `value-proposition-canvas`: ERRCで描いた新価値が、非顧客の**ペイン/ゲイン**に本当に噛み合うかを検証し、価値曲線を具体的な提供価値へ落とす。
- `premortem`: 「新市場が離陸せず失敗した」と仮定し、需要創造・価格・採用の失敗要因を先回りで潰す揺さぶり枠。
- 補完として `business-model-canvas`（新しい価値曲線を収益モデルに落とす）、`persona`（非顧客像を具体化）を添えると実装に繋がる。
