# バリューチェーン分析

## 概要

バリューチェーン分析は、企業の事業を **価値を生む個々の活動（value activities）の連鎖** として捉え、
どの活動がどれだけ価値とコストを生んでいるかを分解して、**競争優位の源泉** を突き止めるフレームワーク。
Michael E. Porter が『Competitive Advantage』(1985) で提示した（→出典・要確認）。

活動は2群に分かれる。**主活動**（製品・サービスを生み顧客に届ける直接の流れ）と、
**支援活動**（主活動を横断して支える基盤）。

| 群 | 活動 | 中身 |
|---|---|---|
| **主活動**（左→右の流れ） | 購買物流 Inbound Logistics | 投入物の受入・保管・社内配分 |
| | 製造/オペレーション Operations | 投入物を製品・サービスへ変換 |
| | 出荷物流 Outbound Logistics | 完成品の集荷・保管・流通 |
| | マーケティング・販売 | 買い手に知らせ購入を促す |
| | サービス Service | 販売後の価値維持（保守・サポート） |
| **支援活動**（主活動の上に横断） | 全般管理（企業インフラ） | 経営企画・財務・法務・品質管理 |
| | 人的資源管理 | 採用・育成・評価・報酬 |
| | 技術開発 | 設備・ソフト・技術知識・R&D |
| | 調達 Procurement | 投入物・資源の購買 |

- **核となる考え方**: 顧客が支払ってよい額（＝Porterの言う **Value**）から全活動の総コストを引いた差が
  **マージン（利益）**。競争優位は「他社より低コストで同じ活動を行う（**コスト優位**）」か
  「他社が真似できない価値を活動に埋め込む（**差別化優位**）」のどちらかで生まれる。
- **リンケージ（linkages）が肝**: 活動は独立でなく相互に連結する。ある活動のやり方が別活動のコスト/効果を
  左右する（例: 調達仕様の甘さ→製造の不良→サービスのクレーム増）。優位は個々のベストプラクティスの寄せ集めでなく、
  **活動と連結の「組み合わせ（fit）」** から生まれる。ここを見るのがバリューチェーン分析の本質。
- **value system（価値システム）**: 自社のチェーンは、上流（サプライヤーのチェーン）と下流（チャネル・買い手のチェーン）に
  連なる大きな流れの一部。優位の源泉が自社内でなく、サプライヤーやチャネルとの連結にある場合もある。

## いつ使う / 使わない

**使う（適する状況）**
- **自社の強み/弱みが「結局どの活動にあるのか」を具体的に突き止めたい**とき（漠然とした「品質が強み」を活動レベルに落とす）。
- **利益率が競合に負ける理由**を、どの活動のコストが過大かに分解したいとき（コスト構造の可視化）。
- **内製 / 外注（アウトソース）の判断**——価値を生まない/優位でない活動を外に出し、優位の源泉に集中したいとき。
- **投資・リソースをどの活動に集中すべきか**を決めたいとき（差別化のネタを事業プロセスから探す）。
- VRIO で「持続的競争優位」を検証する前段として、**候補となる強みの所在**を洗い出したいとき。

**使わない / よくある誤用（アンチパターン）**
- **工程を並べて終わり、優劣・次の一手に繋げない**——最頻の失敗。分解は手段であり、必ず「どの活動が優位/劣位か」を
  **競合との比較**で判定し、打ち手（強化/集中/外注/廃止）へ変換する。
- **内部フォーカスの罠**——個々の活動に没入して、市場・競合の大局（外部の機会/脅威）を見落とす。
  バリューチェーンは内部分析なので、単独では全体像を欠く。PEST・5フォースと併用する。
- **活動を「部署」と取り違える**——バリューチェーンは組織図でなく「価値を生む活動」の連鎖。
  部署の壁で切ると、部署をまたぐリンケージ（最大の優位源）を見逃す。
- **リンケージを無視して活動を個別最適する**——各活動を単体で改善しても、連結の不整合でトータルの価値は上がらない。
  「この活動の変更が前後の活動に何を及ぼすか」を必ず問う。
- **サービス業・デジタル事業へ製造業の型を機械的に当てはめる**——原型はモノの流れ（製造業）前提。
  従業員と顧客の相互作用が中心のサービス業やソフト/プラットフォーム事業では、主活動の定義を業態に合わせて読み替える。
- **一度描いて放置**——市場・技術・競争で価値の所在は動く。静的な図として固定しない。

## 前提と限界

- **前提**: 分析対象（会社/事業/製品ライン）が1つに定まり、その **収益構造・コストの内訳** にある程度アクセスできること。
  各活動のコスト/価値を切り分けるデータが要る。無ければ壁打ちで概算を引き出すか、定性判断であることを明示する。
  競争優位を語るには **比較対象（主要競合 or 業界標準）** が要る。「誰と比べて優位か」が無いと羅列に堕ちる。
- **限界（批判を踏まえて）**:
  - **データ収集が難しく主観が入る**——各活動のコスト/収益/資産を正確に按分する長期データは揃わないことが多い。
    埋められない箇所を仮定で埋めると分析が誤誘導される。「精密会計というより art（技芸）」と評される所以。
  - **内部志向で外部が手薄**——強みの分解には強いが、外部環境（規制・マクロ・業界構造）は射程外。
  - **業態適合の偏り**——製造業のモノの流れを前提とするため、サービス業・デジタル事業・1985年以降の業態には
    当てはめにくい面がある（HR等が「全般管理」に一括りにされる等）。業態に合わせた読み替えが要る。
  - **静的**——価値の所在は環境で動く。スナップショットとして扱い、定期的に描き直す。
- これらの限界は、**外部は PEST・5フォースで補い、強みの持続性は VRIO で検証し、
  ムダの除去は ECRS・バリューストリームマッピングに繋ぐ** ことで補完できる（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **対象と目的、比較対象を1つに固定する。** 「何のためのVC分析か」（コスト削減／差別化／内製外注判断）と、
   対象（会社/事業/製品）、比較対象（主要競合 or 業界標準）を明文化する。
   なぜ: 目的と比較軸が無いと、活動を並べただけの羅列に終わる（最頻の失敗）。
2. **主活動を業態に合わせて洗い出す。** 購買物流→製造→出荷物流→販売→サービスの流れに、自社の実際の活動を割り当てる。
   サービス業/デジタルなら主活動の定義を業態に読み替える（例: 「製造」→コンテンツ制作/開発）。
   なぜ: 汎用の型をそのまま使うと実態に合わない。自社の価値の流れに翻訳して初めて使える。
3. **支援活動を洗い出す。** 全般管理・人事・技術開発・調達が、どの主活動をどう支えているかを対応づける。
   なぜ: 優位の源泉が支援活動（例: 独自の技術開発、調達網）にあることは多い。主活動だけ見ると見落とす。
4. **各活動のコストと価値を評価する。** 活動ごとに「コストがどれだけかかるか」「顧客価値をどれだけ生むか」を
   （定量が無ければ高/中/低で）評価する。売上−総コスト＝マージンの構造を掴む。
   総コストは人員工数・設備稼働・原価費目の紐付けで活動別に配賦し、按分できない共通費は明示的に「共通」として切り分ける（これで高/中/低評価の根拠を数字に接地させる）。
   なぜ: コスト過大な活動と、価値の割にコストが低い（＝優位の）活動を分けるのが分析の核。
5. **競合と比較して優位/劣位を判定する。** 各活動を「競合より強い/同等/弱い」で相対評価する。
   なぜ: 競争優位は絶対値でなく相対で決まる。「誰と比べて」を欠くと強み判定が思い込みになる。
6. **リンケージ（活動間の連結）を点検する。** 「この活動のやり方が前後の活動のコスト/価値に何を及ぼすか」、
   上流（サプライヤー）・下流（チャネル・顧客）との連結も含めて確認する。
   なぜ: 最大の優位は個別活動でなく連結の組み合わせ（fit）に宿る。単体最適では見えない。
7. **打ち手に変換する。** 判定を踏まえ、(a) 優位の源泉＝**強化・投資を集中**、(b) 劣位で非中核＝**外注・廃止・簡素化**、
   (c) コスト過大＝**削減（ECRS等）**、(d) 差別化余地＝**価値を上げる投資**、に振り分ける。
   なぜ: 分析はゴールでなく起点。ここで止めると「描いて終わり」に陥る。
8. **VRIOで強みの持続性を検算する（任意だが推奨）。** 「優位」と判定した活動が、価値・希少・模倣困難・組織で
   本当に持続的優位か問い直す。なぜ: 一時的な優位を過信しないため。真の中核に集中投資する判断材料になる。

## 壁打ち質問リスト

各活動を事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この分析で **最終的に決めたいこと** は何ですか？（コストを下げる／差別化する／内製外注を決める／投資先を選ぶ）
2. 対象は何ですか？（会社全体／特定事業／製品ライン）そして **誰と比較** しての優位・劣位を見たいですか？（主要競合／業界標準）
3. あなたの事業の **主活動（価値を生み顧客に届ける一連の流れ）** を、実際の言葉で並べるとどうなりますか？
   （製造業の型に無理に合わせず、自社の工程で）
4. 各活動の中で、**コストが最も大きい/かかりすぎていると感じる** のはどこですか？その根拠（数字・実感）は？
5. 顧客が「この会社を選ぶ理由」は、どの活動が生んでいると思いますか？それは **競合が容易に真似できない** ものですか？
6. 支援活動（技術開発・調達・人事・全般管理）のうち、**優位の源泉になっている / 足を引っ張っている** ものはどれですか？
7. 活動と活動の **つなぎ目（例: 調達と製造、販売とサービス）** で、無駄や強みが生まれている箇所はありますか？
   上流のサプライヤーや下流のチャネルとの連結はどうですか？
8. すでにある **コスト/収益のデータ** は何で、まだ **確認できていない前提**（推測で埋めている箇所）は何ですか？

## 出力フォーマット

ALWAYS この2段構えで出力する（分解→戦略化）。各活動は必ず「コスト」「価値」「競合比較」の3列で評価し、
評価の無い羅列にしない。データが無い箇所は「（推測）」と明記する。


## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。地域の中小食品メーカーが、大手に利益率で負ける理由を
突き止め、どこで戦うかを決める場面。

- **手順①目的**: 「利益率の劣位を分解し、コストで戦うか差別化で戦うか決める」。対象=同社の主力製品ライン、比較対象=大手。
- **手順②③活動の洗い出し**: 主活動＝原料調達物流／製造（自社レシピ）／出荷／営業・販売／顧客対応。
  支援活動＝品質管理（全般管理）／熟練職人の技術（技術開発）／原料の目利き調達／採用育成（人事）。
- **手順④コストと価値**: 製造は職人依存でコスト「高」だが顧客価値「高」。出荷物流はコスト「中」・価値「低」。
  調達は原料の目利きが価値「高」。
- **手順⑤競合比較**: 製造の品質は大手より「強」。出荷物流の効率は大手のスケールに「弱」。調達の目利きは「強」。
- **手順⑥リンケージ**: 「目利き調達（強）→製造品質（強）→顧客対応での産地説明」が連結して差別化を生んでいる。
  一方「出荷物流の非効率」が全体コストを押し上げ、利益率の劣位に直結。
- **手順⑦打ち手**:
  - 優位の源泉（集中）: 調達の目利き×製造品質×産地の物語という連結を、差別化の軸として前面に出す。
  - コスト削減/外注: スケールで勝てない出荷物流は自前拡大せず、外部物流に委託して固定費を下げる。
  - 差別化の余地: 顧客対応（サービス）に産地・製法の情報発信を足し、価値をさらに上げる。
- **手順⑧VRIO検算**: 「職人の技術」は希少で模倣困難か？→ 属人化なら組織(O)が弱点。標準化・継承の投資で持続性を担保。
- **次の一手**: 「差別化で戦う」方針を採り、出荷物流の外注可否と、製造ノウハウの標準化を検証する。
- **未確認の前提**: 各活動の実コスト按分と、物流外注時のコスト差——ここは実データで裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `vrio`: VC分析で挙げた「優位の源泉」が、本当に持続的競争優位か（価値/希少/模倣困難/組織）を検証する直接の続き（手順⑧）。
- `five-forces`: 内部フォーカスの弱点を補い、業界構造（買い手/売り手の交渉力・新規参入・代替品）から外部の力学を読む。
- `pest`: マクロ環境（政治/経済/社会/技術）の変化を押さえ、価値の所在が今後どう動くかの前提を与える。
- `swot`: VC分析で特定した活動レベルの強み/弱みを、SWOTの内部要因(S/W)として精緻に流し込む。
- `ecrs`: コスト過大・低価値と判定した活動を、排除/結合/交換/簡素化で具体的に削る実行フレーム。
- `value-stream-mapping`: 主活動（特に製造・物流）の工程内のムダを、時間軸で詳細に可視化して掘り下げる。
- 揺さぶり枠として `reverse-assumption`（「価値の源泉は本当にそこか」を反転して疑う）や
  `devils-advocate`（優位判定の思い込みに反対役をぶつける）を添えると、内部志向の盲点を突ける。
