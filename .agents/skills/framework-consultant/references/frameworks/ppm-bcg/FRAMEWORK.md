# PPM（BCGマトリクス）

## 概要

PPM（プロダクト・ポートフォリオ・マネジメント）は、複数の事業単位（SBU）や製品を
**市場成長率（縦軸）** と **相対的市場シェア（横軸）** の2軸で4象限に分類し、
**限られた経営資源（主にキャッシュ）を、どこに投資し・維持し・撤退するか＝「選択と集中」** を判断するフレームワーク。

| | 相対シェア 高 | 相対シェア 低 |
|---|---|---|
| **市場成長 高** | 花形(Stars) | 問題児(Question Marks) |
| **市場成長 低** | 金のなる木(Cash Cows) | 負け犬(Dogs) |

- **核となる考え方**: 事業をキャッシュの**生み手**と**使い手**に分け、**ポートフォリオ全体が自己資金で回る（self-funding）**
  ように資源を再配分する。金のなる木が生む余剰で、次の花形候補（問題児）を育てる循環を設計する。
- **理論的裏付け**: **経験曲線**（累積生産量が多い＝高シェアほど単位コストが下がり高マージン・高キャッシュ）と
  **製品ライフサイクル**（成長期は投資が要り、成熟期に回収）。この2つがPPMの前提を支える。
- **2軸の意味**: 縦軸の**市場成長率＝キャッシュの「使用」量**の代理指標（成長は投資を要求する）。
  横軸の**相対シェア＝キャッシュの「創出」力**の代理指標（経験曲線でコスト優位＝高マージン）。
- **軸の目盛（要確認扱いの慣例）**:
  - 相対的市場シェア ＝ **自社シェア ÷ 最大競合のシェア**。高/低の境界は慣例で **1.0**（＝首位と互角）。しばしば対数目盛。
  - 市場成長率の高/低の境界は慣例で **約10%** または当該経済の **GDP成長率**。10%は後年の目安で恣意的との批判がある。
- **出自（諸説あり・要確認）**: BCG が1960年代後半〜1970年に開発。創業者 **Bruce D. Henderson** が
  1970年のエッセイ **"The Product Portfolio"**（BCGの *Perspectives*）で提示・普及させた。図の視覚化は
  同僚 **Alan Zakon** の最初のスケッチに由来する、という帰属が二次資料で語られる（一次資料での確証は弱い→出典・要確認参照）。

## いつ使う / 使わない

**使う（適する状況）**
- **複数事業・複数製品**を持つ多角化企業/事業部が、事業横断で**資源配分（選択と集中）**を決めたいとき。
- 限られた予算・人員を**どこに集中し、どこから引くか**の優先順位を、一枚で俯瞰したいとき。
- ポートフォリオ全体の**キャッシュ均衡**（稼ぎ頭が投資先を賄えているか＝自己資金性）を点検したいとき。
- 事業の整理・撤退・売却（ダイベストメント）の**議論の土台**を作りたいとき。

**使わない / よくある誤用（アンチパターン）**
- **単一事業・単一製品に適用する**——比較する複数の事業単位が無ければ4象限は成立しない。まず対象を複数に。
- **市場の定義を都合よく選ぶ**——「市場」の切り方で分類が正反対になる（全コーヒーでは負け犬、プレミアム単一産地では首位）。
  定義を恣意的に動かすと結論を操作でき、最も危険な誤用。定義基準を明示し一貫させる。
- **「負け犬＝即撤退」の短絡**——負け犬でもキャッシュを生む／他事業の補完財／競合の足止め／戦略的価値がある場合がある。
  ラベルだけで機械的に切らない。
- **金のなる木を「搾乳」しすぎる**——投資を絞りすぎるとブランド首位が崩れる（消費財では首位が新規より強いという反証）。
- **シェア＝収益性と決めつける**——経験曲線が効かない業種（サービス、関係性B2B、ニッチ高付加価値）では前提が崩れる。
- **境界線付近を機械分類する**——成長9.9%と10.1%、相対シェア0.9と1.1で象限が跳ねる。境界近傍は感度を注記する。
- **一度作って放置する**——静的スナップショットのため、移行・環境変化を捉えない。定期更新前提で使う。
- 収益性の精緻な最適化や、シナジーが価値の源泉の事業群の評価には単独では不向き。他フレームで補完する。

## 前提と限界

- **前提**: (1) 分析対象が**複数の事業単位**に分けられること。(2) 各単位について**自社シェア・最大競合シェア・市場成長率**の
  データ（または妥当な推計）が取れること。(3) 各単位の**「市場」を一貫した基準で定義**できること。
  データが無ければ壁打ちで補うか、3C/5フォースで市場・競合情報を先に固める。
- **限界（批判を踏まえて）**:
  - **2軸への過度な単純化**——市場魅力度＝成長率、競争力＝シェア、と割り切るのは乱暴。利益率・シナジー・技術変化・
    参入障壁など他要因を無視する。この不足を埋めるため多基準版の **GE/McKinsey 9ボックス**が派生した。
  - **市場定義への依存**——分類が「市場」の切り方に全面的に依存し、恣意性が入り込む。
  - **シェア＝コスト優位の非普遍性**——経験曲線が効かない業種では横軸の意味が崩れる。
  - **静的**——一時点の写真で、問題児→花形→金のなる木という**移行の動き**を捉えない。
  - **実証的疑問**——ポートフォリオ計画モデル採用企業のリターンが低かったとの研究報告もある（Slater & Zwierlein 1992、
    標本・結論の射程は要確認）。「作って満足」を戒める根拠。
- これらは、**成長のさせ方をアンゾフで具体化する／2軸の外の魅力度・競争力を3C・5フォース・VRIOで補う／
  撤退判断をプレモータムや悪魔の代弁者で揺さぶる**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップに「なぜ」を添える。

1. **分析対象（事業単位）を定義する。** 何を1つの単位とみなすか（SBU／製品ライン／ブランド）を決め、リスト化する。
   なぜ: 単位の粒度がぶれると比較が成立しない。複数単位があって初めてポートフォリオになる。
2. **各単位の「市場」を一貫基準で定義する。** どの範囲を市場と呼ぶか（製品カテゴリ／地域／セグメント）を明文化する。
   なぜ: 市場の切り方で分類が反転するため、ここが最重要。基準を統一し、恣意的な操作を排す。
3. **データを集める。** 各単位について「自社シェア」「最大競合のシェア」「その市場の成長率」を取得（無ければ推計＋前提を明示）。
   なぜ: 3つの数字が2軸の座標を決める。推測と実測を分けて扱う。
4. **相対的市場シェアを計算する。** 相対シェア＝自社シェア÷最大競合シェア。高/低の境界を置く（慣例1.0、または首位基準）。
   なぜ: 絶対シェアでなく「首位に対する相対位置」がコスト優位（経験曲線）の代理になるため。
5. **市場成長率で高/低を分ける。** 一貫した閾値を設定する（GDP成長率、または産業に応じた線。歴史的には約10%）。閾値の根拠を明記する。
   なぜ: 閾値は恣意的になりがち。基準を言語化し、境界近傍の感度を意識する。
6. **バブルで作図し4象限に分類する。** 各単位を売上規模＝円の大きさでプロットし、花形/金のなる木/問題児/負け犬に振る。
   なぜ: 規模を可視化すると、どの象限に事業の重心があるかが直感的に分かる。
7. **ポートフォリオ全体のキャッシュ均衡を読む。** 金のなる木の余剰が花形・問題児の投資を賄えているか（自己資金性）を確認する。
   なぜ: PPMの本質は個別評価でなく**全体の資金循環**。稼ぎ頭が枯れれば成長投資も止まる。
8. **単位ごとに戦略を割り当てる。** build（育成）/ hold（維持）/ harvest（収穫）/ divest（撤退）を選ぶ。
   - **花形**: hold/build。投資して首位を守り、成熟時に金のなる木化させる。
   - **金のなる木**: hold/harvest。維持しつつ余剰を他へ回す。搾乳しすぎない。
   - **問題児**: 見込みある**少数に集中投資(build)**し花形化を狙う／残りはdivest。全部には賭けない。
   - **負け犬**: harvest/divest。ただし補完財・戦略価値・キャッシュ創出があれば例外として残す。
   なぜ: 資源は有限。全象限に等分するのでなく、成功シーケンス（問題児→花形→金のなる木）を意図的に設計する。
9. **定性面で検算し、次の一手に落とす。** シナジー、市場定義の妥当性、負け犬の戦略価値を問い直し、投資/撤退の意思決定と
   検証すべき仮説を1〜3個決める。なぜ: 2軸は世界を単純化している。機械的分類のまま撤退を確定させない。

## 壁打ち質問リスト

各象限を事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. このPPMで**最終的に決めたいこと**は何ですか？（投資先の選定／撤退・売却の判断／予算配分／全体バランスの点検）
2. 分析する**事業単位（製品・事業・ブランド）は複数**ありますか？それぞれをどの粒度で1単位とみなしますか？
3. 各単位の**「市場」をどの範囲で定義**しますか？（広く取るか狭く取るかで分類が変わります——基準を1つに揃えられますか）
4. 各単位について、**自社シェア・最大競合のシェア・その市場の成長率**の数字（または推計の根拠）はありますか？
5. 高/低を分ける**閾値**（相対シェアの境界、成長率の境界）は何を根拠に置きますか？境界近くの事業はありますか？
6. 各単位の**売上規模**はどれくらいですか？（バブルの大きさ＝ポートフォリオの重心を測るため）
7. 事業間に**シナジー**（技術・販路・ブランド・顧客の共有）はありますか？単独では負け犬でも他を支えていませんか？
8. 「シェアが高い＝コストが低く儲かる」という**経験曲線の前提は、この業界で成り立ち**そうですか？
9. どの**時間軸**で見ますか？（今の写真か、3年後の移行を見込むか。問題児にいつまで賭け続けますか）

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**複数の製品ライン**を持つ中堅メーカーが、
限られた投資予算の配分を検討する場面。

- **手順①②単位と市場定義**: 主力の成熟品ライン、成長中の新カテゴリ品、老朽化した旧製品、投入直後の実験的製品——を単位化。
  各「市場」を製品カテゴリ×国内、と一貫定義する。
- **手順③④⑤データと軸**: 各ラインの自社シェア・最大競合シェア・市場成長率を収集。相対シェアの境界を1.0、成長率の境界を
  GDP成長率相当に置く（根拠を明記）。数字が無い実験的製品は「推計・要検証」と札を付ける。
- **手順⑥分類**:
  - 金のなる木: 成熟品ライン（成長は鈍いが国内首位、安定した利益源）。
  - 花形: 成長カテゴリ品（市場が伸び、自社も上位）。
  - 問題児: 実験的製品（市場は伸びるがシェアはこれから）。
  - 負け犬: 旧製品（市場縮小・シェアも低い）。
- **手順⑦キャッシュ均衡**: 成熟品（金のなる木）の利益が、花形の防衛投資と問題児の育成投資を賄えているかを点検する。
- **手順⑧資源配分**:
  - hold: 成熟品を維持し、搾乳しすぎずブランドを守る。
  - build: 花形に投資して首位を固め、実験的製品（問題児）のうち**見込みある一つに絞って集中投資**。
  - harvest/divest: 旧製品（負け犬）は投資を絞り、補完価値が無ければ撤退候補に。
- **手順⑨定性検算**: 旧製品が主力の付属品として販路を支えていないか、市場定義を狭めれば負け犬が別の顔になるかを確認。
  機械分類のまま撤退を確定しない。
- **次の一手**: 「問題児のうちどれに賭けるか」を、小さく検証（限定投入→シェア反応の観測）してから本投資に進める。
- **未確認の前提**: 各市場成長率の出所、競合シェアの精度、経験曲線が自社原価に効いているか——実データで裏取りが要る。

## 相性（組み合わせると効く）

- `ansoff`: PPMが示す「どこに投資するか（花形・問題児）」に対し、アンゾフは「**どう成長させるか**」（既存/新規×製品/市場）を与える直接の続き。
- `3c`: 市場・競合・自社の3視点で、PPMの入力（自社/競合シェア・市場魅力度）を精緻化し、2軸の粗さを補う前工程。
- `five-forces`: 「市場成長率」だけでは測れない**市場の真の魅力度・収益性**を業界構造から評価し、象限の解釈を補正する。
- `vrio`: 高シェア＝本当に持続的な優位か（価値/希少/模倣困難/組織）を検証し、「花形/金のなる木」の思い込みを弾く。
- `swot`: 各事業単位の内部・外部を棚卸しし、撤退/育成の判断材料をPPMに供給する。
- `decision-matrix` / `payoff-matrix`: 2軸で足りないとき、複数評価軸（GE/McKinsey的な多基準）で投資先を採点し直す。
- 揺さぶり枠として `premortem`（撤退/搾乳判断が失敗する要因を先回り）、`devils-advocate`（「負け犬＝撤退」への機械反応を疑う）、
  `jtbd`（負け犬に未充足ジョブという別の価値が眠っていないか——PPMの撤退示唆と衝突させて再解釈）を添えると洞察が増す。
