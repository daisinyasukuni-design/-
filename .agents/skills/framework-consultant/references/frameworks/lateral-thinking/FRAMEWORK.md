# 水平思考（ラテラルシンキング）

## 概要

水平思考（Lateral Thinking）は、段階的な論理（**垂直思考 / vertical thinking**）だけでは辿り着けない
発想を、**前提・常識を意図的に外して「横に飛ぶ」**ことで生み出す思考法。分析的・批判的思考を
**置き換えるものではなく補完する**、訓練可能なスキルとして位置づけられる。

- **核となる考え方**: 脳は一度うまくいったやり方を「パターン（掘られた穴）」として固定し、自動化する。
  水平思考はその**知覚（perception）**の部分に働きかけ、パターン自体を組み替える。
  デボノの比喩――**「同じ穴を深く掘っても、別の場所には掘れない」**（You cannot dig a hole in a
  different place by digging the same hole deeper）。垂直思考＝既存の穴を深掘り、水平思考＝新しい穴を掘り始める。
- **垂直思考との違い**: 垂直は直線的・段階的で「正しさ」を積み上げる。水平は多方向で、命題の
  **「動かす価値（movement value）」**――正しいかより「そこから次の発想へ動けるか」――を重視する。
  批判的思考が真偽の判定・誤り探しに関心を向けるのに対し、水平思考は判断を保留して**動き**を作る。
- **4種類のツール（デボノの整理）**: ①発想生成（現在のパターンを壊す）②焦点（探す場所を広げる/再定義する）
  ③収穫（出た発想から価値を取りこぼさない）④処理（現実の制約下で実行可能にする）。本スキルの手順はこの4層に対応する。
- **出自（要確認扱い・断定回避）**: **エドワード・デボノ（Edward de Bono）**が**1967年**頃に用語を提唱。
  原典は *The Use of Lateral Thinking*（1967）、体系化は *Lateral Thinking: A Textbook of Creativity*（1970）とされる。
  デボノはマルタ出身の医師・心理学者と紹介されるが、肩書・国籍・刊行年は資料により揺れる（→出典・要確認）。

## いつ使う / 使わない

**使う（適する状況）**
- **ロジカルに詰め切ったのに手詰まり**――既存の論理の延長線上に答えが見えないとき。
- **既存路線の改善では限界**――同じ土俵での最適化ではジャンプが起きないとき（コモディティ化からの脱却など）。
- **ありきたりな案しか出ない**――ブレストが凡庸化し、支配的な前提に全員が縛られているとき。
- **そもそもの前提・課題設定を疑いたい**――「本当にこの問題を解くべきか」を問い直し、リフレーミングしたいとき。
- 新規事業・商品企画・広告表現など、**斬新な打ち手や意外性**が価値になる局面。

**使わない / よくある誤用（アンチパターン）**
- **唯一解を精緻に詰める場面には不向き**――因果の厳密検証・数値最適化・合意形成が主目的なら、ロジカル/分析系を使う。
- **焦点を捨てて自由連想に流れる**――最頻の失敗。自由発想ゆえ焦点が定まらず、**当初の課題とかけ離れた結論**に至り、
  課題解決に繋がらない。必ず①で焦点を固定し、最後に元の焦点へ引き戻す。
- **発散中に評価を挟む**――「それは無理」と判断した瞬間に発想が死ぬ。**判断保留（movement優先）が前提**。
  評価は収穫・処理の段階まで意図的に遅らせる。
- **評価を一切しないまま終える**――逆に、出た芽を magic のように扱い、実行可能性を検証しない。
  水平思考は**効く保証のある手続きではなく、パターンを外す誘発装置**。出力は必ずロジカル/クリティカルで選別する。
- **単独で完結させる**――「ロジカルで整理 → ラテラルで飛ぶ → クリティカルで精査」の往復で初めて精度が出る。単発の思いつきで止めない。

## 前提と限界

- **前提**: 焦点（何について発想するか）が1つに定まること。焦点なきラテラルは連想遊びに堕ちる（手順①が要）。
  参加者が**判断保留のルール**を受け入れること（否定・評価を発散段階で持ち込まない合意）。
- **限界（批判を踏まえて）**:
  - **有効性の科学的証拠が弱い**――「classic pseudoscience（典型的な疑似科学）, derivative and untested」との批判がある（Aeon）。
    認知心理学者 Robert Weisberg は有効性の証拠が不十分とし、創造は論理的思考・試行錯誤・フィードバック・省察で説明できると主張する。
    デボノの思考教育プログラム CoRT の汎化効果も研究上まちまち。→ **「必ず良案が出る手法」ではない**前提で、量と揺さぶりを稼ぐ道具として使う。
  - **出力の質が保証されない**――挑発やランダム入力からは使えない案も大量に出る。**収穫・処理・評価をセットにしない限り価値化されない**。
  - **西洋的思考＝敵対的論争、という前提の単純化**への批判もある。手法の背景思想を絶対視しない。
- これらの限界は、**発散後に必ずロジカル系（logic-tree/mece）とクリティカル系（pmi/devils-advocate）で選別する / 焦点に引き戻す**
  ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。①→②で土台を作り、③〜⑥で意図的に揺さぶり、⑦⑧で価値化する。

1. **焦点を1つに固定する（Focus）。** 「何について新しい発想が欲しいのか」を一文で書く。必要なら焦点自体を再定義する
   （例:「待ち時間を短くする」→「待ち時間を苦にさせない」）。
   なぜ: 焦点が無いと自由連想に流れ、課題と無関係な結論に至る最頻の失敗に直結する。
2. **支配的な前提を棚卸しする。** この問題で「当然そういうもの」と皆が握っている前提・制約・常識を列挙する。
   なぜ: デボノの第一原則は「支配的（分極的）アイデアを**認識する**」こと。見えていない前提は外せない。まず可視化する。
3. **前提を問い直す（Challenge）。** 各前提に「なぜこうなっている？」「本当に固定か？」を**非対立的に**問う。
   欠陥を責めるのではなく「別のやり方もあり得るのでは」と開く。
   なぜ: 現状のやり方は多くの場合「唯一解」ではなく「たまたま定着した一つ」に過ぎない。ここを緩める。
4. **概念を抽出して別案を生む（Alternatives / Concept Extraction）。** 今の案から**上位の狙い（概念）**を抜き出し、
   その概念を満たす**別の具体案**を作る（例: 「行列を捌く」の概念＝「顧客の体感待ち時間を下げる」→整理券以外の手段へ）。
   なぜ: 具体案に固執すると視野が狭まる。一段上げて概念に戻ると、同じ狙いの別ルートが見える。
5. **意図的に揺さぶる（Provocation / Po ＋ Random Entry）。** 判断保留のまま、次のいずれかで既存パターンを壊す。
   - **挑発（Po）**: わざと非現実・不可能な命題を置く（例:「工場は自分より川下にある」「店に店員がいない」）。正しさは問わない。
   - **ランダム入力**: 課題と**無関係な語・物**（辞書の名詞など）を1つ選び、強制的に焦点へ結びつける（デボノ例: コピー機×「鼻」→紙切れ時に香りで知らせる）。
   なぜ: 論理の外から刺激を入れないと、脳は既存パターンへ戻る。ランダム性・不合理さが新しい入口を作る。
6. **芽から前へ動かす（Movement）。** 挑発やランダム連想を「無理だ」で捨てず、そこから**動く**。
   手口: 原理を抜き出す／今との差異に注目する／良い点だけ取り出す／それが成り立つ特別な状況を想像する。
   なぜ: 挑発は答えではなく踏み台。判断（judgment）ではなく movement で扱うのが水平思考の作法。
7. **収穫する（Harvest）。** 出た芽を取りこぼさず書き留め、焦点との関連で有望なものを数個選ぶ。まだ完成度は問わない。
   なぜ: 良い芽は「まだ粗い」状態で現れる。評価を急ぐと消える。まず捕まえてから磨く。
8. **現実化して次の一手に橋渡しする（Treatment）。** 選んだ芽を、制約・資源を踏まえ実行可能な仮説へ整える。
   ここで**初めてロジカル/クリティカルの評価**（実現性・効果・リスク）に渡し、検証すべき仮説を1〜3個決める。
   なぜ: 水平思考はゴールでなく起点。評価と接続しないと「面白い思いつき」で終わる。

## 壁打ち質問リスト

各段階の材料を引き出す問い。空欄は勝手に埋めず、まずこれで確定させる。

1. この発想で**最終的に動かしたいこと（焦点）**は一文で言うと何ですか？ その焦点自体、別の言い方に**再定義**できませんか？
2. この問題について、あなたや周囲が**「当然そういうもの」と握っている前提・制約**は何ですか？（最低3つ挙げてください）
3. その前提のうち、**「なぜそうなっているのか説明できない／たまたま定着しただけ」**のものはどれですか？ それが崩れたら何が起きますか？
4. 今の案が本当に狙っている**上位の目的（概念）**は何ですか？ 同じ目的を、**まったく別の手段**で満たすとしたら？
5. あえて**非現実・不可能な前提（例: 予算無限／逆に予算ゼロ／担当者ゼロ／時間逆流）**を置くと、どんな打ち手が見えますか？
6. 目の前の**無関係な物や言葉を1つ**選ぶとしたら何ですか？ それをこの課題に無理やり結びつけると、何が連想されますか？
7. 出てきた「一見ムリな案」の中で、**良い点・面白い点だけを取り出す**としたら、どこですか？（否定から入らずに）
8. 最終的に、出た芽を**どんな基準（実現性・効果・コスト・リスク）で選別**しますか？ 検証すべき仮説は何になりそうですか？

## 出力フォーマット

ALWAYS この4段構えで出力する（土台→揺さぶり→収穫→現実化）。発散段階（②〜⑥）では評価を書かず、選別は【収穫】以降でのみ行う。

```
【焦点】<何について発想するか・一文／再定義した場合は再定義後の焦点>

【前提の棚卸しと問い直し】
  支配的な前提: - <当然視されている前提> …
  問い直し:     - <その前提へのChallenge「なぜ？本当に固定か？」> …

【揺さぶり（判断保留・評価しない）】
  概念抽出:   <今の案の上位の狙い> → <その狙いを満たす別ルート>
  挑発(Po):   <非現実な命題> → <そこからのmovement（原理/差異/良い点/特別な状況）>
  ランダム入力: <無関係な語・物> → <強制連結で出た連想>

【収穫】<焦点に関連して有望な芽を2〜4個。まだ粗くてよい>
  - <芽1> / <芽2> / …

【現実化と次の一手】
  - <芽を実行可能な仮説に整えたもの>（評価軸: 実現性/効果/リスク）
  - <検証すべき仮説・意思決定・アクションを1〜3個 → ロジカル/クリティカルへ橋渡し>
【未確認の前提】<事実確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**人気飲食店で行列・待ち時間への不満を減らしたい**場面。

- **①焦点（再定義）**: 「待ち時間を短くする」では既存改善（席増・回転向上）の延長で頭打ち。
  焦点を**「待ち時間を"苦にさせない"／むしろ価値に変える」**へ再定義する。
- **②支配的な前提の棚卸し**: 「待つのは苦痛」「待ち時間は無価値な空白」「客は席に着いて初めて体験が始まる」「行列は捌く対象」。
- **③問い直し（Challenge）**: 「なぜ待ち時間は無価値と決めつける？」「なぜ体験は"着席後"からしか始まらない？」――いずれも
  「たまたまそう扱ってきた」だけで固定ではない。
- **④概念抽出**: 今の狙いの上位概念＝「顧客の**体感**待ち時間を下げる／不満の総量を下げる」。
  実測の短縮に固執せず、**体感**に効く別ルートを探す。
- **⑤揺さぶり**:
  - 挑発(Po): 「**店に店員がいない**」→ movement: 待つ間の案内・注文を客が自分で進められる仕組みへ（先に注文が済めば体感待ちが減る）。
  - ランダム入力: 無関係な語「**図書館**」→ 連想: 静かに時間を潰せる場・予約制・順番待ちの見える化。「待ち＝図書館的な過ごし方の提供」という発想。
- **⑥movement**: 挑発「店員ゼロ」の**良い点だけ取り出す**＝「待ち中に顧客が能動的に動ける」。差異に注目＝「受動的に待つ」との対比。
- **⑦収穫**: 芽=「待ち時間の事前注文で体感短縮」「順番の見える化＋その場を離れて待てる」「待ち時間そのものを楽しめる体験化」。
- **⑧現実化と次の一手**: 有望な芽を「順番の見える化＋離席可の呼び出し」に絞り、**小さく試して"体感満足度"を検証する仮説**に落とす。
  ここで実現性・コスト・オペ負荷をロジカル/クリティカルで評価し、採否を判断する。
- **未確認の前提**: 顧客が本当に苦にしているのは「総待ち時間」か「拘束される不自由」か――ここは実データ・顧客の声で裏取りが要る（推測のまま進めない）。

> 補足（実在の documented 例）: デボノの挑発「工場は自分より川下にある」→ 自社取水口の上流に排水させる規制の着想、
> コピー機×「鼻」→ 紙切れを香りで知らせる、は原典・Wikipediaで紹介される代表例（→出典）。

## 相性（組み合わせると効く）

- `reverse-assumption`: 前提を体系的に反転させる専用手法。手順②③（前提の棚卸し・問い直し）を強力に駆動する直接の相棒。
- `six-hats`: 6つの視点を切替える枠。特に**緑帽子（創造）**で発散し、**黒帽子（慎重）**で収穫物を選別――発散と評価の役割分担を明示化できる。
- `random-word`: ランダム入力（手順⑤）を独立技法として深掘りし、刺激語の量を稼ぐ。
- `scamper` / `osborn-checklist`: 強制発想のチェックリストで、揺さぶりの「切り口」を体系的に増やす発散系の補完。
- `analogical-thinking`: 遠い分野の構造を借りて「横に飛ぶ」。概念抽出（手順④）と接続し、別ルート探索を加速する。
- `logic-tree` / `mece`: 発散後の**収穫・現実化（手順⑦⑧）**を論理的に整理し、実行可能性の評価に橋渡しする（水平単独の弱点を補う）。
- 揺さぶり・検証枠として `pmi`（出た芽をPlus/Minus/Interestingで多面評価）、`devils-advocate`（案の過信を疑う）、
  `premortem`（現実化した案の失敗要因を先回り）を添えると、疑似科学批判（証拠の弱さ）を運用でカバーできる。
