# NM法

## 概要

NM法は、解きたい課題の本質を **キーワード** に凝縮し、そこから **遠い分野・自然界の類比（アナロジー）** を探し、
その **背景・仕組み** を分解して **自分の課題へ転用** することで新しいアイデアを生む、日本発の **類比発想法**。

核となる考え方は「**創造的な人が無意識にたどる思考プロセスを、誰でも辿れる明示的なステップに落とす**」こと。
ひらめきを才能任せにせず、下の4問（KW→QA→QB→QC）を順に回すことで、凡人でも飛躍したアイデアに到達させる。

| ステップ | 略号 | 問い | やること |
|---|---|---|---|
| キーワード | **KW** | どんな本質・働き？ | 課題の本質を動詞・形容詞・機能で抽象化 |
| 類比 | **QA** (Question Analogy) | 例えば何のように？ | 遠い分野・自然界から似たものを探す |
| 背景 | **QB** (Question Background) | それはなぜ・どう成立する？ | 類比の特徴・構造・メカニズムを分解 |
| 転用 | **QC** (Question Conception) | それは今の課題に役立たないか？ | 背景の特徴を課題に当てはめ具体案化 |

- **出自（諸説あり・要確認）**: 考案者は **中山正和**（創造工学研究所所長）。頭文字 N.M. から命名。
  「**1970年頃**に考案」とする資料が多いが、年は資料により幅があるため断定しない。
  理論的な下敷きは **W.J.J. ゴードンのシネクティクス（Synectics）**——アナロジーで異分野を結ぶ発想法——で、
  NM法は「シネクティクスを**手順として明確化・体系化**し、初心者でも回せるようにした発展形」と位置づけられる。
  一部資料は「コトバ（言語）とイメージ（映像）の往復」を重視する記憶モデルを理論基礎に挙げる（→出典・要確認）。
- **バリエーション（型）**: 用途別に複数の型がある。**NM-H型**（技術・発明向け。最も使われる／本スキルの標準）、
  **NM-T型**（雑多な情報からヒントを得る、ソフトな問題向け）、**NM-S型**（時系列でアイデアを実用化）、
  **NM-A型**（アイデアをグルーピングして新案化）、**NM-D型**（仮説→データ）。まずは H型 の KW→QA→QB→QC を身につける。

## いつ使う / 使わない

**使う（適する状況）**
- 新商品・新規事業・企画のアイデアが **出尽くした／行き詰まった** とき、既存の延長でない **飛躍** がほしいとき。
- ブレストや通常発想が **マンネリ化** し、同じ枠内の似た案しか出てこないとき。
- **他業界・自然界・異分野の成功例** からヒントを借りて、自分の課題に移植したいとき。
- **発明・技術課題の突破口**（H型）や、コンテンツ・ストーリー・デザインの発想を広げたいとき。
- 類比発想に不慣れなメンバーでも、**型に沿って** 一定品質のアイデアを量産したいとき。

**使わない / よくある誤用（アンチパターン）**
- **近すぎる類比しか出さない**——最頻の失敗。テーマと同分野の似た例を挙げても、ありきたりな案にしかならない。
  QAでは意識的に **遠い分野・自然界** から採る。「関係なさそう」なほど飛躍が生まれる。
- **QB（背景分析）を飛ばす**——QAの類比からいきなりアイデアに飛ぶと、根拠のない **こじつけ** に終わる。
  「なぜ・どうやってそれが成立するか」を分解して初めて、転用できる素材が手に入る。
- **キーワードが具体的すぎる／名詞のまま**——「傘」で止めると類比が同分野に留まる。
  「濡れないよう覆う」「携帯する」など **動詞・機能で抽象化** して初めて遠い類比に手が届く。
- **出た案をそのまま採用する**——NM法は **発散** の技法。評価・優先順位づけ・実装は範囲外。必ず収束・検証を別に行う。
- **1人・少数の連想力任せで詰まる**——良い類比とKWに品質が依存する（属人性）。数を出す・場を回す設計が要る。
- 論理的な現状分析・意思決定・因果特定・定量最適化そのものには不向き。分析系・意思決定系フレームで補完する。

## 前提と限界

- **前提**: 解きたい課題（テーマ）が **1つに絞れている** こと。課題の本質を **抽象化（機能・働きのキーワード化）** できること。
  類比→背景→転用の往復を、途中で投げずに **粘れる** こと（1周で出なければ別の類比で繰り返す前提）。
- **限界（批判・注意点を踏まえて）**:
  - **発散専用**——アイデアの評価・選別・実装は扱わない。出力は「候補の束」であり、そのままでは意思決定に使えない。
  - **属人性**——類比・キーワードの筋の良さに成果が左右される。良い類比が出ない日もある。**数・多視点・場の設計** で補う。
  - **誤った類推（false analogy）のリスク**——表面が似ているだけで構造が違う類比を使うと、転用が破綻する。
    QBで **構造・メカニズムの対応** を確認し、成り立たない対応は捨てる。
  - **定量・因果には無力**——なぜ売れないか等の原因分析や、精緻な最適化には向かない。
- これらは、**発散後に KJ法 で束ね、ペイオフマトリクス／PMI で絞り（収束）**、
  **reverse-assumption や premortem で有望案を揺さぶって検証** することで補える（→相性）。

## 進め方（手順）

NM-H型（KW→QA→QB→QC→収束）を基本に、命令形で示す。各ステップの「なぜ」を添える。

1. **テーマ（課題）を1つに固定する。** 「何のアイデアを生みたいか」（例: この製品を刷新／この工程の飛躍案）を明文化する。
   なぜ: テーマが複数だと類比が発散し、どれにも効かない案になる。
2. **キーワード(KW)を決める。** テーマの本質を **動詞・形容詞・機能** で1〜3語に抽象化する（例: 傘→「濡れないよう覆う」）。
   なぜ: 具体名詞のままだと類比が同分野に留まる。機能に還元して初めて遠い分野へ橋が架かる。
3. **類比を発想する(QA)。** 「KWといえば？」と問い、**遠い分野・自然界** から似たものを複数挙げる（例: 覆う→カタツムリの殻、蓮の葉、テント）。
   なぜ: テーマから離れた類比ほど、既存の延長を破る飛躍が生まれる。まず量を出す。
4. **筋の良い類比を選ぶ。** テーマから **遠く**、かつ自分が **仕組みを説明できる** ものを1つ取る。
   なぜ: 遠さ（飛躍）と、説明可能性（転用の素材が取れる）の両立が転用の成否を決める。
5. **背景・仕組みを探る(QB)。** その類比が「**なぜ・どうやって**」成立するか、特徴・構造・メカニズム・原理を書き出す。
   なぜ: ここが転用の材料庫。QBを飛ばすと表面的なこじつけになる。構造レベルまで下ろす。
6. **課題に結びつける(QC)。** QBで挙げた特徴を一つずつ「**今の課題にどう役立つか**」と問い、具体アイデアに変換する。
   なぜ: 背景の分解は手段で、課題への転用が目的。特徴×課題の掛け算で具体案が出る。
7. **別の類比で繰り返す。** 手順3〜6（QA→QB→QC）を複数回まわし、アイデアを量産する。
   なぜ: 1つの類比では偏る。複数の類比を重ねると、組み合わせで強い案が生まれる。
8. **まとめる（収束）。** 出たアイデアを組み合わせ・絞り込み、1〜3の解決案に整える。評価軸での選別は別フレームに委ねる。
   なぜ: NM法はここで発散を終える。収束・評価を混ぜると発散が萎む。分けて回すのが定石。

## 壁打ち質問リスト

各ステップを埋めるために、利用者へ投げ返す問い。空欄を勝手に埋めず、まずこれで引き出す。

1. このNM法で **最終的に生み出したいアイデア** は何ですか？（新商品／新規事業／技術課題の突破／企画・ストーリーなど、テーマを1つに）
2. その課題の **本質を、動詞・形容詞・機能で言い換える** と何ですか？（例: 傘＝「濡れないよう覆う」「携帯する」。具体的な製品名でなく“働き”で）
3. そのキーワードから連想する、**まったく別の分野・自然界のもの** は何ですか？（3つ以上。関係なさそうなほど良い）
4. その類比は「**なぜ・どうやって**」成り立っていますか？特徴・構造・仕組みを分解すると、どんな要素がありますか？
5. その仕組みの特徴を **今の課題に当てはめる** と、どんな打ち手・アイデアになりますか？（特徴ごとに変換してみる）
6. 今出ているアイデアは既存の **延長ですか、それとも飛躍** がありますか？似た案ばかりなら、どの前提を外せば遠い類比に届きますか？
7. 出たアイデアの中で、**効果と実現性** で見て、次に検証・試作すべきものはどれですか？（ここは収束の視点）

## 出力フォーマット

ALWAYS この型で出力する（発散のサイクルを見せ、最後に収束する）。

```
【テーマ】<解きたい課題を1つ>
【KW（キーワード）】<本質を動詞・形容詞・機能で／1〜3語>

【類比サイクル】（複数回まわす）
  ① QA（類比）    : <遠い分野・自然界のもの>
     QB（背景・仕組み）: <なぜ/どう成立するか。特徴・構造・原理を分解>
     QC（転用アイデア）: <その特徴を課題に当てはめた具体案>
  ② QA : <別の類比> ／ QB : <…> ／ QC : <…>
  ③ QA : <別の類比> ／ QB : <…> ／ QC : <…>

【まとめ（収束）】<有望なアイデアを組み合わせ・絞り込み、1〜3案に>
【次の一手】<検証すべき仮説・試作・意思決定を1〜3個>
【未確認の前提】<裏取りが要る点（技術的実在性・需要など。推測のまま進めない）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**携帯できる雨具の新しい商品アイデア** を出す場面。

- **手順①テーマ**: 「持ち運びを意識させない、新しい携帯雨具の案を出す」。
- **手順②KW**: 傘という具体物でなく機能に還元 → **「濡れないよう覆う／身にまとって携帯する」**。
- **手順③〜⑥ 類比サイクル**:
  - ① QA=**カタツムリの殻** → QB: 体と一体化していて“持ち運ぶ”意識が要らない／軽量／らせん構造で強度を稼ぐ
    → QC: 傘を別に持たず、**衣服やバッグと一体化した“着る雨具”**（携帯という行為自体をなくす）。
  - ② QA=**蓮の葉** → QB: 表面の微細な凹凸で水を弾き、汚れも一緒に流れ落ちる（撥水の仕組み）
    → QC: **超撥水の生地で、畳まず軽く振れば水が落ちて乾く**雨具（濡れて重くならない）。
  - ③ QA=**折り紙** → QB: 平らな面が折りで極小に畳め、開くと大きな立体になる
    → QC: **極小に畳め、一動作で瞬時に展開/収納できる**構造（かさばらない）。
- **手順⑦繰り返し**: 3つの類比から、遠い分野の異なる原理（一体化／撥水／可折性）を引き出せた。
- **手順⑧まとめ（収束）**: 「一体化して携帯を意識させない」×「濡れても重くならない撥水」を組み合わせ、
  **“畳めて濡れない、持ち歩きを忘れる雨具”** という1つのコンセプトに統合。
- **次の一手**: 超撥水素材のコスト・耐久・量産可否を技術調査で裏取りし、小さく試作して有効性を確かめる。
- **未確認の前提**: 撥水表面の量産での再現性、こうした雨具への実需——ここは実データで確認が要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `synectics`: NM法の源流。より自由・即興的なアナロジー発想（直接類比・擬人類比など）を試したいとき、上流として併用。
- `analogical-thinking`: 類比を「表面の類似」でなく「構造の対応」で扱う思考の土台。QB（背景の分解）を深める際に効く。
- `equivalent-transformation`: 本質を抽出し別領域へ移す等価変換理論。NM法の QB→QC と発想が近く、抽象度の上げ下げを補強する相互補完。
- `kj-method`: NM法で量産したアイデアを親和性でグルーピングし収束させる（NM-A型の発想とも符合）。発散→収束の受け皿。
- `scamper`: 類比が枯れたときに、7つの操作で別方向の発散を足し、網羅性を補う代替の発散技法。
- `payoff-matrix`: 出たアイデアを効果×実現性で絞り込む収束（意思決定レンズ）。NM法の“束”を1〜2案に落とす。
- 揺さぶり枠として `reverse-assumption`（前提を反転させて遠い類比の幅を広げる）や `premortem`（有望案の失敗要因を先回りして磨く）を添えると、発散に検証の芯が通る。
