# SWOT分析

## 概要

SWOT分析は、検討対象を **強み(Strengths) / 弱み(Weaknesses) / 機会(Opportunities) / 脅威(Threats)** の
4象限に棚卸しし、戦略の出発点となる「戦略的位置」を把握するフレームワーク。軸は2つ——
**内部 / 外部** と **好ましい / 好ましくない**——の掛け合わせで決まる。

| | 好ましい | 好ましくない |
|---|---|---|
| **内部**（自社で動かせる） | 強み(S) | 弱み(W) |
| **外部**（自社で動かせない） | 機会(O) | 脅威(T) |

- **核となる考え方**: 環境トレンド（機会・脅威）と内部能力（強み・弱み）の最適な適合（strategic fit）を見つける。
  強みで機会を掴み、弱みを補正・回避して脅威をかわす、という戦略の骨格を作る。
- **出自（諸説あり・議論がある）**: SWOTの考案者は単一に確定していない。主に1965年の2系統が語られる。
  (a) スタンフォード研究所(SRI)の長期計画研究チーム（Robert Stewart ら）が前身の **SOFT分析**
  （Satisfactory/Opportunity/Fault/Threat、当時は「現在/将来」で区分）を用いた説。SRIの
  **Albert Humphrey** がしばしば「SWOTの父」と紹介されるが、この帰属は後年の通説で異論がある。
  （※SOFTチームの正確な構成メンバー名は資料により食い違い、確証が持てないため個別列挙は避ける。）
  (b) ハーバードの Learned・Christensen・Andrews・Guth 『Business Policy』(1965) が強み/弱み/機会/脅威の
  評価を説いた **LCAGフレームワーク** 説（ただし2×2マトリクスや詳細手順は無い）。
  頭字語「SWOT」は1972年頃に文献へ登場。**起源は断定せず、両説と不確実性を前提に扱う**（→出典・要確認項目参照）。

## いつ使う / 使わない

**使う（適する状況）**
- 戦略・事業計画・マーケ計画の**初手**として、現状を一枚に俯瞰したいとき。
- 自社/事業/製品/チーム/個人の**棚卸し**（何が武器で、何が穴で、追い風/向かい風は何か）。
- PEST・3C・5フォースなどで集めた材料を**1つの器に統合**して戦略に橋渡ししたいとき。
- 新規事業や参入検討で、まず**全体像と論点**を洗い出したいとき。

**使わない / よくある誤用（アンチパターン）**
- **羅列で終わり戦略に繋げない**——最頻の失敗。Hill & Westbrook (1997) は「SWOTの出力が後続の戦略立案で
  一度も使われていなかった」と報告した。棚卸しは手段であり、必ずクロスSWOT/TOWSで打ち手へ変換する。
- **内部と外部の混同**——「優秀な人材（内部=強み）」と「市場の成長（外部=機会）」を取り違える。
  判定基準は「自社の意思で動かせるか（内部）／動かせないか（外部）」。ここを曖昧にすると4象限が崩れる。
- **優先順位をつけず全要素を等価に並べる**——重要な戦略論点と些末な事項が同じ重みで混ざり、示唆が薄まる。
- **主観・声の大きい人の支配**——1人や少人数で作ると偏る。事実・データで裏を取り、複数視点を入れる。
- **一度作って放置**——静的なため環境変化に追随しない。定点でなく定期的に見直す前提で使う。
- 精緻な定量最適化・因果分析や、優先順位が既に定まった実行フェーズには不向き。他フレームで補完する。

## 前提と限界

- **前提**: 対象・目的・スコープが1つに定まっていること。目的が曖昧なSWOTは羅列に堕ちる（後述の手順①が要）。
  外部環境（O/T）を語るには市場・競合の基礎情報が要る。無ければ壁打ちで補うか、PEST/3C/5フォースを先に回す。
- **限界（批判を踏まえて）**:
  - **記述的で分析が浅くなりがち**——Mintzberg らは単純・静的と批判。Porter は精緻さ不足を理由に5フォースを提唱した。
  - **Schoemaker の5つの罠（うち主要4つ）**——(1)内向き過ぎで外部が手薄、(2)現状維持を基準にO/Tを先入観で善悪判定、
    (3)箇条書きへの還元でシステム思考が欠ける、(4)「未来から逆算」の視点不足。使い方を誤ると現状維持を強化し得る。
  - **要素が状況で反転する**——同じ事実が機会にも脅威にもなる（例: 新技術は追い風にも脅威にもなる）。
    「これは強みか？誰と比べて？いつまで？」と相対・時間軸で問い直さないと固定観念を強化する。
- これらの限界は、**クロスSWOTで戦略化する / 外部深掘りにPEST・5フォースを併用する / 強みの真の優位性はVRIOで検証する**
  ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **目的とスコープを1つに固定する。** 「何のためのSWOTか」（例: この事業を伸ばすか撤退か／新製品の投入可否）を明文化する。
   なぜ: 目的が無いと要素が発散し、羅列で終わる最頻の失敗に直結する。
2. **外部（O/T）を先に洗い出す。** 市場・顧客・競合・技術・規制・経済などマクロ〜業界の変化を、機会と脅威に振り分ける。
   なぜ: 内部から始めると内向き（navel-gazing）に陥りやすい。外部の土俵を先に押さえると強み/弱みの意味が定まる。
   材料が薄ければ PEST（マクロ）／5フォース（業界構造）を先に回して持ち込む。
3. **内部（S/W）を洗い出す。** 資源・能力・ブランド・コスト・人材・オペレーションなどを、強みと弱みに振り分ける。
   なぜ: 強み/弱みは絶対値でなく**競合との相対**で決まる。「誰と比べて」を常に添える。
4. **内部/外部の切り分けを検算する。** 各要素に「自社の意思で変えられるか」を問う。Yes=内部、No=外部。
   なぜ: 混同（強み↔機会、弱み↔脅威）はSWOT最大の技術的ミス。ここで弾く。
5. **重要度で絞り込み優先順位をつける。** 各象限で「戦略に効くもの」を上位数個に絞る。
   なぜ: 等価な長大リストは示唆を生まない。影響度×確からしさで重みづけする。
6. **要素を掛け合わせて打ち手に変換する（クロスSWOT/TOWS）。** これがSWOTを戦略にする核。
   - **SO（強み×機会）= 積極戦略**: 強みで機会を最大限掴む。
   - **ST（強み×脅威）= 差別化戦略**: 強みで脅威をかわす／差別化に転換する。
   - **WO（弱み×機会）= 改善戦略**: 弱みを克服して機会を逃さない。
   - **WT（弱み×脅威）= 防衛/撤退戦略**: 最悪シナリオを回避する（守り・縮小・撤退）。
   なぜ: 4象限の棚卸しだけでは動けない。掛け合わせて初めて具体的な選択肢が出る。
7. **次の一手に落とす。** 導いた戦略から、検証すべき仮説・意思決定・アクションを1〜3個決める。
   なぜ: SWOTはゴールでなく起点。ここで止めると「作って終わり」の典型に陥る。

## 壁打ち質問リスト

各要素を事実で埋めるために、利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. このSWOTで**最終的に決めたいこと**は何ですか？（伸ばす/守る/撤退/参入など、目的を1つに）
2. 対象は何ですか？（会社全体／特定事業／製品／チーム／個人）そして**誰と比較**しての強み・弱みですか？
3. **強み**として、競合が容易に真似できない資源・能力・実績は何ですか？その根拠（数字・顧客の声）は？
4. その強みは**今後1〜3年、競合の追随や環境変化に対してどれだけ持続しそう**ですか？（今は強みでも陳腐化しないか＝時間軸・持続性の確認）
5. **弱み**として、機会を逃す原因や、顧客に選ばれない理由になっている内部要因は何ですか？
6. 外部環境で、この1〜3年で起きている/起きそうな**変化**は何ですか？（市場・技術・規制・競合・顧客行動）
7. その変化のうち、自社に**追い風（機会）**なものと**向かい風（脅威）**なものはどれですか？なぜそう判断しますか？
8. すでにある情報・データは何で、まだ**確認できていない前提**は何ですか？（推測と事実を分ける）

## 出力フォーマット

ALWAYS この2段構えで出力する（棚卸し→戦略化）。ただし cross-swot スキルが併用選定されている場合は【SWOT（棚卸し）】段のみ出力し、戦略化は cross-swot 側の出力フォーマットに委ねる（4戦略マトリクスの二重出力を避ける）。

```
【SWOT（棚卸し）】目的: <このSWOTで決めたいこと> ／ 対象・比較対象: <…>
  強み(S):   - <相対優位＋根拠> …（重要順に絞る）
  弱み(W):   - <…>
  機会(O):   - <外部の追い風＋確からしさ> …
  脅威(T):   - <外部の向かい風＋影響度> …

【クロスSWOT（戦略化）】
  積極(SO 強み×機会):   <強みで機会を掴む打ち手>
  差別化(ST 強み×脅威): <強みで脅威をかわす/差別化する打ち手>
  改善(WO 弱み×機会):   <弱みを克服し機会を取りにいく打ち手>
  防衛(WT 弱み×脅威):   <最悪回避・守り/撤退の打ち手>

【次の一手】<検証すべき仮説・意思決定・アクションを1〜3個>
【未確認の前提】<事実確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。地域の中小コーヒー焙煎店が事業拡大を検討する場面。

- **手順①目的**: 「拡大するなら、何を軸にどう伸ばすか」を決める。対象=同店、比較対象=大手チェーン/EC専業。
- **手順②外部(O/T)**:
  - 機会(O): 家庭用の高品質豆への関心増、EC/サブスクの普及、地元産・作り手の物語への評価。
  - 脅威(T): 大手チェーン/EC専業の低価格攻勢、生豆（原料）価格の変動、地域の人手不足。
- **手順③内部(S/W)**:
  - 強み(S): 自家焙煎の品質、常連客との関係、生活動線上の立地。
  - 弱み(W): 資金力の限界、オンライン販路の弱さ、スタッフ数の制約。
- **手順④検算**: 「品質」は自社で動かせる→内部(S)。「EC普及」は外部→機会(O)。混同なし。
- **手順⑤絞り込み**: 影響が大きい「品質(S)×EC普及(O)」と「価格攻勢(T)」を主要論点に据える。
- **手順⑥クロスSWOT**:
  - 積極(SO): 品質×EC普及 → 焙煎したての豆の定期便サブスクを立ち上げる。
  - 差別化(ST): 品質・物語性×低価格攻勢 → 安売り競争を避け、産地/焙煎の物語で高付加価値化。
  - 改善(WO): EC弱い×EC普及 → 自前構築せず外部ECモールを使い低コストで参入。
  - 防衛(WT): 資金/人手×価格競争 → 無理な安売り・多店舗化を避け、主力商品と常連基盤に集中。
- **手順⑦次の一手**: 「定期便サブスク（積極戦略）」を小さく試し、継続率という仮説を検証する。
- **未確認の前提**: 家庭需要の実際の規模、常連のEC移行意向——ここは実データで裏取りが要る（推測のまま進めない）。

## 相性（組み合わせると効く）

- `cross-swot`: SWOTの4要素を掛け合わせ、SO/ST/WO/WT の具体戦略に変換する直接の続き（手順⑥の深掘り）。
- `pest`: 機会・脅威（外部）を政治/経済/社会/技術のマクロ視点で網羅し、O/Tの抜け漏れを防ぐ前工程。
- `3c`: 市場・競合・自社の3視点でSWOTの入力（特に相対的な強み/弱み）を精緻化する。
- `five-forces`: 脅威（T）を業界構造（新規参入・代替品・売り手/買い手の交渉力・競合）として掘り下げる。
- `vrio`: 挙げた「強み」が本当に持続的な競争優位か（価値/希少/模倣困難/組織）を検証し、思い込みを弾く。
- 揺さぶり枠として `premortem`（防衛/WT戦略の失敗要因を先回り）や `devils-advocate`（強みの過信を疑う）を添えると洞察が増す。
