# 逆設定法（天邪鬼法）

## 概要

逆設定法は、あるテーマについて無意識に前提としている **「当たり前・常識・定説・成功体験」を洗い出し、
それを意図的に反転（逆設定）** させ、「その逆を成立させるにはどうするか」を問うことで、
既存の枠内では出てこない非連続なアイデアを生むアイデア発想法。別名 **天邪鬼法（あまのじゃく法）**。

- **核となる考え方**: 私たちは「レストランにはメニューがある」「鍋は大勢で食べる」のように、疑いもしない前提を
  大量に抱えている。これらが発想を無意識に縛る。前提を鏡写しにひっくり返し（mirror image view）、
  「メニューの無いレストラン」「一人用の鍋」を**あえて成立させる**方向に頭を向けると、常識の裏に隠れた機会が見える。
  イノベーションは既存の延長線上には無い——枠内の改善では差別化できないときに、枠そのものを外すための技法。
- **出自**: 考案者は米国の創造性コンサルタント **Stephen R. Grossman**（"Assumption Reversals"）。**Arthur B. VanGundy** が
  『Techniques of Structured Problem Solving』で構造化技法として収録し、**Michael Michalko** が『Thinkertoys』第5章 "False Faces"
  として改称・普及させた。日本語では「逆設定法」、通称「天邪鬼法」（わざと人と反対の言動をするへそ曲がり）。
  版年・ISBN・肩書の裏取り・名の綴りの揺れは出典・要ファクトチェック欄に集約（→出典）。

## いつ使う / 使わない

**使う（適する状況）**
- 発散が**出尽くして行き詰まった**とき、または案が**どれも既視感があり差別化できない**とき。枠を外す起爆剤になる。
- 業界・社内の**「常識」が強固**で、その常識自体が機会を隠している疑いがあるとき（成熟市場・レッドオーシャン）。
- これまでの改善・打ち手が**効かない根深い問題**を、前提から崩したいとき。
- **矛盾を含む課題**（「より少ない資源でより多くを」「安くて高品質」など）で、両立の突破口を探すとき。
- 商品・サービス・オペレーション・ビジネスモデル・企画のいずれでも、**新規性が要る発想フェーズ**全般。

**使わない / よくある誤用（アンチパターン）**
- **反転して満足し、机上の空論で終わる**——最頻の失敗。逆設定はゴールでなく起点。各逆転に必ず「どうすれば成立するか(How)」
  「なぜ価値があるか(Why)」を問い、価値×実現性で選別して現実解に変換しないと、奇抜なだけのメモで終わる。
- **「ありえない！」で即棄却する**——反転直後に判断を入れると発想が死ぬ。判断は保留し、凡庸案・珍案も過程として許容する。
- **表層の前提しか反転しない**——瑣末な前提ばかり裏返しても新規性は出ない。最も**当然視している核心的前提**を選んで挑む。
- **反転が常に有効と過信する**——元の前提は必ずしも誤りではなく、反転が有望解を生む保証もない。効く問題を選ぶ技法。
- 方向が既に定まった**実行・最適化フェーズ**、事実データの**分析・因果究明**が要る局面、精緻な定量最適化には不向き。
  そこは分析系・検証系の他フレームで補完する（→相性）。

## 前提と限界

- **前提**: テーマ（対象）が1つに定まっていること。曖昧なテーマだと前提列挙が発散し、逆転しても収束しない。
  また「判断保留→後で選別」の2段運用ができること（発散と収束を混ぜない）。
- **限界（批判を踏まえて）**:
  - **有望解を保証しない**——反転は前提を揺さぶる刺激であって、良い答えそのものではない。多くは捨て案になる前提で量を出す。
  - **問題を選ぶ**——矛盾を内包する課題や常識が強固な領域で効く一方、前提が正当で反転に意味が薄い問題では空回りする。
  - **逆張りへの組織的抵抗**——「常識に反する」ため周囲の反発を招きやすい。仮説段階（自由に反転）と検証段階（評価）を
    明確に分け、いきなり実行提案として出さない。
  - **逆ブレスト（reverse brainstorming）との混同**——逆ブレストは「どうすれば問題を**悪化**させられるか」と課題/目的を
    反転する別技法。逆設定法は問題の**前提（assumption）**を反転する。操作対象が違うので取り違えない。
- これらの限界は、**出た案を pmi / payoff-matrix で選別する / 発散量を scamper・brainstorming で足す /
  逆張り案の弱点を premortem・devils-advocate で先回り検証する**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。**発散（②〜④）と収束（⑤〜⑥）を混ぜない**のが要。

1. **テーマを1つに固定する。** 「何についてのアイデアが欲しいか」を具体的に言語化する（例: この商品の売り方／この
   サービスの提供形態／この店の集客）。なぜ: テーマが曖昧だと前提が発散し、逆転しても収束しない。
2. **前提（常識・定説・成功体験）を洗い出す。** 「このテーマでは当然○○だ」を思いつく限り列挙する。
   〈誰が・何を・いつ・どこで・どうやって・なぜ・誰のために・いくらで〉の切り口で網羅する。
   なぜ: 発想を縛っているのは、疑いもしない暗黙の前提。まず見える化しないと反転できない。
3. **核心的な前提を選ぶ。** 列挙のうち「最も当然視していて、疑うほど揺さぶりが大きい」前提を数個選ぶ。
   なぜ: 瑣末な前提を裏返しても新規性は出ない。核心を突くほど発想の飛距離が伸びる。
4. **機械的に反転する（逆設定）。** 選んだ前提を、実現性を一切考えず反対にする。
   反転の語彙例: ある↔ない／する↔しない／多い↔少ない／大↔小／足す↔引く／売る↔配る／集める↔手放す／
   固定↔可変／専門家↔素人／有料↔無料／来てもらう↔こちらが行く／一つ↔複数／速い↔遅い。
   なぜ: この段階で「ありえない」と判断を入れると発想が死ぬ。判断は保留し、逆の世界を一旦成立させて眺める。
5. **「どうすれば成立するか(How)」「なぜ価値があるか(Why)」を問う。** 各逆転について、それが成り立つ状況・
   仕組み・顧客・技術を具体的に考え、そこに潜む価値や機会を書き出す。
   なぜ: 逆設定はここで初めてアイデアになる。反転しただけでは机上の空論。裏に隠れた機会を掘り当てる工程。
6. **価値×実現性で選別し、現実解に落とす。** 出た芽を「新規性・価値」と「実現可能性」の2軸で評価し、有望なものを
   数個ピックアップして深掘りする。**その場で使える簡易スコア基準**: 各案を〈新規性・価値〉と〈実現性〉でそれぞれ
   **高／中／低の3段階**に付け、**両方が「中」以上＝採用候補**、**片方でも「低」＝保留**（捨てずに記録）、
   **両方「低」＝棄却**とする。同点で迷ったら〈新規性・価値=高〉を優先して残す（実現性は後から仕組みで補えるが、
   新規性は後から足せない）。なぜ: 大半は捨て案。閾値を先に決めておくと選別が主観に流れず、pmi・payoff-matrix 等の
   本格評価に渡す前段の足切りを素早くできる。
7. **次の一手に落とす。** 選んだ案から、検証すべき仮説・小さく試す実験・意思決定を1〜3個決める。
   なぜ: 逆設定法は起点。ここで止めると「面白い雑談」で終わる。

## 壁打ち質問リスト

各工程を事実と当事者の言葉で埋めるために、利用者へ投げ返す問い。空欄を勝手に埋めず、まずこれで引き出す。

1. このテーマで**最終的に欲しいのは何**ですか？（新商品の切り口／集客の打ち手／提供形態の刷新など、対象を1つに）
2. このテーマについて、あなたや業界が**「当然そういうものだ」と思い込んでいること**は何ですか？できるだけ多く挙げてください。
3. その前提のうち、**最も揺らがない・疑ったことすらない核心的な前提**はどれですか？なぜそれが当然だと思うのですか？
4. その核心的な前提を**真逆にしたら**どうなりますか？（「ある→ない」「有料→無料」「来てもらう→出向く」など、実現性は考えず反転してください）
5. その逆転した状態が**すでに成立している例・近い例**は、他の業界や過去にありませんか？どんな条件が揃えば成り立ちますか？
6. 逆転した状態には、どんな人が・どんな場面で**価値を感じそう**ですか？誰の、どんな不満や隠れた欲求に刺さりますか？
7. 出てきた芽のうち、**新規性が高く、かつ自社で小さく試せそう**なものはどれですか？何を検証すれば有望さが分かりますか？
8. 逆張り案に対して**周囲やお客様が抱きそうな抵抗・反論**は何ですか？それはどう和らげられそうですか？

## 出力フォーマット

ALWAYS この2段構えで出力する（前提の反転 → 現実解への変換）。テーマと選別基準を必ず明記する。

```
【逆設定（前提の反転）】テーマ: <何についての発想か>
  前提① <当然視している常識>        → 逆設定: <その真逆>
  前提② <…>                         → 逆設定: <…>
  前提③（核心）<最も揺るがない前提>  → 逆設定: <…>   ★核心を明示
  …（核心的な前提を優先し、瑣末な反転は絞る）

【アイデア化（How / Why）】
  逆設定①より: <どうすれば成立するか＋なぜ価値があるか（隠れた機会）>
  逆設定③より: <…>
  …（有望な逆設定について、成立条件と刺さる相手を具体化）

【選別（価値×実現性）】
  採用候補: <新規性・価値が高く実現可能な案を数個。2軸での位置づけを一言>
  保留/棄却: <面白いが今は非現実的な案（捨てずに記録）>

【次の一手】<小さく試す実験・検証すべき仮説・意思決定を1〜3個>
【未確認の前提】<反転が妥当か、価値があるか、事実で裏取りが要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。街の書店が来店客の減少に悩み、新しい売り方を発想する場面。

- **手順①テーマ**: 「この書店の"売り方・店のあり方"に新しい切り口を出す」。
- **手順②前提の洗い出し**: 「書店は多数の本を並べる／客が棚から選ぶ／本を売って稼ぐ／店内は静かに読む場所／
  営業時間中はいつでも入れる／店員は本を薦める人」。
- **手順③核心の選定**: 最も当然視しているのは「**書店は多数の本を並べる**」。ここを核心に据える。
- **手順④機械的な反転**: 「多数→一冊だけ」「客が選ぶ→店が選ぶ」「本を売る→場や体験を売る」。実現性は一旦問わない。
- **手順⑤How / Why**:
  - 「一冊だけ並べる」→ 成立条件: その一冊を深く掘る展示・著者イベント・関連物販を束ねる。価値: 選ぶ疲れからの解放、
    一冊に没入する体験、話題性。誰に: 情報過多に疲れた読者、贈り物を選びたい人。
  - 「場・体験を売る」→ 成立条件: 会員制の読書ラウンジやサブスク化。価値: 滞在時間と関係性で稼ぐ（本の粗利依存から脱却）。
- **手順⑥選別（価値×実現性）**: 「一冊特集＋著者イベント」は新規性・実現性とも高く採用候補。「全面サブスク化」は
  価値は高いが初期投資が重く保留。
- **手順⑦次の一手**: 月替わりで「一冊だけを深掘りする棚」を店の一角で小さく試し、来店動機と滞在時間の変化を見る。
- **未確認の前提**: 「選ぶ疲れ」の需要が実際どれだけあるか、イベント集客が採算に乗るか——ここは実データで裏取りが要る
  （面白さだけで実行に飛ばさない）。
  ※「一冊だけの書店」は実在の店舗が知られるが、本例は逆設定法の手順を示すための一般化であり特定企業の実話ではない。

## 相性（組み合わせると効く）

- `scamper`: 逆設定で外した枠に対し、7動詞（代用・結合・逆転など）で発想を量産・展開する発散の相方。
- `brainstorming`: 逆設定を刺激カードにして、判断保留のまま連想量を稼ぐ。発散量が足りないときに前後で回す。
- `lateral-thinking`: 同じ「前提を疑う」視点転換系。逆設定法は反転、水平思考は横滑り。併用で揺さぶりの幅が広がる。
- `jtbd`: 反転した案が「顧客の本当に片付けたい用事」に刺さるかを検証し、機会の裏取りをする（手順⑤⑥の精緻化）。
- `pmi`: 出た逆設定案を Plus/Minus/Interesting で多面評価し、収束（手順⑥）を助ける。
- `payoff-matrix`: 採用候補を効果×実現性で絞り込み、次の一手を1〜3個に決める（手順⑥⑦の意思決定）。
- 揺さぶり枠として `premortem`（逆張り案が失敗する要因を先回り）や `devils-advocate`（反転の過信・抵抗を洗う）を
  添えると、奇抜さと現実性のバランスが取れる。
