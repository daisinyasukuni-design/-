## 記入順の原則

- **右側（顧客側＝価値サイド）から始める。** 順序の推奨: CS → VP → CH → CR → RS、その後 左側（インフラ側＝効率サイド）KR → KA → KP → C$。最後に RS と C$ を突き合わせて採算を見る。
- 理由: 価値を先に設計するとオペレーションを「価値を届けるため」に設計できる。逆に手持ち資源から始めると、価値が「自社の都合」に寄る。
- ただし原典は「9要素を同時に俯瞰する」ことも重視する。上記は強い推奨であり絶対規則ではない。行き来（イテレーション）してよい。
- 中央の **VP は CS と対で考える**。「誰の・どの用事に効くか」が言えない価値提案は空論。深掘りは Value Proposition Canvas（VPC）へ。

## 1. 顧客セグメント（CS / Customer Segments）

**定義**: 価値を届ける相手。誰の課題を解くのか。**最も重要な顧客は誰か**を選ぶ（＝捨てる相手を決める）。
**型（どれに当たるか）**: マスマーケット / ニッチ / セグメント化（近いが別ニーズ）/ 分化（無関係な複数）/ マルチサイドプラットフォーム（例: 利用者と広告主の両面）。

設問:
- この事業で価値を届ける相手は誰ですか？ 複数いるなら、**最も重要な1〜2セグメント**はどれですか。
- そのセグメントは「別の価値提案・別のチャネル・別の採算」を必要とするほど**他と違います**か（違えば別セグメントとして分ける）。
- B2Bなら、意思決定者・利用者・購買者・承認者は**別人**ですか。誰の課題を軸に置きますか。
- マルチサイド（両面市場）ですか。片方が増えると他方の価値が上がる構造はありますか。

つまずき所:
- **広すぎ/狭すぎ**（新規起業家の典型ミス）。「20〜40代の女性全員」は広すぎ、示唆が出ない。行動・状況で切る。
- 「全員が顧客」は「誰も顧客でない」に等しい。**捨てる相手**を言えるまで絞る。

## 2. 価値提案（VP / Value Propositions）

**定義**: 顧客の課題を解決し、ニーズを満たす製品・サービスの束。**なぜ競合でなく自社を選ぶのか**の理由。
**価値の源泉（例）**: 新規性 / 性能 / カスタマイズ / 「仕事を片付ける」/ デザイン / ブランド・ステータス / 価格 / コスト削減 / リスク低減 / アクセス性 / 利便性・使いやすさ。

設問:
- そのセグメントが抱える**未解決の課題・不満・やりたい用事（ジョブ）**は具体的に何ですか。
- 自社は、それをどう解決しますか。**顧客が得られる利得**は何ですか（時間・お金・手間・不安のどれが減る/増える）。
- 既存の代替手段（競合・自作・我慢）と比べ、**なぜ自社を選ぶ**のですか。その差は顧客が体感できますか。
- その価値は「あれば嬉しい（nice-to-have）」ですか、「無いと困る（must-have）」ですか。

つまずき所:
- 機能の羅列で終わり、**顧客にとっての意味（便益）**に翻訳できていない。
- CSと結びつかないVP（誰のどの課題か不明）は空論。深掘りは VPC / JTBD へ。

## 3. チャネル（CH / Channels）

**定義**: 顧客に価値を届け、コミュニケーションする経路。**認知 → 評価 → 購入 → デリバリー → アフターサポート**の5フェーズで考える。
**型**: 自社直販（店舗・営業・自社EC）/ 間接（卸・小売・パートナー）。オンライン/オフライン。

設問:
- 顧客は、この価値を**どこで知り、どこで買い、どう受け取り**ますか。5フェーズのどこが弱いですか。
- 各フェーズで自社チャネルと他社チャネルのどちらを使いますか。**コスト効率**とセグメント到達のどちらを優先しますか。
- 顧客が最も**接触してほしいと望む**経路はどれですか（望む経路と実際の経路がズレていませんか）。

つまずき所: 「販売」だけ考えて、認知・アフターが抜ける。チャネルはVPを届けきる一連の流れで見る。

## 4. 顧客との関係（CR / Customer Relationships）

**定義**: 各セグメントとどんな関係を結び、維持するか。獲得・維持・拡大（アップセル）の狙いで設計。
**型**: 個別対応（人的）/ 専任担当 / セルフサービス / 自動化サービス / コミュニティ / 共創（co-creation）。

設問:
- 顧客を**獲得**する関係と、**維持・継続**させる関係は同じですか、違いますか。
- 関係は**人手（高コスト・高密着）**ですか、**自動化・セルフ（低コスト・低密着）**ですか。セグメントの期待と合っていますか。
- 解約・離反はどこで起きますか。関係のどの段階で顧客をつなぎ止めますか。

つまずき所: CH（届ける経路）とCR（結ぶ関係）の混同。CHは「どこで」、CRは「どう付き合うか」。

## 5. 収益の流れ（RS / Revenue Streams）

**定義**: 各セグメントから得る収益。**顧客は本当に、何に対して、いくら払うのか**。
**型**: 物販（資産販売）/ 利用料 / 定額課金（サブスク）/ レンタル・リース / ライセンス / 仲介手数料 / 広告。
**価格メカニズム**: 固定（定価・数量割引・機能別）/ 動的（交渉・オークション・需給・市場連動）。

設問:
- 顧客は**何に対して**お金を払いますか。今払っているのは何に対してですか（現状）。
- 課金は**一括**ですか、**継続（サブスク等）**ですか。単価×頻度×継続でLTVはどう積み上がりますか。
- 各セグメントの収益は全体の何割ですか。**どの収益が事業を支えて**いますか。
- 価格は誰が決めますか（自社の定価 / 市場・交渉）。値上げ余地・値崩れリスクはありますか。

つまずき所: VPが強いのに「無料/薄利」で価値を回収できていない。VP↔RSの非対称に注意。

## 6. 主要リソース（KR / Key Resources）

**定義**: このビジネスモデルを機能させるために不可欠な資産。VP・CH・CR・RSを支える。
**型**: 人的 / 物的（設備・拠点・在庫）/ 知的（ブランド・特許・データ・ノウハウ）/ 財務（資金・与信）。

設問:
- VPを実現し届けるために、**絶対に欠かせない資産**は何ですか（無いと事業が止まるもの）。
- そのうち**自社が握るべき**もの、**借りる/外注できる**ものはどれですか。
- 模倣されにくい・代替しにくいリソースはどれですか（＝競争優位の源泉。VRIOで検証可）。

つまずき所: 「あれば良い」資源まで並べる。VPとRSに直結する不可欠なものに絞る。

## 7. 主要活動（KA / Key Activities）

**定義**: ビジネスモデルを回すために最も重要な活動。VPを作り、届け、関係を維持し、収益を得る中核業務。
**型**: 生産（ものづくり）/ 問題解決（コンサル・受託・課題解決型）/ プラットフォーム・ネットワーク運営（マッチング・保守・プロモーション）。

設問:
- VPを生み・届けるために、**最も重要な活動トップ3**は何ですか。
- そのうち自社の**強み・差別化の源泉**になっている活動はどれですか。
- 外注・自動化できる活動と、**自社で磨き続けるべき**活動の線引きはどこですか。

つまずき所: 日常業務を全部書く。差別化と採算に効く中核活動に絞る。KR（資産）とKA（動作）を混同しない。

## 8. パートナー（KP / Key Partnerships）

**定義**: モデルを機能させる外部の供給者・提携先のネットワーク。
**動機**: 最適化と規模の経済 / リスクと不確実性の低減 / 特定リソース・活動の獲得。

設問:
- **自社で持たず外部に頼る**リソース・活動は何ですか。誰がそれを供給しますか。
- そのパートナーは代替可能ですか。**依存が過度**でリスクになっていませんか。
- 提携で得るのは「コスト削減」ですか「能力獲得」ですか「リスク分散」ですか。狙いは明確ですか。

つまずき所: 単なる取引先を全部並べる。モデルの成立に不可欠な提携に絞る。

## 9. コスト構造（C$ / Cost Structure）

**定義**: このモデルを動かすのにかかる主要コスト。KR・KA・KPから発生する。
**型**: コスト主導（低コストを最重視）/ 価値主導（高価値・プレミアム重視）。**構造**: 固定費 / 変動費 / 規模の経済 / 範囲の経済。

設問:
- 最も**大きなコスト**は何ですか。どのKR/KA/KPから発生していますか。
- 固定費と変動費の比率は。損益分岐に必要な数量・単価はどのくらいですか。
- このモデルは「安さで勝つ（コスト主導）」ですか、「高い価値で勝つ（価値主導）」ですか。コストのかけ方はそれと整合していますか。

つまずき所: RS（入り）と切り離してコストだけ見る。必ずRSと突き合わせて採算を判断する。

## 整合チェック（fit の検算）

9マスを埋めた後、**要素間の整合（fit）**を必ず検算する。BMCの価値は個々のマスでなく、**マス同士の因果と矛盾**にある。

- **CS ↔ VP**: そのVPは、選んだCSの課題に本当に刺さるか。刺さらないなら片方が間違い。
- **VP ↔ CH ↔ CR**: 価値の届け方・付き合い方は、VPとセグメントの期待に合っているか（高価値VPをセルフサービスだけで届けていないか）。
- **RS ↔ C$（採算）**: 収益がコストを上回るか。VPが強いのに薄利になっていないか。
- **左右のバランス**: インフラ（KR/KA/KP/C$）は、右側（価値サイド）を支えるために存在するか。手持ち資源に価値を寄せていないか。
- **静的スナップショットの限界を補う**: いま埋めた1枚は「現時点の一断面」。3年後どう変わるか、競合が同じ手を打ったらどうなるか（BMCは競争を描かない → 5フォース等で補う）を別途問う。
