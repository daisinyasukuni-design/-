# KJ法

## 概要

KJ法は、文化人類学者 **川喜田二郎（かわきた じろう, 1920–2009）** が、フィールドワークで集めた大量の
質的データをどう統合するかを試行錯誤する中で編み出した**発想法（創造性開発の技法）**。名称「KJ」は
考案者のイニシャルに由来する。主著は『**発想法 — 創造性開発のために**』（**中公新書136、1967年6月刊**）。

- **核となる考え方＝「分類ではなく統合(integration, not classification)」**。
  既存のカテゴリー・枠組みに当てはめる**トップダウンの分類**ではなく、カードの「近い感じ」から
  **ボトムアップで束ね**、断片の奥にある構造や新しい意味を立ち上げる。既存の型で仕分けた瞬間に、
  データが孕む新発見の芽は捨てられる——ここがKJ法の要。
- **推論の型はアブダクション（仮説形成）**。統計的な帰納でも演繹でもなく、雑多な事実から「こういう構造では
  ないか」という仮説を跳躍的に立ち上げる。グループ編成は論理より「**情念（感じ）で束ね、理性はその後**」。
- **狭義／広義**: 図解化までを狭義のKJ法、**叙述化（文章化）まで**含めて広義のKJ法と呼ぶ。図解で終わらせず
  文章にすることで、図の穴が見え、新たな発見が出る。さらに川喜田は、**思考と経験の二層を往復するW字**の流れ
  ——**探検→観察→発想（＝KJ法が担う仮説形成）→仮説→実験→検証**——を **W型問題解決モデル** として示し、
  KJ法をその「野外科学（探検・観察・発想）」段階の中核、とりわけ**発想（仮説形成）**を担う道具に位置づけた。
- **出自の注意**: 「KJ法」は**株式会社川喜田研究所が保有する登録商標（商標登録第4867036号）**である。
  **新QC七つ道具の「親和図法(Affinity Diagram)」はKJ法を源流とする別物**——親和図は作図技法であり、
  KJ法の野外科学の思想を伴わない。両者を同一視するのはよくある誤解（→前提と限界／出典）。

## いつ使う / 使わない

**使う（適する状況）**
- ブレストや会議で**アイデア・意見が大量に出て収拾がつかない**とき。付箋・議事録・ホワイトボードの断片を統合したい。
- **インタビュー・アンケート自由記述・観察メモ・ユーザーの声**など、質的データから示唆や仮説を引き出したいとき。
- 「何かが気になるが問題がまだ言語化できていない」**曖昧な状況**を、切り口ごと立ち上げたいとき。
- チームの**バラバラな認識をボトムアップで一枚に統合**し、共通理解と次の論点を作りたいとき。
- 既存フレーム（SWOT等の型）に**はまらない、データ由来の新しい構造**が欲しいとき。

**使わない / よくある誤用（アンチパターン）**
- **最初から大分類する**——最頻の誤用。テーマを見た瞬間に「価格・品質・接客…」と大枠を作ると、その時点で
  方向が固定され、新発見が死ぬ。**小さな束から始め、関係で中・大へ上げる**のが鉄則。
- **KJ法を「分類」「要素分解の分析」と混同する**——KJ法は分類でも分析でもなく**統合**。既存概念に収める作業に
  なった時点で別物になる。
- **親和図法と同一視する**——親和図は図を描く技法にすぎない。KJ法は思想（情念で束ね、仮説を立ち上げる）を伴う。
- **表札を安易な名詞ラベルにする**——「不満」「価格」等の要約語で括ると肌触りが失われる。表札は**元の声が伝わる
  一行**で本質を凝縮する（ここが成否を分ける）。
- **図解・叙述化を省く**——束ねて終わりでは新発見が出ない。空間配置と文章化まで通して初めて仮説が立つ。
- **多数決・声の大きい人で束を決める**——KJ法は判断保留と全員の直感が要。
- 選択肢が既に絞れ**優先順位づけだけ**したい／**定量最適化・厳密な因果分析**／カードが極端に少ない、
  には不向き。他フレームで補う。

## 前提と限界

- **前提**: (1) 束ねるに足る**カードの数と多様性**があること（薄いと統合が起きない。足りなければブレストや調査で
  補う）。(2) **1枚1情報**で、事実の肌触りを残して書けていること。(3) 参加者が**既存の型を保留**し、情念で束ねる
  姿勢を持てること。(4) 図解・叙述化まで通す**時間**が取れること。
- **限界（批判を踏まえて）**:
  - **主観的で再現性が低い**——同じカードでも束ね方は人・場で変わる。客観的な唯一解を出す手法ではない。
  - **時間コストが大きい**——数十枚規模でも数時間かかる。緊急の意思決定や少数データには過剰。
  - **大人数だと発散し収束しにくい**——ファシリテーションの技量に強く依存する。
  - **品質のばらつき**——「正しく学んでいない解説」が多く、ネット上のやり方には不正確なものが混じる
    （分類手法としての誤紹介が典型）。原典（『発想法』）に照らして運用する。
  - **定量・因果には向かない**——数値最適化や統計的検証は別手法（ロジックツリー/MECE、意思決定マトリクス等）で補う。
- これらは、**素材出しにブレストを前置し／図解の後にMECEやロジックツリーでトップダウン検証し／
  立ち上がった仮説をアブダクションやJTBDで磨く**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップに「なぜ」を添える。**分類ではなく統合**、を全工程で貫く。

1. **テーマ（問い）を1つ立てる。** 「このデータから何を掴みたいか」を切実な問いにする。ただし**答えを決め打ちしない**。
   なぜ: 問いが無いと発散し、答えを決め打ちすると型の追認に堕ちる。「良い問い×開いた態度」が両立の条件。
2. **ラベル（カード）をつくる。** 1データ＝1枚。**名詞の羅列でなく一文**で、発言・観察の肌触りを残して書く。
   なぜ: 1枚に複数情報を詰めると束ねられない。要約しすぎると後で新しい意味が立ち上がらない。
3. **全カードを広げて読む。** 束ね始める前に、いったん全部を眺めて頭を素材に浸す。
   なぜ: 先に全体に触れることで、既存の枠でなく「データが語る近さ」を感じ取れる。
4. **島をつくる（グループ編成）。** 「**近い感じ**」のもの2〜3枚を集める。**最初から大分類しない**。
   関連の薄い**一匹狼カードは無理に束ねず、そのまま置く**。
   なぜ: 大分類から入ると方向が固定される。孤立カードを無理に押し込むと、そこに潜む新規性を殺す。
5. **表札をつくる。** 各島の本質を**一行見出し**に凝縮する。元の声が伝わる表現にし、安易な要約語を避ける。
   なぜ: 表札づくりが統合の核。ここで肌触りを失うと、以降はただの分類表になる。
6. **束ね上げる。** 表札を新カードとみなし、小島→中島→大島へボトムアップで。一度に扱う束は**多くても6〜7程度**に。
   なぜ: 一気に多数を扱うと関係が見えない。少数単位の統合を積み上げるのがコツ（枚数は原典の目安、要確認）。
7. **空間配置し図解する（A型）。** 大きな紙に島を配置し、**重要な関係は近づけ、関係線・記号（因果/相互/対立/時系列）**で
   結び、全体の構造を可視化する。**大人数なら**、島づくりまでを3〜4人の小班に分業し、各班の中島を全体で持ち寄って
   統合・配置する二段構えにする。物理付箋なら模造紙上で島ごと動かして最適配置を探り、確定してから関係線を引く。
   オンラインボード（Miro/Mural等）なら島を枠で囲み、コネクタで因果・相互・対立を色分けして結ぶ。
   なぜ: 空間的な配置しだいで新しい意味が見える——これがKJ法創出のひらめきそのもの。分業と可動な配置が、
   大人数の発散を「小班の統合を積み上げる」形に変えて収束させる。
8. **叙述化する（B型）。** 図解を**口頭または文章で一気に語る/書く**。詰まった箇所＝図解の穴、書く中で出る発見を拾う。
   **大人数なら**、まず1人が図解を指でたどりながらストーリーとして口頭で語り（ナレーター役）、他メンバーが
   引っかかった箇所を指摘して穴を洗い出し、その後に清書役が一続きの文章へ落とす、と役割を分担する。
   なぜ: 図で終わると理解の穴に気づけない。文章化が図解を検算し、新たな仮説を析出させる。語り役と検算役を
   分けると、大人数でも一貫した筋と多視点の検証を両立できる。
9. **次の一手に落とす。** 立ち上がった構造・仮説から、**検証すべき仮説やアクションを1〜3個**取り出す。
   なぜ: KJ法はゴールでなく発想の起点。「作って終わり」を避け、W型の次段（実験・検証）へ橋渡しする。

## 壁打ち質問リスト

各段階の材料を引き出す問い。空欄を勝手に埋めず、まずこれで引き出す。

1. **このKJ法で最終的に掴みたいこと（問い）は何ですか？** そして今、答えの見当を決め打ちしていませんか？（決め打ちは型の追認になる）
2. 素材は**どこから来た何ですか？**（ブレスト/インタビュー/自由記述/観察メモ/議事録など）**何枚くらい**、どれだけ**多様**にありますか？
3. 各カードは**「1枚1情報」で、事実の肌触りを残した一文**になっていますか？（名詞ラベルや要約しすぎになっていないか）
4. 束ねるとき、**既存の枠組み（例: 部署別・SWOT等の型）を無意識に当てはめていませんか？** 「近い感じ」で束ねられていますか？
5. どうしても**どの島にも入らない“一匹狼”カード**はありますか？（無理に束ねず、その違和感が新発見の芽かもしれない）
6. 各島の**表札は、元の声が伝わる一行**になっていますか？ それとも「不満」「価格」のような要約語で肌触りを失っていませんか？
7. 図解して、島と島の間に**因果・対立・相互・時系列などの関係**は見えましたか？ 意外な隣接や食い違いはありましたか？
8. 立ち上がった構造から、**次に検証したい仮説・打ち手**は何ですか？ まだ**事実確認が要る前提**はどれですか？

## 出力フォーマット

ALWAYS この型で出力する（統合の階層→図解の構造→仮説の順で、分類表にしない）。

```
【テーマ（問い）】<掴みたいこと。決め打ちしていないか一言添える>
【素材】<出所（ブレスト/IV/自由記述/観察…）と枚数・多様性のメモ>

【グループ編成（島と表札／ボトムアップの階層）】
  ■大島A：<本質を凝縮した一行表札>
     └ 中島A-1：<一行表札>  ← [元カード例: <肌触りの残る声>, <…>]
     └ 中島A-2：<一行表札>  ← [元カード例: <…>]
  ■大島B：<一行表札>
     └ …
  ・一匹狼：<どの島にも入れなかったカードと、その違和感の意味>

【図解（構造）】<島どうしの関係を言語化：A→B（因果）／A↔C（相互）／B×D（対立/緊張）／時系列 など。
              意外な隣接・食い違いを明示>

【叙述（立ち上がった仮説）】<図解を一続きの文章で語り、そこから見えた構造・新しい仮説を1〜3個>
【次の一手】<検証すべき仮説・アクション（W型の次段へ）>
【未確認の前提】<事実確認が要る点（壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。あるサービス運営チームが、集めた**利用者の声**から
改善の切り口を発見したい場面。

- **手順①テーマ**: 「利用者の声の奥に、どんな未充足があるか」。決め打ちの結論は置かない。
- **手順②ラベル**: 問い合わせ・レビュー・インタビューの発言を、1件1枚・肌触りを残して一文で書き起こす
  （例:「説明を読んでも次に何を押せばいいか迷った」）。名詞ラベル（「UI」等）にはしない。
- **手順③④島づくり**: 全カードを眺め、「操作の途中で迷う」系の声、「サポートの返答が遅い」系の声、
  「機能はあるのに気づかれない」系の声…が2〜3枚ずつ自然に近づく。**最初に「機能／価格／サポート」と
  大分類しない**。強い違和感のある単発の声は一匹狼として残す。
- **手順⑤表札**: 各島に一行表札（例:「“やり方は載っているのに辿り着けない”体験」）。要約語で潰さない。
- **手順⑥束ね上げ**: 表札同士でさらに束ね、「発見のされにくさ」という大島が立ち上がる。
- **手順⑦図解(A型)**: 島を配置。「発見のされにくさ」→「途中離脱」（因果）、「サポート遅延」×「自力解決の失敗」
  （緊張関係）などを関係線で描く。**意外な隣接**として、機能不足だと思っていた声の多くが実は「導線の問題」に
  隣接していた、と見える。
- **手順⑧叙述(B型)**: 図解を文章化する中で、「不満の主因は機能の欠如ではなく“既にある価値への到達不能”では
  ないか」という**仮説**が立ち上がる（当初の決め打ちと違う切り口）。
- **手順⑨次の一手**: この仮説を、導線改善の小さな試作と離脱計測で検証する、と決める。
- **未確認の前提**: 声の分布が実際の利用者全体を代表しているか（偏りの確認が要る）——推測のまま進めない。

## 相性（組み合わせると効く）

- `brainstorming`: KJ法の**素材（カード）を発散して供給する前工程**。判断保留で量を出し、それをKJ法で統合する。
- `mind-map`: 中心テーマから連想で素材を出す／KJ法の図解の代替・補完。発散の見取り図として併用。
- `mece`・`logic-tree`: KJ法（ボトムアップの統合）の**後にトップダウンで検算**する分析レンズ。統合で立てた
  構造に漏れ・ダブりが無いかを確かめ、主観的になりがちな弱点を補う（レンズが対照的で効く）。
- `so-what-why-so`: 立ち上がった図解から「で、何が言えるか（So What?）／なぜそう言えるか（Why So?）」を
  往復し、仮説を鋭くする。
- `jtbd`: KJ法で統合した「顧客の声の構造」から、片付けたいジョブ（未充足）を抽出して事業仮説へ橋渡し。
- `abduction`: KJ法の核である**アブダクション（仮説形成）**を明示的に接続し、跳躍した仮説を検証可能な形に整える。
- 揺さぶり枠として `reverse-assumption`（束の常識的な括りを反転して別の構造を試す）、
  `devils-advocate`（表札や仮説の解釈を疑い、都合の良い統合を弾く）を添えると洞察が増す。
