# マッキンゼー7S

## 概要

マッキンゼー7Sは、組織を相互依存する **7つの要素** に分解し、要素間の **整合（alignment / fit）** を診断する
フレームワーク。中心に **Shared Values（共通の価値観）** を置き、他の6要素がこれと、そして互いに噛み合っているかを見る。

| 区分 | 要素 | 中身 |
|---|---|---|
| **ハードの3S**（可視・計測しやすい・速く変えられる） | Strategy 戦略 | 競争優位を築くための計画・方向性 |
| | Structure 組織構造 | 部門編成・指揮命令/報告関係（組織図） |
| | Systems システム/制度 | 業務を回す手続き・プロセス（評価・報酬・資源配分・意思決定の仕組み） |
| **ソフトの4S**（無形・文化的・変えにくい） | Shared Values 共通の価値観 | **中心**。理念・規範・行動指針＝組織文化の核 |
| | Style 経営スタイル/風土 | リーダーシップ・意思決定/行動のパターン・社風 |
| | Staff 人材 | 人的資源の量と種類、採用・育成・動機づけ・処遇 |
| | Skills スキル/組織能力 | 組織としてのコアコンピタンス・際立った能力 |

- **核となる考え方**: 原典タイトルの通り「**Structure Is Not Organization（組織＝構造ではない）**」。
  戦略と構造だけを動かしても変革は成功せず、**7要素が相互に補強し合って初めて機能する**。
  Tom Peters の要約「**Hard is soft. Soft is hard.**」——動かしにくい本丸はむしろソフト側（文化・人・スタイル）にある。
- **使いどころの本質**: 7つの箱を埋めること自体が目的ではない。**どの要素が互いに引っ張り合い（不整合）、
  それが「戦略は良いのに実行できない」等の症状を生んでいるか** を突き止める診断ツール。
- **出自（要確認扱い）**: McKinsey & Company 社内で 1977–1980 に開発。1977年に同社の Ron Daniel が
  「戦略は賢いのに実行されない」問題意識から Tom Peters に組織有効性の研究を委嘱したのが発端とされる。
  初出は **Waterman・Peters・Phillips (1980) "Structure Is Not Organization," Business Horizons**。
  Anthony Athos（頭韻＝全要素をSで揃える案を主張）と Richard Pascale が精緻化に関与。当初の
  「**Superordinate Goals（上位目標）**」が後に「**Shared Values**」へ改称された（→出典・要確認参照）。

## いつ使う / 使わない

**使う（適する状況）**
- **「戦略は正しいのに現場で回らない/実行されない」** の原因を、組織の側から診断したいとき。
- **組織変革・組織再編**をどこから手をつけるか、変革の論点と優先順位を洗い出したいとき。
- **新戦略の実行**に向け、戦略に合わせて構造・制度・人・文化を作り替える必要があるとき。
- **M&A/組織統合（PMI）** で、両社の制度・スタイル・価値観の噛み合わなさを可視化したいとき。
- **「制度は変えたのに行動・風土が変わらない」** ——ハードだけ動かしソフトが取り残された状態の診断。
- 組織の**現状を体系的に棚卸し**し、抜け漏れなく論点を並べたいとき（特にソフト面の見落とし防止）。

**使わない / よくある誤用（アンチパターン）**
- **各要素を1段落ずつ書いて満足する**——最頻の失敗。StrategyU は「各要素に段落を1つ書くと、
  立派な文書が1つできるが洞察はゼロ（a nice document and no insight）」と評する。価値は
  **要素間の"引っ張り合い"を1つでも特定すること**。棚卸しで止めず、必ず不整合→打ち手へ繋ぐ。
- **静的な使い方（作って放置）**——環境変化やリーダー交代で整合はすぐ崩れる。整合はダイナミックであり、
  定点でなく定期的に見直す前提で使う（『In Search of Excellence』の優良企業が後年失速した件がこの罠の例証）。
- **7要素を等価に並べる**——実際はレバレッジが異なる（例: Systems は比較的低コストで効きやすい）。
  「今この組織で、動かすと最も効くのはどの要素か」を問わないと総花的な診断に終わる。
- **ハード面の議論に終始する**——戦略・構造・制度は可視で扱いやすいため議論が偏る。7Sの真価は
  ソフト4S（価値観・スタイル・人・スキル）を土俵に上げること。ここを飛ばすと使う意味が薄い。
- **外部環境の分析に使う**——7Sは内部志向。顧客・競合・市場・技術・規制は扱わない。外部はSWOT/PEST/5フォースへ。
- **具体的な是正策が自動で出ると期待する**——7Sは "what is"（現状）を描くが "what should be"（あるべき）や
  是正手段は自動的には示さない。診断の後は別途、変革計画・目標設定のフレームで補う。

## 前提と限界

- **前提**: 診断の**対象組織とスコープ**（全社／事業部／部門／統合後の新組織）と、**目的**（例: この新戦略を
  実行できる組織にする）が1つに定まっていること。目的が無い7Sは箱の穴埋めに堕ちる（手順①が要）。
  ソフト4Sを事実で語るには、現場の観察・インタビュー・行動データが要る。憶測で埋めない（壁打ちで引き出す）。
- **限界（批判を踏まえて）**:
  - **要素間の"つながり方"は示さない**——7要素が関係することは言うが、どう連動するかのメカニズムは与えない。
    Bill Bain は「定量的裏付けの欠如・定義の緩さ・要素間関係の疑わしさ」を批判したと伝わる（二次引用・要確認）。
  - **測定が主観的**——特にソフト4S（価値観・スタイル）は標準的な測り方が無く、評価者間でブレる。
    複数人・事実・具体的行動で裏を取らないと、印象論の整合診断になる。
  - **内部志向で外部が抜ける**——市場・競合・破壊的技術・危機などの外部変化を明示的に扱わない。
  - **"あるべき"と是正策を示さない**——不整合を検出しても、どう直すかは別途設計が要る。
- これらの限界は、**外部はSWOT/PESTで補完する / 変革の目標はKGI/KPI/OKRで定量化する /
  個別不整合の真因はなぜなぜ分析で掘る / あるべき7Sはバックキャスティングで未来から定義する**ことで補える（→相性）。

## 進め方（手順）

命令形で示す。各ステップの「なぜ」を添える。

1. **対象・スコープ・目的を1つに固定する。** 「どの組織を、何のために診るのか」（例: 新事業戦略を実行できる
   組織へ変える）を明文化する。なぜ: 目的が無いと7つの箱を無目的に埋めるだけになり、不整合が見えない。
2. **Shared Values（共通の価値観）を最初に言語化する。** 「この組織が実際に大切にしている（建前でなく行動が
   示している）価値観・理念は何か」を中心に据える。なぜ: 中心がぶれると他6要素の整合基準が定まらない。
   **公式の理念（掲げている値）と、実際に報われている行動（効いている値）のズレ**まで見る。
3. **ハードの3S（戦略・構造・制度）を現状（as-is）で洗い出す。** 事実・文書・組織図・評価制度で裏を取る。
   なぜ: 可視で確認しやすく、診断の骨格になる。ここは憶測でなく資料で埋められる。
4. **ソフトの4S（価値観・スタイル・人・スキル）を現状で洗い出す。** 観察・インタビュー・行動データで、
   「実際にどう動いているか」を書く。なぜ: 議論はハードに偏りがち。**ソフトを土俵に上げるのが7Sの主目的**。
   建前でなく実態（誰が昇進するか＝Style、何が本当にできる組織か＝Skills）を書く。
5. **7要素の整合をペアで検算し、不整合を特定する。** 各要素が①中心のShared Valuesと、②互いに噛み合うかを問う。
   「戦略が求める行動を、制度（評価・報酬）は促しているか」「構造は戦略の実行を助けているか阻んでいるか」等。
   なぜ: **これが7Sの核**。単独の箱でなく"引っ張り合い"を見つける。最低1つは具体的な不整合ペアを名指しする。
6. **あるべき姿（to-be）と、動かすと最も効く要素を決める。** 目的を果たす整合状態を描き、レバレッジ
   （小さく変えて全体に効く要素）を選ぶ。なぜ: 7要素を等価に全部変えるのは非現実的。効き所に絞る。
7. **不整合を打ち手に変え、次の一手に落とす。** 特定した不整合ごとに是正アクションを決める。
   1要素を変えると他要素の再調整が要る点を織り込む。なぜ: 7Sは診断であり、変革計画（目標・実行・検証）へ
   橋渡しして初めて価値になる。ここで止めると「立派な文書、洞察ゼロ」の典型に陥る。

## 壁打ち質問リスト

各要素を事実で埋め、不整合を炙り出すために利用者へ投げ返す問い。空欄は勝手に埋めず、まずこれで引き出す。

1. この7S診断で**最終的に何を決めたい／変えたい**ですか？対象組織はどこ（全社／事業部／統合後の新組織）ですか？
2. **Shared Values（共通の価値観）**: 掲げている理念と、実際に**報われている・評価されている行動**は一致していますか？
   ズレているなら、現場は本当はどちらに従って動いていますか？
3. **Strategy（戦略）**: 今の戦略は何で、それを実行するには現場に**どんな行動・能力**が必要ですか？
4. **Structure/Systems（構造・制度）**: 評価・報酬・予算・意思決定の仕組みは、その戦略が求める行動を
   **促していますか、それとも妨げていますか**？（例: 協業を求めるのに個別成果だけで評価している等）
5. **Style（経営スタイル/風土）**: 経営層の実際の振る舞い（誰が昇進し、何が黙認され、何が叱られるか）は、
   掲げる価値観・戦略と整合していますか？
6. **Staff/Skills（人材・組織能力）**: 戦略の実行に必要な人材・組織能力は足りていますか？
   **足りない or 過剰な**のはどこですか？その根拠（実績・離職・スキルギャップ）は？
7. 7要素のうち、**互いに引っ張り合っている（噛み合っていない）ペア**はどれとどれだと感じますか？
8. すでに事実・データで確認できていることは何で、まだ**憶測のまま**なのはどの要素ですか？（実態と建前を分ける）

## 出力フォーマット

ALWAYS この2段構えで出力する（現状棚卸し→不整合と打ち手）。7つの箱の穴埋めで終わらせず、必ず不整合ペアを名指しする。

```
【7S 現状診断】対象: <組織・スコープ> ／ 目的: <この診断で決めたいこと>
  ◆Shared Values（中心）: <建前の理念／実際に効いている値／その差>
  ハード3S:
   Strategy 戦略:    - <現状。戦略が現場に求める行動>
   Structure 構造:   - <編成・報告関係。戦略実行を助ける/阻む点>
   Systems 制度:     - <評価・報酬・資源配分。どの行動を促すか>
  ソフト4S:
   Style スタイル:   - <経営陣の実際の振る舞い・社風>
   Staff 人材:       - <人的資源の過不足・動機づけ>
   Skills 組織能力:  - <組織としてできること/できないこと>

【不整合（引っ張り合い）】※最低1ペア名指し・重要順
  - <要素A> ↔ <要素B>: <どう噛み合っていないか> → 生じている症状（例: 実行されない）
  - …

【あるべき姿と効き所】<to-beの整合状態／小さく変えて全体に効くレバレッジ要素>
【次の一手】<不整合ごとの是正アクションを1〜3個。1要素変更に伴う他要素の再調整も明記>
【未確認の前提】<実態確認が要る要素（特にソフト4S。壁打ちで埋める）>
```

## 具体例（ワークスルー）

対象を一般化した例（架空の数値・企業名は用いない）。**顧客本位のサービス強化を新戦略に掲げた地域金融機関**が、
「戦略は掲げたのに現場が動かない」を診断する場面。

- **手順①目的**: 「顧客本位戦略を実行できる組織にする」。対象＝営業部門を含む全社。
- **手順②Shared Values**: 掲げる理念は「顧客第一」。だが実際に評価・称賛されるのは短期の販売ノルマ達成
  ——**建前（顧客第一）と実際に効いている値（当期の販売量）がズレている**。
- **手順③ハード3S**:
  - Strategy: 顧客の課題解決を軸にした長期的な関係構築。
  - Structure: 商品別の縦割り組織で、顧客単位で横串を通す部署が無い。
  - Systems: 評価・報酬が当期の商品販売量に強く連動。顧客満足や継続関係は指標化されていない。
- **手順④ソフト4S**:
  - Style: 経営会議の主議題は販売進捗。顧客本位の行動が称賛される場が乏しい。
  - Staff: 販売スキルは高いが、顧客の課題を掘る対話・提案の人材が薄い。
  - Skills: 商品を売る組織能力は高いが、顧客の課題起点で解を組む組織能力は未成熟。
- **手順⑤不整合の特定**:
  - **Strategy ↔ Systems**: 顧客本位を掲げるのに、制度は販売量だけを報いている → 現場は従来の売り方に回帰。
  - **Shared Values ↔ Style**: 「顧客第一」と言いつつ、経営の関心・称賛は販売実績に向く → 建前化。
  - **Strategy ↔ Skills/Staff**: 課題起点の提案力という組織能力・人材が不足 → 戦略を担う土台が無い。
- **手順⑥あるべき姿と効き所**: 効き所は **Systems（評価・報酬）**。ここが販売量偏重のままでは他をいくら
  訓示しても行動は変わらない。まず制度を顧客継続・満足を含む形に組み替えるのがレバレッジ。
- **手順⑦次の一手**: (1)評価指標に顧客継続/満足を組み込む（Systems）→ (2)それに合わせ経営会議の議題と称賛の
  対象を変える（Style）→ (3)課題起点の提案研修と横串の顧客担当を整備（Skills/Structure）。
  制度(Systems)を動かせば人材配置・スタイルの再調整が連鎖する点を計画に織り込む。
- **未確認の前提**: 「実際に効いている値」「提案人材の不足度」は現場観察・インタビューで裏取りが要る
  （建前と実態を分け、憶測のまま進めない）。

## 相性（組み合わせると効く）

- `swot`: 7Sが手薄な**外部環境（機会・脅威）**を補い、Strategy要素の妥当性を外側から検証する前/後工程。
- `kgi-kpi-okr`: 7Sで特定した不整合の是正を、**定量目標・指標**に落として変革計画を管理可能にする（手順⑦の続き）。
- `five-whys`: 特定した不整合ペア（例: 戦略↔制度）の**真因**を「なぜ」で掘り下げ、対症療法を避ける。
- `backcasting`: あるべき7S（to-be）を現状の延長でなく**未来から逆算**して定義し、変革の目標像を鮮明にする（手順⑥）。
- `herzberg`: ソフト4S（Staff/Style）の**動機づけ**を、衛生要因/動機づけ要因に分けて具体化する。
- 揺さぶり枠として `premortem`（この組織変革が1年後に失敗した前提で要因を先回り）や
  `devils-advocate`（「うちは整合している」という思い込みを反対役で崩す）を添えると診断の甘さを潰せる。
