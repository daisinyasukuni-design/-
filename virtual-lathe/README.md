# バーチャル旋盤 試作ファイル

設計書：[docs/virtual-lathe/design.md](../docs/virtual-lathe/design.md)

| ファイル | 内容 |
|---|---|
| `connection-test.html` | 接続テスト用のページ。ネットワークなしで動く1ファイルの HTML |
| `firmware/vl_handle/vl_handle.ino` | ESP32 ハンドルユニット用のテストプログラム（Arduino） |

---

## 1. タブレットでのテスト（ハンドルユニットがなくてもできる）

1. `connection-test.html` を USB メモリか共有フォルダに入れる。
2. タブレットの「ドキュメント」フォルダなどにコピーする。
3. ファイルを右クリック →「プログラムから開く」→ **Microsoft Edge** を選ぶ。
4. 「1 この端末のチェック」に ○ / △ / × が出る。
   - **USB の接続機能** が ○ なら、USB ケーブルでハンドルをつなげる。
   - **Bluetooth の接続機能** が ○ なら、Bluetooth でもつなげる。
   - × のときは、その下に書いてある対処を見る。
5. 有線イヤホンをつなぎ、「2 音のテスト」で音が聞こえるか確かめる。
6. 「5 結果の記録」で「結果をまとめる」→「コピーする」を押し、端末ごとの確認表に貼り付ける。

> ファイルとして開いたページ（file://）で Bluetooth が使えるかどうかは、端末と学校の設定によって違う可能性があります。1台ずつ確かめてください。

## 2. ハンドルユニット（ESP32）への書き込み

### 準備（教員用 PC で1回だけ）
1. Arduino IDE 2 を入れる。
2. 「ボードマネージャー」で **esp32（Espressif Systems）** を入れる。
3. 「ライブラリマネージャー」で次の2つを入れる。
   - **ESP32Encoder**（Kevin Harrington 作）
   - **Adafruit DRV2605 Library**
4. ESP32 開発ボードを USB でつなぐ。COM ポートが出てこないときは、ボードの USB 変換チップ（CP2102 か CH340）のドライバーが必要。

### 書き込み
1. `firmware/vl_handle/vl_handle.ino` を開く。
2. ファイルの先頭にある `#define DEVICE_NAME "VL-01"` を、本体のラベルの番号に合わせる。
3. ボードに「ESP32 Dev Module」を選び、書き込む。

> このプログラムは、作成した環境で書き込みツールが使えなかったため、**まだコンパイルを確かめていません**。エラーが出たら、そのメッセージを知らせてください。

## 3. ハンドルユニットをつないだテスト

1. タブレットで `connection-test.html` を開く。
2. **USB の場合**：ケーブルでつなぎ、「USB でつなぐ」を押して、出てきたポートを選ぶ。
   **Bluetooth の場合**：ユニットの電源を入れ、「Bluetooth でつなぐ」を押して、`VL-01` などを選ぶ。
   - 学校の端末で USB のポートが一覧に出ないときは、USB 変換チップのドライバーが入っていない可能性があります。その場合は Bluetooth を使うか、ICT 担当に相談してください。
3. 確かめること

| 確かめること | よい状態 |
|---|---|
| 往復台のハンドルを1回転 | 目盛りが 110 進み、22.000 mm 動く |
| 横送りのハンドルを1回転 | 目盛りが 200 進み、直径の変化が 10.000 mm |
| 刃物送り台のハンドルを1回転 | 目盛りが 150 進み、3.000 mm 動く |
| 回す向き | 実機と同じ向き（逆のときは「設定」で「回転方向を逆にする」に印を付ける） |
| 回転数つまみ | 0〜4000 min⁻¹ まで連続して変わる |
| 起動・停止ボタン | 押している間、ランプが点く |
| 非常停止 | 押すと画面全体が赤くなる。配線を外しても赤くなる（b接点） |
| 届く間隔 | 平均 20ms 前後、最大 50ms 以下 |
| 取りこぼし | ほとんど増えない |
| 振動のテスト | 選んだ場所だけが振動する。非常停止中は振動しない |
